## Règle De Mise À Jour

Pour chaque ligne : reproduire, confirmer la cause, corriger, tester, valider dans
le navigateur, puis seulement passer le statut à `Corrigé`. Un correctif sans
preuve navigateur ou sans régression automatisée reste `Partiellement corrigé`.
