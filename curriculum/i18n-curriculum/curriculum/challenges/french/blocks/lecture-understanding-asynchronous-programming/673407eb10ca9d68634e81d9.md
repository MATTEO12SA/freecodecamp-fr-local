# --description--

La Geolocation API fournit un moyen pour les sites web de demander la localisation de l'utilisateur. Il est important de noter que, pour des raisons de confidentialité, l'utilisateur doit donner son autorisation avant que sa localisation puisse être accessible via le site.

La principale méthode sur laquelle on se concentrera aujourd'hui est `getCurrentPosition`. Cette méthode sert à collecter la localisation géographique de l'appareil. Voici un exemple d'utilisation de `getCurrentPosition` :

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

Dans ce code, on appelle `getCurrentPosition` et on lui passe une fonction qui sera appelée quand la position est obtenue avec succès. Cet objet position contient diverses informations, mais on se concentre uniquement sur `latitude` et `longitude`.

S'il y a un problème pour obtenir la position, alors l'erreur sera affichée dans la console.

La méthode `getCurrentPosition` utilise le GPS, les réseaux Wi-Fi, ou la géolocalisation par adresse IP, selon l'appareil et ses réglages. Une fois la localisation trouvée, la fonction callback de succès est appelée avec un objet position.

L'objet position contient diverses propriétés, dont les plus couramment utilisées sont `latitude` et `longitude`, mais il peut aussi inclure `altitude`, `accuracy`, `speed`, et `heading`, etc.

Une considération importante lors de l'utilisation de la géolocalisation est la confidentialité de l'utilisateur. Explique à tes utilisateurs pourquoi tu as besoin de leurs données de localisation et comment tu les utiliseras.
