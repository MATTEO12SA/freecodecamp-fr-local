# --description--

Le moteur JavaScript a la capacité de lire, comprendre et exécuter ton code. Il fonctionne comme un convertisseur qui prend ton code, le transforme en instructions que l'ordinateur peut comprendre et exécuter.

Un des moteurs JavaScript les plus connus est V8, développé par Google, utilisé dans Chrome et Node.js. Le moteur JavaScript travaille en plusieurs étapes. D'abord, il parse ton code, le lit ligne par ligne pour s'assurer qu'il n'y a pas d'erreur. Ensuite, il convertit ce code en bytecode, une version intermédiaire plus simple plus facile à comprendre et exécuter pour l'ordinateur. Enfin, il exécute ce bytecode pour réaliser les instructions de ton programme. Voici un exemple de code JavaScript :

```js
const greeting = "Hello, World!";
console.log(greeting);
```

Quand tu exécutes ce code, le moteur JavaScript le parse d'abord pour vérifier les erreurs de syntaxe. Parser signifie que le moteur lit le code et le décompose en une structure qu'il peut comprendre, en vérifiant les erreurs au passage.

Ensuite, il compile le code en un format intermédiaire (souvent du bytecode ou du code machine, selon le moteur). Compiler est le processus de conversion du code lisible par l'humain en un format plus efficace que l'ordinateur peut exécuter plus vite.

Enfin, le moteur exécute le code, affichant `Hello, World!` dans la console.

Maintenant, parlons du runtime JavaScript. Le runtime JavaScript est l'environnement dans lequel ton code JavaScript est exécuté. Il inclut le moteur JavaScript (comme V8 dans Chrome ou SpiderMonkey dans Firefox), qui traite et exécute le code, ainsi que des fonctionnalités supplémentaires fournies par l'environnement (comme un navigateur web ou Node.js, que tu apprendras plus en détail dans de futures leçons).

Alors que le langage JavaScript de base gère les variables, boucles et fonctions, le runtime fournit des outils supplémentaires qui permettent à JavaScript d'interagir avec des choses hors du langage lui-même, comme le DOM (pour les pages web) ou la Fetch API (pour les requêtes réseau).

En résumé, le runtime permet à JavaScript de faire plus que des tâches de programmation basiques — comme interagir avec des pages web ou gérer des actions basées sur le temps — en fournissant ces fonctionnalités au-delà du langage lui-même.

Même si tu n'as pas besoin de connaître chaque détail des moteurs et runtimes pour écrire du JavaScript, une compréhension de base peut t'aider à écrire un code plus efficace et à déboguer plus efficacement.
