# --description--

Les attributs `async` et `defer` des éléments HTML `script` jouent un rôle crucial dans le chargement et l'exécution des fichiers JavaScript. Les comprendre peut améliorer les performances et l'expérience utilisateur de ton site. Quand tu inclus un `script` dans ton fichier HTML, cela ressemble à ceci :

```js
<script src="example.js"></script>
```

Quand le navigateur trouve cette balise `script`, il arrête le parsing HTML, télécharge le script, l'exécute, puis continue le parsing HTML. Cela peut ralentir le chargement de ta page, surtout avec de gros scripts.

C'est là qu'interviennent les attributs `async` et `defer`. Ils permettent de charger les scripts plus efficacement.

Commençons par l'attribut `async` :

```js
<script src="example.js" async></script>
```

En ajoutant l'attribut `async` à une balise `script`, le navigateur continue le parsing HTML pendant le téléchargement du script. Une fois le script entièrement téléchargé, le navigateur met en pause le parsing HTML, exécute le script, puis reprend le parsing. Cela peut accélérer nettement le chargement de la page.

Il est important de noter que les scripts async s'exécutent dès qu'ils sont téléchargés, ce qui signifie qu'ils peuvent ne pas s'exécuter dans l'ordre souhaité. C'est là que l'attribut `defer` vient à la rescousse. Voyons à quoi ressemble l'attribut `defer` :

```js
<script src="example.js" defer></script>
```

L'attribut `defer` est similaire à l'attribut `async`. Cependant, les scripts defer ne s'exécutent pas immédiatement après leur téléchargement. Ils attendent que le parsing HTML soit terminé. De plus, les scripts defer s'exécutent dans l'ordre où ils apparaissent dans le code HTML.

En résumé, utilise `async` pour les scripts dont l'ordre d'exécution n'importe pas, et utilise `defer` quand tu dois garantir que les scripts s'exécutent dans le bon ordre. Les deux attributs peuvent améliorer nettement les temps de chargement en permettant au navigateur de continuer le parsing HTML pendant que les scripts sont téléchargés en arrière-plan.
