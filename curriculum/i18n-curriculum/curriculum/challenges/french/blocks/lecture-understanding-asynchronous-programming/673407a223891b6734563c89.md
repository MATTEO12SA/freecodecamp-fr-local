# --description--

La Fetch API permet aux applications web de faire des requêtes réseau, généralement pour récupérer ou envoyer des données au serveur. Cette API fournit une méthode `fetch()` que tu peux utiliser pour ces requêtes. Voyons un exemple basique d'utilisation de `fetch` :

```js
fetch('https://api.example.com/data')
```

Dans cet exemple, on fait une requête `GET` vers `https://api.example.com/data`. Cela nous renvoie des données qu'il faut convertir au format JSON pour pouvoir les utiliser où on veut.

Par défaut, la Fetch API utilise la méthode `GET` pour récupérer des données. Cela sera couvert dans la prochaine leçon, avec d'autres méthodes de requête HTTP courantes.

Maintenant, discutons de quelques types de ressources couramment récupérés depuis le réseau.

Dans nos applications web, nous avons besoin de données courantes comme la météo, des listes de métiers, des noms de pays, des codes pays ou des icônes/images de drapeaux. Avec ces données, on peut rendre l'app plus informative et interactive. Grâce à la Fetch API, on peut obtenir ces ressources depuis le réseau.

Les images sont des ressources fréquemment récupérées. Tu pourrais utiliser fetch pour charger des images statiquement ou dynamiquement selon les actions de l'utilisateur, et les afficher dans ton application web.

Les fichiers texte sont un autre type de ressource souvent récupéré. Cela peut inclure des fichiers de configuration, des journaux, ou même des documents entiers que tu veux afficher sur ta page.

Dans certains cas, tu pourrais récupérer des fichiers audio ou vidéo. La Fetch API peut aussi gérer ces types de ressources, ce qui te permet de travailler avec une grande variété de types de données.
