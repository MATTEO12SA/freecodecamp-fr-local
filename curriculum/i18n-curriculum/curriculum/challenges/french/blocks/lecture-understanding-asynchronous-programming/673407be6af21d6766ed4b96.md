# --description--

Dans la leçon précédente, nous avons vu ce qu'est la Fetch API et comment l'utiliser. Dans cette leçon, nous parlerons des méthodes HTTP `GET`, `POST`, `PUT` et `DELETE` de la Fetch API.

Commençons par la méthode HTTP la plus courante, la méthode `GET`. Elle sert à récupérer des données depuis un serveur. Quand tu utilises `fetch()` sans préciser de méthode, elle utilise `GET` par défaut.

```js
fetch('https://api.example.com/data')
```

Dans ce code, on fait une requête `GET` vers `https://api.example.com/data`. Note bien que tu ne peux pas utiliser ces données directement : tu dois convertir la réponse au format JSON. Ensuite seulement tu pourras les utiliser où tu veux dans ton projet. Voici un exemple de comment faire :

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
```

Dans ce code, la réponse de la Fetch API est une promesse, et on utilise un gestionnaire `.then` pour convertir la réponse au format JSON. Dans une leçon précédente, tu as appris qu'une `Promise` est un objet qui représente l'achèvement éventuel (ou l'échec) d'un processus asynchrone et sa valeur.

La valeur d'une promesse n'est pas connue à sa création. Elle n'est connue que lorsque le processus asynchrone est terminé. Quand on enchaîne les deux gestionnaires `.then` à l'appel fetch, c'est ce qu'on appelle le chaînage de promesses, qui sera enseigné dans la prochaine leçon.

Jusqu'ici, nous avons récupéré des ressources depuis un serveur. Mais savais-tu qu'on peut aussi envoyer des données au serveur ? La méthode `POST` sert à envoyer des données à un serveur pour créer une ressource. Voici un exemple d'une méthode `POST` utilisée pour créer des données sur le serveur :

```js
fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Doe',
    email: 'john@example.com'
  })
})
```

Dans cet exemple, on envoie une requête `POST` pour créer un nouvel utilisateur. On précise la méthode comme `POST`, on définit les en-têtes appropriés, et on inclut un `body` avec les données à envoyer. Le corps doit être une chaîne, donc on utilise `JSON.stringify()` pour convertir notre objet en chaîne JSON.

La méthode `PUT` sert à mettre à jour des ressources existantes sur un serveur. Voici un exemple :

```js
fetch('https://api.example.com/users/45', {
  method: 'PUT',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Smith',
    email: 'john@example.com'
  })
})
```

Dans cet exemple, regarde bien l'URL : tu vois un `45` à la fin. C'est typiquement utilisé comme ID unique pour identifier les données à mettre à jour. On a utilisé la méthode `PUT` dans le code et on a aussi précisé les données comme `body` qui serviront à mettre à jour les données identifiées.

La méthode `DELETE` sert à supprimer une ressource du serveur. Voici un exemple :

```js
fetch('https://api.example.com/users/45', {
  method: 'DELETE',
})
```

Dans ce code, on inclut la méthode `DELETE` et un ID à la fin de l'url pour identifier les données à supprimer.
