# --interactive--

Apprenons le but de la méthode `preventDefault()` sur les événements.

Chaque événement déclenché dans le DOM a une sorte de comportement par défaut. L'événement `click` sur une case à cocher bascule l'état de cette case, par défaut. Appuyer sur la barre d'espace sur un bouton focalisé active le bouton. La méthode `preventDefault()` sur ces objets d'événement empêche ce comportement de se produire.

Regardons un exemple. Définissons un élément `input` pour qu'un utilisateur puisse y taper :

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<label>Enter some characters:
  <input type="text">
</label>
```

```css
label {
  display: flex;
  flex-direction: column;
  font-family: Arial, sans-serif;
  font-size: 14px;
  color: #333;
  margin-bottom: 12px;
}

input[type="text"] {
  padding: 8px 12px;
  border: 1px solid #ccc;
  border-radius: 4px;
  font-size: 14px;
  margin-top: 4px;
  width: 100%;
  box-sizing: border-box;
  transition: border-color 0.2s, box-shadow 0.2s;
}

input[type="text"]:focus {
  border-color: #0078d4;
  box-shadow: 0 0 3px rgba(0, 120, 212, 0.5);
  outline: none;
}

```

:::

Et si nous regardons le résultat, nous pouvons taper dans le champ de saisie comme prévu. Mais peut-être que nous ne voulons pas cela. Peut-être, à la place, que nous aimerions afficher le caractère tapé par l'utilisateur dans un élément séparé. D'abord, définissons notre élément pour cela :

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<label>Enter some characters:
  <input type="text">
</label>
<p id="output"></p>
```

```css
body {
  font-family: Arial, sans-serif;
  background-color: #f0f0f0;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  height: 100vh;
  margin: 0;
}

label {
  font-size: 1.2rem;
  color: #333;
  margin-bottom: 1rem;
  display: flex;
  flex-direction: column;
}

input[type="text"] {
  padding: 0.5rem;
  font-size: 1rem;
  border: 2px solid #ccc;
  border-radius: 5px;
  margin-top: 0.5rem;
  outline: none;
}

input[type="text"]:focus {
  border-color: #007BFF;
}

#output {
  margin-top: 1rem;
  font-size: 1.1rem;
  color: #555;
}

```

:::

Ensuite, nous devons nous brancher sur l'événement `keydown` pour écouter un caractère tapé au clavier. Note que nous ne voulons pas les événements `change` ou `input` ici, car nous avons besoin des informations du clavier.

```js
const input = document.querySelector("input");

input.addEventListener("keydown", (e) => {

})
```

L'événement `keydown` se déclenche quand tu appuies sur une touche du clavier. Quand cela se produit, affichons le caractère dans notre élément `p`.

```js

const output = document.getElementById("output");

input.addEventListener("keydown", (e) => {
  output.innerText = `You pressed the ${e.key} key`;
});
```

:::

`e.key` te donne la valeur de la touche pressée, comme `a` pour la touche `a` ou `Enter` pour la touche `Enter`.

Avec le code ci-dessus, quand tu tapes dans l'`input`, le caractère que tu tapes sera affiché dans l'élément `p`.

C'est bien, mais nous ne voulons pas afficher les caractères dans l'`input` aussi. C'est là qu'intervient notre méthode `preventDefault()`. Le comportement par défaut d'un `keydown` est d'afficher le caractère dans l'input. Évitons cela en appelant `e.preventDefault()` :

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<label>Enter some characters:
  <input type="text">
</label>
<p id="output"></p>
<script src="index.js"></script>
```

```css

  display: flex;
  flex-direction: column;
  align-items: center;

  height: 100vh;
  margin: 0;
}

label {
  font-size: 1.2rem;
  color: #333;
  margin-bottom: 1rem;
  display: flex;
  flex-direction: column;
}

input[type="text"] {
  padding: 0.5rem;
  font-size: 1rem;
  border: 2px solid #ccc;
  border-radius: 5px;
  margin-top: 0.5rem;
  outline: none;
}

input[type="text"]:focus {
  border-color: #007BFF;
}

#output {
  margin-top: 1rem;
  font-size: 1.1rem;
  color: #555;

```

```js
const input = document.querySelector("input");
const output = document.getElementById("output");

input.addEventListener("keydown", (e) => {
  e.preventDefault();
  output.innerText = `You pressed the ${e.key} key`;
});
```

:::

Et voilà, tu as empêché le comportement par défaut pour te permettre d'implémenter ta propre gestion d'événement personnalisée.

Un autre exemple courant d'utilisation de la méthode `e.preventDefault` concerne les soumissions de formulaire. Par défaut, soumettre un formulaire envoie les données au serveur et recharge la page. Utiliser `e.preventDefault()` empêche cela de se produire.

```js
const form = document.querySelector("form");

form.addEventListener("submit", (e) => {
  e.preventDefault();
  // rest of code goes here
});
```

Empêcher le comportement par défaut est utile quand tu as besoin de plus de contrôle sur la façon dont un utilisateur interagit avec la page, mais il est important de garder à l'esprit des aspects comme l'accessibilité – ton comportement personnalisé devrait offrir les mêmes fonctionnalités que le comportement par défaut.
