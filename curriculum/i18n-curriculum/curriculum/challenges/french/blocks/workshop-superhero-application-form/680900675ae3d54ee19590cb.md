# --description--

Dans une leçon précédente, tu as appris à afficher une liste d'options avec la méthode `map()` comme ceci :

```jsx
function FruitList() {
  const fruits = ["Apple", "Banana", "Cherry", "Date"];
  return (
    <ul>
      {fruits.map((fruit, index) => (
        <li key={`${fruit}-${index}`}>{fruit}</li>
      ))}
    </ul>
  );
}
```

Souviens-toi que la `key` doit toujours être unique. Elle aide React à identifier quels éléments ont changé, été ajoutés ou retirés.

Après la première `option`, utilise une fonction fléchée pour parcourir le tableau `powerSourceOptions` avec `source` comme paramètre.

Puis dans la méthode `map()`, crée un élément `option` avec une `key` de `source` et une `value` de `source`. Enfin, utilise `{source}` pour afficher le nom de chaque source de pouvoir dans le menu déroulant.
