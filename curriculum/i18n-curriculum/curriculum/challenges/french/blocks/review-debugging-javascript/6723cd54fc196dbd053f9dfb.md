## Types courants de messages d'erreur

- **SyntaxError** : Ces erreurs surviennent quand tu écris quelque chose d'incorrect dans ton code, comme une parenthèse ou un crochet manquant. Pense-y comme à une faute de grammaire dans une phrase.

```js
const arr = ["Beau", "Quincy" "Tom"]
```

- **ReferenceError** : Il existe plusieurs types d'erreurs de référence, déclenchés de différentes manières. Le premier type d'erreur de référence concerne les variables non définies. Un autre exemple de ReferenceError consiste à accéder à une variable, déclarée avec `let` ou `const`, avant qu'elle n'ait été définie.

:::interactive_editor

```js
console.log(num);
const num = 50;
```

:::

- **TypeError** : Ces erreurs surviennent quand tu essaies d'effectuer une opération sur le mauvais type.

```js
const developerObj = {
  name: "Jessica",
  country: "USA",
  isEmployed: true
};

developerObj.map()
```

- **RangeError** : Ces erreurs surviennent quand ton code essaie d'utiliser une valeur qui est en dehors de la plage que JavaScript peut gérer.

```js
const arr = [];
arr.length = -1;
```

## L'instruction `throw`

- **Définition** : L'instruction `throw` en JavaScript sert à lever une exception définie par l'utilisateur. Une exception en programmation, c'est quand un événement inattendu se produit et perturbe le flux normal du programme.

:::interactive_editor

```js
function validateNumber(input) {
  if (typeof input !== "number") {
    throw new TypeError("Expected a number, but received " + typeof input);
  }
  return input * 2;
}

console.log(validateNumber("Naomi"));   // TypeError: Expected a number, but received string
```

:::

## `try...catch...finally`

- **Définition** : Le bloc `try` sert à encapsuler du code qui pourrait lever une erreur. Il agit comme un espace sûr pour essayer quelque chose qui pourrait échouer. Le bloc `catch` capture et gère les erreurs qui surviennent dans le bloc try. Tu peux utiliser l'objet d'erreur à l'intérieur de catch pour inspecter ce qui s'est mal passé. Le bloc `finally` s'exécute après les blocs try et catch, qu'une erreur se soit produite ou non. Il est couramment utilisé pour des tâches de nettoyage, comme fermer des fichiers ou libérer des ressources.

:::interactive_editor

```js
function processInput(input) {
  if (typeof input !== "string") {
    throw new TypeError("Input must be a string.");
  }

  return input.toUpperCase();
}

try {
  console.log("Starting to process input...");
  const result1 = processInput("hello");
  console.log("Processed result:", result1);  // HELLO
  const result2 = processInput(9);  // throws TypeError
  console.log("Processed result:", result2);  // not executed
} catch (error) {
  console.error("Error occurred:", error.message);
}
```

:::

## Techniques de débogage

- **Instruction `debugger`** : Cette instruction te permet de mettre en pause ton code à une ligne précise pour examiner ce qui se passe dans le programme.

:::interactive_editor

```js
let firstNumber = 5;
let secondNumber = 10;

debugger; // Code execution pauses here
let sum = firstNumber + secondNumber;

console.log(sum);
```

:::

- **Points d'arrêt** : Les points d'arrêt te permettent de mettre en pause l'exécution de ton code à une ligne précise de ton choix. Après la pause, tu peux inspecter les variables, évaluer des expressions et examiner la pile d'appels.
- **Expressions de surveillance** : Les expressions de surveillance te permettent de suivre les valeurs de variables ou d'expressions pendant que le code s'exécute, même si elles sont hors de la portée actuelle.
- **Profilage** : Le profilage t'aide à identifier les goulots d'étranglement de performance en te permettant de capturer des captures d'écran et d'enregistrer l'utilisation du processeur, les appels de fonction et le temps d'exécution.
- **`console.dir()`** : Cette méthode sert à afficher une liste interactive des propriétés d'un objet JavaScript spécifié. Elle produit une liste hiérarchique qui peut être développée pour voir toutes les propriétés imbriquées.

```js
console.dir(document);
```

- **`console.table()`** : Cette méthode affiche des données tabulaires sous forme de tableau dans la console. Elle prend un argument obligatoire, qui doit être un tableau ou un objet, et un argument optionnel pour spécifier quelles propriétés (colonnes) afficher.
