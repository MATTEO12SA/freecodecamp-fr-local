# --interactive--

Quand tu plonges dans JavaScript, tu découvres rapidement qu'effectuer des opérations mathématiques est une tâche courante. Si les opérateurs arithmétiques de base peuvent gérer des calculs simples, JavaScript offre un objet `Math` intégré pour relever des défis mathématiques plus complexes.

Cet outil pratique fournit une variété de méthodes qui facilitent l'exécution de calculs avancés et la manipulation des nombres. Explorons ces méthodes et voyons comment elles peuvent simplifier ton expérience de programmation.

La méthode `Math.random()` génère un nombre à virgule flottante aléatoire entre `0` (inclus) et `1` (exclu). Cela signifie que la sortie possible peut être `0`, mais elle n'atteindra jamais réellement `1`. Voici un exemple d'utilisation de la méthode `Math.random()` :

:::interactive_editor

```js
const randomNum = Math.random();

console.log(randomNum);
// any number between 0 and 1 – 0 inclusive and 1 exclusive
```

:::

`Math.min()` et `Math.max()` prennent toutes deux un ensemble de nombres et renvoient respectivement la valeur minimale et la valeur maximale. Voici un exemple d'utilisation de ces deux méthodes :

:::interactive_editor

```js
const smallest = Math.min(1, 5, 3, 9);
console.log(smallest); // 1

const largest = Math.max(1, 5, 3, 9);
console.log(largest); // 9
```

:::

Le premier `console.log()` affichera le nombre `1`, car `1` est le plus petit de cette liste de nombres. Et le second `console.log()` affichera le nombre `9`, car `9` est le plus grand de cette liste.

Si tu voulais arrondir des nombres vers le haut ou vers le bas à l'entier le plus proche, tu pourrais utiliser les méthodes `Math.ceil()` et `Math.floor()`. Voici un exemple d'utilisation de `Math.ceil()` :

:::interactive_editor

```js
console.log(Math.ceil(4.3)); // 5
```

:::

`Math.ceil()` arrondira `4.3` vers le haut à l'entier le plus proche, qui est `5` dans ce cas. Maintenant, regardons comment arrondir un nombre vers le bas :

:::interactive_editor

```js
console.log(Math.floor(4.7)); // 4
```

:::

`Math.floor()` arrondira `4.7` vers le bas à l'entier le plus proche, qui est `4` dans ce cas. `Math.round()` est l'hybride de `Math.ceil()` et `Math.floor()`. Elle arrondit un nombre à son entier le plus proche, en tenant compte de la virgule décimale :

:::interactive_editor

```js
console.log(Math.round(2.3)); // 2
console.log(Math.round(4.5)); // 5
console.log(Math.round(4.8)); // 5
```

:::

Donc, si la décimale est inférieure à `5`, le nombre est arrondi vers le bas. Et si la décimale est égale ou supérieure à `5`, le nombre est arrondi vers le haut. Une application pratique de `Math.floor()` et `Math.random()` consiste à générer un nombre aléatoire entre deux nombres entiers. Voici la syntaxe pour cela :

:::interactive_editor

```js
const max = 10;
const min = 5;
const randomNum = Math.floor(Math.random() * (max - min + 1)) + min;
console.log(randomNum);
```

:::

Générer un nombre aléatoire entre `20` et `1` ressemblerait à ceci :

:::interactive_editor

```js
const randomNumBtw1And20 = Math.floor(Math.random() * 20) + 1;
console.log(randomNumBtw1And20);
```

:::

Une autre méthode utile de `Math` serait la méthode `Math.trunc()`. `Math.trunc()` supprime la partie décimale d'un nombre, ne renvoyant que la partie entière, sans arrondir :

:::interactive_editor

```js
console.log(Math.trunc(2.9)); // 2
console.log(Math.trunc(9.1)); // 9
```

:::

Si tu as besoin d'obtenir la racine carrée ou la racine cubique d'un nombre, tu peux utiliser respectivement les méthodes `Math.sqrt()` et `Math.cbrt()` :

:::interactive_editor

```js
console.log(Math.sqrt(81)); // 9
console.log(Math.cbrt(27)); // 3
```

:::

La première instruction d'affichage affichera `9` car la racine carrée de `81` est `9`, tandis que la seconde affichera `3` car la racine cubique de `27` est `3`. Si tu as besoin d'obtenir la valeur absolue d'un nombre, tu peux utiliser la méthode `Math.abs()` :

:::interactive_editor

```js
console.log(Math.abs(-5)); // 5
console.log(Math.abs(5)); // 5
```

:::

`Math.abs()` renvoie la valeur absolue d'un nombre, transformant les négatifs en positifs. La dernière méthode que nous examinerons sera la méthode `Math.pow()` :

:::interactive_editor

```js
console.log(Math.pow(2, 3)); // 8
console.log(Math.pow(8, 2)); // 64
```

:::

`Math.pow()` prend deux nombres et élève le premier à la puissance du second. Il existe bien d'autres méthodes appartenant à l'objet `Math`, que tu peux explorer par toi-même. Cependant, celles-ci ne sont que quelques-unes des plus couramment utilisées que l'on trouve dans les bases de code JavaScript.
