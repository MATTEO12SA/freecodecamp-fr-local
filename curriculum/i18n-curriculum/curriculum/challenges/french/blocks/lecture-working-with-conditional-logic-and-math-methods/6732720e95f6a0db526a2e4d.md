# --interactive--

Les opérateurs logiques binaires t'aident à évaluer deux expressions et à renvoyer un résultat en fonction de leur caractère truthy ou falsy. Examinons les trois opérateurs logiques binaires les plus courants : le ET logique, le OU logique, et l'opérateur de coalescence des nuls.

L'opérateur ET logique est représenté par une double esperluette (`&&`). Il vérifie si les deux opérandes sont vrais et renvoie un résultat. Si les deux opérandes sont truthy, il renvoie la deuxième valeur, c'est-à-dire celle de droite :

:::interactive_editor

```js
const result = true && 'hello';

console.log(result); // hello
```

:::

Dans l'exemple ci-dessus, le texte `hello` est affiché dans la console car les deux opérandes sont `true`. Si l'un des opérandes est falsy, il renvoie la valeur falsy :

:::interactive_editor

```js
const result = 0 && 3;

console.log(result); // 0
```

:::

Comme `0` est une valeur falsy, le nombre `0` est affiché dans la console. Et si les deux opérandes sont falsy, il renvoie la première valeur falsy :

:::interactive_editor

```js
const result = false && 0;

console.log(result); // false
```

:::

Comme `false` est une valeur falsy, `false` est affiché dans la console. L'opérateur ET logique est utile quand tu veux vérifier plusieurs conditions et t'assurer qu'elles sont toutes vraies avant de continuer. Voici un exemple :

:::interactive_editor

```js
if (2 < 3 && 3 < 4) {
 console.log('The if block runs');
} else {
 console.log('The else block runs');
}
```

:::

Dans la condition, comme `2` est inférieur à `3` ET `3` est inférieur à `4`, la phrase `The if block runs` sera affichée dans la console.

L'opérateur OU logique vérifie si au moins l'un des opérandes est truthy. Si le premier opérande est truthy, il renvoie cette valeur :

:::interactive_editor

```js
const result = 'This is truthy' || false;

console.log(result); // This is truthy
```

:::

Si le premier opérande est falsy mais que le second est truthy, la deuxième valeur sera affichée dans la console :

:::interactive_editor

```js
const result = 0 || 'This is truthy';

console.log(result); // This is truthy
```

:::

Il est courant d'utiliser l'opérateur OU logique dans les instructions `if/else` comme ceci :

:::interactive_editor

```js
let userInput;

if (userInput || 'Guest') {
 console.log('A user is present');
} else {
 console.log('No user detected');
}
```

:::

Comme nous n'avons pas affecté de valeur à la variable `userInput`, elle vaut actuellement `undefined`. La condition de l'instruction `if` vérifie si la variable `userInput` ou la chaîne `Guest` est truthy. Comme la chaîne `Guest` est vraie dans un contexte booléen comme celui-ci, la chaîne `A user is present` sera affichée dans la console.

L'opérateur de coalescence des nuls est plus sophistiqué que le OU logique et le ET logique. Représenté par un double point d'interrogation (`??`), il est utile dans les scénarios où tu veux renvoyer une valeur uniquement si la première est `null` ou `undefined`. Voici un exemple d'utilisation de l'opérateur de coalescence des nuls :

:::interactive_editor

```ts
const result = null ?? 'default';

console.log(result); // default
```

:::

Comme `null` est une valeur nulle (nullish), la chaîne `default` serait affichée dans la console. L'opérateur de coalescence des nuls est incroyablement utile dans les situations où `null` ou `undefined` sont les seules valeurs qui devraient déclencher une valeur de repli ou par défaut. Voici un exemple qui traite des réglages de préférences d'un utilisateur :


:::interactive_editor

```ts
const userSettings = {
 theme: null,
 volume: 0,
 notifications: false,
};

let theme = userSettings.theme ?? 'light';
console.log(theme); // light
```

:::

Dans l'exemple ci-dessus, nous avons un objet appelé `userSettings` qui contient les propriétés `theme`, `volume` et `notifications`. Nous accédons au `theme` à l'aide de la notation par point comme `userSettings.theme`. Tu en apprendras davantage sur la façon de travailler avec les objets dans une prochaine leçon. Comme le `theme` de l'utilisateur est actuellement défini à `null`, la chaîne `light` sera affichée dans la console.
