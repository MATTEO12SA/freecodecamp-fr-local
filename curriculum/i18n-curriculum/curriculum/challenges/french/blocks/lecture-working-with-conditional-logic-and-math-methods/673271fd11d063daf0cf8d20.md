# --interactive--

Les instructions conditionnelles te permettent de prendre des décisions dans ton code JavaScript. Elles permettent à ton programme de se dérouler d'une manière particulière en fonction de certaines conditions. Voyons comment `if`, `else if`, `else` et l'opérateur ternaire fonctionnent pour te permettre de contrôler le déroulement de ton code.

Une instruction `if` prend une condition et exécute un bloc de code si cette condition est truthy. Les valeurs truthy sont toutes les valeurs qui donnent `true` lorsqu'elles sont évaluées dans un contexte booléen comme une instruction `if`. Voici des exemples de valeurs truthy :

- les chaînes non vides, par exemple, `hello`

- tout nombre autre que `0` et `-0`, par exemple, `4`, `-5`, et d'autres

- les tableaux

- les objets

- le booléen `true`

En revanche, les valeurs falsy sont des valeurs qui s'évaluent à `false` dans un contexte booléen. JavaScript a peu de valeurs falsy, ce qui les rend faciles à retenir. Voici quelques valeurs falsy :

- le booléen `false`

- `0` (zéro)

- `""` (chaîne vide)

- `null`

- `undefined`

- `NaN` (Not a Number)

Maintenant que nous avons une compréhension de base des valeurs truthy et falsy, voyons comment cela fonctionne avec les instructions `if`. Dans ce premier exemple, nous utilisons deux instructions `if` pour effectuer une vérification par rapport à des valeurs truthy et falsy :

:::interactive_editor

```js
if (null) {
  console.log("This will not run.");
}

if ("freeCodeCamp") {
  console.log("This will run.");
}
```

:::

Comme `null` est une valeur falsy, le message à l'intérieur du bloc ne sera jamais affiché dans la console. Mais pour la deuxième instruction `if`, la chaîne `freeCodeCamp` est une valeur truthy, et sera considérée comme `true` dans ce contexte booléen de l'instruction `if`. Par conséquent, le message `This will run.` sera affiché dans la console.

Examinons quelques exemples supplémentaires sur la façon dont les instructions `if` fonctionnent avec différents opérateurs de comparaison. Voici un exemple d'utilisation d'une instruction `if` pour vérifier si l'utilisateur est en droit de voter :

:::interactive_editor

```js
const age = 22;

if (age >= 18) {
 console.log("You're eligible to vote"); // You're eligible to vote
}
```

:::

Dans cet exemple, comme `age` vaut actuellement `22`, cela signifie que la condition s'évaluera à `true` car `22` est supérieur ou égal à `18`. Donc le message `You're eligible to vote` sera affiché dans la console. Si nous changeons l'exemple pour que `age` vaille maintenant `15`, alors la condition s'évaluera à `false` et le message ne sera pas affiché dans la console :

:::interactive_editor

```js
const age = 15;

if (age >= 18) {
 console.log("You're eligible to vote"); // Code not running because age is less than 18
}
```

:::

Quand une condition est `false`, tu peux utiliser une clause `else` :

:::interactive_editor

```js
const age = 15;

if (age >= 18) {
 console.log("You're eligible to vote");
} else {
 console.log("You're not eligible to vote"); // You're not eligible to vote
}
```

:::

Dans cet exemple, `15` n'est pas supérieur ou égal à `18`, donc la condition serait `false`. Le code à l'intérieur du bloc `else` s'exécutera dans ce cas.

Si tu veux vérifier plusieurs conditions, tu peux utiliser un bloc `else if`. Cela permet à ton programme de choisir entre plus de deux chemins.

:::interactive_editor

```js
const score = 87;

if (score >= 90) {
 console.log('You got an A');
} else if (score >= 80) {
 console.log('You got a B'); // You got a B
} else if (score >= 70) {
 console.log('You got a C');
} else {
 console.log('You failed! You need to study more!');
}
```

:::

Comme `score` vaut actuellement `87`, le message `You got a B` serait affiché dans la console.

L'opérateur ternaire est une façon compacte d'écrire de simples instructions `if/else`. Il comporte trois parties : une condition, un résultat si la condition est vraie, et un résultat si elle est fausse. Voici la syntaxe de base :

```js
condition ? expressionIfTrue : expressionIfFalse;
```

Voici un exemple qui traite des températures météo en Celsius :

:::interactive_editor

```js
const temperature = 30;
const weather = temperature > 25 ? 'sunny' : 'cool';

console.log(`It's a ${weather} day!`);
```

:::

Si `temperature` est supérieure à `25`, le code ci-dessus affiche `It's a sunny day!`. Si `temperature` est inférieure ou égale à `25`, il affiche `It's a cool day!`.

Alors, lequel utiliser entre une instruction if et un ternaire ? Utilise un ternaire quand tu traites une seule condition ou de simples expressions, ou quand tu veux une syntaxe compacte pour une logique simple. Utilise les instructions `if/else` quand tu traites des conditions complexes et plusieurs instructions, car les choses deviennent illisibles si tu imbriques des ternaires.
