## Travailler avec les boucles

- **Boucle `for`** : ce type de boucle est utilisé pour répéter un bloc de code un certain nombre de fois. Cette boucle se compose de trois parties : l'instruction d'initialisation, la condition et l'instruction d'incrémentation/décrémentation. L'instruction d'initialisation est exécutée avant le démarrage de la boucle. Elle sert généralement à initialiser une variable de compteur. La condition est évaluée avant chaque itération de la boucle. Une itération est un seul passage dans la boucle. Si la condition vaut `true`, le bloc de code à l'intérieur de la boucle est exécuté. Si la condition vaut `false`, la boucle s'arrête et tu passes au bloc de code suivant. L'instruction d'incrémentation/décrémentation est exécutée après chaque itération de la boucle. Elle sert généralement à incrémenter ou décrémenter la variable de compteur.

:::interactive_editor

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

:::

- **Boucle `for...of`** : ce type de boucle est utilisé quand tu dois parcourir les valeurs d'un itérable. Les tableaux et les chaînes sont des exemples d'itérables.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];

for (const num of numbers) {
  console.log(num);
}
```

:::

- **Boucle `for...in`** : ce type de boucle est surtout utile quand tu dois parcourir les propriétés d'un objet. Cette boucle itère sur toutes les propriétés énumérables d'un objet, y compris les propriétés héritées et les propriétés non numériques.

:::interactive_editor

```js
const fruit = {
  name: 'apple',
  color: 'red',
  price: 0.99
};

for (const prop in fruit) {
  console.log(fruit[prop]);
}
```

:::

- **Boucle `while`** : ce type de boucle exécute un bloc de code tant que la condition vaut `true`.

:::interactive_editor

```js
let i = 5;

while (i > 0) {
  console.log(i);
  i--;
}
```

:::

- **Boucle `do...while`** : ce type de boucle exécute le bloc de code au moins une fois avant de vérifier la condition.

```js
let userInput;

do {
  userInput = prompt("Please enter a number between 1 and 10");
} while (Number(userInput) < 1 || Number(userInput) > 10);

alert("You entered a valid number!");
```

## Instructions `break` et `continue`

- **Définition** : une instruction `break` sert à sortir d'une boucle plus tôt, tandis qu'une instruction `continue` sert à ignorer l'itération courante d'une boucle et à passer à la suivante.

:::interactive_editor

```js
// Example of break statement
for (let i = 0; i < 10; i++) {
  if (i === 5) {
    break;
  }
  console.log(i);
}

// Output: 0, 1, 2, 3, and 4

// Example of continue statement
for (let i = 0; i < 10; i++) {
  if (i === 5) {
    continue;
  }
  console.log(i);
}

// Output: 0, 1, 2, 3, 4, 6, 7, 8, and 9
```

:::
