# --description--

L'affectation augmentée combine une opération binaire et une affectation en une seule étape. Elle prend une variable, lui applique une opération avec une autre valeur, et stocke le résultat dans la même variable.

Si tu connais un langage comme JavaScript, tu as probablement déjà entendu parler de l'opérateur d'affectation par addition (`+=`) ou d'affectation par soustraction (`-=`), et d'autres. Ils existent aussi en Python. La seule différence, c'est qu'on les appelle des **affectations augmentées**.

La syntaxe de base d'une affectation augmentée ressemble à ceci :

```python
variable <operator>= value
```

C'est une façon plus efficace de faire ceci :

```python
variable = variable <operator> value
```

Par exemple, voici comment utiliser l'affectation augmentée pour ajouter `5` à une variable existante :

```python
my_var = 10
my_var += 5

print(my_var) # 15
```

Et voici la même chose, mais sans affectation augmentée :

```python
my_var = 10
my_var = my_var + 5

print(my_var) # 15
```

L'avantage de l'affectation augmentée, c'est qu'elle offre une façon concise et lisible de mettre à jour la valeur d'une variable sans répéter son nom. Cela réduit la redondance et les erreurs potentielles qui pourraient venir d'une faute de frappe ou d'un oubli similaire.

Chaque opérateur peut utiliser une affectation augmentée. On a déjà vu l'opérateur d'affectation par addition (`+=`), alors regardons les autres.

- L'opérateur d'affectation par soustraction (`-=`) soustrait l'opérande de droite de la variable de gauche et stocke la différence dans la variable de gauche :

```python
count = 14
count -= 3

print(count) # 11
```

- L'opérateur d'affectation par multiplication (`*=`) multiplie la variable de gauche par l'opérande de droite et stocke le produit dans la variable de gauche :

```python
product = 65
product *= 7

print(product) # 455
```

- L'opérateur d'affectation par division (`/=`) divise la variable de gauche par celle de droite et stocke le résultat dans la variable de gauche :

```python
price = 100
price /= 4

print(price) # 25.0
```

- L'opérateur de division entière (`//=`) applique la division entière de la variable de gauche par celle de droite et stocke le résultat dans la variable de gauche :

```python
total_pages = 23
total_pages //= 5

print(total_pages) # 4
```

- L'opérateur d'affectation par modulo (`%=`) calcule le reste de la variable de gauche divisée par celle de droite et le stocke dans la variable de gauche :

```python
bits = 35
bits %= 2

print(bits) # 1
```

- L'opérateur d'affectation par exponentiation (`**=`) élève la variable de gauche à la puissance de celle de droite et stocke le résultat dans la variable de gauche :

```python
power = 2
power **= 3

print(power) # 8
```

Tu peux aussi utiliser certains opérateurs d'affectation augmentée avec des chaînes. Par exemple, l'opérateur d'affectation par addition facilite la concaténation de chaînes :

```python
greet = 'Hello'
greet += ' World'

print(greet) # Hello World
```

Et l'opérateur d'affectation par multiplication peut servir à répéter une chaîne :

```python
greet = 'Hello'
greet *= 3

print(greet) # HelloHelloHello
```

Les autres affectations augmentées lèvent une `TypeError` quand tu les utilises avec des chaînes :

```python
greet = 'Hello'
greet -= ' World'

print(greet) # TypeError: unsupported operand type(s) for -=: 'str' and 'str'


greet = 'Hello'
greet /= 'World'

print(greet) # TypeError: unsupported operand type(s) for /=: 'str' and 'str' 
```

Si tu te demandes si les opérateurs d'incrémentation et de décrémentation (`++` et `--`) fonctionnent en Python, ce n'est pas le cas. C'est parce que Python évite volontairement les raccourcis d'incrémentation et de décrémentation de style C, afin de garder le langage clair et explicite.

Au lieu de `x++`, tu peux simplement écrire `x += 1`, ce qui rend évident que tu incrémentes la valeur de `x` de `1`.

Écrire `++x` en Python applique simplement le plus unaire deux fois, et n'incrémente rien :

```python
my_var = 5

print(+my_var)   # 5
print(++my_var)  # 5
print(+++my_var) # 5

my_var += 1

print(my_var) # 6
```
