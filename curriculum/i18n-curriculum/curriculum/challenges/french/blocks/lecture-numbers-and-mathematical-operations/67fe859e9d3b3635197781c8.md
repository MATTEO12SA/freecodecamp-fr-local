# --description--

Les entiers et les flottants sont les principaux types de données numériques en Python. Avec eux, tu peux stocker des données numériques et effectuer des opérations mathématiques.

Regardons ce que sont les entiers et les flottants, comment effectuer des calculs arithmétiques avec eux, et plusieurs méthodes que Python fournit pour travailler avec les deux.

Les entiers sont des nombres sans partie décimale, positifs ou négatifs :

```python
my_int_1 = 56
my_int_2 = -4

print(type(my_int_1)) # <class 'int'>
print(type(my_int_2)) # <class 'int'>
```

Voici comment effectuer une addition avec des entiers :

```python
my_int_1 = 56
my_int_2 = 12

sum_ints = my_int_1 + my_int_2
print('Integer Addition:', sum_ints) # Integer Addition: 68
```

Voici comment effectuer une soustraction avec des entiers :

```python
my_int_1 = 56
my_int_2 = 12

# Subtraction
diff_ints = my_int_1 - my_int_2
print('Integer Subtraction:', diff_ints) # Integer Subtraction: 44
```

Voici comment effectuer une multiplication avec des entiers :

```python
my_int_1 = 12
my_int_2 = 4

# Multiplication
product_ints = my_int_1 * my_int_2
print('Integer Multiplication:', product_ints) # Integer Multiplication: 48
```

Et voici comment effectuer une division avec des entiers :

```python
my_int_1 = 56
my_int_2 = 12

# Division
div_ints = my_int_1 / my_int_2
print('Integer Division:', div_ints) # Integer Division: 4.666666666666667
```

Les flottants sont des nombres positifs ou négatifs avec une virgule décimale, comme `3.14`, `-0.5` ou `0.0`.

```python
my_float_1 = -12.0
my_float_2 = 4.9

print(type(my_float_1)) # <class 'float'>
print(type(my_float_2)) # <class 'float'>
```

Voici une addition avec des flottants :

```python
my_float_1 = 5.4
my_float_2 = 12.0

float_addition = my_float_1 + my_float_2
print('Float Addition:', float_addition) # Float Addition: 17.4
```

Voici une soustraction avec des flottants :

```python
my_float_1 = 5.4
my_float_2 = 12.0

float_subtraction = my_float_2 - my_float_1
print('Float Subtraction:', float_subtraction) # Float Subtraction: 6.6
```

Voici une multiplication avec des flottants :

```python
my_float_1 = 5.4
my_float_2 = 12.0

float_multiplication = my_float_2 * my_float_1
print('Float Multiplication:', float_multiplication) # Float Multiplication: 64.80000000000001
```

Et voici une division avec des flottants :

```python
my_float_1 = 5.4
my_float_2 = 12.0

float_division = my_float_2 / my_float_1
print('Float Division:', float_division) # Float Division: 2.222222222222222
```

Si tu additionnes un entier et un flottant, le résultat est automatiquement converti en flottant :

```python
my_int = 56
my_float = 5.4

sum_int_and_float = my_int + my_float

print(sum_int_and_float) # 61.4
print(type(sum_int_and_float)) # <class 'float'>
```

C'est aussi vrai pour les autres opérations arithmétiques de base, comme la soustraction, la multiplication et la division. Si tu mélanges des entiers et des flottants, Python renvoie un flottant comme résultat.

Tu peux aussi effectuer des calculs arithmétiques plus complexes, comme obtenir le reste de deux nombres avec l'opérateur modulo, la division entière et l'exponentiation, aussi bien avec des entiers qu'avec des flottants.

L'opérateur modulo (`%`) renvoie le reste lorsque la valeur de gauche est divisée par la valeur de droite :

```python
my_int_1 = 56
my_int_2 = 12

my_float_1 = 5.4
my_float_2 = 12.0

mod_ints = my_int_1 % my_int_2
mod_floats = my_float_2 % my_float_1

print('Integer Modulo:', mod_ints) # Integer Modulo: 8
print('Float Modulo:', mod_floats) # Float Modulo: 1.1999999999999993
```

La division entière divise deux nombres et renvoie le plus grand entier inférieur ou égal au résultat. On la réalise avec l'opérateur double slash (`//`) :

```python
my_int_1 = 56
my_int_2 = 12

my_float_1 = 5.4
my_float_2 = 12.0

floor_div_ints = my_int_1 // my_int_2
floor_div_floats = my_float_2 // my_float_1

print('Integer Floor Division:', floor_div_ints) # Integer Floor Division: 4
print('Float Floor Division:', floor_div_floats) # Float Floor Division: 2.0
```

L'exponentiation élève un nombre à la puissance d'un autre, et se fait avec l'opérateur double astérisque (`**`) :

```python
my_int_1 = 56
my_int_2 = 12

my_float_1 = 5.4
my_float_2 = 12.0

exp_ints = my_int_1 ** my_int_2
exp_floats = my_float_1 ** my_float_2

print('Integer Exponentiation:', exp_ints) # Integer Exponentiation: 951166013805414055936
print('Float Exponentiation:',  exp_floats) # Float Exponentiation: 614787626.1765089
```

Parfois, tu peux remarquer que le résultat d'une opération impliquant des flottants a plus de chiffres décimaux que prévu. Par exemple, la somme `0.1 + 0.2` vaut `0.30000000000000004` au lieu de `0.3`.

Cela se produit parce que les nombres sont stockés au format binaire, et certaines fractions ne peuvent pas être représentées exactement en binaire. Par conséquent, elles sont stockées comme des approximations finies, de la même façon que la fraction `1/3` ne peut pas être représentée avec un nombre fini de chiffres en décimal et est tronquée après un certain nombre de ses chiffres infinis (`0.33333...`).

Cela entraîne de petites erreurs d'arrondi.

Python fournit aussi des fonctions intégrées pour convertir des données numériques ou des chaînes en entiers ou en flottants.

La fonction `float()` renvoie un nombre à virgule flottante construit à partir du nombre donné :

```python
my_int_1 = 56
my_float_1 = float(my_int_1)

print(my_float_1)  # 56.0
print(type(my_float_1))  # <class 'float'>
```

La fonction `int()` renvoie un entier construit à partir du nombre donné :

```python
my_float = 12.92563
my_int = int(my_float)

print(my_int)  # 12
print(type(my_int))  # <class 'int'>
```

Tu peux aussi utiliser les mêmes fonctions intégrées pour convertir une chaîne en flottant ou en entier :

```python
my_str_int = '45'
my_str_float = '7.8'

converted_int = int(my_str_int)
converted_float = float(my_str_float)

print(converted_int, type(converted_int))  # 45 <class 'int'>
print(converted_float, type(converted_float))  # 7.8 <class 'float'>
```

Voici d'autres méthodes que Python fournit pour travailler avec les entiers et les flottants.

- `round()` : arrondit un nombre au nombre de décimales spécifié. Par défaut, cette fonction arrondit à l'entier le plus proche et renvoie un nombre entier sans décimales :

```python
my_int_1 = 4.798
my_int_2 = 4.253

rounded_int_1 = round(my_int_1)
rounded_int_2 = round(my_int_2, 1)

print(rounded_int_1) # 5
print(rounded_int_2) # 4.3
```

- `abs()` : renvoie la valeur absolue d'un nombre,

```python
num = -15

absolute_value = abs(num)
print(absolute_value) # 15
```

- `pow()` : élève un nombre à la puissance d'un autre ou effectue une exponentiation modulaire.

```python
result_1 = pow(2, 3)  # Equivalent to 2 ** 3
print(result_1)  # 8

result_2 = pow(2, 3, 5)  # (2 ** 3) % 5
print(result_2)  # 3
```
