## Travailler avec HTML, CSS et JavaScript

Alors que HTML et CSS fournissent la structure d'un site web, JavaScript apporte de l'interactivité aux sites web en permettant des fonctionnalités complexes, comme la gestion des saisies de l'utilisateur, l'animation d'éléments, et même la création d'applications web complètes.

## Les types de données en JavaScript

Les types de données aident le programme à comprendre le genre de données qu'il manipule, qu'il s'agisse d'un nombre, de texte ou d'autre chose.

- **Number** : un nombre représente à la fois les entiers et les valeurs à virgule flottante. Des exemples d'entiers incluent 7, 19 et 90.
- **Floating point** : un nombre à virgule flottante est un nombre comportant une virgule décimale. Des exemples incluent 3.14, 0.5 et 0.0001.
- **String** : une chaîne est une séquence de caractères, ou du texte, entourée de guillemets. `"I like coding"` et `'JavaScript is fun'` sont des exemples de chaînes.
- **Boolean** : un booléen représente l'une de deux valeurs possibles : `true` ou `false`. Tu peux utiliser un booléen pour représenter une condition, comme `isLoggedIn = true`.
- **Undefined and Null** : une valeur `undefined` est une variable qui a été déclarée mais à laquelle aucune valeur n'a été affectée. Une valeur `null` est une valeur vide, ou une variable à laquelle on a intentionnellement affecté la valeur `null`.
- **Object** : un objet est une collection de paires clé-valeur. La clé est le nom de la propriété, et la valeur est la valeur de la propriété.

Ici, l'objet `pet` a trois propriétés ou clés : `name`, `age` et `type`. Les valeurs sont respectivement `Fluffy`, `3` et `dog`.

```js
let pet = {
  name: "Fluffy",
  age: 3,
  type: "dog"
};
```

- **Symbol** : le type de données Symbol est une valeur unique et immuable qui peut être utilisée comme identifiant pour les propriétés d'un objet.

Dans l'exemple ci-dessous, deux symboles sont créés avec la même description, mais ils ne sont pas égaux.

:::interactive_editor

```js
const crypticKey1= Symbol("saltNpepper");
const crypticKey2= Symbol("saltNpepper");
console.log(crypticKey1 === crypticKey2); // false
```

:::

- **BigInt** : quand le nombre est trop grand pour le type de données `Number`, tu peux utiliser le type de données BigInt pour représenter des entiers d'une longueur arbitraire.

En ajoutant un `n` à la fin du nombre, tu peux créer un BigInt.

```js
const veryBigNumber = 1234567890123456789012345678901234567890n;
```

## Les variables en JavaScript

- Les variables peuvent être déclarées à l'aide du mot-clé `let`.

```js
let cityName;
```

- Pour affecter une valeur à une variable, tu peux utiliser l'opérateur d'affectation `=`.

```js
cityName = "New York";
```

- Les variables déclarées avec `let` peuvent être réaffectées à une nouvelle valeur.

:::interactive_editor

```js
let cityName = "New York";
cityName = "Los Angeles";
console.log(cityName); // Los Angeles
```

:::

- En dehors de `let`, tu peux aussi utiliser `const` pour déclarer une variable. Cependant, une variable `const` ne peut pas être réaffectée à une nouvelle valeur.

```js
const cityName = "New York";
cityName = "Los Angeles"; // TypeError: Assignment to constant variable.
```

- Les variables déclarées avec `const` servent à déclarer des constantes, qui ne sont pas autorisées à changer tout au long du code, comme `PI` ou `MAX_SIZE`.

## Les conventions de nommage des variables

- Les noms de variables doivent être descriptifs et significatifs.
- Les noms de variables doivent être en camelCase, comme `cityName`, `isLoggedIn` et `veryBigNumber`.
- Les noms de variables ne doivent pas commencer par un chiffre. Ils doivent commencer par une lettre, `_` ou `$`.
- Les noms de variables ne doivent pas contenir d'espaces ni de caractères spéciaux, à l'exception de `_` et `$`.
- Les noms de variables ne doivent pas être des mots-clés réservés.
- Les noms de variables sont sensibles à la casse. `age` et `Age` sont des variables différentes.

## Les chaînes et l'immuabilité des chaînes en JavaScript

- Les chaînes sont des séquences de caractères entourées de guillemets. Elles peuvent être créées avec des guillemets simples ou des guillemets doubles.

```js
let correctWay = 'This is a string';
let alsoCorrect = "This is also a string";
```

- Les chaînes sont immuables en JavaScript. Cela signifie qu'une fois qu'une chaîne est créée, tu ne peux pas modifier les caractères de la chaîne. Cependant, tu peux quand même réaffecter une chaîne à une nouvelle valeur.

```js
let firstName = "John";
firstName = "Jane"; // Reassigning the string to a new value
```

## La concaténation de chaînes en JavaScript

- La concaténation est le procédé qui consiste à joindre plusieurs chaînes ou à combiner des chaînes avec des variables qui contiennent du texte. L'opérateur `+` est l'une des méthodes les plus simples et les plus fréquemment utilisées pour concaténer des chaînes.

:::interactive_editor

```js
let studentName = "Asad";
let studentAge = 25;
let studentInfo = studentName + " is " + studentAge + " years old.";
console.log(studentInfo); // Asad is 25 years old.
```

:::

- Si tu as besoin d'ajouter du texte à une chaîne existante, tu peux utiliser l'opérateur `+=`. C'est utile quand tu veux enrichir une chaîne en lui ajoutant davantage de texte au fil du temps.

:::interactive_editor

```js
let message = "Welcome to programming, ";
message += "Asad!";
console.log(message); // Welcome to programming, Asad!
```

:::

- Une autre façon de concaténer des chaînes est d'utiliser la méthode `concat()`. Cette méthode joint deux chaînes ou plus ensemble.

:::interactive_editor

```js
let firstName = "John";
let lastName = "Doe";
let fullName = firstName.concat(" ", lastName);
console.log(fullName); // John Doe
```

:::

## Afficher des messages avec `console.log()`

- La méthode `console.log()` est utilisée pour afficher des messages dans la console. C'est un outil utile pour déboguer et tester ton code.

:::interactive_editor

```js
console.log("Hello, World!");
// Output: Hello, World!
```

:::

## Les points-virgules en JavaScript

- Les points-virgules servent principalement à marquer la fin d'une instruction. Cela aide le moteur JavaScript à comprendre la séparation entre les instructions individuelles, ce qui est crucial pour une exécution correcte.

```js
let message = "Hello, World!"; // first statement ends here
let number = 42; // second statement starts here
```

- Les points-virgules aident à éviter les ambiguïtés dans l'exécution du code et garantissent que les instructions sont correctement terminées.

## Les commentaires en JavaScript

- Toute ligne de code mise en commentaire est ignorée par le moteur JavaScript. Les commentaires servent à expliquer le code, à prendre des notes ou à désactiver temporairement du code.
- Les commentaires sur une seule ligne se créent avec `//`.

```js
// This is a single-line comment and will be ignored by the JavaScript engine
```

- Les commentaires multilignes se créent avec `/*` pour commencer le commentaire et `*/` pour le terminer.

```js
/*
This is a multi-line comment.
It can span multiple lines.
*/
```

## JavaScript, un langage à typage dynamique

- JavaScript est un langage à typage dynamique, ce qui signifie que tu n'as pas besoin de préciser le type de données d'une variable quand tu la déclares. Le moteur JavaScript détermine automatiquement le type de données en fonction de la valeur affectée à la variable.

```js
let error = 404; // JavaScript treats error as a number
error = "Not Found"; // JavaScript now treats error as a string
```

- D'autres langages, comme C#, qui ne sont pas à typage dynamique généreraient une erreur :

```csharp
int error = 404; // value must always be an integer
error = "Not Found"; // This would cause an error in C#
```

## Utiliser l'opérateur `typeof`

- L'opérateur `typeof` est utilisé pour vérifier le type de données d'une variable. Il renvoie une chaîne indiquant le type de la variable.

:::interactive_editor

```js
let age = 25;
console.log(typeof age); // "number"

let isLoggedIn = true;
console.log(typeof isLoggedIn); // "boolean"
```

:::

- Cependant, il existe une bizarrerie bien connue en JavaScript en ce qui concerne `null`. L'opérateur `typeof` renvoie `"object"` pour les valeurs `null`.

:::interactive_editor

```js
let user = null;
console.log(typeof user); // "object"
```
