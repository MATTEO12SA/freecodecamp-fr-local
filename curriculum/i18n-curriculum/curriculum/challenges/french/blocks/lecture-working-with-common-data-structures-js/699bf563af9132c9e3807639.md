# --description--

Les tableaux sont une structure de données fondamentale en informatique. Tous les tableaux stockent des collections ordonnées de données, mais selon leur type, ils peuvent fonctionner différemment en coulisses.

Leur comportement sous-jacent peut avoir un effet important sur l'efficacité du programme, alors apprenons les tableaux dynamiques et statiques et leurs différences, pour que tu puisses choisir le plus efficace pour ton programme.

Nous commencerons par les tableaux statiques.

Les **tableaux statiques** ont une taille fixe. Ils stockent les éléments dans des emplacements mémoire adjacents.

La taille d'un tableau statique est déterminée quand le tableau est initialisé. Une fois ce bloc de mémoire spécifique alloué, il est fixe et ne peut pas être modifié pendant l'exécution du programme. C'est une caractéristique clé des tableaux statiques.

Stocker les éléments dans des emplacements mémoire adjacents rend le processus de récupération des données plus efficace, car le programme peut stocker l'emplacement du premier élément puis utiliser des indices pour faire des calculs simples et trouver les autres éléments en mémoire.

Grâce à cela, accéder aux valeurs d'un tableau statique prend un temps constant `O(1)`, ce qui est très efficace.

Tu peux utiliser un tableau statique quand tu connais à l'avance le nombre d'éléments qui seront stockés. C'est aussi utile quand les valeurs seront consultées très fréquemment, puisque l'opération d'accès est très efficace.

Cependant, cette structure de données ne peut ni grandir ni rétrécir, donc si le nombre d'éléments à stocker peut varier, tu devrais plutôt utiliser un tableau dynamique.

Essayer d'augmenter la taille d'un tableau statique impliquerait de créer un nouveau tableau et de copier tous les éléments de l'ancien vers le nouveau, ce qui est inefficace. Dans ce cas, un tableau dynamique serait bien meilleur car il gère ce processus automatiquement.

JavaScript n'a pas de tableaux statiques traditionnels de bas niveau comme C ou Java, mais tu peux simuler un tableau de taille fixe avec l'objet intégré `Array` :

```js
let numbers = new Array(3); // fixed size of 3
numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;
```

Bien que JavaScript permette le redimensionnement, conceptuellement cela représente un tableau de longueur fixe.

Les tableaux en JavaScript sont dynamiques par défaut, alors regardons ceux-là.

Les **tableaux dynamiques** sont plus flexibles car ils peuvent grandir ou rétrécir automatiquement pendant l'exécution du programme.

Ils fonctionnent via un mécanisme de redimensionnement automatique qui copie les éléments dans un nouveau tableau quand le tableau d'origine est plein. Le processus est fait efficacement car la taille du nouveau tableau est choisie de façon efficace, ce qui rend ces opérations coûteuses en calcul moins fréquentes.

Accéder aux éléments d'un tableau dynamique prend un temps constant `O(1)`, donc cette opération est très efficace.

Insérer un élément au milieu du tableau prend un temps linéaire `O(n)` car les éléments après lui doivent être déplacés.

Insérer un élément à la fin du tableau prend un temps constant `O(1)` s'il reste de l'espace disponible dans le tableau dynamique, mais si le tableau est plein et doit être redimensionné, cette opération a une complexité `O(n)`.

Tu devrais utiliser des tableaux dynamiques quand tu ne connais pas à l'avance le nombre de valeurs que tu auras besoin de stocker dans le tableau. Ils sont aussi utiles quand tu vas fréquemment insérer et supprimer des éléments.

Pour créer un tableau en JavaScript, tu écris les éléments entre crochets, séparés par des virgules :

```js
let numbers = [3, 4, 5, 6];
```

Cela crée un tableau dynamique avec quatre éléments.

Tu peux accéder à un élément du tableau en écrivant le nom de la variable, suivi de crochets contenant l'indice.

Les indices commencent à 0 pour le premier élément et augmentent de 1 pour chaque élément suivant.

```js
numbers[0]; // 3
numbers[1]; // 4
numbers[2]; // 5
numbers[3]; // 6
```

Pour mettre à jour une valeur, tu as juste besoin de la réassigner :

```js
numbers[2] = 16
```

Maintenant, le tableau devient `[3, 4, 16, 6]`.

Pour ajouter un élément à la fin du tableau, utilise la méthode `.push()` :

```js
numbers.push(7)
```

Maintenant le tableau devient `[3, 4, 16, 6, 7]` :

Pour insérer des éléments à un index spécifique, JavaScript n'a pas de `.insert()` comme Python, mais tu peux utiliser la méthode `.splice()`. La syntaxe ressemble à ceci :

```js
array.splice(index, deleteCount, newElement)
```

Voici un exemple :

```js
numbers.splice(3, 0, 15);
```

Cet exemple signifie :

- Commencer à l'index 3
- Supprimer 0 éléments
- Insérer 15

Si le tableau était `[3, 4, 16, 6, 7]`, il devient maintenant `[3, 4, 16, 15, 6, 7]`.

Tu peux supprimer un élément à un index spécifique avec la même méthode `.splice` :

```js
numbers.splice(2, 1);
```

Cela signifie commencer à l'index 2 et supprimer 1 élément.

Pour supprimer le dernier élément, utilise la méthode `.pop()` :

```js
numbers.pop();
```

Il existe plein d'autres méthodes de tableau intégrées que tu peux consulter dans la documentation pour travailler avec les tableaux en JavaScript.

C'est ça la puissance des tableaux dynamiques.

En général, tu devrais utiliser des tableaux statiques quand tu connais le nombre d'éléments à l'avance et que tu dois y accéder fréquemment, et utiliser des tableaux dynamiques quand le nombre d'éléments est inconnu ou variable dans le temps.

Tu devrais toujours considérer le compromis entre la simplicité des tableaux statiques et la flexibilité des tableaux dynamiques. Ils sont tous les deux utiles pour des cas d'usage et des scénarios spécifiques. Être capable de choisir le meilleur pour un problème donné fait partie des compétences de résolution de problèmes que tu développeras progressivement avec la pratique.
