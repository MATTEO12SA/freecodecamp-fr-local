## Constructeur `Audio` et méthodes courantes

- **Définition** : le constructeur `Audio`, comme les autres constructeurs, est une fonction spéciale appelée avec le mot-clé `new`. Il renvoie un `HTMLAudioElement`, que tu peux ensuite utiliser pour lire de l'audio pour l'utilisateur ou ajouter au DOM pour que l'utilisateur le contrôle lui-même. Quand tu appelles le constructeur, tu peux éventuellement passer une URL comme (seul) argument. Cette URL doit pointer vers la source du fichier audio que tu veux lire. Ou, si tu as besoin de changer la source dynamiquement, tu peux assigner l'URL à la propriété `src` de l'élément audio renvoyé.
- **Méthode `play()`** : cette méthode s'utilise avec les éléments `audio` ou `video` pour démarrer la lecture du média.

:::interactive_editor

```html
<audio id="audio" controls>
  <source src="https://www.w3schools.com/html/horse.mp3" type="audio/mpeg">
</audio>

<button id="playBtn">Play Audio</button>

<script>
  const audio = document.getElementById("audio");
  const playBtn = document.getElementById("playBtn");

  playBtn.addEventListener("click", () => {
    audio.play();
  });
</script>
```

:::

- **Méthode `pause()`** : cette méthode s'utilise avec les éléments `audio` ou `video` pour mettre en pause la lecture du média. Elle conserve la position actuelle, donc si `play()` est appelé, la lecture reprend à partir de cette position.

:::interactive_editor

```html
<audio id="myAudio" controls>
  <source src="https://www.w3schools.com/html/horse.mp3" type="audio/mpeg">
</audio>

<br>

<button id="pauseBtn">Pause Audio</button>

<script>
  document.addEventListener("DOMContentLoaded", () => {
    const audio = document.getElementById("myAudio");
    const pauseBtn = document.getElementById("pauseBtn");

    pauseBtn.addEventListener("click", () => {
      audio.pause();
    });
  });
</script>
```

:::

- **Méthode `addTextTrack()`** : cette méthode te permet de spécifier une piste de texte à associer à l'élément média — ce qui est particulièrement utile pour ajouter des sous-titres à une vidéo.
- **Méthode `fastSeek()`** : cette méthode te permet de déplacer la position de lecture à un moment précis dans le média.

Le constructeur `Audio()` a des propriétés tout comme il a des méthodes. Ces propriétés incluent :

- `currentTime` : pour obtenir le temps de lecture actuel d'un audio
- `loop` : pour faire jouer l'audio en continu en le redémarrant automatiquement quand il atteint la fin
- `muted` : pour couper la sortie audio d'un élément média, indépendamment du réglage de volume

## Différents formats audio et vidéo

- **Type MIME** : un type MIME, pour Multipurpose Internet Mail Extensions, est une façon standardisée d'indiquer programmatiquement un type de fichier. Le type MIME peut indiquer à une application, comme ton navigateur, comment gérer un fichier spécifique. Dans le cas de l'audio et de la vidéo, le type MIME indique qu'il s'agit d'un format multimédia qui peut être intégré dans la page web.
- **Élément `source`** : il sert à spécifier un type de fichier et une source — et tu peux inclure plusieurs types différents en utilisant plusieurs éléments source. Quand tu fais cela, le navigateur déterminera le meilleur format à utiliser pour l'environnement actuel de l'utilisateur.
- **MP3** : c'est un type de format de fichier numérique utilisé pour stocker de la musique, de l'audio ou du son. C'est une version compressée d'un enregistrement sonore qui réduit la taille du fichier, ce qui le rend plus facile à stocker et à partager. Le MP3 a le support navigateur le plus large et le type MIME `audio/mpeg`.
- **MP4** : un MP4 est un type de format de fichier numérique utilisé pour stocker de la vidéo et de l'audio. Il sert de conteneur qui regroupe à la fois la vidéo (images) et le son (musique ou parole) dans un seul fichier. Un MP4 peut avoir le type MIME `audio/mp4` OU `video/mp4`, selon qu'il s'agit d'un fichier vidéo ou audio uniquement.
- D'autres formats sont `WMV`, associé à l'application Windows Media Player, `OGG`, `MKV`, `AVI`, et bien d'autres.

## Codecs

- **Définition** : un codec, abréviation de « encoder/decoder », est un algorithme ou un logiciel qui peut convertir l'audio et la vidéo entre formats analogiques et numériques. Les codecs peuvent être spécifiés dans le type MIME. La syntaxe de base pour définir un codec est d'ajouter un point-virgule après le type de média, puis `codecs=` et le codec.

## API HTMLMediaElement

- **Définition** : l'API `HTMLMediaElement` sert à contrôler le comportement des éléments audio et vidéo sur ta page. Elle étend l'interface de base `HTMLElement`, donc tu as accès aux propriétés et méthodes de base ainsi qu'à des événements utiles comme `waiting`, `ended`, `canplay`, `canplaythrough`, et plus encore. Des exemples de méthodes incluent `play()`, `fastSeek()`, `pause()`, et `canPlayType()` pour vérifier si un navigateur est susceptible de pouvoir lire un fichier audio.

## API Media Capture and Streams

- **Définition** : l'API Media Capture and Streams, ou l'API MediaStream, sert à capturer de l'audio et de la vidéo depuis ton appareil. Pour utiliser l'API, tu dois créer l'objet `MediaStream`. Tu pourrais le faire avec le constructeur, mais il ne serait pas lié au matériel de l'utilisateur. À la place, la propriété `mediaDevices` de l'objet `global` navigator a une méthode `getUserMedia()` à utiliser.

```js
window.navigator.mediaDevices.getUserMedia({
  audio: true,
  video: {
    width: {
      min: 1280,
      ideal: 1920,
      max: 3840
    },
    height: {
      min: 720,
      ideal: 1080,
      max: 2160
    }
  }
});
```

## API Screen Capture

- **Définition** : l'API Screen Capture sert à enregistrer l'écran d'un utilisateur. Cette API est exposée en appelant la méthode `getDisplayMedia()` de l'objet `mediaDevices` et en consommant le flux média renvoyé.

## API MediaStream Recording

- **Définition** : l'API MediaStream Recording fonctionne de concert avec les API MediaStreams, te permettant d'enregistrer un MediaStream (ou même un `HTMLMediaElement` directement).

## API Media Source Extensions

- **Sujet** : l'API Media Source Extensions est ce qui te permet de passer directement le flux de la webcam d'un utilisateur à un élément vidéo avec la propriété `srcObject`.

## API Web Audio

- **Définition** : l'API Web Audio alimente tout ce qui est audible sur le web. Cette API inclut des objets importants comme un `AudioBuffer` (représentant un Buffer contenant spécifiquement des données audio) ou l'`AudioContext`, utilisé pour représenter un graphe de traitement audio.
