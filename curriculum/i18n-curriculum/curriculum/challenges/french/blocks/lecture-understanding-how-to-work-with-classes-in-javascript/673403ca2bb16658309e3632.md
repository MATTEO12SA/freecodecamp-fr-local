# --interactive--

Tu as appris que les classes sont comme des plans que tu peux utiliser pour créer des objets.

Ces plans ont besoin d'un moyen général de faire référence à l'objet spécifique qui est créé, consulté ou modifié dans le code. C'est exactement à cela que sert le mot-clé `this`. Il fait référence au contexte dans lequel le code est censé s'exécuter. Si tu l'utilises dans une méthode, la valeur de `this` sera une référence à l'objet associé à cette méthode. Ainsi, tu peux accéder aux propriétés et méthodes de l'objet au sein de la classe et réutiliser la méthode sur différents objets.

Par exemple, voici une classe `Dessert`. Cette fois, on définit une propriété `hasPeanuts`.

```js
class Dessert {
  constructor(hasPeanuts) {
    this.hasPeanuts = hasPeanuts;
  }
}
```

Remarque qu'on utilise le mot-clé `this` dans le constructeur. Souviens-toi que le constructeur est appelé automatiquement lorsqu'un nouvel objet de la classe est créé.

Le mot-clé `this` indique au programme que `hasPeanuts` doit être une propriété de l'objet actuellement en cours de création.

Le côté droit de l'instruction d'affectation assigne la valeur du paramètre `hasPeanuts` à la propriété `hasPeanuts` du nouvel objet.

```js
this.hasPeanuts = hasPeanuts;
```

C'est dans le contexte du constructeur, mais tu peux aussi utiliser le mot-clé `this` dans d'autres méthodes.

Voici notre classe `Dessert` avec quelques changements. On a maintenant deux propriétés : `name` et `price`.

```js
class Dessert {
  constructor(name, price) {
    this.name = name;
    this.price = price;
  }

  showPrice() {
    console.log(`The price of ${this.name} is $${this.price}.`);
  }
}
```

On a aussi une nouvelle méthode `showPrice`. Dans cette méthode, on affiche un message descriptif dans la console avec le nom et le prix de l'objet dessert.

Remarque comment on utilise le mot-clé `this` pour accéder aux propriétés de l'objet dans la méthode `showPrice`.

Quelle valeur aura le mot-clé `this` dans le contexte de cette méthode ? Il fera référence à l'objet sur lequel la méthode est appelée. Dans ce cas, on crée une nouvelle instance de Dessert avec le nom `"Brownie"` et le prix `$5.99` :

```js
const brownie = new Dessert("Brownie", 5.99);
```

Si on appelle la méthode `.showPrice()` sur cet objet :

```js
brownie.showPrice();
```

Voici l'exemple complet :

:::interactive_editor

```js
class Dessert {
  constructor(name, price) {
    this.name = name;
    this.price = price;
  }

  showPrice() {
    console.log(`The price of ${this.name} is $${this.price}.`);
  }
}

const brownie = new Dessert("Brownie", 5.99);
brownie.showPrice();
console.log(brownie);
```

:::

Le nom et le prix de l'objet courant (`brownie`) sont remplacés dans la chaîne.

Tout cela grâce au mot-clé `this`, qui te donne un moyen général de faire référence à l'objet courant au sein de la classe. Cela te permet de réutiliser la méthode sur différents objets.

C'est dans le contexte des méthodes d'objet, mais le mot-clé `this` aura aussi une valeur dans les fonctions autonomes et les fonctions fléchées.

Sa valeur dans une fonction autonome fait typiquement référence à l'objet global (en mode non strict) ou à `undefined` (en mode strict).

La valeur du mot-clé `this` est un peu différente dans les fonctions fléchées. Les fonctions fléchées héritent de la valeur de `this` du scope englobant où elles sont définies. Elles ne créent pas leur propre liaison `this`. Cela signifie que la valeur de `this` dépend du contexte où la fonction fléchée est définie, et non de l'endroit ni de la façon dont elle est appelée. Cela rend les fonctions fléchées utiles pour les callbacks ou pour préserver le contexte.

Cependant, pour cette raison, la valeur de `this` ne fera pas référence à l'objet courant dans les méthodes d'objet, donc c'est quelque chose à garder à l'esprit lorsque tu travailles avec des fonctions fléchées.

La même chose s'applique aux fonctions fléchées définies à l'intérieur d'autres fonctions. Elles hériteront de la valeur de `this` de leur scope parent.

Le mot-clé `this` est un outil puissant pour accéder et manipuler les objets. Comprendre son fonctionnement est essentiel pour maîtriser la programmation orientée objet en JavaScript.
