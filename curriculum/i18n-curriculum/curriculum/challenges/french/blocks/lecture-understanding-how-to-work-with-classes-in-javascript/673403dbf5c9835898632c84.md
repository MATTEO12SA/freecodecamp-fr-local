# --interactive--

Les propriétés et méthodes statiques appartiennent à la classe elle-même, et non aux instances individuelles de la classe. Tu peux y accéder directement via le nom de la classe sans créer d'instance. Elles sont définies dans les classes pour encapsuler des fonctionnalités liées.

Tu peux définir une méthode statique en écrivant le mot-clé `static` avant le nom de la méthode.

```js
class MyClass {
  static staticMethod() { ... }
}
```

Ensuite, tu peux appeler la méthode statique directement sur la classe, avec la notation point et en passant les arguments nécessaires :

```js
MyClass.staticMethod();
```

Remarque que tu peux appeler la méthode sans créer d'instance de la classe. C'est l'une des caractéristiques clés des méthodes statiques.

Voici un exemple. Disons qu'on crée une application de films et qu'on veut pouvoir comparer des films selon leur note.

On pourrait considérer cette méthode de comparaison comme une méthode de plus haut niveau qui n'est pas spécifique à un film en particulier :

```js
if (movieA.rating < movieB.rating) {
  console.log(`${movieB.title} has a higher rating.`);
}
```

C'est comme une méthode plus générale liée à la classe `Movie`.

Pour la lisibilité et la maintenabilité, il serait utile de la définir dans la classe `Movie` afin de garder toutes les méthodes liées relativement proches les unes des autres.

Par conséquent, c'est un candidat parfait pour une méthode statique. Tu peux la voir ici, juste sous le constructeur :

:::interactive_editor

```js
class Movie {

  constructor(title, rating) {
    this.title = title;
    this.rating = rating;
  }

  static compareMovies(movieA, movieB) {
    if (movieA.rating > movieB.rating) {
      console.log(`${movieA.title} has a higher rating.`);
    } else if (movieA.rating < movieB.rating) {
      console.log(`${movieB.title} has a higher rating.`);
    } else {
      console.log("These movies have the same rating.");
    }
  }

}

let movieA = new Movie("Movie A", 80);
let movieB = new Movie("Movie B", 45);
console.log(movieA);
```

:::

La méthode statique est définie avec le mot-clé `static` et s'appelle `compareMovies`. Elle a deux paramètres : `movieA` et `movieB`. Ce seront des instances de la classe `Movie`.

On les comparera selon leur note, sur une échelle de `0` à `100`. Cette logique est implémentée avec une conditionnelle et affichera un message approprié selon quel film a la note la plus élevée.

Une fois la méthode définie, tu peux l'appeler sur la classe. Mais d'abord, tu dois avoir les arguments prêts et définis dans ton programme.

Dans ce cas, la méthode prend deux instances de film comme arguments, donc on définit ces instances ici :

```js
let movieA = new Movie("Movie A", 80);
let movieB = new Movie("Movie B", 45);
```

Tu peux voir que `movieA` a une note plus élevée que `movieB`. Voyons la sortie de cette méthode.

Pour appeler la méthode, tu n'as qu'à utiliser la notation point sur la classe elle-même.
Tu écris le nom de la classe (`Movie`), suivi d'un point, puis le nom de la méthode statique (`compareMovies`).

Ensuite, tu passes les arguments entre parenthèses. Dans ce cas, ce sont les deux instances de film dont la méthode a besoin.

```js
Movie.compareMovies(movieA, movieB);
```

Voici l'exemple mis à jour :

:::interactive_editor

```js
class Movie {

  constructor(title, rating) {
    this.title = title;
    this.rating = rating;
  }

  static compareMovies(movieA, movieB) {
    if (movieA.rating > movieB.rating) {
      console.log(`${movieA.title} has a higher rating.`);
    } else if (movieA.rating < movieB.rating) {
      console.log(`${movieB.title} has a higher rating.`);
    } else {
      console.log("These movies have the same rating.");
    }
  }

}

let movieA = new Movie("Movie A", 80);
let movieB = new Movie("Movie B", 45);
Movie.compareMovies(movieA, movieB);
console.log(movieA);
```

:::

Les méthodes statiques sont aussi utiles pour implémenter des méthodes « factory ». Une méthode factory est une méthode que tu définis en plus du constructeur pour créer des objets selon des critères spécifiques.

Voici un exemple avec une classe `Pizza`. La méthode statique `createMargherita` est une méthode factory que tu peux appeler pour créer une instance de pizza Margherita avec son type et son prix déjà définis.

```js
class Pizza {
  constructor(type, price) {
    this.type = type;
    this.price = price;
  }

  static createMargherita() {
    return new this("Margherita", 6.99);
  }
}
```

Cela met aussi en évidence quelque chose de très important à propos des méthodes statiques.

La valeur du mot-clé `this` dans les méthodes statiques est la classe elle-même, puisque la méthode statique appartient à la classe.

C'est pourquoi on peut utiliser `this` pour créer une nouvelle instance de la classe `Pizza`.

Si tu appelles cette méthode sur la classe `Pizza` elle-même et que tu assignes l'instance renvoyée à une variable, comme dans cet exemple :

```js
let myPizza = Pizza.createMargherita();
```

Tu peux l'utiliser partout où tu en as besoin dans ton code. Par exemple, tu peux l'afficher dans la console :

```js
console.log(myPizza);
```

Voici la sortie :

```js
Pizza { type: 'Margherita', price: 6.99 }
```

Tu peux aussi utiliser la notation point pour appeler ses méthodes et accéder à ses propriétés, comme ceci :

```js
console.log(myPizza.type);
```

Voici l'exemple complet :

```js
class Pizza {
  constructor(type, price) {
    this.type = type;
    this.price = price;
  }

  static createMargherita() {
    return new this("Margherita", 6.99);
  }
}

let myPizza = Pizza.createMargherita();
console.log(myPizza);
console.log(myPizza.type);
```

En plus des méthodes, tu peux aussi définir des propriétés statiques avec le mot-clé `static`.

Dans cet exemple, on a une propriété statique `numberOfPizzasSold`.

```js
class Pizza {
  static numberOfPizzasSold = 0;

  constructor(type) {
    this.type = type;
    Pizza.numberOfPizzasSold++;
  }
}
```

Elle est statique parce qu'elle n'appartient à aucune instance de pizza en particulier, elle appartient à la classe elle-même.

Elle a une valeur initiale de `0` et elle est mise à jour chaque fois qu'une nouvelle instance est créée.

Si tu crées deux instances de pizza, la valeur sera mise à jour deux fois :

```js
let pizza1 = new Pizza("Margherita");
let pizza2 = new Pizza("Neapolitan");
```

Pour accéder à la valeur d'une propriété statique, tu n'as qu'à utiliser la notation point sur la classe elle-même, puisque la propriété appartient à la classe.

```js
class Pizza {
  static numberOfPizzasSold = 0;

  constructor(type) {
    this.type = type;
    Pizza.numberOfPizzasSold++;
  }
}

let pizza1 = new Pizza("Margherita");
let pizza2 = new Pizza("Neapolitan");

console.log(Pizza.numberOfPizzasSold);
```

Dans ce cas, la sortie est `2` parce que deux pizzas ont été vendues.

Voilà les fondamentaux des propriétés et méthodes statiques en JavaScript. Comprendre les membres statiques est essentiel pour créer des classes réutilisables et efficaces.

## --text--

Quelle est la principale différence entre une méthode statique et une méthode d'instance en JavaScript ?

## --answers--

Les méthodes statiques ne peuvent être utilisées qu'à l'intérieur de la classe, tandis que les méthodes d'instance peuvent être utilisées à l'extérieur de la classe.
