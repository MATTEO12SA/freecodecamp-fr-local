# --interactive--

En JavaScript moderne, les classes sont comme des plans que tu peux définir dans le code pour créer plusieurs objets du même type.

Par exemple, si tu modélises un système d'inventaire, tu auras besoin de créer plusieurs objets par type de produit.

Chaque produit individuel aura ses propres propriétés et actions, mais les produits du même type peuvent être créés à partir du même « plan ». C'est à cela que servent les classes.

Les classes peuvent être définies soit comme une expression de classe, soit comme une déclaration de classe.

Voici la syntaxe de base d'une déclaration de classe :

```js
class MyClassName {
  // Class Methods
  constructor() { ... }
  method1() { ... }
  method2() { ... }
  ...
}
```

Tu commences par écrire le mot-clé `class` suivi du nom de la classe. Pour nommer les classes, tu dois utiliser la convention `PascalCase` plutôt que `camelCase`.

Le contenu entre les accolades s'appelle le corps de la classe. C'est là que vont le constructeur et les méthodes.

Le constructeur est une méthode spéciale qui est appelée automatiquement lorsqu'un nouvel objet est créé à partir de la classe. Il sert typiquement à initialiser les propriétés de l'objet.

Dans cet exemple, tu peux voir une classe `Dog` avec un constructeur.

```js
class Dog {
  constructor(name) {
    this.name = name;
  }
}
```

Le mot-clé `this` est utilisé ici pour faire référence à l'instance courante de la classe `Dog`, ce qui te permet d'assigner la propriété `name` à l'objet en cours de création. Tu en apprendras davantage sur le mot-clé `this` dans une prochaine leçon.

Sous le constructeur, tu peux avoir ce qu'on appelle des méthodes. Les méthodes sont des fonctions définies à l'intérieur d'une classe qui effectuent des actions ou des opérations. Elles servent à définir des comportements que les instances de la classe peuvent exécuter.

Voici un exemple d'ajout d'une méthode appelée `bark` à la classe `Dog`.

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}
```

Lorsque la méthode `bark` est appelée, le message sera affiché dans la console avec le nom réel qui lui a été passé. Si tu crées une instance de `Dog` avec le nom `"Buddy"`, appeler la méthode `bark()` sur cette instance affichera `"Buddy says woof!"` dans la console.

Une fois ta classe définie, tu peux créer une instance de la classe avec le mot-clé `new`, le nom de la classe et ses arguments.

Dans cet exemple, on crée une nouvelle instance de `Dog` avec le nom `Gino`, puis on l'assigne à la variable `dog`.

```js
const dog = new Dog("Gino");
```

Quand tu écris `new Dog("Gino")` dans ton code, le nouvel objet est créé et le constructeur est appelé automatiquement avec les arguments fournis.

Tu peux ensuite accéder à cette propriété avec la notation point, comme tu peux le voir dans la ligne de code suivante :

```js
console.log(dog.name);
```

Voici l'exemple complet :

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);
```

:::

Tu peux aussi appeler des méthodes. Dans cet exemple, on appelle la méthode `bark()` sur l'instance `dog`.

```js
dog.bark();
```

Voici l'exemple complet avec l'appel de méthode inclus :

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }
  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);
dog.bark();
```

:::

Comme mentionné plus tôt, tu peux aussi définir des classes sous forme d'expression de classe. Dans ce cas, la classe est anonyme et assignée à une variable.

Voici à quoi ressemble l'exemple précédent sous forme d'expression de classe :

```js
const Dog = class {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
};
```

La plupart du temps, tu utiliseras des déclarations de classe, mais comprendre les expressions de classe est aussi utile, car elles peuvent offrir plus de flexibilité, surtout dans des situations de programmation dynamique.

En utilisant les classes et en comprenant leur syntaxe de base, tu peux créer du code réutilisable, l'organiser en unités logiques et favoriser la modularité du code.
