# --interactive--

Les opérateurs de comparaison te permettent de comparer deux valeurs et de renvoyer un résultat `true` ou `false`. Tu peux ensuite utiliser le résultat pour prendre une décision ou contrôler le déroulement de ton programme. Tu utilises les comparaisons dans les instructions `if`, les boucles et bien d'autres situations où tu dois prendre des décisions en fonction de certaines conditions. Plongeons dans les opérateurs de comparaison les plus courants et voyons comment ils fonctionnent.

L'opérateur supérieur à, représenté par un chevron droit (`>`), vérifie si la valeur de gauche est supérieure à celle de droite :

:::interactive_editor

```js
let a = 6;
let b = 9;

console.log(a > b); // false
console.log(b > a); // true
```

:::

L'opérateur supérieur ou égal, représenté par un chevron droit et le signe égal (`>=`), vérifie si la valeur de gauche est supérieure ou égale à celle de droite :

:::interactive_editor

```js
let a = 6;
let b = 9;
let c = 6;

console.log(a >= b); // false
console.log(b >= a); // true
console.log(a >= c); // true
```

:::

L'opérateur inférieur à, représenté par un chevron gauche (`<`), fonctionne de manière similaire à `>`, mais à l'inverse. Il vérifie si la valeur de gauche est plus petite que celle de droite :

:::interactive_editor

```js
let a = 6;
let b = 9;

console.log(a < b); // true
console.log(b < a); // false
```

:::

L'opérateur inférieur ou égal, représenté par un chevron gauche et le signe égal (`<=`), vérifie si la valeur de gauche est inférieure ou égale à celle de droite :

:::interactive_editor

```js
let a = 6;
let b = 9;
let c = 6;

console.log(a <= b); // true
console.log(b <= a); // false
console.log(a <= c); // true
```

:::
