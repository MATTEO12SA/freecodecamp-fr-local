# --interactive--

Si tu travailles avec des nombres et que tu as besoin d'augmenter ou de diminuer une valeur de un, les opérateurs d'incrémentation et de décrémentation facilitent la tâche. Décomposons cela de manière simple.

Les opérateurs d'incrémentation et de décrémentation sont représentés respectivement par `++` et `--`. Tous deux te permettent d'ajuster la valeur d'une variable de `1`.

Au lieu d'écrire quelque chose comme `x = x + 1` ou `x = x - 1`, tu peux simplement utiliser `x++` pour ajouter `1`, ou `x--` pour soustraire `1`. C'est plus rapide, plus propre et plus facile à lire.

Il y a une subtilité dans le fonctionnement des opérateurs d'incrémentation et de décrémentation : ils existent sous deux formes, préfixe et postfixe, la différence résidant dans le moment où la valeur est mise à jour. Pour l'opérateur d'incrémentation, le préfixe est `++x` et le postfixe est `x++`.

Le préfixe (`++x`) augmente d'abord la valeur de la variable, puis renvoie une nouvelle valeur. Le postfixe (`x++`) renvoie d'abord la valeur actuelle de la variable, puis l'augmente :

:::interactive_editor

```js
let x = 5;

console.log(++x); // 6
console.log(x); // 6
```

:::

Dans le code ci-dessus, `++x` signifie « incrémenter `x` d'abord, puis l'utiliser ». Donc quand tu affiches `++x`, tu obtiens immédiatement la valeur incrémentée, c'est-à-dire `6`.

Maintenant, regardons un exemple utilisant le postfixe :

:::interactive_editor

```js
let y = 5;

console.log(y++); // 5
console.log(y); // 6
```

:::

Dans cet exemple, `y++` signifie « utiliser `y` d'abord, puis l'incrémenter ». Quand tu affiches `y++`, tu obtiens `5`, mais `y` devient `6` après cette ligne de code.

L'opérateur de décrémentation fait la même chose que l'incrémentation, sauf qu'il diminue la valeur de `1`. Là encore, il existe deux formes : le préfixe (`--x`) diminue d'abord la valeur de la variable, puis renvoie la nouvelle valeur. Et le postfixe (`x--`) renvoie d'abord la valeur actuelle, puis la diminue :

:::interactive_editor

```js
let x = 5;
console.log(--x); // 4
console.log(x); // 4

let y = 5;
console.log(y--); // 5
console.log(y); // 4
```

:::

Alors, lequel devrais-tu utiliser : le préfixe ou le postfixe ? Dans bien des cas, peu importe lequel tu utilises. Les deux font le travail. Cependant, si tu utilises la valeur immédiatement dans une expression, la différence devient importante. Regardons cet exemple :

:::interactive_editor

```js
let a = 5;
let b = ++a;
console.log(b); // 6 (a was incremented before assignment)

let c = 5;
let d = c++;
console.log(d); // 5 (c was incremented after assignment)
```

:::

Donc, si tu as besoin de la valeur mise à jour tout de suite, utilise le préfixe. Si tu veux d'abord la valeur actuelle et que l'incrémentation ne t'importe que plus tard, opte pour le postfixe.
