# --interactive--

En JavaScript, tous les opérateurs arithmétiques ont une forme d'affectation composée. Les opérateurs d'affectation composée offrent un raccourci concis pour effectuer une opération sur une variable, puis stocker le résultat dans cette même variable. Ils combinent l'opération et l'affectation en une forme plus courte comme `x += y`, qui équivaut à écrire `x = x + y` mais sans répéter le nom de la variable. Au lieu d'écrire quelque chose comme ceci :

:::interactive_editor

```js
let num = 5;
num = num + 2;

console.log(num); // 7
```

:::

Tu peux écrire quelque chose comme ceci :

:::interactive_editor

```js
let num = 5;
num += 2;

console.log(num); // 7
```

:::

Remarque comment `num += 2` combine en une seule étape l'addition et l'affectation. Cela fait gagner du temps et réduit l'encombrement dans ton code. Plongeons plus en détail dans les opérateurs d'affectation composée les plus courants en JavaScript.

Comme tu l'as déjà vu, l'opérateur `+=` te permet d'ajouter une valeur à une variable existante. Il est connu sous le nom d'opérateur d'affectation par addition. L'opérateur d'affectation par addition prend la valeur actuelle de la variable, y ajoute le nombre spécifié, puis réaffecte le résultat à la variable :

:::interactive_editor

```js
let total = 10;
total += 5;

console.log(total); // 15
```

:::

Comme tu peux le deviner, il existe un opérateur d'affectation par soustraction noté `-=`. L'opérateur d'affectation par soustraction soustrait la valeur spécifiée de la valeur actuelle de la variable et réaffecte la nouvelle valeur à la variable :

:::interactive_editor

```js
let score = 20;
score -= 7;

console.log(score); // 13
```

:::

Si tu n'utilisais pas l'affectation par soustraction, tu aurais fait quelque chose comme ceci :

:::interactive_editor

```js
let score = 20;
score = score - 7;

console.log(score); // 13
```

:::

L'opérateur d'affectation par multiplication est représenté par `*=`. Il multiplie la valeur actuelle de la variable par le nombre spécifié et la réaffecte à la variable :

:::interactive_editor

```js
let points = 5;
points *= 3;

console.log(points); // 15
```

:::

Enfin, il existe un opérateur d'affectation par division noté `/=`. Comme les autres avant lui, il te permet de diviser la valeur actuelle d'une variable par un nombre que tu spécifies, puis de réaffecter le résultat à la variable :

:::interactive_editor

```js
let balance = 100;
balance /= 4;

console.log(balance); // 25
```

:::

Souviens-toi qu'il existe un opérateur d'affectation composée pour chaque opérateur en JavaScript. Donc, en dehors des quatre déjà mentionnés, nous avons aussi :

- L'opérateur d'affectation par reste (`%=`), qui divise une variable par le nombre spécifié et affecte le reste à la variable.

- L'opérateur d'affectation par exposant (`**=`), qui élève une variable à la puissance du nombre spécifié et réaffecte le résultat à la variable.

- L'opérateur d'affectation ET bit à bit (`&=`), qui effectue une opération ET bit à bit avec le nombre spécifié et réaffecte le résultat à la variable.

- L'opérateur d'affectation OU bit à bit (`|=`), qui effectue une opération OU bit à bit avec le nombre spécifié et réaffecte le résultat à la variable.
