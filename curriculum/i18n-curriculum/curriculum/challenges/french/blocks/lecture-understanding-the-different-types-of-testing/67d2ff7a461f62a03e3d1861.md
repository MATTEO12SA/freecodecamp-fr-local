# --description--

Si une application logicielle est lente à répondre ou instable, cela mènera à une mauvaise expérience utilisateur. Les tests de performance consistent à tester la vitesse, la réactivité, la scalabilité et la stabilité d'une application sous différentes charges. L'objectif est de résoudre tout goulot d'étranglement de performance avant qu'il n'atteigne tes utilisateurs.

Dans cette leçon, on passera en revue quelques types de tests de performance.

Le premier type est le load testing. Une charge dans ce contexte désigne la quantité de travail ou de demande mise sur un système. Le load testing détermine comment un système se comporte en charge normale et en pic. L'objectif est d'analyser des métriques comme les temps de réponse et l'usage des ressources, et de déterminer si le build logiciel actuel est prêt ou non.

Un autre type est le stress testing. Tu testes ton application sous des charges extrêmes et tu vois comment le système répond. L'objectif est d'identifier les goulots d'étranglement et les vulnérabilités en testant le système au-delà de ses limites.

Le type suivant est le soak testing, aussi appelé endurance testing. C'est un type de load testing où tu testes le système avec une charge élevée pendant une période prolongée. L'objectif est de détecter d'éventuelles fuites mémoire et dégradations de performance.

Un autre type est le spike testing. Tu augmentes et diminues dramatiquement les charges et tu analyses les réactions du système. L'objectif est de voir si ton système échouera face à ces changements dramatiques de charge.

Enfin, il y a le breakpoint testing, aussi appelé capacity testing. La charge augmente lentement au fil du temps jusqu'au point où le système commence à échouer ou à se dégrader. L'objectif est de mieux comprendre les limites et capacités du système.

Ce ne sont que quelques types de tests de performance que tu peux faire sur tes applications. Comme la performance joue un rôle vital dans le développement logiciel, il est important de réaliser ces tests pour t'assurer que ton application n'a pas de problèmes majeurs et offre une expérience fluide aux utilisateurs.
