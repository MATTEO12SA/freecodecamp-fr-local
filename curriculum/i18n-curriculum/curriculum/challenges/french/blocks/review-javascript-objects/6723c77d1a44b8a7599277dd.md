## Les bases des objets

- **Définition** : un objet est une structure de données constituée de propriétés. Une propriété se compose d'une clé et d'une valeur. Pour accéder aux données d'un objet, tu peux utiliser soit la notation par point, soit la notation par crochets.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  city: "New York"
};

console.log(person.name);  // Alice
console.log(person["name"]); // Alice
```

:::

Pour définir une propriété d'un objet existant, tu peux utiliser soit la notation par point, soit la notation par crochets, avec l'opérateur d'affectation.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30
};

person.job = "Engineer"
person["hobby"] = "Knitting"
console.log(person);  // {name: 'Alice', age: 30, job: 'Engineer', hobby: 'Knitting'}
```

:::

## Supprimer des propriétés d'un objet

- **Opérateur `delete`** : cet opérateur est utilisé pour supprimer une propriété d'un objet.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  job: "Engineer"
};

delete person.job;

console.log(person.job); // undefined
```

:::

## Vérifier si un objet possède une propriété

- **Méthode `hasOwnProperty()`** : cette méthode retourne un booléen indiquant si l'objet possède la propriété spécifiée comme propriété propre.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30
};

console.log(person.hasOwnProperty("name")); // true
console.log(person.hasOwnProperty("job")); // false
```

:::

- **Méthode `Object.hasOwn()`** : c'est la façon moderne et recommandée de vérifier si un objet possède une propriété comme propriété propre (non héritée). La syntaxe est `Object.hasOwn(object, propertyName)`. Elle retourne `true` si la propriété existe sur l'objet et `false` sinon — quelle que soit la valeur de la propriété. Cela la rend plus sûre que `hasOwnProperty()` et plus fiable que `if (obj.prop)` lorsque les valeurs peuvent être `0`, `false`, `null` ou `undefined`.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30
};

console.log(Object.hasOwn(person, "name")); // true
console.log(Object.hasOwn(person, "job")); // false
```

:::

Voici un exemple plus détaillé montrant pourquoi `Object.hasOwn()` est plus fiable que vérifier la valeur directement :

:::interactive_editor

```js
const settings = {
  darkMode: false,
  fontSize: 0,
  language: null
};

// Object.hasOwn() correctly sees these properties exist
console.log(Object.hasOwn(settings, "darkMode")); // true (value is false, but exists)
console.log(Object.hasOwn(settings, "fontSize")); // true (value is 0, but exists)
console.log(Object.hasOwn(settings, "theme"));    // false (property was never added)

// Using if() directly is unsafe for falsy values!
if (settings.darkMode) {
  console.log("Dark mode on"); // Does NOT print — misleading!
}

// Object.hasOwn() is the safe way
if (Object.hasOwn(settings, "darkMode")) {
  console.log("darkMode exists, value is:", settings.darkMode); // darkMode exists, value is: false
}
```

:::

- **Opérateur `in`** : cet opérateur retourne `true` si la propriété existe dans l'objet.

:::interactive_editor

```js
const person = {
  name: "Bob",
  age: 25
};

console.log("name" in person);  // true
```

:::

## Accéder aux propriétés d'objets imbriqués

- **Accéder aux données** : accéder aux propriétés d'objets imbriqués implique d'utiliser la notation par point ou la notation par crochets, tout comme pour accéder aux propriétés d'objets simples. Cependant, tu devras enchaîner ces accesseurs pour descendre dans la structure imbriquée.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  contact: {
    email: "alice@example.com",
    phone: {
      home: "123-456-7890",
      work: "098-765-4321"
    }
  }
};

console.log(person.contact.phone.work); // "098-765-4321"
```

:::

## Les types de données primitifs et non primitifs

- **Types de données primitifs** : ces types de données incluent les nombres, les chaînes, les booléens, `null`, `undefined` et les symboles. Ces types sont appelés « primitifs » parce qu'ils représentent des valeurs uniques et ne sont pas des objets. Les valeurs primitives sont immuables, ce qui signifie qu'une fois créées, leur valeur ne peut pas être modifiée.
- **Types de données non primitifs** : en JavaScript, ce sont les objets, qui incluent les objets classiques, les tableaux et les fonctions. Contrairement aux primitifs, les types non primitifs peuvent contenir plusieurs valeurs sous forme de propriétés ou d'éléments.

## Les méthodes d'objet

- **Définition** : les méthodes d'objet sont des fonctions associées à un objet. Elles sont définies comme des propriétés d'un objet et peuvent accéder aux données de l'objet et les manipuler. Le mot-clé `this` à l'intérieur de la méthode fait référence à l'objet lui-même, permettant d'accéder à ses propriétés.

:::interactive_editor

```js
const person = {
  name: "Bob",
  age: 30,
  sayHello: function() {
    return "Hello, my name is " + this.name;
  }
};

console.log(person.sayHello()); // "Hello, my name is Bob"
```

:::

## Le constructeur d'objet

- **Définition** : en JavaScript, un constructeur est un type spécial de fonction utilisé pour créer et initialiser des objets. Il est invoqué avec le mot-clé `new` et peut initialiser des propriétés et des méthodes sur l'objet nouvellement créé. Le constructeur `Object()` crée un nouvel objet vide.

```js
new Object()
```

## Travailler avec l'opérateur de chaînage optionnel (`?.`)

- **Définition** : cet opérateur te permet d'accéder en toute sécurité aux propriétés d'un objet ou d'appeler des méthodes sans te soucier de savoir si elles existent.

:::interactive_editor

```ts
const user = {
  name: "John",
  profile: {
    email: "john@example.com",
    address: {
      street: "123 Main St",
      city: "Somewhere"
    }
  }
};

console.log(user.profile?.address?.street); // "123 Main St"
console.log(user.profile?.phone?.number);   // undefined
```

:::

## La déstructuration d'objets

- **Définition** : la déstructuration d'objets te permet d'extraire des valeurs des objets et de les affecter à des variables d'une façon plus concise et lisible.

:::interactive_editor

```js
const person = { name: "Alice", age: 30, city: "New York" };

const { name, age } = person;

console.log(name); // Alice
console.log(age);  // 30
```

:::

## Travailler avec le JSON

- **Définition** : JSON signifie JavaScript Object Notation. C'est un format de données léger, basé sur du texte, couramment utilisé pour échanger des données entre un serveur et une application web.

```js
{
  "name": "Alice",
  "age": 30,
  "isStudent": false,
  "list of courses": ["Mathematics", "Physics", "Computer Science"]
}
```

- **`JSON.stringify()`** : cette méthode est utilisée pour convertir un objet JavaScript en une chaîne JSON. C'est utile lorsque tu veux stocker ou transmettre des données dans un format qui peut être facilement partagé ou transféré entre des systèmes.

:::interactive_editor

```js
const user = {
  name: "John",
  age: 30,
  isAdmin: true
};

const jsonString = JSON.stringify(user);
console.log(jsonString); // '{"name":"John","age":30,"isAdmin":true}'
```

:::

- **`JSON.parse()`** : cette méthode reconvertit une chaîne JSON en un objet JavaScript. C'est utile lorsque tu récupères des données JSON depuis un serveur web ou le localStorage et que tu as besoin de manipuler les données dans ton application.

:::interactive_editor

```js
const jsonString = '{"name":"John","age":30,"isAdmin":true}';
const userObject = JSON.parse(jsonString);

// result: { name: 'John', age: 30, isAdmin: true }
console.log(userObject);
```

:::
