# --interactive--

En JavaScript, un objet est une structure de données fondamentale qui te permet de stocker et d'organiser des données et des fonctionnalités liées.

Tu peux voir un objet comme un conteneur qui contient diverses informations, un peu comme un classeur contient différents dossiers et documents.

Ces informations sont appelées propriétés, et elles se composent d'un nom (ou clé) et d'une valeur.

```js
const exampleObject = {
  propertyName: value,
}
```

Les objets sont incroyablement polyvalents et constituent l'épine dorsale de JavaScript. En fait, presque tout en JavaScript est un objet ou peut être traité comme tel. Cela inclut les tableaux, les fonctions, et même les types de données primitifs comme les chaînes et les nombres lorsqu'ils sont utilisés de certaines façons.

Cette nature centrée sur les objets de JavaScript est l'une des raisons pour lesquelles c'est un langage si flexible et puissant. Voyons comment tu peux créer un objet :

```js
const person = {
  name: "Alice",
  age: 30,
  city: "New York"
};
```

Dans cet exemple, nous avons créé un objet appelé `person` avec trois propriétés : `name`, `age` et `city`. Chaque propriété a un nom et une valeur, séparés par deux-points.

Maintenant, explorons comment tu peux accéder à ces propriétés. Il existe deux façons principales d'accéder aux propriétés d'un objet en JavaScript : la notation par point et la notation par crochets.

La notation par point est la façon la plus courante et la plus simple d'accéder aux propriétés d'un objet. Voici la syntaxe de base de la notation par point :

```js
objectName.propertyName
```

Voici comment tu utiliserais la notation par point avec notre objet `person` :

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  city: "New York"
};

console.log(person.name);  // Alice
console.log(person.age);   // 30
```

:::

La notation par point est concise et facile à lire, ce qui en fait le choix préféré lorsque tu connais le nom exact de la propriété à laquelle tu veux accéder et que ce nom est un identifiant JavaScript valide (c'est-à-dire qu'il ne commence pas par un chiffre et ne contient pas de caractères spéciaux ni d'espaces).

La notation par crochets, en revanche, te permet d'accéder aux propriétés d'un objet en utilisant une chaîne entre crochets. Voici comment tu utiliserais la notation par crochets :

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  city: "New York"
};

console.log(person["name"]); // Alice
console.log(person["age"]); //  30
```

:::

La notation par crochets est plus flexible que la notation par point car elle te permet d'utiliser des noms de propriété qui ne sont pas des identifiants JavaScript valides. Par exemple, si tu avais un nom de propriété avec des espaces ou qui commence par un chiffre, tu devrais utiliser la notation par crochets :

:::interactive_editor

```js
const oddObject = {
  "1stProperty": "Hello",
  "property with spaces": "World"
};

console.log(oddObject["1stProperty"]);  // Hello
console.log(oddObject["property with spaces"]);  // World
```

:::

Un autre avantage de la notation par crochets est qu'elle te permet d'utiliser des variables pour accéder aux propriétés de manière dynamique :

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  city: "Wonderland"
};

let propertyName = "city";
console.log(person[propertyName]); // Wonderland
```

:::

Cette flexibilité rend la notation par crochets particulièrement utile lorsque tu ne connais pas le nom exact de la propriété au moment où tu écris le code, ou lorsque tu travailles avec des noms de propriété qui proviennent d'une saisie utilisateur ou d'une autre source dynamique.

Il est utile de noter que les objets en JavaScript sont incroyablement puissants et polyvalents. Ils peuvent contenir non seulement des valeurs simples comme des chaînes et des nombres, mais aussi des tableaux, ou d'autres objets.

Comprendre les objets et comment travailler avec eux est crucial en JavaScript car ils sont largement utilisés dans tout le langage ainsi que dans de nombreuses bibliothèques et frameworks JavaScript.

Au fur et à mesure que tu continueras à apprendre et à travailler avec JavaScript, tu constateras que maîtriser les objets ouvre un monde de possibilités pour créer des applications complexes et puissantes.
