# --interactive--

En JavaScript, un constructeur est un type spécial de fonction utilisé pour créer et initialiser des objets. Il est invoqué avec le mot-clé `new` et peut initialiser des propriétés et des méthodes sur l'objet nouvellement créé.

Dans cette leçon, nous allons voir comment travailler avec le constructeur `Object()`. Le constructeur `Object()` crée un nouvel objet vide. Voici un exemple :

```js
new Object()
```

Lorsque tu appelles `new Object()`, il retourne un nouvel objet qui peut être utilisé pour stocker des valeurs.

Le constructeur `Object()` peut être utilisé avec ou sans le mot-clé `new`. Lorsqu'il est appelé comme une fonction sans `new`, il se comporte différemment selon le type de valeur qui lui est passé. Voici un exemple d'utilisation du constructeur `Object()` sans le mot-clé `new` :

:::interactive_editor

```js
const num = 42;
const numObj = Object(num); // Creates an object wrapper for the number

console.log(numObj);
console.log(typeof numObj); // "object"
```

:::

Comme tu peux le voir dans le second `console.log`, `numObj` est un objet. Cela se produit parce que nous avons utilisé le constructeur `Object()` pour transformer cette entrée numérique en objet.

Que se passe-t-il si nous essayons de passer `null` ou `undefined` au constructeur `Object()` ?

:::interactive_editor

```js
const newObj = new Object(undefined);
console.log(newObj); // {}
```

:::

Eh bien, le résultat sera un objet vide. Un autre cas d'usage du constructeur `Object()` est lorsque tu travailles avec une valeur de type inconnu et que tu dois t'assurer que c'est un objet. Regardons l'exemple suivant :

:::interactive_editor

```js
function toObject(value) {
  if (value === null || value === undefined) {
    return {};
  }

  if (typeof value === "object") {
    return value;
  }

  return Object(value);
}

console.log(toObject(null));

console.log(toObject(true));

console.log(toObject([1, 2, 3]));
```

:::

Dans cet exemple, nous avons une fonction appelée `toObject`. La deuxième condition vérifie si la valeur est de type objet et retourne la valeur si la condition est `true`. Cette condition vérifie les objets ainsi que les tableaux, car les tableaux sont des types spéciaux d'objets.

Si aucune des conditions n'est vraie, la fonction retourne `Object(value)`, qui convertit l'entrée en objet. Cela fonctionne pour des valeurs comme les nombres, les chaînes et les booléens

La plupart du temps, tu n'utiliseras pas le constructeur `Object()` pour créer de nouveaux objets car tu utiliseras plutôt la syntaxe de littéral d'objet (par exemple, `const objectLiteral = { name: "Beau" }`). Mais il est tout de même utile de comprendre les bases du travail avec le constructeur Object.
