# --interactive--

Il existe plusieurs façons de supprimer des propriétés d'un objet, l'opérateur `delete` étant la méthode la plus simple et la plus couramment utilisée.

Lorsque tu utilises `delete`, il supprime la propriété sélectionnée de l'objet. Voici un exemple de comment utiliser l'opérateur `delete` :

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  job: "Engineer"
};

delete person.job;

console.log(person.job); // undefined
```

:::

Dans cet exemple, nous partons d'un objet `person` qui a trois propriétés : `name`, `age` et `job`. Ensuite, nous utilisons l'opérateur `delete` pour supprimer la propriété `job`. Après la suppression, l'objet `person` n'a plus la propriété `job`.

Une autre façon de supprimer des propriétés consiste à utiliser l'affectation par déstructuration avec des paramètres rest. Cette approche ne supprime pas réellement la propriété, mais elle crée un nouvel objet sans les propriétés spécifiées :

:::interactive_editor

```js
const person = {
  name: "Bob",
  age: 25,
  job: "Designer",
  city: "New York"
};

const { job, city, ...remainingProperties } = person;

// { name: "Bob", age: 25 }
console.log(remainingProperties);
```

:::

Dans cet exemple, nous utilisons la déstructuration pour extraire `job` et `city` de l'objet `person`, et collecter les propriétés restantes dans un nouvel objet appelé `remainingProperties`. Cela crée un nouvel objet sans les propriétés `job` et `city`.

Comprendre comment supprimer des propriétés des objets est une compétence importante en programmation JavaScript. Cela te permet de manipuler les objets de manière dynamique, et de nettoyer les données inutiles.
