# --interactive--

Lorsque tu travailles avec JavaScript, tu rencontreras souvent des structures de données complexes qui impliquent des objets imbriqués et des tableaux à l'intérieur d'objets. Ces structures peuvent représenter des données riches et hiérarchiques, mais elles nécessitent aussi une compréhension claire de la façon d'accéder aux données qu'elles contiennent et de les manipuler. Explorons comment naviguer efficacement dans ces structures imbriquées.

Accéder aux propriétés d'objets imbriqués implique d'utiliser la notation par point ou la notation par crochets, tout comme pour accéder aux propriétés d'objets simples. Cependant, tu devras enchaîner ces accesseurs pour descendre dans la structure imbriquée.

Par exemple, considérons un objet imbriqué représentant une personne avec ses informations de contact :

```js
const person = {
  name: "Alice",
  age: 30,
  contact: {
    email: "alice@example.com",
    phone: {
      home: "123-456-7890",
      work: "098-765-4321"
    }
  }
};
```

Pour accéder au numéro de téléphone professionnel d'`Alice`, tu enchaînerais les accesseurs de propriété comme ceci :

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  contact: {
    email: "alice@example.com",
    phone: {
      home: "123-456-7890",
      work: "098-765-4321"
    }
  }
};

console.log(person.contact.phone.work); // "098-765-4321"
```

:::

Tu peux aussi utiliser la notation par crochets, qui est particulièrement utile lorsque les noms de propriété incluent des espaces ou des caractères spéciaux, ou lorsque tu utilises des variables pour accéder aux propriétés :

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  contact: {
    email: "alice@example.com",
    phone: {
      home: "123-456-7890",
      work: "098-765-4321"
    }
  }
};

console.log(person['contact']['phone']['work']); // "098-765-4321"
```

:::

Maintenant, regardons comment nous pouvons accéder aux données lorsque l'une des propriétés de l'objet a pour valeur un tableau. Voici un objet `person` modifié qui inclut un tableau d'adresses :

```js
const person = {
  name: "Alice",
  age: 30,
  addresses: [
    { type: "home", street: "123 Main St", city: "Anytown" },
    { type: "work", street: "456 Market St", city: "Workville" }
  ]
};
```

Voici un exemple de comment accéder à la ville de l'adresse professionnelle d'`Alice` :

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  addresses: [
    { type: "home", street: "123 Main St", city: "Anytown" },
    { type: "work", street: "456 Market St", city: "Workville" }
  ]
};

console.log(person.addresses[1].city); // "Workville"
```

:::

Dans cet exemple, `person.addresses` fait référence au tableau d'adresses. Pour accéder à la deuxième adresse de ce tableau, nous utilisons la notation par crochets et l'index `1`. Ensuite, nous utilisons la notation par point pour accéder à la `city` de cet objet adresse.

Comprendre comment accéder aux propriétés d'objets et de tableaux imbriqués est essentiel lorsqu'on travaille avec des structures de données complexes. Dans de futurs workshops et labs, tu auras l'occasion de t'entraîner à travailler avec ce type de structures de données.
