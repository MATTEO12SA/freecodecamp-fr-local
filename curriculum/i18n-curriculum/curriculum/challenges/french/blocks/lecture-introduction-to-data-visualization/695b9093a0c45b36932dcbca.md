# --description--

Il existe de nombreuses façons de représenter des données sous forme visuelle. Dans cette leçon, tu découvriras quelques types de visualisations de données couramment utilisés.

Le premier type que tu vas découvrir concerne les graphiques qui représentent le changement dans le temps, comme la performance du cours d'une action ou des statistiques de santé.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/what-are-common-chart-types-and-when-should-you-use-them-1.png" alt="exemple de graphique en aires">

Un autre type de visuel courant est le graphique de comparaison de catégories. Ce type de visuel montre des comparaisons entre différentes catégories, comme la performance des publicités selon les canaux marketing, ou les ventes par catégorie de produits pour les boutiques en ligne.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/what-are-common-chart-types-and-when-should-you-use-them-2.png" alt="exemple de graphique à bulles pour la performance des leads par canal marketing">

Si tu as besoin de représenter la position d'un élément dans une liste ordonnée, tu peux utiliser un graphique de classement. Des exemples de ce type de visuel incluent des statistiques de performance ou des résultats d'élection.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/what-are-common-chart-types-and-when-should-you-use-them-3.png" alt="exemple de graphique de classement pour des résultats d'élection">

Un autre type de visualisation de données couramment utilisé est le visuel « partie d'un tout ». Cela inclut les diagrammes circulaires ou les treemaps qui peuvent représenter des budgets ou des catégories de produits.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/what-are-common-chart-types-and-when-should-you-use-them-4.png" alt="exemple de diagramme circulaire pour un budget">

Si tu travailles avec des données qui montrent une corrélation entre deux variables ou plus, tu peux utiliser un graphique de corrélation. Ces types de graphiques incluent les heat maps ou les nuages de points qui peuvent représenter des données comme le revenu vs. le niveau d'éducation, les dépenses publicitaires vs. les ventes, ou la température vs. la consommation d'énergie.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/what-are-common-chart-types-and-when-should-you-use-them-5.png" alt="exemple de nuage de points pour revenu vs. niveau d'éducation">

Il existe bien d'autres types de graphiques comme les organigrammes, les graphiques de distribution, les graphiques de relations, et plus encore. Mais cette leçon visait à te donner une brève introduction à certains types de graphiques que tu pourrais envisager pour représenter des données complexes.
