# --description--

Chaque langage de programmation propose un moyen d'afficher des données dans le terminal via une méthode, une fonction, une propriété ou un mot-clé intégré. En Python, tu peux utiliser la fonction `print` pour afficher des données dans le terminal. Examinons de plus près la fonction `print` pour que tu puisses commencer à l'utiliser en toute confiance.

L'une des premières choses que tu fais quand tu apprends un langage de programmation, c'est d'écrire un simple programme `Hello world!`. Tu peux le faire très facilement en Python avec uniquement la fonction `print`.

Pour ce faire, tu dois simplement placer la chaîne `Hello world!` entre les parenthèses ouvrante et fermante que tu utilises pour appeler la fonction `print` :

```python
print('Hello world!') # Hello world!
```

Tu en apprendras davantage sur les chaînes et les fonctions en Python dans les leçons à venir. Pour l'instant, considère simplement les chaînes comme une séquence de caractères entourée de guillemets simples (`'`) ou doubles (`"`).

Dans l'exemple `print('Hello world!')`, la chaîne `'Hello world!'` est un **argument** passé à la fonction `print`. Tu peux aussi utiliser la fonction `print` pour afficher plusieurs valeurs, ou arguments, à la fois en les séparant par des virgules. Par exemple :

```python
print('My favorite colors are', 'blue', 'green', 'red')

# Output: My favorite colors are blue green red
```

Python ajoute automatiquement un espace entre chaque élément quand tu les sépares par des virgules. C'est utile quand tu veux afficher plusieurs informations ensemble.
