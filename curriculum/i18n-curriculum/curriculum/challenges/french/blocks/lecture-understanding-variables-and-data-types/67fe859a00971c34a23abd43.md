# --description--

Avant de travailler avec des variables Python, il est important de comprendre les types de données. Un type de données décrit le genre de valeur qu'une variable contient. Par exemple, un nombre, un texte, ou une liste d'éléments. Les langages de programmation utilisent les types de données pour savoir comment stocker et manipuler différents types d'informations.

Python est un langage à typage dynamique comme JavaScript, ce qui signifie que tu n'as pas besoin de déclarer explicitement les types des variables. Le langage sait quel type de données possède une variable en fonction de ce que tu lui assignes.

Voici quelques exemples :

```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```

C'est l'opposé de certains langages à typage statique comme C#, Java et C++, où tu dois déclarer les types avec les variables, comme ceci :

```csharp
string name = 'John Doe'
int age = 25
```

La nature à typage dynamique de Python rend le codage très rapide et plus flexible, mais cela peut mener à des bugs inattendus parce que les erreurs de type ne sont détectées que lorsque le programme s'exécute, pas lors de la compilation.

Comme Python détermine les types de données pendant que ton programme **s'exécute**, les erreurs liées au type ne sont découvertes qu'à ce moment-là. Quand un programme s'exécute, Python exécute ton code ligne par ligne. S'il atteint une ligne où un certain objet est censé se comporter d'une certaine manière mais ne le peut pas, Python s'arrête et affiche une erreur.

En revanche, certains langages **compilent** ton programme avant son exécution. Compiler signifie que l'ordinateur vérifie ton code à l'avance et le prépare pour l'exécution. Pendant cette étape, ces langages peuvent détecter les erreurs de type avant même que le programme ne démarre.

Tu n'as pas encore besoin de connaître ces langages. L'idée importante est simplement :

- **En Python, les erreurs de type peuvent se révéler pendant l'exécution**, quand le programme s'exécute réellement et utilise ton code.

- **Les langages compilés détectent les erreurs de type pendant l'étape de compilation**, avant que le programme ne soit autorisé à s'exécuter.

À cause de cela, tu pourrais ne pas découvrir une erreur de type en Python avant que le programme n'atteigne cette ligne de code précise pendant son exécution.

Voici les types de données les plus courants que tu utiliseras en Python :

- Integer : un nombre entier sans décimales, par exemple `10` ou `-5`.

```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- Float : un nombre avec un point décimal, comme `4.41` ou `-0.4`.

```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- String : une séquence de caractères entre guillemets simples ou doubles comme `'Hello world!'`.

```python
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- Boolean : un type vrai ou faux, écrit comme `True` ou `False`.

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

- Set : une collection non ordonnée d'éléments uniques, comme `{0.5, 4, 'apple'}`.
```python
my_set_var = {7, 'hello', 8.5}
print('Set:', my_set_var) # Set: {7, 'hello', 8.5}
```

- Dictionary : une collection de paires clé-valeur entre accolades, comme `{'name': 'John Doe', 'age': 28}`.

```python
my_dictionary_var = {'name': 'Alice', 'age': 25}
print('Dictionary:', my_dictionary_var) # Dictionary: {'name': 'Alice', 'age': 25}
```

- Tuple : une collection ordonnée immuable, entre parenthèses, comme `('apple', 4.5, 7)`.

```python
my_tuple_var = (7, 'hello', 8.5)
print('Tuple:', my_tuple_var) # Tuple: (7, 'hello', 8.5)
```

- Range : une séquence de nombres, souvent utilisée dans les boucles, par exemple `range(5)`.

```python
my_range_var = range(5)
print('Range:', my_range_var) # Range: range(0, 5)
```

- List : une collection ordonnée d'éléments qui accepte différents types de données.
```python
my_list = [22, 'Hello world', 3.14, True]
print(my_list) # [22, 'Hello world', 3.14, True]
```

- None : une valeur spéciale qui représente l'absence de valeur.

```python
my_none_var = None
print('None:', my_none_var) # None: None
```

Pour obtenir le type de données d'une variable, tu peux utiliser la fonction `type()` :

```python
my_var_1 = 'Hello world'
my_var_2 = 21

print(type(my_var_1)) # <class 'str'>
print(type (my_var_2)) # <class 'int'>
```

Et voici tous les types de données couverts dans cette leçon, avec leurs types affichés dans le terminal :

```python
my_integer_var = 10
print(type(my_integer_var))  # <class 'int'>

my_float_var = 4.50
print(type(my_float_var))  # <class 'float'>

my_string_var = 'hello'
print(type(my_string_var))  # <class 'str'>

my_boolean_var = True
print(type(my_boolean_var))  # <class 'bool'>

my_set_var = {7, 'hello', 8.5}
print(type(my_set_var))  # <class 'set'>

my_dictionary_var = {'name': 'Alice', 'age': 25}
print(type(my_dictionary_var))  # <class 'dict'>

my_tuple_var = (7, 'hello', 8.5)
print(type(my_tuple_var))  # <class 'tuple'>

my_range_var = range(5)
print(type(my_range_var))  # <class 'range'>

my_list = [22, 'Hello world', 3.14, True]
print(type(my_list)) # <class 'list'>

my_none_var = None
print(type(my_none_var))  # <class 'NoneType'>
```

La fonction intégrée `isinstance()` te permet de vérifier si une variable correspond à un type de données spécifique. Elle prend un objet et le type que tu veux vérifier, puis renvoie un booléen. Voici quelques exemples :

```python
isinstance('Hello world', str) # True
isinstance(True, bool) # True
isinstance(42, int) # True
isinstance('John Doe', int) # False
```
