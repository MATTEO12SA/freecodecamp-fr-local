# --description--

En Python, les variables ressemblent à une boîte étiquetée pour stocker et référencer des données de différents types. Pour déclarer des variables en Python, tu assignes une valeur à un identifiant avec l'opérateur d'affectation (`=`). Tu n'as pas besoin d'utiliser des mots-clés spéciaux comme `let` ou `const` en JavaScript, ou `char` en C#.

En Python, tu écris simplement le nom de la variable à gauche, suivi de l'opérateur d'affectation, et la valeur que tu veux assigner à la variable à droite. Voici un exemple de déclaration des variables `name` et `age` :

```python
name = 'John Doe'
age = 25
```

Dans l'exemple ci-dessus, la variable `name` contient la valeur `'John Doe'`. Cette valeur est une chaîne, c'est-à-dire une série de caractères utilisée pour représenter du texte. Les chaînes s'écrivent avec des guillemets simples ou doubles, par exemple `'Hello'` ou `"Hello"`. Dans les leçons à venir, tu apprendras davantage sur le travail avec les chaînes en Python.

Lorsque tu nommes des variables en Python, voici des règles importantes à garder en tête :

- Les noms de variables ne peuvent commencer que par une lettre ou un tiret bas (`_`), pas par un chiffre.
- Les noms de variables ne peuvent contenir que des caractères alphanumériques (`a-z`, `A-Z`, `0-9`) et des tirets bas (`_`).
- Les noms de variables sont sensibles à la casse — `age`, `Age` et `AGE` sont tous considérés comme distincts.
- Les noms de variables ne peuvent pas être l'un des mots-clés réservés de Python comme `if`, `class` ou `def`.

Si tu enfreins l'une de ces règles, ton programme Python lève une `SyntaxError` :

```bash
    5variable_name = 5
     ^
SyntaxError: invalid syntax
```

Passons maintenant en revue quelques conventions de nommage courantes pour les variables en Python.

D'abord, les noms de variables devraient être en minuscules, avec des mots séparés par un tiret bas. On appelle cela le snake case :

```python
my_variable_name = 'freeCodeCamp'
```

Ensuite, tu devrais utiliser des noms descriptifs pour les variables. Par exemple, si tu veux enregistrer l'âge d'un utilisateur dans une variable, `user_age` est meilleur que `age` ou une abréviation comme `ua` :

```python
user_age = 30
```

Ainsi, tu peux facilement communiquer le rôle d'une variable aux autres membres de l'équipe (ou à ton futur toi) dans une base de code volumineuse.

Une autre convention consiste à éviter les noms de variables d'une seule lettre. C'est très courant en Python, mais tu devrais l'éviter parce que les noms d'une seule lettre ne communiquent aucun rôle ni signification :

```python
x = 56 # What do you mean by x?
```

Le symbole dièse (`#`) et le texte qui suit dans l'exemple ci-dessus s'appelle un commentaire. Tu connais peut-être déjà les commentaires, passons donc rapidement en revue leur fonctionnement.

En Python, les commentaires commencent par un symbole dièse (`#`), et le langage ignore tout ce qui suit le symbole `#` sur cette ligne :

```python
# This is a single-line comment
```

Tu peux créer des commentaires sur plusieurs lignes en utilisant des commentaires d'une seule ligne consécutifs :

```python
# This is a
# multi-line
# comment
```

Tu peux utiliser les commentaires pour expliquer ton code, te laisser des rappels, ou clarifier pourquoi une ligne existe. Les commentaires sont particulièrement utiles quand tu apprends ou que tu travailles en équipe.

Cependant, tu ne devrais pas utiliser les commentaires pour expliquer ce que signifient tes noms de variables. À la place, les noms que tu choisis pour tes variables devraient être descriptifs et communiquer leur rôle, et respecter les autres règles de nommage mentionnées plus tôt pour éviter les erreurs de syntaxe.
