# --interactive--

L'opérateur de chaînage optionnel (`?.`) est un outil utile en JavaScript qui te permet d'accéder en toute sécurité aux propriétés d'un objet ou d'appeler des méthodes sans te soucier de savoir si elles existent. C'est comme un filet de sécurité pour travailler avec des objets qui pourraient avoir des parties manquantes.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30
};

console.log(person.name); // "Alice"
console.log(person.job); // undefined
```

:::

Dans cet exemple, `person.name` existe, donc il affiche `Alice`. Mais `person.job` n'existe pas, donc il nous donne `undefined`.

Maintenant, disons que nous voulons accéder à une propriété d'un objet qui pourrait ne pas exister :

```js
const person = {
  name: "Alice",
  age: 30
};

console.log(person.address.street); // This will throw an error!
```

Cet exemple déclenchera une `Uncaught TypeError`. Comme `person.address` est `undefined`, nous ne pouvons pas accéder à la propriété `street`. C'est là que l'opérateur de chaînage optionnel s'avère pratique. Voici un exemple d'utilisation de l'opérateur de chaînage optionnel :

:::interactive_editor

```ts
const user = {
  name: "John",
  profile: {
    email: "john@example.com",
    address: {
      street: "123 Main St",
      city: "Somewhere"
    }
  }
};

console.log(user?.profile?.address?.street); // "123 Main St"
console.log(user?.profile?.phone?.number);   // undefined
```

:::

En utilisant l'opérateur de chaînage optionnel, nous indiquons à JavaScript de ne poursuivre l'opération que si l'objet (ou la valeur avant le `?.`) existe et n'est ni `null` ni `undefined`.

Si la valeur avant le `?.` est `null` ou `undefined`, JavaScript retourne `undefined` plutôt que d'essayer de poursuivre l'opération et de déclencher une erreur.

Souviens-toi, l'opérateur de chaînage optionnel est le plus utile lorsque tu n'es pas sûr qu'une propriété ou une méthode existe. Il aide à prévenir les erreurs et rend ton code plus robuste.
