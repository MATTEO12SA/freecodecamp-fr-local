# --interactive--

En JavaScript, `NaN` signifie "Not a Number" (pas un nombre). C'est une valeur spéciale qui représente un résultat numérique non représentable ou indéfini. `NaN` est une propriété de l'objet global, et il est aussi considéré comme un type de nombre en JavaScript, ce qui peut sembler contre-intuitif au premier abord.

`NaN` est généralement le résultat d'opérations qui devraient renvoyer un nombre mais ne peuvent pas produire de valeur numérique significative. Par exemple :

:::interactive_editor

```js
let result = 0 / 0;
console.log(result); // NaN
```

:::

Dans ce cas, diviser zéro par zéro est mathématiquement indéfini, donc JavaScript renvoie `NaN`. Une propriété particulière de `NaN` est qu'il n'est égal à rien, pas même à lui-même :

:::interactive_editor

```js
console.log(NaN === NaN); // false
```

:::

Ce comportement unique rend difficile la vérification qu'une valeur est `NaN` à l'aide des opérateurs de comparaison standard. Pour résoudre ce problème, JavaScript fournit la fonction `isNaN()`. La propriété fonction `isNaN()` est utilisée pour déterminer si une valeur est `NaN` ou non. Cependant, il est important de comprendre comment `isNaN()` fonctionne, car elle peut parfois produire des résultats inattendus. Voici comment `isNaN()` se comporte :

:::interactive_editor

```js
console.log(isNaN(NaN));       // true
console.log(isNaN(undefined)); // true
console.log(isNaN({}));        // true

console.log(isNaN(true));      // false
console.log(isNaN(null));      // false
console.log(isNaN(37));        // false

console.log(isNaN("37"));      // false: "37" is converted to 37
console.log(isNaN("37.37"));   // false: "37.37" is converted to 37.37
console.log(isNaN(""));        // false: empty string is converted to 0
console.log(isNaN(" "));       // false: string with a space is converted to 0

console.log(isNaN("blabla"));  // true: "blabla" is not a number
```

:::

Comme tu peux le voir, `isNaN()` tente d'abord de convertir le paramètre en nombre. S'il ne peut pas être converti, elle renvoie `true`. Ce comportement peut conduire à des résultats surprenants, surtout quand on manipule des chaînes qui peuvent être converties en nombres.

En raison de ces incohérences potentielles, ES6 (la sixième édition de JavaScript, publiée en 2015) a introduit `Number.isNaN()`. Cette méthode ne tente pas de convertir le paramètre en nombre avant de le tester. Elle ne renvoie `true` que si la valeur est exactement `NaN` :

:::interactive_editor

```js
console.log(Number.isNaN(NaN));        // true
console.log(Number.isNaN(Number.NaN)); // true
console.log(Number.isNaN(0 / 0));      // true

console.log(Number.isNaN("NaN"));      // false
console.log(Number.isNaN(undefined));  // false
console.log(Number.isNaN({}));         // false
console.log(Number.isNaN("blabla"));   // false
```

:::

`Number.isNaN()` offre une façon plus fiable de vérifier les valeurs `NaN`, surtout dans les cas où la coercition de type pourrait conduire à des résultats inattendus avec la fonction globale `isNaN()`. En pratique, quand on manipule des opérations numériques ou des saisies utilisateur qui devraient être des nombres, il est souvent nécessaire de vérifier la présence de `NaN` pour gérer les erreurs ou les saisies inattendues avec élégance. Par exemple :

:::interactive_editor

```js
let a = 0;
let b = 0;
let result = a / b;

if (Number.isNaN(result)) {
  result = "Error: Division resulted in NaN";
}

console.log(result); // "Error: Division resulted in NaN"
```

:::

Dans cet exemple, nous utilisons `Number.isNaN()` pour intercepter les cas où l'opération de division aboutit à `NaN`, ce qui nous permet de gérer ce scénario de manière appropriée. Comprendre `NaN` et savoir comment le vérifier correctement est crucial pour écrire du code JavaScript robuste, surtout quand on manipule des opérations mathématiques ou qu'on analyse des saisies utilisateur.
