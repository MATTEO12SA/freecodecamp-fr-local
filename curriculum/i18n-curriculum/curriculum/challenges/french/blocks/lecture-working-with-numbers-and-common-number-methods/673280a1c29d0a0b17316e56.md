# --interactive--

La méthode `.toFixed()` est une fonction JavaScript intégrée qui formate un nombre en utilisant la notation à virgule fixe. Elle est particulièrement utile quand tu as besoin de contrôler le nombre de décimales d'un nombre, surtout pour afficher des valeurs monétaires ou quand tu travailles avec des mesures précises.

La méthode `.toFixed()` est appelée sur un nombre et prend un argument facultatif, qui est le nombre de chiffres à faire apparaître après la virgule décimale. Elle renvoie une représentation sous forme de chaîne du nombre avec le nombre de décimales spécifié. Voici un exemple basique du fonctionnement de `.toFixed()` :

:::interactive_editor

```js
let num = 3.14159;
console.log(num.toFixed(2)); // "3.14"
```

:::

Dans ce cas, nous limitons le nombre de décimales à deux. Ainsi, `3.14159` devient `3.14`. Il est important de noter que `.toFixed()` renvoie une chaîne, pas un nombre. C'est parce que la méthode est principalement destinée au formatage des nombres pour l'affichage, et non pour des calculs ultérieurs.

La méthode `.toFixed()` arrondit le nombre à la valeur la plus proche pouvant être représentée avec le nombre de décimales spécifié. Ce comportement d'arrondi est important à comprendre :

:::interactive_editor

```js
console.log((3.14159).toFixed(3));  // "3.142"
console.log((3.14449).toFixed(3));  // "3.144"
console.log((3.14550).toFixed(3));  // "3.146"
```

:::

Comme tu peux le voir, `.toFixed()` arrondit vers le haut quand le chiffre suivant est `5` ou plus, et vers le bas sinon. Si tu appelles `.toFixed()` sans arguments, elle utilise par défaut `0` décimale :

:::interactive_editor

```js
let num = 3.14159;
console.log(num.toFixed()); // "3"
```

:::

La méthode `.toFixed()` peut être particulièrement utile quand on travaille avec des calculs financiers ou qu'on affiche des prix :

:::interactive_editor

```js
let price = 19.99;
let taxRate = 0.08;
let total = price + (price * taxRate);

console.log("Total: $" + total.toFixed(2)); // "Total: $21.59"
```

:::

Dans cet exemple, `.toFixed(2)` garantit que le total est toujours affiché avec deux décimales, ce qui est la norme pour la monnaie dans de nombreux pays.

En conclusion, la méthode `.toFixed()` est un outil puissant pour formater les nombres en JavaScript, en particulier quand tu as besoin de contrôler l'affichage des décimales. Bien qu'elle soit principalement utilisée pour formater la sortie, souviens-toi de son comportement, surtout quand des calculs précis sont nécessaires.
