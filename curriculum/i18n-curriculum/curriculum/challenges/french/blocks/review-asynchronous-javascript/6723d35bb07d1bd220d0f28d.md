# --description--

- **JavaScript synchrone** s'exécute séquentiellement et attend que l'opération précédente se termine avant de passer à la suivante.
- **JavaScript asynchrone** permet d'exécuter plusieurs opérations en arrière-plan sans bloquer le thread principal.
- **Thread** est une séquence d'instructions qui peut s'exécuter indépendamment du flux principal du programme.
- **Fonctions callback** sont des fonctions passées comme arguments à d'autres fonctions et exécutées après la fin de l'opération ou suite à un événement.

## Le moteur JavaScript et le runtime JavaScript

- Le **moteur JavaScript** est un programme qui exécute du code JavaScript dans un navigateur web. Il fonctionne comme un convertisseur qui prend ton code, le transforme en instructions que l'ordinateur peut comprendre et exécuter.
- V8 est un exemple de moteur JavaScript développé par Google.
- Le **runtime JavaScript** est l'environnement dans lequel le code JavaScript est exécuté. Il inclut le moteur JavaScript qui traite et exécute le code, et des fonctionnalités supplémentaires comme un navigateur web ou Node.js.

## La Fetch API

- La Fetch API permet aux applications web de faire des requêtes réseau, généralement pour récupérer ou envoyer des données au serveur. Elle fournit une méthode `fetch()` que tu peux utiliser pour faire ces requêtes.
- Tu peux récupérer du texte, des images, de l'audio, du JSON, et d'autres types de données avec la Fetch API.

## Méthodes HTTP pour la Fetch API

La Fetch API prend en charge diverses méthodes HTTP pour interagir avec le serveur. Les méthodes les plus courantes sont :

- **GET** : Utilisée pour récupérer des données depuis le serveur. Par défaut, la Fetch API utilise la méthode `GET` pour récupérer des données.

```js
fetch('https://api.example.com/data')
```

Pour utiliser les données récupérées, elles doivent être converties au format JSON avec la méthode `.json()` :

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
```

Dans ce code, la réponse provenant de la Fetch API est une promesse et le gestionnaire `.then` convertit la réponse au format JSON.

- **POST** : Utilisée pour envoyer des données au serveur. La méthode `POST` sert à créer de nouvelles ressources sur le serveur.

```js
fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Doe',
    email: 'john@example.com'
  })
})
```

Dans cet exemple, on envoie une requête `POST` pour créer un nouvel utilisateur. On a précisé la méthode comme `POST`, défini les en-têtes appropriés, et inclus un corps avec les données à envoyer. Le corps doit être une chaîne, donc on utilise `JSON.stringify()` pour convertir notre objet en chaîne JSON.

- **PUT** : Utilisée pour mettre à jour des données sur le serveur. La méthode `PUT` sert à mettre à jour des ressources existantes sur le serveur.

```js
fetch('https://api.example.com/users/45', {
  method: 'PUT',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Smith',
    email: 'john@example.com'
  })
})
```

Dans cet exemple, on met à jour l'ID `45` précisé à la fin de l'URL. On a utilisé la méthode `PUT` dans le code et aussi précisé les données comme corps qui serviront à mettre à jour les données identifiées.

- **DELETE** : Utilisée pour supprimer des données sur le serveur. La méthode `DELETE` sert à supprimer des ressources sur le serveur.

```js
fetch('https://api.example.com/users/45', {
  method: 'DELETE'
})
```

Dans cet exemple, on envoie une requête `DELETE` pour supprimer un utilisateur avec l'ID `45`.

## Promesse et chaînage de promesses

- Les **promesses** sont des objets qui représentent l'achèvement ou l'échec éventuel d'une opération asynchrone et sa valeur résultante. La valeur de la promesse n'est connue que lorsque l'opération `async` est terminée.
- Voici un exemple pour créer une promesse simple :

```js
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```

- La méthode `.then()` est utilisée dans une Promise pour préciser ce qui doit se passer quand la Promise est remplie, tandis que `.catch()` sert à gérer les erreurs qui surviennent.
- Voici un exemple d'utilisation de `.then()` et `.catch()` avec une Promise :

```js
promise
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.error(error);
  });
```

Dans l'exemple ci-dessus, la méthode `.then()` est utilisée pour afficher les données reçues de la Promise, tandis que la méthode `.catch()` est utilisée pour afficher les erreurs qui surviennent.

- **Chaînage de promesses** : Une des fonctionnalités puissantes des Promises est qu'on peut enchaîner plusieurs opérations asynchrones. Chaque `.then()` peut renvoyer une nouvelle Promise, te permettant d'exécuter une séquence d'opérations asynchrones l'une après l'autre.
- Voici un exemple de chaînage de Promises :

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => {
    console.log(data);
    return fetch('https://api.example.com/other-data');
  })
  .then(response => response.json())
  .then(otherData => {
    console.log(otherData);
  })
  .catch(error => {
    console.error(error);
  });
```

Dans l'exemple ci-dessus, on récupère d'abord des données depuis une URL, puis on récupère des données depuis une autre URL basées sur la première réponse, et enfin on affiche les secondes données reçues.

La méthode `catch` gérerait toutes les erreurs survenant pendant le processus. Cela signifie que tu n'as pas besoin d'ajouter la gestion d'erreurs à chaque étape, ce qui peut grandement simplifier ton code.

## Utiliser `async/await` pour gérer les promesses

Async/await facilite l'écriture et la lecture du code asynchrone et est construit sur les Promises.

- **async** : Le mot-clé `async` sert à définir une fonction asynchrone. Une fonction `async` renvoie une Promise, qui se résout avec la valeur renvoyée par la fonction `async`.
- **await** : Le mot-clé `await` est utilisé dans une fonction `async` pour mettre en pause l'exécution de la fonction jusqu'à ce que la Promise soit résolue. Il ne peut être utilisé que dans une fonction `async`.
- Voici un exemple d'utilisation de `async/await` :

```js
async function delayedGreeting(name) {
  console.log("A Messenger entered the chat...");
  await new Promise(resolve => setTimeout(resolve, 2000));
  console.log(`Hello, ${name}!`);
}

delayedGreeting("Alice");
console.log("First Printed Message!");
```

Dans l'exemple ci-dessus, la fonction `delayedGreeting` est une fonction `async` qui fait une pause de 2 secondes avant d'afficher le message de salutation. Le mot-clé `await` est utilisé pour mettre en pause l'exécution de la fonction jusqu'à ce que la `Promise` soit résolue.

- Un des plus grands avantages de `async/await` est la gestion des erreurs via des blocs `try/catch`. Voici un exemple :

```js
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

fetchData();
```

Dans l'exemple ci-dessus, le bloc `try` contient le code qui pourrait lever une erreur, et le bloc `catch` gère l'erreur si elle survient. Cela rend la gestion des erreurs plus directe et lisible.

## L'attribut `async`

- L'attribut `async` dit au navigateur de télécharger le fichier script de façon asynchrone tout en continuant à parser le document HTML.
- Une fois le script téléchargé, le parsing HTML est mis en pause, le script est exécuté, puis le parsing HTML reprend.
- Tu dois utiliser `async` pour les scripts indépendants où l'ordre d'exécution n'importe pas

## L'attribut `defer`

- L'attribut `defer` télécharge aussi le script de façon asynchrone, mais il diffère l'exécution du script jusqu'à ce que le document HTML ait été entièrement parsé.
- Les scripts `defer` maintiennent l'ordre d'exécution tel qu'ils apparaissent dans le document HTML.

- Il est important de noter que les attributs `async` et `defer` sont ignorés pour les scripts en ligne et ne fonctionnent que pour les fichiers de scripts externes.

- Quand les attributs `async` et `defer` sont tous les deux présents, l'attribut `async` a la priorité.

## Geolocation API

- La Geolocation API fournit un moyen pour les sites web de demander la localisation de l'utilisateur.

- L'exemple ci-dessous démontre la méthode `getCurrentPosition()` de l'API qui sert à obtenir la localisation actuelle de l'utilisateur.

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

Dans ce code, on appelle `getCurrentPosition` et on lui passe une fonction qui sera appelée quand la position est obtenue avec succès.

L'objet `position` contient diverses informations, mais ici on a sélectionné uniquement `latitude` et `longitude`.

S'il y a un problème pour obtenir la `position`, alors l'erreur sera affichée dans la console.

- Il est important de respecter la confidentialité de l'utilisateur et de ne demander sa localisation que lorsque c'est nécessaire.
