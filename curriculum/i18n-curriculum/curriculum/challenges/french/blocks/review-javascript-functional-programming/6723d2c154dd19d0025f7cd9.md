## Fonctions pures vs impures

- Une fonction pure est une fonction qui produit toujours la même sortie pour la même entrée et n'a aucun effet de bord. Sa sortie ne dépend que de son entrée, et elle ne modifie aucun état externe.
- Les fonctions impures ont des effets de bord, c'est-à-dire des changements de l'état du programme observables en dehors de la fonction.

## Programmation fonctionnelle

- La programmation fonctionnelle est une approche du développement logiciel qui met l'accent sur l'utilisation de fonctions pour résoudre des problèmes, en se concentrant sur ce qui doit être fait plutôt que sur comment le faire.
- La programmation fonctionnelle encourage l'utilisation de techniques qui aident à éviter les effets de bord, comme l'utilisation de structures de données immuables et de fonctions d'ordre supérieur.
- Bien utilisées, les principes de la programmation fonctionnelle conduisent à un code plus propre et plus maintenable

## Curryfication

- La curryfication est une technique de programmation fonctionnelle qui transforme une fonction à plusieurs arguments en une séquence de fonctions, chacune prenant un seul argument.

Voici un exemple d'une fonction classique vs une fonction curryfiée :

:::interactive_editor

```js
// Regular function
function average(a, b, c) {
  return (a + b + c) / 3;
}

console.log(average(2, 3, 4)); // 3

// Curried function
function curriedAverage(a) {
  return function(b) {
    return function(c) {
      return (a + b + c) / 3;
    };
  };
}

console.log(curriedAverage(2)(3)(4)); // 3
```

:::

- La curryfication peut être particulièrement puissante lorsqu'on travaille avec des fonctions qui prennent de nombreux arguments.
- La curryfication rend ton code plus flexible et plus facile à réutiliser.
- Tu peux utiliser des fonctions fléchées pour créer des fonctions curryfiées de façon plus concise :

```js
const curriedAverage = a => b => c => (a + b + c) / 3;
```

- Bien que la curryfication puisse mener à un code plus flexible et réutilisable, elle peut aussi rendre le code plus difficile à lire si elle est surutilisée.
