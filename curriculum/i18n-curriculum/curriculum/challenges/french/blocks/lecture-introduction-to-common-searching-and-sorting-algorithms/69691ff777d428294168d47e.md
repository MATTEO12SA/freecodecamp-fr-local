# --description--

Le paradigme diviser pour régner en informatique est une technique pour décomposer récursivement des problèmes en sous-problèmes plus petits. Un des aspects clés de cette technique est la récursion, qui se produit quand une fonction s'appelle elle-même de façon répétée jusqu'à atteindre un cas de base. Dans cette leçon, on va examiner l'algorithme de tri fusion pour mieux comprendre comment fonctionne la technique diviser pour régner.

Disons qu'on avait cette liste de nombres :

```md
42 37 53 17
```

Le but est de trier cette liste du plus petit au plus grand avec l'algorithme de tri fusion. La première étape est de diviser cette liste en deux :

```md
42 37 | 53 17
```

Ensuite, on doit regarder le côté gauche de la liste :

```md
42 37
```

On prend cette sous-liste et on la divise encore en deux jusqu'à ce que chaque sous-liste n'ait qu'un seul élément :

```md
42 | 37
```

Une liste avec un seul élément est triée par défaut. Ensuite, on doit fusionner chacune de ces sous-listes d'un élément en une liste triée :

```md
37 42
```

Puis on suit le même processus pour le côté droit de la liste d'origine :

```javascript
// right side of original list
53 17

// divide the list in half
53 | 17

// merge the lists in sorted order
17 53
```

Maintenant que les deux moitiés de la liste d'origine sont triées, on fusionne ces deux moitiés et on trie les éléments :

```markdown
17 37 42 53
```

Voici à quoi ressemble l'algorithme en code :

```javascript
function mergeSort(arr) {
    if (arr.length <= 1) {
        return arr;
    }

    const mid = Math.floor(arr.length / 2);
    const left = mergeSort(arr.slice(0, mid));
    const right = mergeSort(arr.slice(mid));

    const sorted = [];
    let i = 0;
    let j = 0;

    while (i < left.length && j < right.length) {
        if (left[i] <= right[j]) {
            sorted.push(left[i]);
            i += 1;
        } else {
            sorted.push(right[j]);
            j += 1;
        }
    }

    return sorted.concat(left.slice(i)).concat(right.slice(j));
}
```

La complexité temporelle du tri fusion serait `O(n log n)` parce que la liste est continuellement divisée en deux (`log n`) puis fusionnée (`O(n)`). Contrairement à d'autres algorithmes de tri comme le tri à bulles, le tri fusion n'est pas trié sur place et a une complexité spatiale de `O(n)`.
