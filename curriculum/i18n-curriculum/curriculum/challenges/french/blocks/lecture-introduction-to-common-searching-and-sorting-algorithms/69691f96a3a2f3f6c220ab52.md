# --description--

Parcourir une liste d'éléments est une opération courante en informatique. Il y a deux algorithmes clés que tu dois connaître pour la recherche : la recherche linéaire et la recherche binaire.

La recherche linéaire commence au début d'une liste et parcourt chaque élément jusqu'à trouver la valeur cible recherchée.

Si la valeur cible est trouvée, l'indice où elle se trouve dans la liste est renvoyé. Si la valeur cible n'est pas trouvée, `-1` est renvoyé. On renvoie `-1` parce que ce n'est pas un indice valide dans la plupart des langages de programmation.

Voici à quoi ressemble le code pour la recherche linéaire :

```javascript
function linearSearch(arr, target) {
    for (let i = 0; i < arr.length; i++) {
        if (arr[i] === target) {
            return i;
        }
    }
    return -1;
}
```

Si la liste à parcourir est `[13, 4, 7, 9, 10]` et que la valeur cible est `9`, la fonction renverrait `3` parce que `9` est à l'indice `3`.

Si on changeait la valeur cible en `5`, la fonction renverrait `-1` parce que `5` n'est pas dans la liste.

Bien que cet algorithme soit relativement simple, ce n'est pas le plus efficace. Si tu as une grande liste d'éléments, la recherche linéaire peut prendre longtemps pour trouver la valeur cible.

La complexité temporelle de la recherche linéaire est `O(n)` parce que le temps nécessaire pour parcourir la liste croît linéairement avec la taille de la liste.

La complexité spatiale de la recherche linéaire est `O(1)` parce qu'elle ne nécessite aucun espace supplémentaire pour parcourir la liste.

La recherche binaire est un algorithme plus efficace pour parcourir une grande liste d'éléments. La condition est que la liste doit être triée par ordre croissant.

La recherche binaire fonctionne en divisant la liste en deux et en vérifiant si la valeur cible est au milieu de la liste. Si la valeur cible est au milieu de la liste, l'indice de la valeur cible est renvoyé. Sinon, l'algorithme vérifie si la valeur cible est dans la moitié gauche ou droite de la liste.

Il continue à diviser les parties restantes de la liste en moitiés jusqu'à ce que la valeur cible soit trouvée. Si la valeur cible n'est pas dans la liste, il renvoie `-1`

Voici à quoi ressemble le code pour la recherche binaire :

```javascript
function binarySearch(arr, target) {
    let low = 0;
    let high = arr.length - 1;

    while (low <= high) {
        const mid = Math.floor((low + high) / 2);

        if (arr[mid] === target) {
            return mid;
        } else if (arr[mid] < target) {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }

    return -1;
}
```

On commence par identifier un indice `low` et un indice `high`. Cela représente la plage de la liste que l'on parcourt.

On vérifie ensuite la condition que `low` soit inférieur ou égal à `high`. Si `low` est supérieur à `high`, on a parcouru toute la liste et la valeur cible n'a pas été trouvée. Dans ce cas, on arrête la recherche et on renvoie `-1`.

Si l'indice `low` est inférieur ou égal à l'indice `high`, on calcule l'indice du milieu de la liste, `mid`. On vérifie ensuite si la valeur cible est à l'indice du milieu. Si c'est le cas, on renvoie l'indice du milieu.

Sinon, on vérifie si la valeur au milieu est inférieure à la cible. Si c'est le cas, on met à jour l'indice bas pour qu'il soit l'indice du milieu plus un. Cela signifie qu'on cherchera dans la moitié droite de la liste.

Enfin, si aucune des autres conditions n'est `True`, on met à jour l'indice `high` pour qu'il soit l'indice du milieu moins un. Cela signifie qu'on cherchera dans la moitié gauche de la liste.

On continue à répéter ce processus jusqu'à trouver la cible ou déterminer que la cible n'est pas dans la liste.

La complexité temporelle de la recherche binaire est `O(log n)` parce que le temps nécessaire pour parcourir la liste croît de façon logarithmique avec la taille de la liste.

La complexité spatiale de la recherche binaire est `O(1)` parce qu'elle ne nécessite aucun espace supplémentaire pour parcourir la liste.

La recherche binaire et la recherche linéaire peuvent servir pour une variété de problèmes que tu rencontreras en informatique. Il est important de comprendre les différences entre les deux algorithmes et quand utiliser chacun.
