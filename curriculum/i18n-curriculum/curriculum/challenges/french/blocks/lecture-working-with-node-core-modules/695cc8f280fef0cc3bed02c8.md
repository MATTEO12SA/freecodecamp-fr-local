# --description--

Crypto est un autre module de base intégré à Node.js. Il inclut des outils pour le hachage, le chiffrement, le déchiffrement et la création de signatures numériques, tous utilisés pour protéger les informations sensibles et sécuriser ton app.

Cela dit, `crypto` te donne des briques de bas niveau, pas de la sécurité clé en main. Écrire ton propre code de chiffrement ou d'authentification peut être dangereux si tu n'es pas prudent. Dans la plupart des cas, il vaut mieux utiliser des bibliothèques bien testées comme `bcrypt` pour le hachage de mots de passe ou `jsonwebtoken` (JWT) pour gérer les connexions et tokens.

Cela dit, il est toujours utile de comprendre comment certaines méthodes du module crypto fonctionnent.

Pour utiliser ces méthodes, tu dois importer le module `crypto` :

```js
const crypto = require("crypto");
```

Certaines méthodes servent à la transformation de données, comme celles pour hasher et chiffrer, et d'autres à la gestion des clés et de la sécurité, comme celles pour générer des valeurs aléatoires et créer des secrets.

Regardons d'abord les méthodes pour hasher et chiffrer des données.

La méthode `createHash()` crée un objet de hachage en prenant des algorithmes comme `sha256`, `sha512` ou `md5`. C'est une opération à sens unique, donc tu ne peux pas l'inverser.

`createHash()` est utile pour hasher des mots de passe et empreinter des fichiers. Pour l'utiliser, tu passes ton algorithme, tu utilises la méthode `update()` pour fournir les données, puis `digest()` avec un encodage pour obtenir la valeur de hachage :

```js
const crypto = require("crypto");

const hashedPassword = crypto
  .createHash("sha256")
  .update("myStrongPassword")
  .digest("hex");

console.log("createHash result:", hashedPassword);
// createHash result: f92c9cfa0ead1bcec05ca75888a4074ba994ad237e5e2a8c7cc6a620378c061d
```

`createHmac()` fait presque la même chose que `createHash()`, mais va plus loin en acceptant une clé secrète, afin que seule une personne ayant cette clé puisse vérifier le hachage. C'est idéal pour l'authentification et la vérification de l'intégrité des données :

```js
const crypto = require("crypto");

const hashedMessage = crypto
  .createHmac("sha256", "secretkey")
  .update("important-secret-message")
  .digest("hex");

console.log("createHmac result:", hashedMessage);
// createHmac result: da48d6f026b6036286b1fb872c63264130d5cc4271f3a213bb6ddca5a023e77e
```

Les méthodes `createCipheriv()` et `createDecipheriv()` chiffrent et déchiffrent des données. Elles prennent toutes deux un algorithme, une clé et un `iv`, qui est un bloc de données aléatoires ou uniques utilisé au début du processus de chiffrement :

```js
createCipheriv(algorithm, key, iv);
createDecipheriv(algorithm, key, iv);
```

Pour déchiffrer les données, la clé doit être la même, sinon le déchiffrement échouera, et tu obtiendras soit une erreur, soit du charabia illisible au lieu du message d'origine.

Voici les deux en action :

```js
const crypto = require("crypto");

// A key must match the algorithm length. Here AES-256 is 32 bytes
const key = Buffer.from("12345678901234567890123456789012");

// A fixed IV, 16 bytes for AES
const iv = Buffer.from("1234567890123456");

const cipher = crypto.createCipheriv("aes-256-cbc", key, iv);

let encrypted = cipher.update("Hello campers!", "utf8", "hex");
encrypted += cipher.final("hex");

console.log("Encrypted data:", encrypted);
// Encrypted data: 4ee93aa398ab44e3540e4a67ca96bc8c

// Decrypt the "Hello campers!" message
const decipher = crypto.createDecipheriv("aes-256-cbc", key, iv);
let decrypted = decipher.update(encrypted, "hex", "utf8");
decrypted += decipher.final("utf8");

console.log("Decrypted data:", decrypted);
// Decrypted data: Hello campers!
```

Une autre méthode crypto pour la transformation de données est `sign()` et `verify()`.

`sign()` crée une signature numérique à partir de données en utilisant une clé privée. Cette signature prouve que les données viennent du détenteur de la clé privée et n'ont pas été altérées.

`verify()` vérifie ensuite cette signature, et échoue si les données ou la signature ne correspondent pas.

Maintenant, regardons les méthodes crypto pour générer des valeurs aléatoires et créer des secrets.

`randomBytes()` prend une `size` et génère des tokens cryptographiquement sécurisés. Cela en fait un bon choix pour générer des UUID (identifiants universellement uniques). De plus, c'est un bon remplacement de `Math.random()`, qui n'est pas sûr pour les tokens et les clés.

```js
console.log("Random Bytes:", crypto.randomBytes(16));
// Random Bytes: <Buffer 01 88 aa 1e 2c 38 48 39 26 e1 6b a9 d8 c5 ed 49>
```

La sortie est un buffer par défaut. Comme tu l'as appris dans la leçon sur le module Buffer, tu peux convertir ce Buffer en chaîne avec la méthode `toString()` :

```js
console.log("Random Bytes:", crypto.randomBytes(16).toString("hex"));
// Random Bytes: a6154ef5a296fa176ad0f332bd94d712
```

L'argument `'hex'` dans `toString('hex')` indique ici à Node d'encoder les données binaires du Buffer en chaîne hexadécimale.

La méthode `randomInt()` prend des valeurs `min` et `max` et génère un entier aléatoire sécurisé entre elles. Elle est utile pour les OTP et la sélection aléatoire.

```js
console.log("Random Int:", crypto.randomInt(0, 100)); // 89
```

Encore une fois, l'avantage sur `Math.random()` et `Math.floor()` est que la méthode utilise une aléatoire cryptographiquement sécurisée sous le capot, donc les attaquants ne peuvent pas prédire le nombre aléatoire résultant.

Une autre méthode est `createSecretKey()`. Elle prend un buffer et génère des octets bruts encapsulés dans un `KeyObject` :

```js
const crypto = require("crypto");

const secret = crypto.createSecretKey(crypto.randomBytes(32));
console.log(secret); // SecretKeyObject [KeyObject] { [Symbol(kKeyType)]: 'secret' }
```

Tu peux ensuite utiliser la méthode `export` pour envoyer ce `KeyObject` :

```js
const secret = crypto.createSecretKey(crypto.randomBytes(32));
console.log(secret.export());
// <Buffer 53 06 a1 c7 75 69 8b 38 8b a4 b2 f7 1b bc b8
// ae e2 d1 bf 67 af 1a 6a 0a 6e a0 29 62 bb 52 52 32>
```

Et enfin, utiliser `toString()` sur le buffer pour voir sa représentation en chaîne :

```js
const secret = crypto.createSecretKey(crypto.randomBytes(32));
console.log(secret.export().toString('hex'));
// 32dfe5917668580160986f1623bf8152913329c71163be9c3404a110cd78efd6
```

En plus de celles-ci, il y a :

- `createPublicKey()` et `createPrivateKey()` qui te permettent de travailler avec des clés générées ailleurs
- `createDiffieHellman()` pour que deux parties génèrent un secret partagé sans envoyer le secret directement
- `Certificate()` pour travailler avec celui utilisé en HTTPS, afin de parser, exporter et vérifier le contenu des certificats
