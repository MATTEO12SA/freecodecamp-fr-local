# --description--

De nombreux langages et frameworks offrent des moyens de travailler avec les fichiers et dossiers. Node.js te le permet avec le module `fs` ou file system.

Cette leçon se concentre sur le module Node `fs`, son fonctionnement, et les trois façons différentes d'utiliser les méthodes qu'il fournit.

Le module Node `fs` te fournit des méthodes pour travailler avec les fichiers et dossiers, notamment ouvrir et fermer, lire et écrire, et supprimer.

Le module `fs` est un module standard de Node.js, donc il est disponible tant que Node.js est installé dans ton environnement. Pour l'utiliser, tu l'importes ainsi :

```js
const fs = require("fs");
```

La flexibilité du module `fs` est qu'il te permet d'utiliser ses méthodes de façon synchrone et asynchrone. Les méthodes du module `fs` sont asynchrones par défaut, mais pour chaque méthode, il existe une forme synchrone :

```js
fs.writeFile() // Asynchronous file writing
fs.writeFileSync() // Synchronous file writing

fs.readFile() // Asynchronous file reading
fs.readFileSync() // Synchronous file reading

fs.open() // Opens a file
fs.openAsBlob() // Opens as blob
fs.openSync() // Synchronous open
fs.opendir() // Opens directory
fs.opendirSync() // Synchronous directory open
```

Ce n'est pas tout. Selon tes besoins, tu peux utiliser les méthodes de trois façons :

- avec des callbacks, par exemple `fs.writeFile()` (asynchrone)
- avec des promises si tu préfères la syntaxe `async/await`, par exemple `fs.promises.writeFile()`
- de façon synchrone, par exemple `fs.writeFileSync()`

Voici la syntaxe de base pour l'utilisation asynchrone des méthodes :

```js
fs.writeFile("filePath", "content", "utf8", (err) => {
  if (err) {
    throw err;
  }
  console.log("File written to!");
});
```

Pour la version promises, tu peux l'importer depuis `fs/promises` ou enchaîner `promises` à ton import `fs`. Voici la syntaxe :

```js
async function promisesExample() {
  try {
    await fs.promises.writeFile("filePath", "content", "utf8");
    console.log("File written to!");
  } catch (err) {
    console.error("Error:", err);
  }
}

promisesExample();
```

Et voici la version synchrone :

```js
try {
  fs.writeFileSync("filePath", "content", "utf8");
  console.log("File written to!");
} catch (err) {
  console.error("Error:", err);
}
```

Note que l'utilisation de n'importe laquelle de ces méthodes de façon synchrone est bloquante. Autrement dit, ton programme s'arrête et attend que l'opération soit terminée avant de passer à la ligne de code suivante.

Pour des scripts rapides, de petits projets ou des tâches ponctuelles, les méthodes synchrones conviennent probablement. Mais dans les applications réelles, les I/O (entrées/sorties) bloquantes posent problème car elles peuvent figer d'autres parties de ton app pendant que Node attend que le système de fichiers termine. Cela ralentit tout et nuit aux performances et à l'expérience utilisateur.

C'est pour cela que les méthodes asynchrones existent. Elles laissent le reste de ton programme continuer pendant que Node gère les opérations sur les fichiers en arrière-plan. Traditionnellement, on utilisait des callbacks, mais ceux-ci deviennent vite difficiles à gérer quand ton app grandit.

Les promises et `async/await` résolvent ce problème. Elles restent non bloquantes, mais le code se lit comme du code synchrone normal et est bien plus facile à maintenir.

Pour cette raison, l'approche basée sur les promises est généralement préférée aujourd'hui, et c'est celle que nous utiliserons dans le reste de cette leçon.

La méthode `writeFile()` te permet d'écrire dans un fichier existant. Si le fichier n'existe pas, elle le crée dans le répertoire courant, puis y écrit le contenu spécifié.

Voici comment utiliser la méthode `writeFile()` :

```js
const fs = require("fs/promises");

async function writeToFile() {
  try {
    await fs.writeFile(
      "article.md",
      "## Node `fs` Module: The Complete Guide",
      "utf8",
    );
    console.log("File written to!");
  } catch (err) {
    console.error("Error writing to file:", err);
  }
}

writeToFile(); // File written to!
```

Voici le contenu du fichier article.md après cela :

```md
## Node `fs` Module: The Complete Guide
```

La méthode `appendFile()` te permet d'ajouter au contenu d'un fichier existant. Voici comment l'utiliser :

```js
const fs = require("fs/promises");

async function appendToFile() {
  try {
    await fs.appendFile(
      "article.md",
      "\nIn this article, you will learn all there is to know about the Node fs module...",
      "utf8",
    );
    console.log("File appended to!");
  } catch (err) {
    console.log("Error appending to file:", err);
  }
}

appendToFile(); // File appended to!
```

La méthode `readFile()` te permet de voir le contenu d'un fichier :

```js
const fs = require("fs/promises");

async function readFileContent() {
  try {
    const fileContent = await fs.readFile("article.md", "utf8");
    console.log("File content:", fileContent);
  } catch (err) {
    console.log("File read successfully");
  }
}

readFileContent();

/*
File content: ## Node `fs` Module: The Complete Guide

In this article, you will learn all there is to know about the Node fs module...
*/
```

Si tu ne spécifies pas l'encodage de caractères `utf8`, tu obtiens le contenu du fichier sous forme de buffer :

```js
async function readFileContent() {
  try {
    const fileContent = await fs.readFile("article.md");
    console.log("File content:", fileContent);
  } catch (err) {
    console.log("File read successfully");
  }
}

readFileContent();

/*

72 more bytes>
*/
```

Enfin, la méthode `unlink()` te permet de supprimer un fichier :

```js
const fs = require("fs/promises");

async function deleteFile() {
  try {
    await fs.unlink("article.ts");
    console.log("File deleted successfully!");
  } catch (err) {
    console.error("Error deleting file:", err);
  }
}

deleteFile();
```

Si le fichier n'existe pas, tu obtiens un message d'erreur similaire à celui-ci :

```bash
Error deleting file: Error: ENOENT: no such file or directory, unlink 'article.ts'
```

S'il existe, le fichier est supprimé, et tu obtiens le message de succès que tu as défini.
