# --description--

Le module OS est un autre module standard intégré à Node.js.

Il te permet d'interagir avec le système d'exploitation sur lequel Node s'exécute pour accéder à des informations vitales comme le type d'OS, les détails du CPU, la mémoire disponible, la mémoire totale, les interfaces réseau, et plus encore.

Pour utiliser le module OS, tu l'importes ainsi :

```js
const os = require("os");
```

Le module OS fournit plusieurs méthodes que tu peux utiliser pour rendre ton application plus consciente du système. Regardons quelques-unes des plus courantes.

La méthode `platform()` récupère le système d'exploitation sur lequel Node s'exécute actuellement :

```js
const os = require("os");
console.log(os.platform()); // darwin
```

Elle peut être utile pour implémenter des scripts multiplateformes :

```js
if (os.platform() === 'win32') {
 // Windows specific code
} else {
 // Non-Windows specific code
}
```

La méthode `arch()` affiche une chaîne représentant l'architecture CPU pour laquelle Node.js a été compilé :

```js
const os = require("os");
console.log(os.arch()); // arm64
```

Cela peut être utile si tu veux que les utilisateurs téléchargent les bons binaires et dépendances pour une architecture donnée.

D'autres valeurs possibles sont `'x64'`, `'arm'`, `'arm64'`, `'ia32'`, `'mips'`, `'ppc'`, et d'autres.

`type()` obtient le nom officiel de l'OS, pour que tu puisses identifier les systèmes d'exploitation par programme :

```js
const os = require("os");
console.log(os.type()); // Darwin (the core OS for macOS, iOS, and other Apple products)
```

`release()` affiche la version du noyau OS du système, la partie centrale du système d'exploitation qui gère les ressources système et la communication entre le matériel et les composants logiciels. Cette méthode peut être utile pour suivre la compatibilité entre les versions du noyau OS et les exigences du serveur.

Elle renvoie cela sous forme de chaîne comme `'20.6.0'` :

```js
const os = require("os");
console.log(os.release()); // 25.0.0
```

`version()` renvoie la version spécifique du système d'exploitation avec plus de détails que la méthode `release()` :

```js
const os = require("os");
console.log(os.version());
// Darwin Kernel Version 25.0.0: Wed Sep 17 21:41:39 PDT 2025;
// root:xnu-12377.1.9~141/RELEASE_ARM64_T8103
```

`cpus()` renvoie un tableau d'objets avec des détails sur chaque cœur CPU logique. Cela peut aider à surveiller la charge CPU :

```js

console.log(os.cpus());
```

`uptime()` affiche le temps écoulé depuis le démarrage du système. Cela peut aider à déterminer depuis combien de temps les serveurs tournent :

```js
const os = require("os");
console.log(os.uptime()); // 23047
```

`totalmem()` et `freemem()` affichent respectivement la quantité totale de mémoire système en octets et la mémoire système libre en octets :

```js
const os = require("os");
console.log(os.totalmem()); // 8589934592 (8 GB)
console.log(os.freemem()); // 93585408 (87 MB)
```

`userInfo()` renvoie un objet contenant des informations sur l'utilisateur système actuel :

```js
const os = require("os");
console.log(os.userInfo());

/*
[Object: null prototype] {

 gid: 20,

 homedir: '/Users/user',
 shell: '/bin/zsh'
}
*/
```
