# --description--

JavaScript a été créé à l'origine pour s'exécuter dans les navigateurs web, où son rôle principal était de rendre les pages interactives. Pour cette raison, le JavaScript précoce se concentrait surtout sur le texte des formulaires et la manipulation du Document Object Model (DOM).

Cependant, toutes les données sur le web ne sont pas du texte. Les fichiers, images et vidéos sont des données binaires, qui nécessitent d'autres mécanismes de traitement. Dans les navigateurs, ces types de données sont généralement traités par des composants spécialisés du navigateur plutôt que par JavaScript lui-même.

Les navigateurs modernes utilisent des moteurs de rendu et des moteurs JavaScript pour gérer ces tâches — par exemple Blink (avec V8) dans Chrome, WebKit (avec JavaScriptCore) dans Safari, et Gecko (avec SpiderMonkey) dans Firefox.

Node.js ne s'exécute pas dans le navigateur, il lui fallait donc sa propre façon de gérer les données binaires, surtout pour les entrées/sorties (I/O) de fichiers et les flux TCP, où les données arrivent par morceaux. C'est là qu'intervient le module `Buffer`.

Le module Node.js `Buffer` te permet de travailler directement avec des données binaires comme des fichiers, images ou flux réseau. Avec lui, tu peux stocker et manipuler des binaires directement en mémoire.

Comme le module `fs`, `Buffer` est l'un des modules de base de Node.js, donc tu n'as pas besoin de l'installer séparément avant de l'utiliser.

Pour l'utiliser, importe d'abord le module par déstructuration :

```js
const { Buffer } = require("buffer");
```

Puis appelle `Buffer` avec les méthodes qu'il fournit. Par exemple, `Buffer.from()` te permet de créer un buffer à partir d'une chaîne, d'un tableau ou d'autres données brutes.

Voici comment créer un `Buffer` à partir d'une chaîne et d'un tableau :

```js
// Create a buffer from a string
const myStrBuffer = Buffer.from("freeCodeCamp");
console.log(myStrBuffer); // <Buffer 66 72 65 65 43 6f 64 65 43 61 6d 70>

// Create a buffer from an array of numbers
const myNumBuffer = Buffer.from([
  70, 82, 69, 69, 67, 79, 68, 69, 67, 65, 77, 80,
]);

console.log(myNumBuffer); // <Buffer 46 52 45 45 43 4f 44 45 43 41 4d 50>
```

Bien qu'il soit possible d'utiliser certaines méthodes du module `Buffer` sans l'importer d'abord, d'autres méthodes ne sont pas disponibles sauf si tu importes explicitement `Buffer`. Il est donc recommandé d'importer toujours Buffer dès que tu l'utilises dans tes projets.

Tu peux accéder aux éléments individuels d'un `buffer` comme à un tableau :

```js
console.log(myNumBuffer[0]); // 70
console.log(myStrBuffer[0]); // 102
```

Tu peux aussi utiliser la méthode `toString()` sur les buffers pour voir à quoi ils ressemblent vraiment :

```js
console.log(myStrBuffer.toString()); // freeCodeCamp
console.log(myNumBuffer.toString()); // FREECODECAMP
```

`Buffer.alloc()` te permet de créer un nouveau buffer d'une taille donnée (nombre d'octets). Chaque octet à l'intérieur est automatiquement rempli avec `0` :

```js
const someBuffer = Buffer.alloc(10);
console.log(someBuffer); // <Buffer 00 00 00 00 00 00 00 00 00 00>
```

Tu peux voir que le buffer est initialisé avec des zéros, selon la taille passée à la méthode `alloc()`.

Tu peux ensuite utiliser la méthode `Buffer.write()` pour écrire dans ce buffer :

```js
someBuffer.write("Hello fCC");

console.log(someBuffer); // <Buffer 48 65 6c 6c 6f 20 66 43 43 00>
console.log(someBuffer.toString()); // Hello fCC
```

Si tu écris plus de données que le buffer ne peut en contenir, elles seront tronquées :

```js
someBuffer.write("Hello freeCodeCamp");

console.log(someBuffer); // <Buffer 48 65 6c 6c 6f 20 66 72 65 65>
console.log(someBuffer.toString()); // Hello free
```

Enfin, tu peux utiliser `Buffer.byteLength()` pour afficher le nombre d'octets nécessaires pour stocker une chaîne dans un certain encodage :

```js
console.log(Buffer.byteLength("Hello freeCodeCamp")); // 18
```

D'autres méthodes `Buffer` incluent :

- `Buffer.isBuffer()` : vérifie si un objet donné est un buffer
- `Buffer.compare()` : compare deux buffers et renvoie leur ordre de tri
- `Buffer.concat()` : joint plusieurs buffers en un seul
