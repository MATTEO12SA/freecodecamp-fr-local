# --description--

Si tu as regardé la console, tu as peut-être été surpris de voir la valeur `false` au lieu de `true`. Cela arrive parce que React ne met pas immédiatement à jour le state. Le state ne sera mis à jour qu'au prochain cycle de rendu.

C'est une erreur courante pour les développeurs nouveaux à React de placer des instructions console juste après une fonction set. C'est donc quelque chose à garder en tête quand tu construis tes applications React.

Comme le `console.log()` n'est plus nécessaire, retire-le de ta fonction `handleToggleVisibility`.

# --hints--
