# --description--

Dans la leçon précédente, tu as appris à travailler avec les types union. Une façon courante de travailler avec les types union est d’utiliser un alias de type.

Un alias de type est un nom pour un type. Voici un exemple qui donne un nom à un type union :

```ts
type ID = number | string;
```

Souvent dans tes projets, tu créeras des alias de type et tu les utiliseras dans tout ton programme comme ceci :

```ts
type ID = number | string;

type User = {
  id: ID;
  name: string;
};

function getUserId(user: User): ID {
  return user.id;
}
```

Cet exemple utilise deux types nommés `ID` et `User`. `ID` serait un type union pour `number` ou `string`, tandis que `User` est un type d’objet avec les propriétés `id` et `name`. L’`id` est spécifié avec le type `ID` tandis que le `name` a le type `string`.

La fonction `getUserId` a un paramètre appelé `user` et son type est `User`. Le type de retour de la fonction `getUserId` serait `ID`.

Les alias de type sont une excellente façon de décrire la forme d’un objet. Il est courant de créer des types d’objets et de les utiliser dans des tableaux comme ceci :

```ts
type User = {
  id: number | string;
  name: string;
};

const users: User[] = [
  { id: 101, name: "Alice" },
  { id: "A102", name: "Bob" },
  { id: 103, name: "Charlie" }
];
```

Dans cet exemple, le tableau `users` ne doit être rempli que d’objets `User`. Si tu oublies une propriété dans l’un des objets, TypeScript lèvera une erreur comme celle-ci :

```ts
type User = {
  id: number | string;
  name: string;
};

const users: User[] = [
  // Property 'name' is missing in type '{ id: number; }' but required in type 'User'.
  { id: 101 },
  { id: "A102", name: "Bob" },
  { id: 103, name: "Charlie" }
];
```

Tu as peut-être remarqué l’utilisation du PascalCase pour nommer les alias de type. C’est parce que, par convention, utiliser le PascalCase aide à distinguer les types des variables. Cela aide aussi à la lisibilité. Quand tu vois `User[]`, tu sauras que c’est un tableau d’objets de type `User`.
