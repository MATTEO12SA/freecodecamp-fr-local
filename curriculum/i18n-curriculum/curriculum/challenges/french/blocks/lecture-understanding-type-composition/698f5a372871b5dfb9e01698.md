# --description--

Dans les leçons précédentes, tu as appris à travailler avec des types primitifs comme `string` et `boolean`. Mais TypeScript te permet de construire de nouveaux types à partir de types existants. Un exemple serait le type union.

Un type union est un type qui combine deux ou plusieurs autres types.

Voici la syntaxe de base :

```ts
type1 | type2 | type3
```

Regardons quelques exemples pour mieux comprendre le concept.

Voici une variable appelée `id` avec un type union pour `string` ou `number` :

```ts
let id: string | number = "user_783";
```

La valeur peut être mise à jour avec un nombre, ce qui reste valide pour le type union :

```ts
let id: string | number = 1024;
```

Si tu essayais d’assigner une autre valeur qui n’est ni un `string` ni un `number`, TypeScript afficherait un message d’erreur :

```ts
// Type 'string[]' is not assignable to type 'string | number'.
let id: string | number = ["Java", "Python"];
```

Quand tu travailles avec des types union, il est important d’utiliser des méthodes qui fonctionnent pour tous les types, sinon TypeScript lèvera une erreur comme celle-ci :

```ts
function getId(id: string | number) {
  // Property 'toUpperCase' does not exist on type 'string | number'.
  return id.toUpperCase();
}
```

Il y a une solution qui consiste à réduire (narrow) l’union. Mais tu en apprendras davantage à ce sujet ainsi que sur le fonctionnement des types union avec les alias de type dans de futures leçons.

Les types union sont aussi utiles quand tu travailles avec les valeurs `null` et `undefined`.

Voici un exemple où une variable peut contenir une valeur `string`, ou être `null` si aucune valeur n’a encore été définie :

```ts
let username: string | null;

// Type 'number' is not assignable to type 'string | null'.
username = 42;
```

Dans ce cas, `username` peut être soit un `string`, soit `null`, mais rien d’autre. Tu pourrais utiliser `null` quand tu veux représenter intentionnellement l’absence d’une valeur.

Voici un autre exemple utilisant `undefined` :

```ts
let score: number | undefined;

score = undefined;

// Type 'string' is not assignable to type 'number | undefined'.
score = "high";
```

Dans cet exemple, `score` peut être soit un `number`, soit `undefined`. Tu pourrais utiliser `undefined` quand une valeur n’a pas encore été assignée.

Utiliser des types union avec `null` et `undefined` clarifie quand une valeur peut manquer, tout en permettant à TypeScript de détecter les assignations invalides.
