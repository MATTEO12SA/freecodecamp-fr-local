# --interactive--

Dans la leçon précédente, tu as appris à travailler avec l'objet `arguments`, qui est un objet de type tableau contenant les valeurs des arguments passés à la fonction.

:::interactive_editor

```js
function logArgs() {
  for (const arg of arguments) {
    console.log(arg);
  }
}

logArgs(1, 2, 3);
// result:
// 1
// 2
// 3
```

:::

Bien que ce soit une façon valide d'accéder à un ensemble variable d'arguments et d'y travailler depuis une fonction, les applications JavaScript modernes utiliseront plutôt la syntaxe des paramètres rest.

Voici un exemple mis à jour utilisant la syntaxe des paramètres rest au lieu de l'objet `arguments` :

:::interactive_editor

```js
function logArgs(...args) {
  for (const arg of args) {
    console.log(arg);
  }
}

logArgs(1, 2, 3);
// result:
// 1
// 2
// 3
```

:::

Cet exemple mis à jour ne fait plus référence directement à l'objet `arguments`. À la place, le dernier paramètre de la définition de la fonction a trois points devant lui. Cela fait que ce paramètre rest est placé dans un objet `Array`. Tu peux nommer ce paramètre rest comme tu le souhaites. Assure-toi simplement qu'il est le dernier paramètre dans la définition de la fonction, comme ceci :

```js
function exampleFunction(a, b, ...restOfArgs) {
  // some code here
}

function anotherFunction(x, y, ...theArgs) {
  // some code here
}
```

Il y a quelques restrictions supplémentaires lorsqu'on travaille avec la syntaxe des paramètres rest. Une restriction est que les définitions de fonction ne peuvent avoir qu'un seul paramètre rest. L'exemple suivant serait donc considéré comme invalide.

```js
// Won't work

function badFunction(...args, ...moreArgs) {
  // some code here
}
```

La restriction suivante est que les virgules finales ne sont pas autorisées après le paramètre rest : `function exampleFunction(a, b, ...restOfArgs, )`.

Une autre restriction est que le paramètre rest ne peut pas avoir de valeur par défaut. Sinon, une `SyntaxError` sera levée.

```js
function badFunction(...args = [1,2]){
  // some code here
}
```

Alors, quelles sont certaines différences entre l'objet `arguments` et les paramètres `rest` ?

Une différence clé est que l'objet `arguments` n'est pas un vrai tableau, donc il ne prend pas en charge des méthodes comme `includes`, `pop` et `push`. Mais le paramètre rest est une instance de `Array`. Tu peux donc utiliser des méthodes de tableau intégrées valides sans avoir besoin de le convertir d'abord en un vrai tableau.

:::interactive_editor

```js
function hasCat(...args) {
  return args.includes("cat");
}

console.log(hasCat("dog", "chicken", "cat")); // true
console.log(hasCat("dog", "chicken", "horse")); // false
```

:::
