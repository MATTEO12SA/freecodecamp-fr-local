# --interactive--

Comme tu te le rappelles des leçons et ateliers précédents, tu peux créer des fonctions avec un certain nombre de paramètres et appeler cette fonction avec des arguments.

Voici un rappel :

```js
// function definition
function getSum(num1, num2) {
  return num1 + num2;
}

// function call
getSum(3, 4); // 7
```

Mais que se passe-t-il si tu as une fonction appelée avec plus d'arguments qu'elle n'en accepte par définition ?

:::interactive_editor

```js
// function definition
function getSum(num1, num2) {
  return num1 + num2;
}

// function call with extra argument
console.log(getSum(3, 4, 5)); // 7
```

:::

JavaScript ne lèvera pas d'erreur dans ce cas. Il ignorera plutôt l'argument supplémentaire et additionnera simplement les nombres `3` et `4`. Les fonctions qui acceptent un nombre variable d'arguments sont appelées <dfn>fonctions variadiques</dfn>.

Si tu travailles avec des fonctions variadiques, tu peux utiliser l'objet `arguments`. Cet objet de type tableau contient les valeurs des arguments passés à la fonction.

Voici un exemple :

:::interactive_editor

```js
function logArgs() {
  for (const arg of arguments) {
    console.log(arg);
  }
}

logArgs(1, 2, 3);
// result:
// 1
// 2
// 3

logArgs("example"); // "example"
```

:::

Comme l'objet `arguments` est de type tableau, tu peux accéder à un argument à un index précis comme ceci :

:::interactive_editor

```js
function getArg() {
  return arguments[1];
}

console.log(getArg(2, 4, 6)); // 4
```

:::

Tu peux aussi utiliser la propriété `length` comme ceci pour obtenir le nombre d'arguments avec lesquels la fonction a été appelée :

:::interactive_editor

```js
function getArgs() {
  return arguments.length;
}

console.log(getArgs("Example")); // 1
console.log(getArgs("Another", "Example")); // 2
```

:::

Même si l'objet `arguments` semble se comporter comme un vrai tableau, il n'a pas les méthodes `Array` intégrées comme `includes` ou `push`. Pour avoir accès à ces méthodes, tu devrais d'abord convertir l'objet `arguments` en un vrai tableau en utilisant quelque chose comme `slice`, `Array.from()` ou l'opérateur spread :

:::interactive_editor

```js
function hasCat() {
  return [...arguments].includes("cat");
}

console.log(hasCat("dog", "chicken", "cat")); // true
console.log(hasCat("dog", "chicken", "horse")); // false
```

:::

Bien qu'il soit possible de travailler avec l'objet `arguments` pour les fonctions variadiques, les applications JavaScript modernes utilisent normalement la syntaxe des paramètres rest. Tu en apprendras davantage dans une leçon future.

## --text--

Pourquoi ne peux-tu pas utiliser les méthodes `Array` intégrées comme `includes` ou `push` sur l'objet `arguments` ?

## --answers--

L'objet `arguments` est toujours vide sauf s'il est explicitement initialisé.

### --feedback--
