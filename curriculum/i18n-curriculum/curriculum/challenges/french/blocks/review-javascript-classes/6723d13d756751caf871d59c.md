## Bases pour travailler avec les classes

- **Définition** : Les classes en JavaScript servent à définir des modèles pour créer des objets et encapsuler des données. Les classes incluent un constructeur, une méthode spéciale appelée automatiquement quand un nouvel objet est créé à partir de la classe. Elle sert à initialiser les propriétés de l'objet. Le mot-clé `this` est utilisé ici pour faire référence à l'instance courante de la classe. Sous le constructeur, tu peux avoir ce qu'on appelle des méthodes. Les méthodes sont des fonctions définies dans une classe qui effectuent des actions ou des opérations sur les données ou l'état de la classe. Elles servent à définir des comportements que les instances de la classe peuvent réaliser.

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);  // Gino
```

:::

Pour créer une nouvelle instance de la classe, tu utiliseras le mot-clé `new` suivi du nom de la classe :

```js
const dog = new Dog("Gino");
```

Tu peux aussi créer des classes sous forme d'expressions de classe. Dans ce cas, la classe est anonyme et assignée à une variable.

:::interactive_editor

```js
const Dog = class {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
};

const dog = new Dog("Gino");
console.log(dog.name);  // Gino
dog.bark();  // Gino says woof!
```

:::

## Héritage de classes

- **Définition** : En programmation, l'héritage te permet de définir des classes qui héritent des propriétés et méthodes de classes parentes. Cela favorise la réutilisation du code et établit une relation hiérarchique entre les classes. Une classe parente est une classe qui sert de modèle pour d'autres classes. Elle définit des propriétés et méthodes héritées par d'autres classes. Une classe enfant est une classe qui hérite des propriétés et méthodes d'une autre classe. Les classes enfants peuvent aussi étendre les fonctionnalités de leurs classes parentes en ajoutant de nouvelles propriétés et méthodes. En JavaScript, on utilise le mot-clé `extends` pour mettre en place l'héritage. Ce mot-clé indique qu'une classe est la classe enfant d'une autre classe.

:::interactive_editor

```js
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  honk() {
    console.log("Honk! Honk!");
  }
}

const myCar = new Car("freeCodeCamp Motors", 2019);
console.log(myCar.brand);  // freeCodeCamp Motors
console.log(myCar.year);  // 2019
myCar.honk();  // Honk! Honk!
```

:::

Le mot-clé `super` sert à accéder aux méthodes, constructeurs et champs de la classe parente.

:::interactive_editor

```js
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  constructor(brand, year, numDoors) {
    super(brand, year);
    this.numDoors = numDoors;
  }
}

const myCar = new Car("freeCodeCamp Motors", 2019, 4);
console.log(myCar.brand);  // freeCodeCamp Motors
console.log(myCar.year);  // 2019
console.log(myCar.numDoors);  // 4
```

:::

## Travailler avec les méthodes et propriétés statiques

- **Méthodes statiques** : Ces méthodes sont souvent utilisées pour des fonctions utilitaires qui n'ont pas besoin d'accéder à l'état spécifique d'un objet. Elles sont définies dans les classes pour encapsuler des fonctionnalités liées.

:::interactive_editor

```js
class Movie {
  constructor(title, rating) {
    this.title = title;
    this.rating = rating;
  }

  static compareMovies(movieA, movieB) {
    if (movieA.rating > movieB.rating) {
      console.log(`${movieA.title} has a higher rating.`);
    } else if (movieA.rating < movieB.rating) {
      console.log(`${movieB.title} has a higher rating.`);
    } else {
      console.log("These movies have the same rating.");
    }
  }
}

let movieA = new Movie("Movie A", 80);
let movieB = new Movie("Movie B", 45);

Movie.compareMovies(movieA, movieB);  // Movie A has a higher rating.
```

:::

Les méthodes statiques sont aussi utiles pour implémenter des méthodes « factory ». Une méthode factory est une méthode que tu définis en plus du constructeur pour créer des objets selon des critères spécifiques.

```js
class Pizza {
  constructor(type, price) {
    this.type = type;
    this.price = price;
  }

  static createMargherita() {
    return new this("Margherita", 6.99);
  }
}

let myPizza = Pizza.createMargherita();
console.log(myPizza);  // Pizza { type: "Margherita", price: 6.99 }
console.log(myPizza.type);  // Margherita
```

- **Propriétés statiques** : Ces propriétés servent à définir des valeurs ou attributs associés à la classe elle-même, plutôt qu'aux instances de la classe. Les propriétés statiques sont partagées entre toutes les instances de la classe et peuvent être consultées sans créer d'instance de la classe.

:::interactive_editor

```ts
class Car {
  // Static property
  static numberOfWheels = 4;

  constructor(make, model) {
    this.make = make;
    this.model = model;
  }

  // Instance method
  getCarInfo() {
    return `${this.make} ${this.model}`;
  }

  // Static method
  static getNumberOfWheels() {
    return Car.numberOfWheels;
  }
}

// Accessing static property directly from the class
console.log(Car.numberOfWheels);  // 4
```

:::
