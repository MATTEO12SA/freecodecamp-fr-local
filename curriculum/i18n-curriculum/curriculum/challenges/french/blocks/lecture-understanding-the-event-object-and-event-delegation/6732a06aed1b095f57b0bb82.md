# --interactive--

L'événement `change` est un événement spécial déclenché quand l'utilisateur modifie la valeur de certains éléments de saisie. Plus précisément :

- Quand une case à cocher est cochée ou décochée.

- Quand un bouton radio est coché.

- Quand l'utilisateur fait une sélection dans un sélecteur de date ou un menu déroulant, par exemple.

- Quand un champ perd le focus (l'utilisateur passe au champ suivant au clavier, ou clique hors du formulaire) après avoir modifié la valeur.

- Quand l'utilisateur confirme autrement la valeur, par exemple en appuyant sur Entrée après avoir saisi du texte.

Note que l'événement `change` ne se déclenche PAS quand ton utilisateur tape dans un champ. L'événement `change` ne se déclenchera qu'après qu'il ait porté le focus sur un autre élément.

Voici un exemple d'utilisation de l'événement `change` avec un menu déroulant :

:::interactive_editor

```html
<select id="select-menu">
  <option value="option1">Option 1</option>
  <option value="option2">Option 2</option>
  <option value="option3">Option 3</option>
</select>
<script src="index.js"></script>
```

```js
const selectMenu = document.getElementById("select-menu");
selectMenu.addEventListener("change", (event) => {
  console.log(`You selected: ${event.target.value}`);
});
```

:::

Chaque fois que l'utilisateur sélectionne une option différente dans le menu déroulant, l'événement `change` se déclenche, et la valeur sélectionnée s'affiche dans la console.

L'événement `change` génère quand même un objet `Event`, mais contrairement à la plupart des autres événements, il ne génère pas d'implémentation personnalisée — les seules propriétés et méthodes auxquelles tu auras accès sont celles de l'objet `Event` de base.

Cela diffère de l'événement `input`, qui génère un objet `InputEvent` dédié. L'événement change diffère aussi sur quelques points. Un événement `input` SE DÉCLENCHE quand un utilisateur tape du contenu dans un champ, par exemple.

Ces différences sont importantes à retenir, car tu pourrais être surpris par le moment où ces événements se déclenchent.
