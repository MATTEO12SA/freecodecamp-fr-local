# --description--

En JavaScript, un `Map` est un objet intégré qui stocke des paires clé-valeur, similaire à un objet. Cependant, il diffère des objets JavaScript standard en autorisant des clés de n'importe quel type, y compris des objets et des fonctions.

Un `WeakMap` est une collection de paires clé-valeur, similaire à un `Map`, mais il utilise des références faibles pour ses clés. Les clés doivent être des objets, tandis que les valeurs peuvent être de n'importe quel type.

Pense à la relation entre un `WeakMap` et un `Map` comme similaire à la relation entre un `WeakSet` et un `Set`, comme tu l'as appris dans la leçon précédente.

Pour créer un `Map`, tu utilises le constructeur `Map()` précédé du mot-clé `new` :

```js
const myFirstMap = new Map();
```

Tu peux initialiser le Map avec des valeurs :

```js
const myTreesMap = new Map([
 [{ type: 'deciduous' }, 'Maple tree'],
 [['forest', 'grove'], 'Pine tree'],
 [42, 'Oak tree'],
 [true, 'Birch tree'],
 [function() { return 'I am a function key'; }, 'Willow tree'],
]);
```

Si tu n'as pas initialisé le `Map` avec des valeurs, tu peux utiliser la méthode `set()` pour les ajouter :

```js
const myTreesMap = new Map();
myTreesMap.set({ type: 'deciduous' }, 'Maple tree');
myTreesMap.set([1, 2], 'Pine tree');
myTreesMap.set(42, 'Oak tree');
myTreesMap.set(true, 'Birch tree');
myTreesMap.set(function() { return "I'm a function key"; }, 'Willow tree');

console.log(myTreesMap);
```

D'autres méthodes que tu peux utiliser pour travailler avec un `Map` sont :

- `get(key)` pour récupérer la valeur associée à la `key` spécifiée.
- `has(key)` pour vérifier si une `key` existe dans le `Map`.
- `delete(key)` pour retirer une paire clé-valeur du `Map`.
- `clear()` pour retirer toutes les paires clé-valeur.
- `entries()` pour consulter les entrées du `Map` (il renvoie les entrées dans un `MapIterator`).
- `forEach()` pour parcourir les entrées du `Map`.
- `size` pour indiquer le nombre de paires clé-valeur dans le `Map`.

Il existe un constructeur `WeakMap()` que tu peux utiliser pour créer un `WeakMap` :

```js
const myFirstWeakMap = new WeakMap();
```

Les méthodes `set()`, `get()`, `has()` et `delete()` sont toutes disponibles aussi avec un `WeakMap`. Par exemple, voici comment tu peux assigner des éléments au `Map` avec la méthode `set()` :

```js
const myTreeWeakMap = new WeakMap();

myTreeWeakMap.set({ id: 1 }, 'Maple tree');
myTreeWeakMap.set({ id: 2 }, 'Pine tree');
myTreeWeakMap.set({ id: 3 }, 'Oak tree');
myTreeWeakMap.set({ id: 4 }, 'Birch tree');
myTreeWeakMap.set({ id: 5 }, 'Willow tree');

console.log(myTreeWeakMap);
```

Voici à quoi ressemble un `WeakMap` dans la console :

```js
/*
WeakMap {{…} => 'Willow tree', {…} => 'Maple tree', {…} => 'Pine tree', {…} => 'Oak tree'}
  [[Entries]]
    No properties
  [[Prototype]]: WeakMap
*/
```

Voici les différences entre un `Map` et un `WeakMap` :

| **Fonctionnalité** | **Map** | **WeakMap** |
| --- | --- | --- |
| **Type de clé** | Les clés peuvent être de n'importe quel type de données, y compris des chaînes, des nombres, des objets, ou même des fonctions. | Les clés doivent être des objets. |
| **Cas d'usage** | Utilise un `Map` quand tu as besoin d'associer des données à n'importe quel type de clé. | Utilise un `WeakMap` quand tu as seulement besoin d'associer des données à des objets. |
| **Itération** | Tu peux parcourir un `Map` avec `forEach()`, `keys()`, `values()` ou `entries()`. | Un `WeakMap` n'est pas itérable. |
| **Propriété size** | `Map` a une propriété `size` pour obtenir le nombre de paires clé-valeur. | `WeakMap` n'a pas de propriété `size`. |

## --text--

Lequel de ces éléments différencie un `Map` d'un `WeakMap` en JavaScript ?

## --answers--

Un `Map` n'autorise que des objets comme clés, tandis qu'un `WeakMap` autorise des clés de n'importe quel type.
