# --description--

En JavaScript, `Set` est un objet intégré pour gérer des collections de données. Il te permet de stocker des valeurs uniques de n'importe quel type, qu'elles soient primitives ou des références d'objets. `Set` garantit que chaque valeur n'y apparaît qu'une seule fois, ce qui le rend utile pour éliminer les doublons d'un tableau ou gérer des collections de valeurs distinctes.

Quant à `WeakSet`, c'est un type spécial de `Set` avec moins de fonctionnalités qui te permet de stocker des références faibles à des objets et des symboles. Contrairement à `Set`, `WeakSet` ne prend pas en charge les primitives comme les nombres ou les chaînes.

Contrairement à un `Set` classique, un `WeakSet` ne stocke que des objets, et les références à ces objets sont « faibles », ce qui signifie que les WeakSets n'empêchent pas les objets stockés d'être collectés par le ramasse-miettes s'il n'existe aucune autre référence vers eux. Plus simplement, si l'objet n'est utilisé nulle part ailleurs dans ton code, il est retiré automatiquement pour libérer de la mémoire.

Pour créer un `Set`, tu utilises le constructeur `Set` et tu l'assignes à une variable :

```js
const myFirstSet = new Set();
```

Tu peux aussi initialiser le `Set` avec des valeurs :

```js
const treeSet = new Set(["Baobab", "Jackalberry", "Mopane Tree", "Breadfruit"]);
```

Si tu affiches le `Set` dans la console, voici à quoi ressemble la sortie :

```js
/*
Set(4) {"Baobab", "Jackalberry", "Mopane Tree", "Breadfruit"}
  [[Entries]]
  0: "Baobab"
    value: "Baobab"
  1: "Jackalberry"
    value: "Jackalberry"
  2: "Mopane Tree"
    value: "Mopane Tree"
  3: "Breadfruit"
    value: "Breadfruit"
  size: 4
  [[Prototype]]: Set
*/
```

Si tu n'as pas initialisé le `Set` avec des valeurs, tu peux utiliser la méthode `add()` pour ajouter un élément au `Set` :

```js
const treeSet = new Set();

// Add items to the treeSet
treeSet.add("Baobab");
treeSet.add("Jackalberry");
treeSet.add("Mopane Tree");
treeSet.add("Breadfruit");
```

Le résultat et son apparence dans la console restent les mêmes.

N'oublie pas que les éléments en double seront ignorés dans le `Set` :

```js
const treeSet = new Set();

// Add items to the treeSet
treeSet.add("Baobab");
treeSet.add("Jackalberry");
treeSet.add("Mopane Tree");
treeSet.add("Breadfruit");
treeSet.add("Baobab"); //duplicate item will be ignored

console.log(treeSet);
// Set(4) {"Baobab", "Jackalberry", "Mopane Tree", "Breadfruit"}
```

Les autres méthodes que tu peux utiliser pour manipuler un `Set` sont :

- `delete()`
- `clear()`
- `has()`
- `entries()`
- `forEach()`
- `keys()`
- `values()`

Regardons comment ces méthodes fonctionnent une par une. `delete()` retire un élément spécifié du `Set` :

```js
const treeSet = new Set();

// Add items to the treeSet
treeSet.add("Baobab");
treeSet.add("Jackalberry");
treeSet.add("Mopane Tree");
treeSet.add("Breadfruit");

treeSet.delete("Breadfruit");

console.log(treeSet); // Set(3) {"Baobab", "Jackalberry", "Mopane Tree"}
```

`has()` vérifie si une valeur spécifiée existe dans le `Set` :

```js
const treeSet = new Set();

// Add items to the treeSet
treeSet.add("Baobab");
treeSet.add("Jackalberry");
treeSet.add("Mopane Tree");
treeSet.add("Breadfruit");

treeSet.delete("Breadfruit");

console.log(treeSet.has("Breadfruit")); // false
```

`entries()` renvoie un itérateur `Set` contenant un tableau des valeurs au format `[value, value]` :

```js
const treeSet = new Set();

// Add items to the treeSet
treeSet.add("Baobab");
treeSet.add("Jackalberry");
treeSet.add("Mopane Tree");
treeSet.add("Breadfruit");

treeSet.delete("Breadfruit");

console.log(treeSet.entries());
// SetIterator {"Baobab" => "Baobab", "Jackalberry" => "Jackalberry", "Mopane Tree" => "Mopane Tree"}
```

`keys()` et `values()` affichent les valeurs du `Set`. `keys()` n'est qu'un alias de la méthode `values()` :

```js
const treeSet = new Set();

// Add items to the treeSet
treeSet.add("Baobab");
treeSet.add("Jackalberry");
treeSet.add("Mopane Tree");
treeSet.add("Breadfruit");

treeSet.delete("Breadfruit");

console.log("Keys: ", treeSet.keys());
console.log("Values: ", treeSet.values());
// Keys: SetIterator {"Baobab", "Jackalberry", "Mopane Tree"}
// Values: SetIterator {"Baobab", "Jackalberry", "Mopane Tree"}
```

`forEach()` te permet de parcourir le `Set` :

```js
const treeSet = new Set();

// Add items to the treeSet
treeSet.add("Baobab");
treeSet.add("Jackalberry");
treeSet.add("Mopane Tree");
treeSet.add("Breadfruit");

treeSet.delete("Breadfruit");

treeSet.forEach((tree) => console.log(tree));
/*
Baobab
Jackalberry
Mopane Tree
*/
```

`clear()` retire tous les éléments du tableau :

```js
const treeSet = new Set();

// Add items to the treeSet
treeSet.add("Baobab");
treeSet.add("Jackalberry");
treeSet.add("Mopane Tree");
treeSet.add("Breadfruit");

treeSet.delete("Breadfruit");

treeSet.clear();

console.log(treeSet); // Set(0) {size: 0}
```

Il convient aussi de mentionner qu'il existe une propriété `size` qui renvoie le nombre d'éléments dans le `Set` :

```js
const treeSet = new Set();

// Add items to the treeSet
treeSet.add("Baobab");
treeSet.add("Jackalberry");
treeSet.add("Mopane Tree");
treeSet.add("Breadfruit");

treeSet.delete("Breadfruit");

console.log(treeSet.size); // 3
```

Tout comme `Set`, il existe aussi un constructeur `WeakSet` que tu peux utiliser pour créer un `WeakSet` :

```javascript
const treeWeakSet = new WeakSet();
```

`WeakSet` dispose aussi des méthodes `add()`, `delete()` et `has()` :

```javascript
const treeWeakSet = new WeakSet();

const baobab = { name: "Baobab" };
const jackalberry = { name: "Jackalberry" };
const mopaneTree = { name: "Mopane Tree" };
const breadfruit = { name: "Breadfruit" };

treeWeakSet.add(baobab);
treeWeakSet.add(jackalberry);
treeWeakSet.add(mopaneTree);
treeWeakSet.add(breadfruit);

treeWeakSet.delete(jackalberry);
console.log(treeWeakSet.has(jackalberry)); // false

console.log(treeWeakSet);
```

Dans la sortie, le contenu du `WeakSet` apparaît ainsi :

```javascript
/*
WeakSet {{…}, {…}, {…}}
  [[Entries]]
    0: value: {name: "Mopane Tree"}
    1: value: {name: "Baobab"}
    2: value: {name: "Breadfruit"}
  [[Prototype]]: WeakSet
*/
```

Le contenu est visible ici parce que les variables d'objets conservent encore des références fortes, ce qui maintient ces objets en mémoire. Garde à l'esprit que les WeakSets ne sont pas itérables, donc il n'y a aucun moyen de boucler sur leurs entrées ou d'y accéder par programme. Ce que tu vois dans la sortie n'est qu'une aide au débogage.

N'oublie pas que seuls les symboles et les objets avec des clés et des valeurs bien définies sont pris en charge. Ajouter une primitive, comme des nombres ou des chaînes, provoquera une erreur :

```js
treeWeakSet.add("Alan Smith");

console.log(treeWeakSet); // Invalid value used in weak set
//    at WeakSet.add (<anonymous>)
```

La différence clé entre un `Set` et un `WeakSet` est qu'un `Set` stocke n'importe quelle valeur, tandis qu'un `WeakSet` ne peut stocker que des objets.

Voici d'autres différences notables entre un `Set` et un `WeakSet` :

| Fonctionnalité | Set | WeakSet |
| --- | --- | --- |
| Type de valeurs stockées | Stocke n'importe quel type de données | Stocke uniquement des objets |
| Référencement | Référencement fort | Référencement faible |
| Itération | Prend en charge l'itération avec `forEach` et les boucles | Ne prend pas en charge l'itération |
| Méthodes et propriétés | `add()`, `delete()`, `has()`, `keys()`, `values()`, `size`, et plus | `add()`, `delete()`, et `has()` uniquement |
| Cas d'usage | Collection polyvalente de valeurs uniques et suppression des doublons dans les tableaux | Suivi mémoire efficace des références d'objets |

Tu peux voir les différences dans les types de valeurs que les deux sortes de sets peuvent stocker, leur prise en charge de l'itération sur les objets stockés et leurs cas d'usage idéaux. Prends un moment pour lire le contenu de ce tableau.

En quoi un `Set` diffère-t-il d'un `WeakSet` concernant les données qu'ils prennent tous deux en charge ?
