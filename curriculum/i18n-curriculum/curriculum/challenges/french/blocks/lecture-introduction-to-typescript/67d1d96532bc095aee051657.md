# --description--

JavaScript est considéré comme un langage à typage dynamique. Cela signifie que les variables peuvent recevoir n’importe quelles valeurs à l’exécution — déclarer une variable comme nombre n’empêche pas de lui assigner plus tard une chaîne, et les paramètres de fonction peuvent recevoir n’importe quelle valeur.

Le défi d’un langage à typage dynamique, c’est que le manque de sûreté des types peut introduire des erreurs si tu n’es pas prudent. TypeScript étend le langage JavaScript pour y ajouter le typage statique, ce qui aide à détecter ces erreurs avant même de déployer ton code. Mais comment ça marche ?

Regarde cette fonction JavaScript :

```js
const getRandomValue = (array) => {
  return array[Math.floor(Math.random() * array.length)];
}
```

Notre fonction `getRandomValue` prend un tableau et renvoie une valeur aléatoire de ce tableau. Mais comme JavaScript ne valide pas les types, rien ne t’empêche d’appeler la fonction avec un nombre :

```js
console.log(getRandomValue(10));
```

La sortie console de cet exemple renverra `undefined` parce qu’elle attendait un tableau au lieu d’un nombre.

Mais avec TypeScript, tu peux définir un type pour le paramètre tableau :

```js
const getRandomValue = (array: string[]) => {
  return array[Math.floor(Math.random() * array.length)];
}
```

Cette définition de type indique à TypeScript que l’argument tableau doit être un tableau de chaînes. Ensuite, quand tu appelles `getRandomValue` et que tu lui passes un nombre, tu obtiens un autre type d’erreur appelé erreur de compilation.

La plupart des environnements d’exécution JavaScript, comme un navigateur ou Node.js, ne peuvent pas exécuter TypeScript nativement. Tu dois d’abord compiler, ou traduire, le code TypeScript en JavaScript classique. Tu peux le faire avec le compilateur intégré fourni avec le langage TypeScript. Quand tu lances le compilateur, TypeScript évalue ton code et lève une erreur pour tout problème où les types ne correspondent pas — comme passer un nombre à une fonction qui attend un tableau.

Tu en apprendras davantage sur le fonctionnement de ces types dans les prochaines leçons. Mais c’est cette sécurité supplémentaire qui rend TypeScript attractif pour de nombreux développeurs et organisations.
