# --description--

Dans cette leçon, tu apprendras à travailler avec les types de fonctions. Commençons par les annotations de type des paramètres.

Voici un exemple de fonction de base :

```ts
function circleArea(radius) {
  return Math.PI * radius * radius;
}
```

Pour l’instant, TypeScript afficherait le message `Parameter 'radius' implicitly has an 'any' type`. Le type `any` indique qu’une valeur peut avoir n’importe quel type. Tu en apprendras davantage sur ce type dans une leçon future.

Pour supprimer l’erreur et typer explicitement le paramètre, tu peux le typer ainsi :

```ts
function circleArea(radius: number) {
  return Math.PI * radius * radius;
}
```

Si tu essaies d’appeler la fonction `circleArea` avec un type différent qui n’est pas un nombre, TypeScript affichera une erreur comme celle-ci :

```ts
function circleArea(radius: number) {
  return Math.PI * radius * radius;
}

// Argument of type 'string' is not assignable to parameter of type 'number'
circleArea("3");
```

Si tu essaies de fournir plus d’arguments que la fonction n’en attend, TypeScript affichera une erreur :

```ts
function circleArea(radius: number) {
  return Math.PI * radius * radius;
}

// Expected 1 arguments, but got 2.
circleArea(3, 4);
```

Si tu fournis trop peu d’arguments, TypeScript affichera aussi une erreur :

```ts
function circleArea(radius: number) {
  return Math.PI * radius * radius;
}

// Expected 1 arguments, but got 0.
// An argument for 'radius' was not provided.
circleArea();
```

Tu peux rendre des paramètres optionnels en utilisant le symbole `?` près du paramètre, comme ceci :

```ts
function area(radius: number, height?: number): number {
  const baseArea = Math.PI * radius * radius;

  if (height !== undefined) {
    const sideArea = 2 * Math.PI * radius * height;
    return baseArea + sideArea;
  }

  return baseArea;
}
```

La vérification conditionnelle à l’intérieur de la fonction est là au cas où l’argument `height` n’est pas fourni.

Si tu veux typer tes valeurs de retour, tu peux ajouter des annotations de type de retour comme ceci :

```ts
function circleArea(radius: number): number {
  return Math.PI * radius * radius;
}
```

L’annotation de type de retour se place après la liste des paramètres. Comme pour les annotations de type des variables, la plupart du temps TypeScript sera assez intelligent pour inférer le type de retour. Utilise donc une annotation de type de retour explicite quand tu veux clarifier l’intention de la fonction ou empêcher des changements involontaires de la valeur de retour.

Le prochain exemple portera sur les fonctions asynchrones et les promesses. Si ta fonction doit renvoyer une promesse, tu peux utiliser le type `Promise` comme ceci :

```ts
async function getCityTemperature(city: string): Promise<number> {
  const response = await fetch(`https://api.example.com/weather?city=${city}`);
  const data = await response.json();
  return data.temperature;
}
```

Dans cette situation, si tu essaies de retirer le type de retour, TypeScript pourrait inférer le retour comme `Promise<any>`. Ce serait donc une bonne situation pour typer explicitement la valeur de retour.

Jusqu’ici, on n’a regardé que des exemples de fonctions nommées. Mais comment les types fonctionnent-ils avec les fonctions anonymes ?

Voici un exemple utilisant une fonction anonyme dans le callback passé à un `forEach` :

```ts
const languages = ["JavaScript", "Python", "TypeScript"];

languages.forEach((lang) => {
  console.log(`${lang.toUpperCase()} has ${lang.length} characters`);
});
```

Le paramètre `lang` n’a pas d’annotation de type. À la place, TypeScript utilise le typage contextuel, ce qui signifie qu’il infère le type à partir du contexte dans lequel il apparaît.
