# --description--

Les fonctions sont des morceaux de code réutilisables qui s'exécutent quand tu les appelles. De nombreux langages de programmation fournissent des fonctions intégrées qui facilitent les premiers pas. Python ne fait pas exception, et tu as déjà vu des fonctions intégrées comme `print()` dans les leçons précédentes.

Une autre fonction intégrée utile est `input()`, qui te permet de demander une saisie à l'utilisateur :

```python
name = input('What is your name?') # User types "Kolade" and presses Enter
print('Hello', name) # Output: Hello Kolade
```

D'autre part, `int()` convertit un nombre, un booléen et une chaîne numérique en un entier :

```python
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0
```

Tu peux aussi écrire tes propres fonctions. Pour cela, tu utilises le mot-clé `def`, suivi du nom que tu veux donner à ta fonction, d'une paire de parenthèses et d'un deux-points. Puis, sur une nouvelle ligne, tu écris le code que ta fonction doit exécuter. Le code exécuté par la fonction est aussi appelé le corps de la fonction.

Voici un exemple de fonction personnalisée nommée `hello` qui affiche la chaîne `Hello World` dans le terminal :

```python
def hello():
    print('Hello World')
```

Pour exécuter la fonction, tu dois l'appeler avec son nom suivi d'une paire de parenthèses :

```python
hello() # Hello World
```

Remarque l'indentation avant `print('Hello World')`. Comme tu t'en souviens peut-être des leçons précédentes, Python s'appuie sur l'indentation pour déterminer quels groupes d'instructions vont ensemble. Ces groupes d'instructions s'appellent des blocs de code.

Voici une autre fonction simple qui affiche la somme de deux nombres dans le terminal :

```python
def calculate_sum(a, b):
    print(a + b)
```

Tu peux voir que notre fonction, `calculate_sum`, a `a` et `b` dans ses parenthèses, séparés par une virgule. On les appelle des paramètres. Imagine les paramètres comme des variables de substitution qui agissent comme des « emplacements » pour les valeurs que tu passes aux fonctions quand tu les appelles.

Pour utiliser les paramètres, tu dois passer des « arguments ». Les arguments sont les valeurs que tu passes à une fonction quand tu l'appelles.

Voici comment appeler la fonction `calculate_sum` pour additionner les nombres `3` et `1` :

```python
calculate_sum(3, 1) # 4
```

Si tu appelles la fonction sans le bon nombre d'arguments, tu obtiens une `TypeError` :

```python
calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

Les fonctions utilisent aussi un mot-clé spécial `return` pour quitter la fonction et renvoyer une valeur. Si tu n'utilises pas explicitement `return`, Python renvoie `None` par défaut.

Voici un exemple :

```python
def calculate_sum(a, b):
    print(a + b)

my_sum = calculate_sum(3, 1) # 4
print(my_sum) # None
```

Tu peux voir que la fonction `calculate_sum` affiche la somme de `a` et `b`, mais elle ne renvoie rien explicitement. Donc, quand on assigne son résultat à `my_sum`, la valeur est en réalité `None`. Pour corriger cela, tu peux utiliser le mot-clé `return` pour renvoyer le résultat :

```python
def calculate_sum(a, b):
    return a + b

my_sum = calculate_sum(3, 1)
print(my_sum) # 4
```

Maintenant, `calculate_sum` renvoie la somme de `a` et `b`, qui est stockée dans `my_sum`.
