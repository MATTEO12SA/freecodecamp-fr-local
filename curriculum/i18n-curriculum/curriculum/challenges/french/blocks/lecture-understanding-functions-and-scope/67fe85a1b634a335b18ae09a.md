# --description--

En Python, la portée détermine l'endroit où tu peux accéder à une variable. C'est ce qui contrôle la durée de vie d'une variable et la façon dont elle est résolue dans les différentes parties du code.

Pour déterminer correctement la portée, Python suit la règle **LEGB**, qui correspond à :

- **Portée locale (L)** : variables définies dans des fonctions ou des classes.

- **Portée englobante (E)** : variables définies dans des fonctions englobantes ou imbriquées.

- **Portée globale (G)** : variables définies au niveau supérieur du module ou du fichier.

- **Portée intégrée (B)** : noms réservés de Python pour les fonctions, modules, mots-clés et objets prédéfinis.

Python utilise la règle LEGB pour résoudre la portée des variables dans ton programme. Nous allons examiner chacun de ces niveaux pour que tu comprennes mieux le processus.

La **portée locale** signifie qu'une variable déclarée à l'intérieur d'une fonction ou d'une classe n'est accessible que dans cette fonction ou cette classe.

Voici un exemple :

```python
def my_func():
    my_var = 10
    print(my_var)
```

Dans ce cas, la fonction `my_func` a sa propre portée, qui n'est pas accessible depuis l'extérieur de la fonction. Appeler `my_func` affichera `10`, mais afficher `my_var` en dehors de la fonction produira une `NameError` :

```python
def my_func():
    my_var = 10 # Locally scoped to my_func
    print(my_var)

my_func() # 10

print(my_var) # NameError: name 'my_var' is not defined
```

La **portée englobante** signifie qu'une fonction imbriquée dans une autre fonction peut accéder aux variables de la fonction dans laquelle elle est imbriquée.

Par exemple :

```python
def outer_func():
    msg = 'Hello there!'

    def inner_func():
        print(msg)

    inner_func()

outer_func() # Hello there!
```

Dans cet exemple, la fonction interne, `inner_func`, peut librement accéder à la variable `msg` définie dans la fonction externe, `outer_func`. En revanche, note que les fonctions externes ne peuvent pas accéder aux variables définies dans des fonctions imbriquées :

```python
def outer_func():
    msg = 'Hello there!'
    print(res)

    def inner_func():
        res = 'How are you?'
        print(msg)

    inner_func()

outer_func() # NameError: name 'res' is not defined
```

C'est parce que `res` a une portée locale à `inner_func`. Remarque aussi que `outer_func` essaie d'afficher `res` avant que `inner_func` ne soit appelée.

Une solution consiste à initialiser `res` comme une chaîne vide dans la portée englobante, c'est-à-dire dans `outer_func`. Puis, dans `inner_func`, tu rends `res` non locale avec le mot-clé `nonlocal` :

```python
def outer_func():
    msg = 'Hello there!'
    res = ""  # Declare res in the enclosing scope

    def inner_func():
        nonlocal res  # Allow modification of an enclosing variable
        res = 'How are you?'
        print(msg)  # Accessing msg from outer_func()

    inner_func()
    print(res)  # Now res is accessible and modified

outer_func()

# Output:
# Hello there!
# How are you?
```

La **portée globale** désigne les variables déclarées en dehors de toute fonction ou classe, et qui sont accessibles depuis n'importe où dans le programme. Ici, `my_var` est accessible partout, même à l'intérieur d'une fonction dans laquelle elle n'est pas définie :

```python
my_var = 100

def show_var():
    print(my_var)

show_var() # 100
print(my_var) # 100
```

Et si tu veux rendre globalement accessible une variable de portée locale définie à l'intérieur d'une fonction, tu peux utiliser le mot-clé `global` :

```python
my_var_1 = 7

def show_vars():
    global my_var_2
    my_var_2 = 10
    print(my_var_1)
    print(my_var_2)

show_vars() # 7 10

# my_var_2 is now a global variable and can be accessed anywhere in the program
print(my_var_2) # 10
```

Tu peux aussi utiliser le mot-clé `global` pour modifier une variable globale :

```python
my_var = 10  # A global variable

def change_var():
    global my_var  # Allows modification of a global variable
    my_var = 20

change_var()

print(my_var)  # my_var is now modified globally to 20
```

Enfin, la **portée intégrée** désigne toutes les fonctions, modules et mots-clés intégrés de Python, disponibles partout dans ton programme :

```python
print(str(45)) # '45'
print(type(3.14)) # <class 'float'>
print(isinstance(3, str)) # False
```
