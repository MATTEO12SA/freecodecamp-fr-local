# --interactive--

Les assertions lookahead et lookbehind te permettent de faire correspondre des motifs spécifiques selon la présence ou l'absence de motifs environnants. Il y a quatre variantes de ces assertions.

La première est l'assertion lookahead positive. Cette assertion fera correspondre un motif lorsque le motif est suivi d'un autre motif.

Pour construire un lookahead positif, tu dois commencer par le motif que tu veux faire correspondre. Ensuite, utilise des parenthèses pour envelopper le motif que tu veux utiliser comme condition. Après la parenthèse ouvrante, utilise `?=` pour définir ce motif comme un lookahead positif.

Ce motif ne correspondra au mot `free` que s'il est suivi de `code` :

```js
const regex = /free(?=code)/i;
```

Testons le comportement de notre motif :

:::interactive_editor

```js
const regex = /free(?=code)/i;
console.log(regex.test("freeCodeCamp")); // true
console.log(regex.test("free code camp")); // false
console.log(
  regex.test("I need someone for free to write code for me")
); // false
```

:::

Remarque que seule la chaîne où `free` est immédiatement suivi de `code` réussit le test.

Mais et si tu veux faire correspondre la présence de `free` quand il n'est PAS suivi de `code` ? Tu peux transformer ton lookahead positif en lookahead négatif pour inverser le comportement. Pour cela, change ton `?=` en `?!` :

```js
const regex = /free(?!code)/i;
```

Testons cela contre nos mêmes chaînes :

:::interactive_editor

```js
const regex = /free(?!code)/i;
console.log(regex.test("freeCodeCamp")); // false
console.log(regex.test("free code camp")); // true
console.log(
  regex.test("I need someone for free to write code for me")
); // true
```

:::

Comme prévu, les résultats sont inversés. La seule chaîne qui échoue est la première, où `free` est immédiatement suivi de `code`.

Les assertions lookbehind fonctionnent de façon similaire aux assertions lookahead, sauf que, au lieu de correspondre conditionnellement selon un motif suivant, elles correspondent conditionnellement selon un motif précédent. Regardons un lookbehind positif.

Un lookbehind positif est noté avec `?<=` au lieu de `?=`. Faisons correspondre notre expression régulière à `code` quand il est précédé de `free` :

```js
const regex = /(?<=free)code/i;
```

Tout comme avec notre lookahead positif, notre lookbehind positif correspond à la première chaîne parce que `code` est immédiatement précédé de `free` :

:::interactive_editor

```js
const regex = /(?<=free)code/i;
console.log(regex.test("freeCodeCamp")); // true
console.log(regex.test("free code camp")); // false
console.log(
  regex.test("I need someone for free to write code for me")
); // false
```

:::

Pour faire correspondre `code` quand il n'est PAS précédé de `free`, on peut utiliser un lookbehind négatif. Un lookbehind négatif se définit en remplaçant `?<=` par `?<!` :

```js
const regex = /(?<!free)code/i;
```

Cela correspondrait à toute occurrence de `code` qui n'est PAS immédiatement précédée de `free` :

:::interactive_editor

```js
const regex = /(?<!free)code/i;
console.log(regex.test("freeCodeCamp")); // false
console.log(regex.test("free code camp")); // true
console.log(
  regex.test("I need someone for free to write code for me")
); // true
```

:::

Souviens-toi que `Regex.prototype.test` ne confirme que si une chaîne correspond à l'expression régulière. Utilisons notre lookbehind négatif avec `String.prototype.match` pour voir comment les assertions affectent cela :

```js
const regex = /(?<!free)code/i;
console.log("freeCodeCamp".match(regex)); // null
console.log("free code camp".match(regex)); // ['code', index: 5, input: 'free code camp', groups: undefined]
console.log(
  "I need someone for free to write code for me".match(regex)
); // ['code', index: 33, input: 'I need someone for free to write code for me', groups: undefined]
```

Remarque que même si notre expression régulière utilise un lookbehind pour vérifier la présence de `free`, elle ne correspond pas à `free`. Le seul texte inclus dans la correspondance est `code`.

Les lookaheads et lookbehinds sont incroyablement utiles pour faire correspondre conditionnellement du texte sans impacter la valeur renvoyée de ta correspondance.
