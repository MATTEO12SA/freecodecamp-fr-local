# --interactive--

Les expressions régulières, ou regex, sont une fonctionnalité prise en charge par de nombreux langages de programmation différents.

Une expression régulière est une syntaxe spéciale pour créer un « motif » (pattern), que tu peux ensuite utiliser pour vérifier une chaîne, en extraire du texte, et plus encore.

Regardons une expression régulière basique :

```js
const regex = /freeCodeCamp/;
```

Remarque qu'en JavaScript, tu définis une expression régulière en créant ton motif entre deux barres obliques (`/`). Essaie de ne pas confondre cela avec un commentaire, où le texte vient après les deux barres obliques.

Cette expression régulière particulière correspondra au texte `freeCodeCamp`, avec des `C` majuscules, n'importe où dans une chaîne. Mais comment faire concrètement ?

Cela nous amène à notre première méthode – la méthode `test()`. La méthode `test()` est présente sur les objets `RegExp`, qui sont des objets représentant une expression régulière (comme celle que l'on vient de définir).

La méthode `test()` accepte une chaîne, qui est la chaîne à tester pour des correspondances avec l'expression régulière. Par exemple, essayons de tester la chaîne `e` :

:::interactive_editor

```js
const regex = /freeCodeCamp/;
const test = regex.test("e");
console.log(test);
```

:::

Tu peux voir que nous avons appelé la méthode `test()` sur notre nouvelle regex, et passé la chaîne `e` comme argument.

La méthode `test()` a renvoyé `false` parce que la chaîne `e` ne correspond pas au motif `freeCodeCamp`. Même si le motif `freeCodeCamp` inclut la lettre `e`, c'est le sens inverse du fonctionnement des expressions régulières.

Regardons encore quelques exemples. Prends un moment pour les examiner :

:::interactive_editor

```js
const regex = /freeCodeCamp/;
console.log(regex.test("freeCodeCamp"));
console.log(regex.test("freeCodeCamp is great"));
console.log(regex.test("I love freeCodeCamp"));
console.log(regex.test("freecodecamp"));
console.log(regex.test("FREECODECAMP"));
console.log(regex.test("free"));
console.log(regex.test("code"));
console.log(regex.test("camp"));
```

:::

Remarque que les trois premières chaînes ont renvoyé `true`. Ces chaînes contiennent toutes le texte `freeCodeCamp`, exactement, quelque part dans la chaîne.

Les lignes 5 et 6 renvoient `false`. Bien qu'elles contiennent le texte `freecodecamp`, la casse ne correspond pas. Les expressions régulières sont sensibles à la casse par défaut.

Enfin, bien que les trois dernières contiennent une portion du motif, les chaînes ne contiennent pas le motif entier.

La méthode `test()` renvoie un `boolean`, indiquant si la chaîne correspond du tout à l'expression régulière.

Mais et si tu voulais plus d'informations que cela ? Eh bien, les chaînes ont une méthode `match()`. Cette méthode accepte une expression régulière, bien que tu puisses aussi passer une chaîne qui sera transformée en expression régulière.

`match()` renvoie le tableau de correspondance pour la chaîne. Qu'est-ce qu'un tableau de correspondance ? Eh bien, regardons :

```js
const regex = /freeCodeCamp/;
const match = "freeCodeCamp".match(regex);
console.log(match);
```

Si on exécute ceci, on obtient un tableau ! Mais c'est un tableau d'apparence étrange. Il a quelques propriétés supplémentaires :

```js
// [
//   'freeCodeCamp',
//   index: 0,
//   input: 'freeCodeCamp',
//   groups: undefined
// ]
```

La propriété `groups` montrerait les groupes capturés. Tu apprendras ce que cela signifie dans une leçon future.

La propriété `index` te dit à quel caractère de la chaîne la correspondance a été trouvée. Dans notre cas, elle a été trouvée au début de la chaîne.

La propriété `input` te dit la chaîne sur laquelle la méthode `match()` a été appelée.

Essayons encore quelques exemples, et voyons comment le résultat change :

```js
const regex = /freeCodeCamp/;
console.log("freeCodeCamp".match(regex)); // ['freeCodeCamp', index: 0, input: 'freeCodeCamp', groups: undefined]
console.log("freeCodeCamp is great".match(regex)); // ['freeCodeCamp', index: 0, input: 'freeCodeCamp is great', groups: undefined]
console.log("I love freeCodeCamp".match(regex)); // ['freeCodeCamp', index: 7, input: 'I love freeCodeCamp', groups: undefined]
console.log("freecodecamp".match(regex)); // null
console.log("FREECODECAMP".match(regex)); // null
console.log("free".match(regex)); // null
```

On sait déjà que les trois premières chaînes devraient produire une correspondance, alors regardons celles-là :

```js
// ['freeCodeCamp', index: 0, input: 'freeCodeCamp', groups: undefined]
// ['freeCodeCamp', index: 0, input: 'freeCodeCamp is great', groups: undefined]
// ['freeCodeCamp', index: 7, input: 'I love freeCodeCamp', groups: undefined]
```

Est-ce ce à quoi tu t'attendais ? Tu peux voir comment `input` et `index` ont changé selon la chaîne fournie, et l'emplacement de la correspondance dans la chaîne.

Les trois autres lignes, qui ne correspondent pas, renvoient `null` au lieu d'un tableau.

Maintenant que nous pouvons tester et faire correspondre des chaînes avec notre expression régulière, et si nous voulions remplacer le contenu d'une chaîne ? Peut-être que quelqu'un a écrit `freecodecamp` entièrement en minuscules, et que nous voulons corriger automatiquement la casse pour lui.

D'abord, nous devons mettre à jour notre expression régulière pour correspondre à la forme en minuscules de `freecodecamp`, et créer notre chaîne de test :

```js
const regex = /freecodecamp/;
const str = "freecodecamp is rly kewl";
```

Maintenant, les chaînes ont une méthode `replace()` qui accepte deux arguments : l'expression régulière à faire correspondre (ou une chaîne, si tu n'as pas besoin de toutes les fonctionnalités des regex), et la chaîne par laquelle remplacer la correspondance (ou une fonction à exécuter sur chaque correspondance).

Donc si nous voulions remplacer notre `freecodecamp` par la bonne casse :

:::interactive_editor

```js
const regex = /freecodecamp/;
const str = "freecodecamp is rly kewl";
const replaced = str.replace(regex, "freeCodeCamp");
console.log(replaced);
```

:::

Tu peux voir que `replace()` renvoie la chaîne mise à jour avec le motif correspondant `replaced`.

Les expressions régulières, et toutes les méthodes associées, peuvent sembler complexes et écrasantes. Mais tu auras l'occasion de les explorer davantage dans ce prochain ensemble de leçons.
