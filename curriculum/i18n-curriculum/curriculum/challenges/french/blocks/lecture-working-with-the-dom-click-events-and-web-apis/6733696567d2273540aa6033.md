# --interactive--

L'API `Web Animations` (WAAPI) te permet de créer et de contrôler des animations directement en JavaScript. Avec WAAPI, tu peux travailler les animations de façon plus dynamique, ce qui les rend plus faciles à manipuler.

Regardons WAAPI plus en détail, pour que tu puisses animer directement depuis ton JavaScript. Au cœur de WAAPI se trouve le constructeur `Animation`, qui fournit plusieurs méthodes et propriétés d'instance pour animer des éléments de façon dynamique.

Une méthode importante du constructeur `Animation` est `animate()`. Elle te permet de créer une animation en précisant des keyframes et des options comme la durée, la direction, l'easing et les itérations.

Voici la syntaxe de base de `animate()` :

```js
element.animate(keyframes, options);
```

Regardons un exemple.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />
<div class="square" id="square"></div>
<script src="index.js"></script>
```

```css
body {
  background: #f1f1f1;
  display: flex;
  align-items: center;
  justify-content: center;
  height: 100vh;
}

.square {
  background: #1b1b32;
  width: 10rem;
  aspect-ratio: 1/1;
}
```

```js
const square = document.querySelector("#square");

const animation = square.animate(
  [{ transform: "translateX(0px)" }, { transform: "translateX(100px)" }],
  {
    duration: 2000, // makes animation lasts 2 seconds
    iterations: Infinity, // loops indefinitely
    direction: "alternate", // moves back and forth
    easing: "ease-in-out" // smooth easing
  }
);
```

:::

Le résultat dans le navigateur sera un carré bleu qui se déplace horizontalement d'avant en arrière.

Les méthodes d'instance du constructeur `Animation` incluent :

```js
play()
pause()
reverse()
finish()
cancel()
```

Et les propriétés d'instance incluent :

```md
playbackRate
currentTime
startTime
effect
timeline
playState
finished
onfinish
oncancel
```

Modifions l'exemple pour utiliser les méthodes `play()`, `pause()` et la propriété `onfinish`. Voici la nouvelle version :

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />
<div class="square" id="square"></div>

<button id="playBtn">Play</button>
<button id="pauseBtn">Pause</button>
<script src="index.js"></script>
```

```css
body {
  background: #f1f1f1;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  height: 100vh;
}
.square {
  background: #1b1b32;
  width: 10rem;
  aspect-ratio: 1/1;
  margin-bottom: 20px;
}
button {
  margin: 10px;
  padding: 10px 20px;
  font-size: 16px;
}
```

```js
const square = document.querySelector("#square");
const playBtn = document.querySelector("#playBtn");
const pauseBtn = document.querySelector("#pauseBtn");

const animation = square.animate(
  [{ transform: "translateX(0px)" }, { transform: "translateX(200px)" }],
  {
    duration: 5000, // Animation lasts 5 seconds
    // iterations: Infinity, // Loops indefinitely
    direction: "alternate", // Moves back and forth
    easing: "ease-in-out" // Smooth easing function
  }
);

// Set the onfinish property to log a message when the animation ends
animation.onfinish = () => {
  console.log("Animation finished!");
};

// Play the animation when the "Play" button is clicked
playBtn.addEventListener("click", () => {
  animation.play();
  console.log("You start the animation");
});

// Pause the animation when the "Pause" button is clicked
pauseBtn.addEventListener("click", () => {
  animation.pause();
  console.log("You pause the animation");
});
```

:::

Le résultat dans le navigateur montrera la boîte bleue qui se déplace de gauche à droite quand on clique sur le bouton `play`.

WAAPI étend les capacités des animations CSS en offrant un contrôle plus dynamique des animations directement en JavaScript.

Avec les animations CSS, tu définis les animations de façon déclarative avec des propriétés comme `animation-name`, `animation-duration` et `animation-timing-function`. Tu peux aussi faire la même chose avec la méthode `animate()` de WAAPI.

La différence, c'est que tu contrôles plus directement et dynamiquement les animations créées avec `animate()`, alors qu'avec les animations CSS tu dois faire bien plus : définir des styles personnalisés et les déclencher depuis ton JavaScript.

L'animation CSS est idéale pour des animations simples et déclaratives qui se lancent automatiquement. Cela inclut les effets de survol, les transitions, ou les animations qui n'ont pas besoin de beaucoup d'interaction une fois déclenchées. Si ton animation doit réagir aux interactions utilisateur comme les clics et les défilements, ou si tu veux que l'utilisateur puisse mettre en pause, inverser ou changer la vitesse dynamiquement, WAAPI est le meilleur choix.

Tu peux combiner WAAPI et les animations CSS quand tu veux la simplicité du CSS pour la configuration de base, mais que tu as besoin de contrôler les animations à l'exécution.
