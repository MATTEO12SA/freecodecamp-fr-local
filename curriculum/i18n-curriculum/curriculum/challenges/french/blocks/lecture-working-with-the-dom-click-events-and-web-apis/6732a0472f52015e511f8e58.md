# --description--

Apprenons les API et pourquoi elles sont essentielles au développement web. API signifie Application Programming Interface (interface de programmation applicative). Les API définissent un ensemble de règles et de protocoles qui permettent aux applications de communiquer entre elles et d'échanger des données efficacement.

Tu peux les voir comme des constructions qui permettent aux développeurs de créer des fonctionnalités plus complexes à partir de briques plus simples déjà implémentées.

Il existe différents types d'API. Les API web sont conçues spécifiquement pour les applications web. Il existe différents types d'API web pour le JavaScript côté client. Elles ne font pas partie de JavaScript lui-même.

Ces types d'API sont souvent divisés en deux grandes catégories : les API du navigateur et les API tierces.

Les API du navigateur exposent des données du navigateur. En tant que développeur web, tu peux accéder à ces données et les manipuler avec JavaScript.

Elles donnent aussi accès à diverses fonctionnalités, comme manipuler la structure du site, gérer les événements, travailler avec le stockage et communiquer avec le réseau.

Voici quelques exemples d'API du navigateur couramment utilisées :

L'API DOM, que tu peux utiliser pour manipuler les éléments HTML, leurs styles et leurs attributs. Tu en apprendras beaucoup plus sur le DOM dans les leçons suivantes. C'est un concept central du développement web.

L'API Storage, pour stocker des données localement sur l'appareil de l'utilisateur.

Et d'autres encore.

Il existe diverses API du navigateur que tu peux utiliser pour gérer les interactions utilisateur et obtenir plus d'informations du navigateur, comme la position actuelle de l'utilisateur.

Tu peux aussi travailler avec d'autres types d'éléments, comme la vidéo et l'audio.

Les API du navigateur sont des outils utiles pour construire des applications web puissantes. Elles sont déjà intégrées au navigateur.

Mais tu peux aussi utiliser des API tierces, qui ne sont pas intégrées au navigateur par défaut. Pour les utiliser, tu dois récupérer leur code d'une manière ou d'une autre. En général, elles sont accompagnées d'une documentation détaillée expliquant comment utiliser leurs services.

Un exemple est l'API Google Maps, que tu peux utiliser pour afficher des cartes interactives sur ton site.

Il existe différents types d'API web tierces, notamment des API météo, des API de réseaux sociaux, des API de paiement, des API de données, des API de traduction, et plus encore. Il te suffit de trouver l'API qui correspond à tes besoins.

Les API web sont des outils essentiels pour construire des applications web modernes capables d'interagir avec divers services et sources de données. En apprenant à tirer parti de leur puissance, tu élargiras ta boîte à outils pour créer des sites dynamiques et engageants.

Quelle est la différence entre une API générale et une API web ?
