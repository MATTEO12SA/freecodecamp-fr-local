# --interactive--

Quand tu construis tes programmes, tu voudras souvent qu'une action se produise après un délai, ou se répète à intervalles réguliers. C'est là que `setTimeout()` et `setInterval()` sont utiles. Les deux méthodes acceptent deux paramètres : une fonction et un délai.

Regardons chaque méthode plus en détail pour que tu puisses les utiliser dans tes projets web.

`setTimeout()` te permet de retarder une action pendant un temps donné. Voici la syntaxe de base de `setTimeout()` :

```js
setTimeout(functionToRun, delay);
```

`functionToRun` est le code que tu veux exécuter après un délai donné, et `delay` est le temps (en millisecondes) à attendre avant d'exécuter la fonction. Voici un exemple :

:::interactive_editor

```js
setTimeout(function () {
 console.log("This runs after 3 seconds");
}, 3000);
```

:::

Tu peux aussi utiliser une fonction fléchée pour le callback, comme ceci :

:::interactive_editor

```js
setTimeout(() => {
 console.log("This runs after 3 seconds");
}, 3000);
```

:::

`setInterval()` répète une fonction à un intervalle fixe. C'est comme une alarme qui sonne toutes les quelques secondes. `setInterval()` est parfait quand tu veux qu'une action se répète encore et encore, comme actualiser des données ou créer une animation qui bouge en continu.

Comme `setTimeout()`, elle prend une fonction et un délai :

```js
setInterval(functionToRun, delay);
```

`functionToRun` est le code que tu veux exécuter de façon répétée, tandis que `delay` est le temps en millisecondes entre chaque exécution. Voici un exemple :

:::interactive_editor

```js
setInterval(() => {
 console.log("This runs every 2 seconds");
}, 2000);

// Result:
// This runs every 2 seconds
// This runs every 2 seconds
// This runs every 2 seconds
// ...
```

:::

Comme `setInterval()` continue d'exécuter la fonction fournie à l'intervalle indiqué, tu pourrais vouloir l'arrêter. Pour cela, tu dois utiliser `clearInterval()`.

Pour faire son travail, `clearInterval()` prend l'ID du `setInterval()` que tu veux arrêter. Ce peut être une variable à laquelle tu as assigné l'intervalle. Une façon d'arrêter l'intervalle est dans un `setTimeout()`, ce qui l'arrêtera après un certain temps :

:::interactive_editor

```js
const intervalID = setInterval(() => {
 console.log("This will stop after 5 seconds");
}, 1000);

setTimeout(() => {
 clearInterval(intervalID);
}, 5000);
```

:::

Tu peux aussi arrêter un timeout avec `clearTimeout()` :

:::interactive_editor

```js
let timeoutID = setTimeout(() => {
 console.log("This will not run");
}, 5000);

clearTimeout(timeoutID);
```

:::

Avec ce code, le `setTimeout()` ne s'exécutera pas du tout. Une façon plus élégante est de passer par le DOM, en ajoutant un écouteur de clic à un bouton pour arrêter le timeout :

:::interactive_editor

```html
<h1>Cancel Timeout Example</h1>
<button id="cancelButton">Cancel Timeout</button>
<script src="index.js"></script>
```

```js
let timeoutID = setTimeout(() => {
  console.log("This will run if not canceled");
}, 5000);

document
.querySelector("#cancelButton")
.addEventListener("click", () => {
  clearTimeout(timeoutID);
  console.log("Timeout canceled!");
});
```

:::
