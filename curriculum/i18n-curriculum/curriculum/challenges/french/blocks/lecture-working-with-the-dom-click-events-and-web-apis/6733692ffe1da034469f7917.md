# --interactive--

Il y aura des moments où tu devras manipuler les styles d'un élément HTML depuis ton fichier JavaScript. Un exemple : cacher ou afficher un menu quand un utilisateur clique sur un bouton.

Dans cette leçon, tu vas apprendre à manipuler les styles avec les propriétés `Element.style` et `Element.classList`.

La propriété `Element.style` est une propriété en lecture seule qui représente le style en ligne d'un élément. Tu peux l'utiliser pour obtenir ou définir le style d'un élément.

Voici un exemple d'élément paragraphe avec l'ID `para` :

```html
<p id="para">This is a paragraph</p>
```

Tu peux utiliser la propriété `style` pour changer la couleur de l'élément paragraphe en rouge :

:::interactive_editor

```html
<p id="para">This is a paragraph</p>
<script src="index.js"></script>
```

```js
const paraEl = document.getElementById("para");
paraEl.style.color = "red";
```

:::

La propriété `style` peut servir à définir de nombreuses propriétés CSS, comme `color`, `background-color`, `font-size`, `font-weight`, etc.

Une autre façon de manipuler les styles est d'utiliser `Element.classList`. La propriété `classList` est en lecture seule et permet d'ajouter, retirer ou basculer des classes sur un élément. Regardons quelques exemples.

Dans cet exemple, tu vas ajouter une classe `highlight` à un paragraphe d'ID `para`. En CSS, la classe `highlight` change la couleur de fond du paragraphe en jaune. En JavaScript, nous ajoutons la classe `highlight` au paragraphe avec `classList.add()`.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />
<p id="para">This is a paragraph</p>
<script src="index.js"></script>
```

```css
.highlight {
  background-color: yellow;
}
```

```js
const paraEl = document.getElementById("para");
paraEl.classList.add("highlight");
```

:::

Tu peux aussi ajouter plusieurs classes à un élément en les passant comme arguments à `classList.add()` :

```js
classList.add("class1", "class2", "class3");
```

Si tu as besoin de retirer une classe d'un élément, tu peux utiliser `classList.remove()` comme ceci :

```js
classList.remove("highlight");
```

Pour basculer une classe sur un élément, tu peux utiliser `classList.toggle()`. Dans cet exemple, nous avons un élément `button` avec l'ID `toggle-btn` et un élément `nav` avec l'ID `menu`. En CSS, nous avons ajouté des styles pour le menu et une classe `show` qui change la propriété `display` de `.menu` en `block`. En JavaScript, nous accédons à l'élément menu et à l'élément `button` avec `getElementById()`. Puis nous ajoutons un écouteur à l'élément `button` qui bascule la classe `show` sur l'élément `.menu` au clic :

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />
<button id="toggle-btn">Toggle Menu</button>

<nav id="menu" class="menu">
  <ul>
    <li>Home</li>
    <li>About</li>
    <li>Products</li>
  </ul>
</nav>
<script src="index.js"></script>
```

```css
.menu {
  display: none;
  background-color: lightgray;
  width: 50%;
  padding: 10px;
}

.menu.show {
  display: block;
}
```

```js
const menu = document.getElementById("menu");
const toggleBtn = document.getElementById("toggle-btn");

toggleBtn.addEventListener("click", () => menu.classList.toggle("show"));
```

:::

Quand un utilisateur clique sur le bouton, la classe `show` est ajoutée à `.menu` et le menu s'affiche. S'il clique à nouveau, la classe `show` est retirée de `.menu` et le menu est masqué.

Avec des méthodes et propriétés comme `style`, `add()`, `remove()` et `toggle()`, tu peux facilement manipuler les styles d'un élément en JavaScript, et créer des pages web dynamiques et interactives.
