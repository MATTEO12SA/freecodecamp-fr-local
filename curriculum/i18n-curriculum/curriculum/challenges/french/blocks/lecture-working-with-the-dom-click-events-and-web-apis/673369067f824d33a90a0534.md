# --interactive--

Quand l'utilisateur clique sur un bouton ou qu'il y a un changement dans un formulaire, on parle d'événement. Dans tes programmes, tu auras besoin d'un moyen d'écouter ces événements et d'y répondre.

La méthode `addEventListener()` sert à écouter des événements. Elle prend deux arguments : l'événement que tu veux écouter et une fonction qui sera appelée quand l'événement se produit.

Voici la syntaxe de base :

```js
element.addEventListener("event", listener);
```

L'élément est l'élément HTML à surveiller pour les événements, et event indique le type d'événement à écouter, comme `"click"`.

Le listener est un objet qui recevra la notification quand l'événement se produit. La plupart du temps, ce sera une fonction que tu définis pour gérer l'événement.

Voici un exemple :

```js
element.addEventListener("click", () => {
  // code to run when the click event occurs
});
```

Tu peux aussi choisir de passer une référence de fonction comme ceci :

```js
function handleClick() {
  // code to run when the click event occurs
}

element.addEventListener("click", handleClick);
```

Parfois tu peux vouloir créer une fonction séparée pour gérer l'événement. Cela peut rendre ton code plus facile à lire et à maintenir.

L'argument listener peut aussi être `null`, ou un objet qui utilise l'interface `EventListener`. L'interface `EventListener` définit une seule méthode appelée `handleEvent()`. Cette méthode est automatiquement appelée dès que l'événement que tu écoutes se produit. Cette interface permet au même objet de gérer plusieurs événements si besoin.

La plupart du temps, tu n'auras pas besoin d'utiliser cette interface, et tu pourras plutôt passer une fonction qui sera appelée quand l'événement se produit.

Maintenant, regardons un exemple pour mieux comprendre comment cela fonctionne :

Dans cet exemple, nous avons un élément `button` avec l'id `btn` :

```html
<button id="btn">Show alert</button>
```

Nous voulons écouter l'événement `"click"` sur ce bouton et afficher une alerte quand le bouton est cliqué.

Nous devons d'abord accéder à cet élément `button` dans notre JavaScript. Ensuite nous devons ajouter un écouteur d'événement pour le clic et afficher une alerte quand le bouton est cliqué :

:::interactive_editor

```html
<button id="btn">Show alert</button>
<script src="index.js"></script>
```

```js
const btn = document.getElementById("btn");

btn.addEventListener("click", () => alert("You clicked the button"));
```

:::

Maintenant, à chaque clic sur le bouton, l'utilisateur verra un message d'alerte affiché à l'écran, comme ceci :

```md
You clicked the button
```

Un autre type d'événement que tu peux écouter est l'événement `"input"`. Cet événement est déclenché quand la valeur d'un élément de saisie change.

Voici un exemple :

```html
<input type="text" id="input" placeholder="Type something" />
```

Nous voulons écouter l'événement input sur cet élément de saisie et afficher sa valeur dans la console chaque fois que l'utilisateur tape quelque chose.

Nous devons d'abord accéder à cet élément `input` dans notre JavaScript. Ensuite nous devons ajouter un écouteur pour l'événement input et afficher la valeur dans la console chaque fois que l'utilisateur tape quelque chose :

:::interactive_editor

```html
<input type="text" id="input" placeholder="Type something" />
<script src="index.js"></script>
```

```js
const input = document.getElementById("input");

input.addEventListener("input", () => {
  console.log(input.value);
});
```

:::

Il existe bien d'autres événements que tu peux écouter avec `addEventListener()`. Parmi les plus courants : `mouseover`, `mouseout`, `keydown`, `keyup` et `submit`.

Dans de futures leçons, nous couvrirons plus d'événements et comment utiliser `addEventListener()` pour les écouter.
