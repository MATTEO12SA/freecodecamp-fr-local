# --interactive--

Apprenons `innerText`, `textContent` et `innerHTML`.

Ce sont des propriétés auxquelles tu peux accéder en JavaScript pour obtenir ou modifier le contenu d'un élément HTML. Même si elles peuvent sembler très similaires au premier abord, elles ont des différences clés. Le bon choix dépend de ton cas d'usage, alors plongeons-y.

Commençons par `innerText`.

`innerText` représente le contenu texte visible de l'élément HTML et de ses descendants. Cette propriété n'inclut pas le texte caché ni les balises HTML, seulement le texte rendu.

Par exemple, voici un élément `div` qui contient deux paragraphes :

```html
<div id="container">
  <p>Hello, World!</p>
  <p>I'm learning JavaScript</p>
</div>
```

Si on récupère une référence à cet élément HTML dans notre JavaScript avec `getElementById()`, on peut accéder à la propriété `innerText` de cet élément :

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
console.log(container.innerText);
```

:::

Voici le texte intérieur de cet élément :

```md
Hello, World!
I'm learning JavaScript
```

La propriété renvoie une chaîne avec le texte contenu dans l'élément, y compris le texte de ses descendants.

Tu dois savoir que `innerText` ne renvoie que le texte visible au moment où la chaîne est demandée. Si un élément enfant est caché, son texte ne sera pas visible.

Voici un exemple où le second paragraphe est caché :

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p hidden>I'm learning JavaScript</p>
</div>
```

:::

Si on essaie d'afficher `innerText` à nouveau, la sortie n'aura plus le texte du second paragraphe :

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p hidden>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
console.log(container.innerText);
```

:::

Tu peux définir le `innerText` d'un élément HTML comme ceci, mais cela remplacera le texte existant et ajoutera un élément de saut de ligne (`br`) pour chaque saut de ligne :

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
container.innerText = "JavaScript is awesome!";
```

:::

Comme `innerText` tient compte de la visibilité, lire sa valeur déclenche un processus appelé « reflow », qui recalcule la position de certains éléments sur le site. Ce processus peut être coûteux en calcul, donc tu devrais l'éviter si possible.

Parfait. Parlons maintenant de `textContent`.

`textContent` renvoie le contenu texte brut d'un élément, y compris tout le texte de ses descendants.

La différence la plus importante entre `innerText` et `textContent` est que `textContent` renvoie toujours le contenu texte complet d'un élément HTML et de ses descendants, qu'il soit visible ou caché.

Voici le même exemple en HTML :

```html
<div id="container">
  <p>Hello, World!</p>
  <p>I'm learning JavaScript</p>
</div>
```

Si tu essaies d'accéder à cette propriété, tu verras le texte de l'élément et de ses descendants en sortie, en conservant l'indentation et les espaces :

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
console.log(container.textContent);
```

:::

Si un élément HTML n'est pas visible, comme ici où nous avons caché le second paragraphe, son texte sera quand même inclus dans cette propriété :

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p hidden>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
console.log(container.textContent);
```

:::

`textContent` inclura aussi le contenu d'éléments comme `script` et `style`.

Si tu essaies de remplacer la valeur de `textContent` sur un nœud, cela retirera tous ses nœuds enfants et les remplacera par un seul nœud texte contenant la nouvelle chaîne :

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p hidden>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
container.textContent = "New content";
```

:::

Enfin, voyons en quoi `textContent` et `innerText` diffèrent de `innerHTML`.

Souviens-toi qu'avec `innerHTML` tu peux définir le contenu HTML intérieur d'un élément. C'est utile pour injecter du HTML dans le DOM dynamiquement.

Cependant, souviens-toi que cela pose un risque de sécurité si tu n'as pas le contrôle de la chaîne, par exemple des chaînes contenant des données saisies par l'utilisateur. Si ces données sont malveillantes, cela peut entraîner de sérieux problèmes de sécurité.

Pour l'éviter, il est recommandé d'utiliser la propriété `textContent` pour insérer du texte brut à la place.

Les propriétés `innerText`, `textContent` et `innerHTML` en JavaScript offrent différentes façons d'accéder au contenu des éléments HTML et de le manipuler. Tu dois comprendre les différences entre ces propriétés si tu veux travailler efficacement avec du contenu HTML en JavaScript.
