# --interactive--

L'API `Canvas` est un outil puissant qui te permet de manipuler des graphiques directement dans ton JavaScript. Tout commence par un élément `canvas` en HTML. Cet élément sert de surface de dessin que tu peux manipuler avec les méthodes et propriétés d'instance de l'API `Canvas`.

L'API `Canvas` fournit tout ce qu'il faut pour créer des visuels impressionnants : formes, texte, animations, et même des jeux complexes. Elle a des interfaces comme `HTMLCanvasElement`, `CanvasRenderingContext2D`, `CanvasGradient`, `CanvasPattern`, `TextMetrics` qui fournissent des méthodes et propriétés pour créer des graphiques dans ton JavaScript.

Regardons comment l'API `Canvas` fonctionne pour que tu puisses créer des graphiques avec JavaScript.

D'abord, tu dois créer un élément `canvas` dans ton fichier HTML :

```html
<canvas id="my-canvas"></canvas>
```

L'élément `canvas` est représenté par l'interface `HTMLCanvasElement`, qui fournit des méthodes et propriétés pour le manipuler. Tu peux aussi utiliser des méthodes et propriétés d'autres interfaces de l'API `Canvas`.

Tu peux donner une `width` et une `height` à ton `canvas` dans le HTML :

```html
<canvas id="my-canvas" width="400" height="400"></canvas>
```

Ou tu peux utiliser les propriétés `width` et `height` de l'interface `HTMLCanvasElement` :

```js
const canvas = document.getElementById("my-canvas");
canvas.width = 400;
canvas.height = 400;
```

Pour l'instant, tu ne vois encore rien à l'écran. Après avoir créé ton élément `canvas`, la prochaine étape est d'accéder au contexte de dessin avec la méthode `getContext()` de l'interface `HTMLCanvasElement`.

Le contexte le plus courant est `2d`, qui te permet de dessiner en deux dimensions :

```js
const canvas = document.getElementById("my-canvas");
const ctx = canvas.getContext('2d');
```

Si tu affiches la variable `ctx` dans la console, tu verras les méthodes et propriétés de `CanvasRenderingContext2D` que tu peux utiliser pour créer des formes, des couleurs, des lignes, etc., ainsi que leurs valeurs par défaut :

```js
console.log(ctx);
```

Une fois le contexte 2D obtenu, tu peux commencer à dessiner sur le canvas.

L'API `Canvas` fournit plusieurs méthodes et propriétés pour dessiner des formes, des lignes et du texte. L'une d'elles est la propriété `fillStyle`, que tu peux combiner avec `fillRect()` pour dessiner un rectangle ou un carré :

:::interactive_editor

```html
<html>
  <head>
  </head>
  <body>
    <canvas id="my-canvas" width="400" height="400"></canvas>
    <script src="index.js"></script>
  </body>
</html>
```

```js
const canvas = document.getElementById("my-canvas");

const ctx = canvas.getContext("2d");

// Set the background color
ctx.fillStyle = "crimson";

// Draw a rectangle
ctx.fillRect(1, 1, 150, 100);
```

:::

`fillRect` prend 4 valeurs numériques qui représentent respectivement l'axe x, l'axe y, la largeur et la hauteur.

Il y a maintenant quelque chose à l'écran. Tu peux aussi dessiner du texte ou même créer une animation. Voici un canvas pour représenter du texte :

```html
<canvas id="my-text-canvas" width="300" height="70"></canvas>
```

Pour enfin dessiner le texte, passe le texte à `fillText()` comme premier argument, suivi des valeurs pour les axes x et y :

:::interactive_editor

```html
<html>
  <head>
  </head>
  <body>
    <canvas id="my-text-canvas" width="300" height="70"></canvas>
    <script src="index.js"></script>
  </body>
</html>
```

```js
const textCanvas = document.getElementById("my-text-canvas");

const textCanvasCtx = textCanvas.getContext("2d");

// Set font family and size
textCanvasCtx.font = "30px Arial";

// Set text color
textCanvasCtx.fillStyle = "crimson";

// Draw the text
textCanvasCtx.fillText("Hello HTML Canvas!", 1, 50);
```

:::

Le résultat dans le navigateur sera le texte rouge `Hello HTML Canvas!`.

Tu peux faire bien plus avec l'API `Canvas`. Par exemple, tu peux la combiner avec `requestAnimationFrame` pour créer des animations personnalisées, des visualisations, des jeux, et plus encore.
