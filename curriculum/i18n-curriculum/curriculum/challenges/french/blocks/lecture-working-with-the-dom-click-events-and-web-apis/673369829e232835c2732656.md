# --interactive--

Les dialogs te permettent d'afficher des informations ou des actions importantes aux utilisateurs. Avec l'élément HTML intégré `dialog`, tu peux facilement créer ces dialogs (modaux et non modaux) dans tes applications web.

Un dialog modal force l'utilisateur à interagir avec lui avant de pouvoir accéder au reste de l'application ou de la page. Il bloque effectivement l'interaction avec le reste du contenu jusqu'à ce que l'utilisateur accomplisse une action, comme fermer le dialog ou envoyer un formulaire.

À l'inverse, un dialog non modal permet à l'utilisateur de continuer à interagir avec d'autres parties de la page même quand le dialog est ouvert. Il n'empêche pas l'accès au reste du contenu.

Dans cette leçon, tu vas apprendre à ouvrir et fermer des modales avec les méthodes `showModal()` et `close()`.

Quand tu veux t'assurer que l'utilisateur se concentre sur une action ou un message spécifique d'une modale, tu peux ouvrir le dialog modal avec `showModal()`. Cela ajoute un fond (backdrop) aux autres éléments de la page et les désactive. C'est idéal pour les modales qui affichent des formulaires, des confirmations et des informations critiques qui demandent une action.

Voici le HTML du dialog modal :

:::interactive_editor

```html
<dialog id="my-modal">
  <p>This is a modal dialog.</p>
</dialog>
```

:::

Pour l'instant, tu ne vois rien sur la page car la modale est fermée au premier rendu. Tu peux l'ouvrir automatiquement avec `showModal()` :

:::interactive_editor

```html
<dialog id="modal">
  <p>This is a modal dialog.</p>
</dialog>
<script src="index.js"></script>
```

```js
const dialog = document.getElementById("modal");
dialog.showModal();
```

:::

Le résultat dans le navigateur montrera une modale avec le texte `This is a modal dialog.`

Il est préférable de laisser le contrôle à l'utilisateur. Pour cela, tu peux ajouter un écouteur de clic à un bouton et utiliser `showModal()` :

:::interactive_editor

```html
<dialog id="modal">
  <p>This is a modal dialog.</p>
</dialog>
<button id="open-modal-btn">Open Modal Dialog</button>
<script src="index.js"></script>
```

```js
const dialog = document.getElementById("modal");
const openButton = document.getElementById("open-modal-btn");

openButton.addEventListener("click", () => {
  dialog.showModal();
});
```

:::

Si tu as besoin d'afficher un dialog tout en permettant l'interaction avec le contenu extérieur, tu peux utiliser la méthode `show()` :

:::interactive_editor

```html
<dialog id="modal">
  <p>This is a modal dialog.</p>
</dialog>
<button id="open-modal-btn">Open Modal Dialog</button>
<script src="index.js"></script>
```

```js
const dialog = document.getElementById("modal");
const openButton = document.getElementById("open-modal-btn");

openButton.addEventListener("click", () => {
  dialog.show();
});
```

:::

Pour fermer une modale, tu peux ajouter un bouton à l'intérieur de l'élément `dialog` et utiliser `close()` :

:::interactive_editor

```html
<dialog id="modal">
  <p>This is a modal dialog.</p>
  <button id="close-modal-btn">Close Modal</button>
</dialog>
<button id="open-modal-btn">Open Modal Dialog</button>
<script src="index.js"></script>
```

```js
const dialog = document.getElementById("modal");
const openButton = document.getElementById("open-modal-btn");
const closeButton = document.getElementById("close-modal-btn");

openButton.addEventListener("click", () => {
  dialog.show();
});

closeButton.addEventListener("click", () => {
  dialog.close();
});
```

:::

Quelle est la différence entre un dialog modal et un dialog non modal ?

## --answers--

Un dialog modal permet l'interaction avec le reste de la page, alors qu'un dialog non modal ne le permet pas.
