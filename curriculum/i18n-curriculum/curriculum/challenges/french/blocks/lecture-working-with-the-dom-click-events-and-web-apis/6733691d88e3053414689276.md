# --interactive--

Dans les leçons précédentes, tu as appris à travailler avec les événements grâce à `addEventListener()`. Mais il existe une autre façon, non recommandée, de travailler avec les événements en JavaScript.

Les gestionnaires d'événements en ligne sont des attributs spéciaux sur un élément HTML utilisés pour exécuter du code JavaScript quand un événement se produit.

Voici un exemple d'élément `button` avec un gestionnaire de clic en ligne :

:::interactive_editor

```html
<button onclick="alert('Hello World!')">Show alert</button>
```

:::

Quand l'utilisateur clique sur le bouton, la fonction `alert` est appelée et une boîte de dialogue affiche le message `Hello World!`.

Une autre façon d'utiliser les gestionnaires en ligne est d'appeler une fonction définie dans une balise `script` du document HTML.

Voici un exemple de définition d'une fonction `changeBgColor` et de son appel depuis un gestionnaire de clic en ligne :

:::interactive_editor

```html
<script>
  function changeBgColor() {
    document.body.style.backgroundColor = "lightblue";
  }
</script>

<button onclick="changeBgColor()">Change background color</button>
```

:::

Quand l'utilisateur clique sur le bouton, `changeBgColor` est appelée et la couleur de fond de la page passe au bleu clair. Même s'il est possible d'utiliser des gestionnaires en ligne comme ceci, ce n'est pas considéré comme une bonne pratique.

D'une part, les gestionnaires en ligne ne peuvent attacher qu'un seul écouteur à un élément. Si tu veux en attacher plusieurs au même élément, tu devras utiliser `addEventListener()`. D'autre part, ils mélangent HTML et JavaScript, ce qui rend le code plus difficile à lire et à maintenir. Il est préférable de séparer HTML et JavaScript en utilisant `addEventListener()` pour attacher les écouteurs.

Les gestionnaires d'événements en ligne ne sont pas recommandés en JavaScript moderne. La bonne pratique est donc de rester avec `addEventListener()` pour travailler avec les événements.
