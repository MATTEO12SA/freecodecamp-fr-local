# --interactive--

Apprenons le DOM et pourquoi il est si important pour le développement web. DOM signifie Document Object Model. C'est une interface de programmation qui nous permet d'interagir avec des documents HTML.

Avec le DOM, tu peux ajouter, modifier ou supprimer des éléments sur une page. Tu peux même rendre ton site interactif en faisant écouter et répondre les éléments aux événements.

Dans le DOM, un document HTML est représenté comme un arbre de nœuds. Chaque nœud représente un élément HTML du document :

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>DOM Example</title>
  </head>
  <body>
    <h1>What is the DOM?</h1>
    <h2>Let's learn about the DOM</h2>
  </body>
</html>
```

Voici un diagramme qui représente la structure DOM de base de notre exemple :

```md
Document
========

HTML
-----

- Head
  - Title
- Body
  - H1
  - H2
```

Bien sûr, cela peut être plus détaillé et plus complexe selon la structure du HTML d'une page.

Le document HTML est le nœud racine dans la hiérarchie du DOM. Il a un nœud enfant, l'élément `html`. C'est l'élément racine du document HTML, puisque tous les autres nœuds en descendent.

L'élément `html` a deux enfants : `head` et `body`.

L'élément `head` contient les métadonnées du document. Il fournit des informations essentielles sur la page.

L'élément `body` contient le contenu visible de la page.

Tu peux accéder à ces éléments avec JavaScript, les utiliser dans ton code, et même les modifier dynamiquement. C'est la puissance du DOM et des API web.

Pour accéder à ces éléments en JavaScript, tu peux utiliser les méthodes `getElementById()` et `querySelector()`. Ces méthodes sont des API web parce qu'elles fournissent des moyens standardisés d'interagir avec le DOM en JavaScript.

Avec `getElementById()`, tu obtiens un objet qui représente l'élément HTML ayant l'`id` indiqué. Souviens-toi que les `id` doivent être uniques dans chaque document HTML, donc cette méthode ne renverra qu'un seul objet `Element`. Voici un exemple :

```js
const container = document.getElementById("container");
```

Cette ligne de JavaScript récupère un élément dont la valeur d'`id` est `container` et assigne cet objet à une constante JavaScript. Tu dois passer l'`id` entre guillemets comme argument. Si tu affiches cet objet dans la console, tu le verras dans la sortie :

:::interactive_editor

```html
<div id="container">
  <h1>Hello, World!</h1>
  <p>Welcome to learning about the DOM.</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
console.log(container);
```

:::

`querySelector()` est plus large que `getElementById()`. Avec `querySelector()`, tu peux obtenir le premier élément du document HTML qui correspond au sélecteur CSS passé en argument.

Dans cet exemple, tu obtiendras l'élément qui correspond au sélecteur `section` :

:::interactive_editor

```html
<section>
  <h2>Section Title</h2>
  <p>This is a section of the webpage.</p>
</section>
<script src="index.js"></script>
```

```js
const sectionEl = document.querySelector("section");
console.log(sectionEl);
```

:::

Si tu veux sélectionner un élément par son nom de classe avec `querySelector()`, tu dois préfixer le nom de classe d'un point (`.`). Voici un exemple :

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="highlight">
  <p>This content is highlighted.</p>
</div>
<script src="index.js"></script>
```

```css
body {
  background-color: lightgray;
}

.highlight {
  background-color: yellow;
}
```

```js
const highlightEl = document.querySelector(".highlight");
console.log(highlightEl);
```

:::

Tu as aussi d'autres méthodes pour correspondre à plusieurs éléments, comme `getElementsByClassName()` et `querySelectorAll()`. Tu en apprendras plus dans les leçons suivantes.

En comprenant comment utiliser les API web pour manipuler le DOM efficacement, tu peux créer des applications web puissantes et interactives.
