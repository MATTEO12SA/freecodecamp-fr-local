# --interactive--

Voyons comment créer des nœuds avec `innerHTML` et `createElement()`.

Commençons par `innerHTML`.

`innerHTML` est une propriété des objets `Element` que tu peux utiliser pour définir leur balisage HTML. Avec `innerHTML`, tu peux définir la structure HTML d'un élément existant avec une chaîne, en créant tous les nœuds nécessaires.

Voici un exemple. Nous avons un `div` vide et nous allons y ajouter des éléments avec la propriété `innerHTML` :

```html
<div id="container">
  <!-- Add new elements here -->
</div>
```

D'abord, il faut sélectionner l'élément par son ID :

```js
const container = document.getElementById("container");
```

Ensuite, nous définissons la propriété `innerHTML` du conteneur avec une chaîne. Cette chaîne doit contenir tout le balisage nécessaire pour représenter les nœuds et la structure que tu veux créer. Tu peux la voir comme de l'HTML écrit dans une chaîne.

:::interactive_editor

```html
<div id="container"></div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
container.innerHTML = "<ul><li>Cheese</li><li>Tomato</li></ul>";
```

:::

Nous allons définir le `innerHTML` de cet élément comme une liste non ordonnée d'ingrédients de pizza (fromage et tomate).

Tu peux aussi écrire la chaîne sur plusieurs lignes si cela rend le balisage plus lisible. L'important est que le balisage représente fidèlement la structure HTML que tu veux créer.

Après avoir exécuté ce code, tu verras la structure HTML suivante si tu inspectes ton balisage.

```html
<div id="container">
  <ul>
    <li>Cheese</li>
    <li>Tomato</li>
  </ul>
</div>
```

Les nouveaux nœuds ont été créés et ajoutés dynamiquement au DOM après l'analyse de la chaîne.

`innerHTML` peut être très utile dans certains cas. Cependant, cela comporte des risques de sécurité que tu dois connaître. Tu ne devrais pas l'utiliser si tu n'as pas un contrôle total sur la chaîne.

Par exemple, si la chaîne est saisie par l'utilisateur, tu ne devrais pas utiliser `innerHTML` parce que l'utilisateur pourrait insérer du contenu malveillant dans ton site. Pour cette raison, on recommande en général d'utiliser `textContent` à la place, pour insérer du texte brut.

Une autre façon de créer un nouveau nœud est d'utiliser la méthode `createElement()`. Avec cette méthode, tu peux créer un nouvel élément en indiquant son nom de balise.

Par exemple, si tu veux créer un élément image, tu passerais la balise `img` comme chaîne en appelant cette méthode :

```js
document.createElement("img");
```

Et tu peux assigner ce nouvel objet à une variable :

```js
const img = document.createElement("img");
```

La méthode `createElement()` renvoie un nouvel objet `HTMLElement` si le document est un `HTMLDocument`. Sinon, elle renvoie un objet `Element`.

Une fois cet élément prêt, tu peux l'ajouter au DOM comme enfant d'un autre élément existant avec `appendChild()`, ou l'insérer à un endroit précis avec d'autres méthodes. Choisis celle qui correspond le mieux à tes besoins.

:::interactive_editor

```html
<div id="container"></div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
const img = document.createElement("img");
img.src = "https://cdn.freecodecamp.org/curriculum/cat-photo-app/lasagna.jpg";
img.alt = "A slice of lasagna on a plate.";
container.appendChild(img);
```

:::

Créer des nœuds avec `innerHTML` et `createElement()` te permet de manipuler dynamiquement la structure et le contenu de tes sites. En combinant ces techniques, tu peux construire des applications web interactives.
