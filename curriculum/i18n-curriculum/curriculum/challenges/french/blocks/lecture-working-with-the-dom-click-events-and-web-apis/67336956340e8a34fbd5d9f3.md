# --interactive--

Créer des animations fluides sur une page web peut être délicat, surtout si tu n'es pas sûr de comment gérer le timing. La bonne nouvelle, c'est que l'API `requestAnimationFrame()` simplifie les choses.

`requestAnimationFrame()` est une méthode qui te permet de planifier la prochaine étape de ton animation avant le prochain rafraîchissement de l'écran, pour une expérience fluide et agréable visuellement.

Le prochain rafraîchissement de l'écran désigne le moment où le navigateur actualise l'affichage visuel de la page. Cela se produit plusieurs fois par seconde, généralement autour de 60 fois (ou 60 images par seconde) sur la plupart des écrans.

Pour utiliser `requestAnimationFrame()`, il te suffit de l'appeler et de lui passer une fonction de rappel :

```js
requestAnimationFrame(callback);
```

L'appel à `requestAnimationFrame()` doit d'abord se faire dans une fonction qui gère l'animation, comme `animate()`, avec une fonction pour mettre à jour l'animation, traditionnellement appelée `update()` :

```js
function animate() {
 // Update the animation...
 // for example, move an element, change a style, and more.
 update();
 // Request the next frame
 requestAnimationFrame(animate);
}
```

C'est dans `update()` que la magie opère. Dedans, tu changes ce que tu veux animer. Par exemple, mettre à jour un style ou changer la position d'un élément :

```js
function update() {
 element.style.transform = `translateX(${position}px)`;
 position += 2;
}
```

Ce qui lance vraiment l'animation, c'est d'appeler `requestAnimationFrame()` en lui passant la fonction `animate`, cette fois en dehors de `animate` :

```js
requestAnimationFrame(animate);
```

La boucle continuera jusqu'à ce que tu l'arrêtes.

Regardons un autre exemple. Le HTML est un élément `div` avec le texte `freeCodeCamp is Awesome`. Le CSS fait du `div` un rectangle et masque tout ce qui sort de la zone visible à gauche ou à droite. Le JavaScript déplace le rectangle de `2px` vers la droite à chaque appel de `requestAnimationFrame(animate)` avec `animate` comme callback :

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />
<div id="rect" class="rect">freeCodeCamp is Awesome</div>
<script src="index.js"></script>
```

```css
body {
  overflow-x: hidden;
}

.rect {
  display: flex;
  align-items: center;
  justify-content: center;
  width: 400px;
  height: 250px;
  border-radius: 5px;
  background-color: #1b1b32;
  color: #f5f6f7;
  font-size: 2rem;
  position: absolute;
}
```

```js
const rect = document.getElementById("rect");

let position = 0;

function update() {
  // Move the rectangle 2px to the right
  rect.style.left = position + "px";
  position += 2;

  if (position > window.innerWidth) {
    // Move the rectangle just outside the left side of the screen
    position = -rect.offsetWidth;
  }
}

function animate() {
  update();

  //request the next frame
  requestAnimationFrame(animate);
}

// Start the animation
requestAnimationFrame(animate);
```

:::

Le résultat dans le navigateur sera un titre animé qui flotte à travers l'écran.
