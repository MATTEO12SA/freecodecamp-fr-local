# --description--

Apprenons la méthode `querySelectorAll()`. Tu peux l'utiliser pour obtenir une liste de tous les éléments du DOM qui correspondent à un sélecteur CSS précis.

Voici comment appeler la méthode `querySelectorAll()` :

```js
document.querySelectorAll(selectors);
```

Appelle-la sur l'objet `document` et passe une chaîne avec les sélecteurs CSS comme argument. L'argument doit être une chaîne de sélecteur CSS valide. Sinon, une exception `SyntaxError` sera levée.

`querySelectorAll()` renvoie un objet `NodeList`, une collection de nœuds qui correspondent au sélecteur CSS indiqué.

La liste contiendra un objet `Element` pour chaque élément qui correspond aux sélecteurs CSS. Si aucune correspondance n'est trouvée, la liste sera vide.

Les éléments seront dans l'ordre d'apparition dans le document HTML. Par exemple, tu peux correspondre à tous les éléments d'un type précis :

```js
document.querySelectorAll("div");
```

Tous les éléments avec une classe précise :

```js
document.querySelectorAll(".rounded");
```

Tous les éléments avec un ID précis :

```js
document.querySelectorAll("#logo");
```

Ou tous les éléments avec un attribut précis, comme tous les liens qui emmènent les utilisateurs vers une URL précise :

```js
document.querySelectorAll("a[href='https://www.freecodecamp.org/']");
```

Tu peux aussi utiliser des sélecteurs CSS plus complexes, comme celui-ci, qui correspond à tous les éléments de liste dans un élément de liste non ordonnée avec la classe `ingredients` :

```js
document.querySelectorAll("ul.ingredients li");
```

Comme la méthode renvoie une collection de nœuds, tu peux assigner cette collection à une variable et l'utiliser dans tes programmes pour travailler avec chaque élément, comme tu le vois dans cet exemple avec la syntaxe générale :

```js
const matches = document.querySelectorAll(selectors);
```

Par exemple, si tu as cette liste non ordonnée avec trois éléments de liste :

```html
<ul class="ingredients">
  <li>Flour</li>
  <li>Cheese</li>
  <li>Water</li>
</ul>
```

Tu peux appeler `querySelectorAll()` pour correspondre à tous les éléments de liste dans la liste non ordonnée avec la classe `ingredients` et assigner la valeur renvoyée à la constante `matches` :

```js
const matches = document.querySelectorAll("ul.ingredients li");
```

Cela renverra une collection de trois nœuds. Chaque nœud représente un élément de liste :

```js
// NodeList(3)
{
  0: `<li>Flour</li>`,
  1: `<li>Cheese</li>`,
  2: `<li>Water</li>`,
  length: 3,
}
```

Tu peux travailler avec cette collection exactement comme tu le ferais avec n'importe quel autre tableau JavaScript.

Par exemple, tu peux l'afficher dans la console avec `console.log()` :

```js
console.log(matches);
```

Tu peux aussi vérifier la longueur de la collection avec la propriété `length` :

```js
console.log(matches.length);
```

La sortie sera un entier représentant le nombre de nœuds dans la collection :

```md
3
```

Tu peux aussi accéder aux éléments individuels de la collection avec leurs indices. Le premier élément sera à l'indice `0` :

```js
console.log(matches[0]);
console.log(matches[1]);
console.log(matches[2]);
```

Voici la sortie :

```html
<li>Flour</li>
<li>Cheese</li>
<li>Water</li>
```

Les éléments s'affichent un par un dans la console.

Tu peux aussi parcourir les éléments avec une boucle `for` :

```js
for (let i = 0; i < matches.length; i++) {
  console.log(matches[i]);
}
```

La sortie sera exactement la même dans ce cas. Mais cela peut être très puissant pour travailler avec tous les éléments de la collection.

La méthode `querySelectorAll()` en JavaScript est un outil puissant pour sélectionner plusieurs éléments selon leurs sélecteurs CSS. Avec cette méthode, tu peux sélectionner des éléments précis dans tes pages et les manipuler selon tes besoins.
