# --interactive--

Tu as peut-être l'habitude de travailler avec des attributs dans tes projets HTML et CSS. Mais savais-tu que tu peux ajouter des attributs à tes éléments HTML dans ton fichier JavaScript ?

Dans cette leçon, tu vas apprendre à utiliser la méthode `setAttribute()` pour ajouter des attributs à tes éléments HTML.

Voici la syntaxe de base :

```js
setAttribute(attribute, value);
```

Regardons quelques exemples pour mieux comprendre comment utiliser `setAttribute()`.

Dans ce premier exemple, nous avons un élément `p` dans le HTML :

```html
<p id="para">I am a paragraph</p>
```

Pour ajouter un attribut `class`, il faut d'abord accéder à cet élément `p` avec `getElementById()`. Ensuite on peut utiliser `setAttribute()` pour ajouter l'attribut `class` et définir sa valeur à `my-class`.

Nous utilisons `outerHTML` pour afficher l'élément HTML entier, y compris ses attributs.

:::interactive_editor

```html
<p id="para">I am a paragraph</p>
<script src="index.js"></script>
```

```js
const para = document.getElementById("para");
para.setAttribute("class", "my-class");

console.log(`${para.outerHTML}`);
```

:::

Si tu as déjà un attribut sur un élément HTML, tu peux mettre à jour sa valeur avec `setAttribute()`.

Dans cet exemple, nous avons un élément `div` avec un attribut `class` défini à `my-class` :

```html
<div class="my-class"></div>
```

Pour mettre à jour la valeur de l'attribut `class` à example, on peut utiliser `setAttribute()` à nouveau :

:::interactive_editor

```html
<div class="my-class"></div>
<script src="index.js"></script>
```

```js
const divEl = document.querySelector(".my-class");
divEl.setAttribute("class", "example");

console.log(`${divEl.outerHTML}`);
```

:::

Alors, quels sont des exemples concrets d'usage de `setAttribute()` ?

Si tu construisais une galerie d'images dynamique, tu pourrais avoir besoin de mettre à jour l'attribut `src` d'un élément image quand un utilisateur clique sur une miniature.

Un autre exemple serait la validation de formulaire, où tu dois ajouter certains attributs comme `required` ou `minlength` à un élément `input`.
