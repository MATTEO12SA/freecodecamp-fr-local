# --interactive--

L'événement `DOMContentLoaded` est déclenché quand tout le document HTML a été chargé et analysé. S'il y a des feuilles de style externes ou des images, `DOMContentLoaded` n'attendra pas qu'elles soient chargées. Il n'attendra que le HTML.

Cela diffère de l'événement `load`, qui attend que tout soit chargé, y compris les feuilles de style externes, les images, etc.

Voici un exemple de syntaxe pour utiliser `DOMContentLoaded` :

```js
document.addEventListener("DOMContentLoaded", function () {
  console.log("DOM is loaded.");
});
```

Une fois le DOM chargé, la fonction s'exécute et le message `DOM is loaded.` est affiché dans la console.

Regardons un autre exemple avec `DOMContentLoaded`. Dans cet exemple, nous avons une image dans le HTML. Pour la mettre à jour, nous pouvons créer une fonction qui change les attributs `src` et `alt` de l'image :

:::interactive_editor

```html
<h1>Image Change on DOM Loaded</h1>
<img
  id="example-img"
  src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg"
  alt="Cat relaxing"
/>

<script src="index.js"></script>
```

```js
function changeImg() {
  const img = document.getElementById("example-img");
  img.src =
    "https://cdn.freecodecamp.org/curriculum/responsive-web-design-principles/FCCStickers-CamperBot200x200.jpg";
  img.alt = "CamperBot sticker";
  console.log("image was just changed");
}

changeImg();
```

:::

Nous pouvons ensuite vérifier si le DOM est encore en cours de chargement et ajouter un écouteur pour `DOMContentLoaded`. Si l'événement `DOMContentLoaded` a déjà été déclenché, nous pouvons appeler `changeImg` directement :

```js
if (document.readyState === "loading") {
  document.addEventListener("DOMContentLoaded", changeImg);
} else {
  console.log("DOMContentLoaded has already fired");
  changeImg();
}
```

Si tu exécutais ce code et actualisais la page, tu verrais l'image changer après le chargement du DOM. C'est assez rapide, mais tu verras un léger clignotement au changement d'image.

L'événement `DOMContentLoaded` est utile quand tu veux exécuter du JavaScript dès que le DOM est chargé, mais avant que toutes les ressources externes comme les images et les feuilles de style ne le soient.
