# --interactive--

Dans la leçon précédente, tu as appris à travailler avec les événements `"click"` et `"input"` grâce à `addEventListener()`. Dans cette leçon, tu vas apprendre à retirer des écouteurs d'événements avec `removeEventListener()`.

La méthode `removeEventListener()` sert à retirer un écouteur d'événement précédemment ajouté à un élément avec `addEventListener()`. C'est utile quand tu veux arrêter d'écouter un événement particulier sur un élément.

Voici la syntaxe de base de `removeEventListener()` :

```js
element.removeEventListener("event", listener);
```

Comme `addEventListener()`, `removeEventListener()` prend deux arguments : l'événement que tu veux retirer et la fonction listener précédemment ajoutée.

Il y a aussi un troisième argument optionnel que tu peux passer à `removeEventListener()`. Cet argument peut être `options` ou `useCapture`.

L'argument `options` est un objet qui précise les options de l'écouteur, par exemple s'il doit être passif (passive) ou unique (once).

L'argument `useCapture` est un booléen qui indique si l'événement doit être capturé pendant la phase de propagation.

La plupart du temps, tu n'auras besoin de passer que les arguments event et listener à `removeEventListener()`.

Si nous voulons basculer la couleur de fond entre gris et bleu, nous pouvons utiliser un écouteur d'événement pour cela.

Nous devons d'abord accéder à l'élément `button` ainsi qu'à l'élément `body` :

```js
const bodyEl = document.querySelector("body");
const btn = document.getElementById("btn");
```

Ensuite nous devons créer la fonction responsable du basculement entre les couleurs grise et bleue :

```js
let isBgColorGrey = true;

function toggleBgColor() {
  bodyEl.style.backgroundColor = isBgColorGrey ? "blue" : "grey";
  isBgColorGrey = !isBgColorGrey;
}
```

Nous utilisons une variable booléenne `isBgColorGrey` pour suivre la couleur de fond actuelle. Si le fond est gris, on le passe en bleu, et inversement.

Ensuite nous devons ajouter un écouteur d'événement à l'élément `button` pour appeler `toggleBgColor` quand le bouton est cliqué :

```js
btn.addEventListener("click", toggleBgColor);
```

Nous pouvons mettre à jour le HTML pour inclure un élément paragraphe qui servira à retirer l'écouteur quand on le survole :

```html
<link rel="stylesheet" href="styles.css" />
<h1>Event Listener examples</h1>
<p id="para">MouseOver this text to remove the event listener</p>
<button id="btn">Change background color</button>
<script src="index.js"></script>
```

Pour retirer l'écouteur au survol du paragraphe, nous pouvons ajouter un écouteur à l'élément paragraphe. Nous utilisons l'événement `mouseover` et passons une fonction qui retire l'écouteur de l'élément `button` :

```js
const para = document.getElementById("para");
const btn = document.getElementById("btn");

para.addEventListener("mouseover", () => {
  btn.removeEventListener("click", toggleBgColor);
});
```

Quand le paragraphe est survolé, l'écouteur du clic du bouton est retiré, et la couleur de fond ne changera plus quand on clique sur le bouton.
