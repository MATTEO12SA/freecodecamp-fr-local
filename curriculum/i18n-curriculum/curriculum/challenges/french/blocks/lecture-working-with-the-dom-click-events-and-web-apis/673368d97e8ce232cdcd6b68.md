# --interactive--

Il y aura des moments où tu auras besoin d'ajouter ou de retirer des nœuds du DOM, et tu peux utiliser quelques API web pour cela.

Dans cette leçon, nous allons couvrir les méthodes `appendChild()` et `removeChild()`.

La méthode `appendChild()` sert à ajouter un nœud à la fin de la liste des enfants d'un nœud parent indiqué.

Voici la syntaxe de base de la méthode `appendChild()` :

```js
parentNode.appendChild(newNode);
```

Regardons un exemple pour mieux comprendre comment utiliser `appendChild()`.

Dans cet exemple, nous avons un élément de liste non ordonnée avec l'ID `desserts` dans le HTML. Cette liste contient deux éléments de liste `Cake` et `Pie` :

```html
<ul id="desserts">
  <li>Cake</li>
  <li>Pie</li>
</ul>
```

Pour accéder à cette liste dans le fichier JavaScript, on peut utiliser `getElementById()` :

```js
const dessertsList = document.getElementById("desserts");
```

Nous avons une variable appelée `dessertsList` qui stocke la référence à l'élément `ul` avec l'ID `desserts`.

Ensuite, il faut créer un nouvel élément de liste avec `createElement()` :

```js
const dessertsList = document.getElementById("desserts");
const listItem = document.createElement("li");
```

Le code suivant crée un nouvel élément de liste et le stocke dans une variable appelée `listItem`.

Pour ajouter ce nœud à la fin de la liste des enfants de l'élément `ul`, on peut utiliser `appendChild()` :

```js
const dessertsList = document.getElementById("desserts");
const listItem = document.createElement("li");

dessertsList.appendChild(listItem);
```

Si tu exécutes ce code, tu verras qu'un nouvel élément de liste est ajouté à la fin de la liste des enfants de l'élément `ul`.

:::interactive_editor

```html
<ul id="desserts">
  <li>Cake</li>
  <li>Pie</li>
</ul>
<script src="index.js"></script>
```

```js
const dessertsList = document.getElementById("desserts");
const listItem = document.createElement("li");

dessertsList.appendChild(listItem);
```

:::

Le problème, c'est que le nouvel élément de liste est vide. Pour y ajouter du contenu texte, tu peux utiliser la propriété `textContent` :

:::interactive_editor

```html
<ul id="desserts">
  <li>Cake</li>
  <li>Pie</li>
</ul>
<script src="index.js"></script>
```

```js
const dessertsList = document.getElementById("desserts");
const listItem = document.createElement("li");

listItem.textContent = "Cookies";
dessertsList.appendChild(listItem);
```

:::

Maintenant la liste affichera `Cake`, `Pie` et `Cookies`.

Pour retirer un nœud du DOM, tu peux utiliser la méthode `removeChild()`.

Voici la syntaxe de base de la méthode `removeChild()` :

```js
parentNode.removeChild(childNode);
```

Regardons un exemple où nous voulons retirer le dernier élément paragraphe de cet élément `section` :

```html
<section id="example-section">
  <h2>Example sub heading</h2>
  <p>first paragraph</p>
  <p>second paragraph</p>
</section>
```

On peut accéder à l'élément `section` dans le fichier JavaScript avec `getElementById()` :

```js
const sectionEl = document.getElementById("example-section");
```

Une fois la référence à l'élément `section` obtenue, on peut accéder au dernier paragraphe avec `querySelector()` :

```js
const sectionEl = document.getElementById("example-section");
const lastParagraph = document.querySelector("#example-section p:last-of-type");
```

Nous utilisons la pseudo-classe `:last-of-type` pour sélectionner le dernier élément paragraphe dans l'élément `section`.

Maintenant que nous avons les nœuds parent et enfant, on peut retirer le dernier paragraphe de l'élément `section` avec `removeChild()` :

:::interactive_editor

```html
<section id="example-section">
  <h2>Example sub heading</h2>
  <p>first paragraph</p>
  <p>second paragraph</p>
</section>
<script src="index.js"></script>
```

```js
const sectionEl = document.getElementById("example-section");
const lastParagraph = document.querySelector("#example-section p:last-of-type");

sectionEl.removeChild(lastParagraph);
```

:::
