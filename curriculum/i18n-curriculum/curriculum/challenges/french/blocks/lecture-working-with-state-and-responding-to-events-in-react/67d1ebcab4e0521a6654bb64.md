# --description--

En React, mettre à jour des tableaux dans le state est assez simple, mais il est facile de se tromper, surtout si tu viens du JavaScript vanilla où tu peux modifier les tableaux directement.

En React, le state est traité comme immuable pour que React puisse reconnaître les changements et mettre correctement à jour l'interface utilisateur.

Voyons comment tu peux mettre à jour des tableaux stockés dans le state en React.

Une des erreurs les plus courantes quand on met à jour des tableaux dans un state React est de modifier directement le tableau avec des méthodes comme `push()`, `pop()`, ou `splice()`. Ces méthodes mutent le tableau d'origine, et React ne l'autorise pas.

React s'appuie sur une nouvelle référence de tableau pour détecter les changements, donc modifier directement le tableau peut empêcher le composant de se re-rendre comme prévu.

Voici un exemple qui utilise la méthode `push()` pour ajouter à un tableau dans le state, ce qui ne marchera pas :

```jsx
import { useState } from "react";

function ItemsList() {
  const [items, setItems] = useState([
    { id: 0, name: "Item 1" },
    { id: 1, name: "Item 2" },
    { id: 2, name: "Item 3" },
  ]);

  const addItem = () => {
    const newItem = { id: items.length + 1, name: `Item ${items.length + 1}` };
    items.push(newItem); // This modifies the original array
    setItems(items); // React will not detect this change
  };

  return (
    <div>
      <button onClick={addItem}>Add Item</button>
      <ul>
        {items.map((item) => (
          <li key={item.id}>{item.name}</li>
        ))}
      </ul>
    </div>
  );
}

export default ItemsList;
```

Si tu cliques sur le bouton `Add Item`, rien ne se passe dans l'interface utilisateur.

Il peut aussi être tentant de retirer des éléments du tableau avec la méthode `pop()` :

```js
const removeItem = () => {
  items.pop(); // Modifies the original array
  setItems(items); // React will not detect this change, either
};
```

Pour mettre à jour un tableau dans le state, l'essentiel est de créer un nouveau tableau, faire tes opérations, et le passer à React, plutôt que de muter le tableau existant.

Comme c'est un nouveau tableau, React saura que le state a changé, et déclenchera un re-render.

Voici comment tu peux ajouter au tableau `items` avec l'opérateur spread :

```js
const addItem = () => {
  const newItem = {
    id: items.length + 1,
    name: `Item ${items.length + 1}`,
  };

  // Creates a new array
  setItems((prevItems) => [...prevItems, newItem]);
};
```

`[...prevItems, newItem]` crée un nouveau tableau en copiant tous les éléments du tableau `items` existant dans le state, puis ajoute `newItem` à la fin, ce qui incrémente l'`id` et le numéro d'élément.

Si tu veux retirer quelque chose du tableau, tu peux utiliser la méthode `filter()`, qui renvoie un nouveau tableau après avoir filtré ce que tu veux retirer :

```js
const removeItem = (id) => {
  setItems((prevItems) => prevItems.filter((item) => item.id !== id));
};
```

Voici le code complet :

```jsx
import { useState } from "react";

function ItemsList() {
  const [items, setItems] = useState([
    { id: 0, name: "Item 1" },
    { id: 1, name: "Item 2" },
    { id: 2, name: "Item 3" },
  ]);

  const addItem = () => {
    const newItem = { id: items.length + 1, name: `Item ${items.length + 1}` };
    setItems((prevItems) => [...prevItems, newItem]); // Creates a new array
  };

  const removeItem = (id) => {
    setItems((prevItems) => prevItems.filter((item) => item.id !== id)); // Creates a new array
  };

  return (
    <div>
      <button onClick={addItem}>Add Item</button>
      <ul>
        {items.map((item) => (
          <li key={item.id}>
            {item.name}{" "}
            <button onClick={() => removeItem(item.id)}>Remove</button>
          </li>
        ))}
      </ul>
    </div>
  );
}

export default ItemsList;
```

Voilà quelques façons courantes de mettre à jour un tableau dans le state.
