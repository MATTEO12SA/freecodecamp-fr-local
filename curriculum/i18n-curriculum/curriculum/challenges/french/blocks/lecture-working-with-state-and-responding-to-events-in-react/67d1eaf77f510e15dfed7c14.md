# --description--

Le state est l'un des fondamentaux les plus importants de React et des autres frameworks front-end. C'est comme le cerveau d'un composant : il détient des informations qui peuvent changer au fil du temps et contrôle comment les composants se comportent et apparaissent.

Regardons ce qu'est le state et comment le hook `useState` te permet de travailler avec.

Le state représente les données dynamiques dans ton composant React, comme la valeur d'une saisie utilisateur, des données récupérées depuis une API, ou un élément dans une liste de tâches.

Chaque fois que le state change, React re-rend le composant sans recharger la page pour refléter ces changements dans l'interface utilisateur. Cette réactivité rend ton app interactive.

Le hook `useState` est une fonction qui te permet de déclarer des variables d'état dans des composants fonctionnels.

Avant les hooks, tu ne pouvais utiliser le state que dans des composants classe. Mais avec l'introduction des hooks depuis React 16.8, tu peux utiliser le state dans des composants fonctionnels en utilisant le hook `useState`.

Pour utiliser le hook `useState`, tu dois l'importer depuis React :

```js
import { useState } from "react";
```

Tu peux aussi importer React lui-même et accéder au hook `useState` comme propriété :

```js
import React from "react";
```

Voici comment tu peux déclarer une variable d'état quand tu importes `useState` :

```js
const [stateVariable, setStateFunction] = useState(initialValue);
```

Et voici comment tu peux déclarer une variable d'état quand tu importes React :

```js
const [stateVariable, setStateFunction] = React.useState(initialValue);
```

Dans la variable d'état tu as ce qui suit :

- `stateVariable` détient la valeur actuelle du state
- `setStateFunction` (la fonction setter) met à jour la variable d'état
- `initialValue` définit le state initial

Note que le state dans un composant React est privé, et isolé à chaque instance de composant. Cela signifie que, si tu rends le même composant deux fois, le state d'un composant n'affecte pas l'autre. Cela signifie aussi que, si tu veux partager le state entre composants, tu devras remonter le state vers un parent commun et le passer en props.

Autre point : les hooks doivent être appelés au niveau supérieur d'un composant, juste avant le mot-clé `return`, pour garder le state et les effets cohérents entre les rendus. Cela signifie que tu ne peux pas utiliser le state dans des boucles, des conditions, ou des fonctions imbriquées.

Voici un exemple de gestion du state avec le hook `useState` dans un composant `Counter` :

```jsx
// Importing the useState hook
import { useState } from "react";

function Counter() {
  const initialValue = 0;

  // The state variable and setter function
  const [count, setCount] = useState(initialValue);

  return (
    <div>
      {/* Display current state value */}
      <h2>{count}</h2>

      <button onClick={() => setCount(count - 1)}>Decrement</button>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}

export default Counter;
```

Dans le code ci-dessus, nous avons le hook `useState` importé depuis React. Dans le composant `Counter`, `count` représente le state actuel tandis que `setCount` est la fonction set responsable de la mise à jour du state. La valeur actuelle du state est `0`. L'instruction `return` contient le compteur et deux boutons pour décrémenter et incrémenter le compteur de `1`.

Tu peux gérer plusieurs morceaux de state en appelant le hook `useState` plusieurs fois. C'est particulièrement important quand tu as des variables d'état sans rapport :

```jsx
function UserProfile() {
  const [isOnline, setIsOnline] = useState(false);
  const [notifications, setNotifications] = useState(0);

  // The rest of the component logic
}
```

Tu peux aussi appeler le hook `useState` plusieurs fois quand tu gères plusieurs états qui se mettent à jour séparément, comme des champs de formulaire :

```jsx
function SignUpForm() {
  const [name, setName] = useState("");
  const [username, setUsername] = useState("");
  const [email, setEmail] = useState("");

  // The rest of the component logic
}
```

Mais dans ce cas, il vaut mieux combiner les états puisqu'ils font tous partie du même formulaire :

```jsx
function SignUpForm() {
  const [formData, setFormData] = useState({
    name: "",
    username: "",
    email: "",
  });

  // The rest of the component logic
}
```

Voilà ce qu'est le state et comment tu peux utiliser le hook `useState`.
