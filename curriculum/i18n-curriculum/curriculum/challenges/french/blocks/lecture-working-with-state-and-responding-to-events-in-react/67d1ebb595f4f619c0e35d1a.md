# --description--

Mettre à jour des objets dans le state en React peut être délicat si tu as l'habitude de changer directement les valeurs des propriétés d'objet.

React traite le state comme immuable, ce qui signifie que tu ne devrais pas le modifier directement.

Voyons ce qui se passe si tu essaies de changer des objets dans le state React directement, puis plongeons dans la bonne façon de le faire.

Disons que tu as un objet dans le state de ton composant qui représente le profil d'un utilisateur, et tu veux que l'utilisateur mette à jour son âge :

```jsx
import { useState } from "react";

function Profile() {
  const [user, setUser] = useState({
    name: "John Doe",
    age: 31,
    city: "LA",
  });

  // Change user age directly
  const handleAgeChange = (e) => {
    user.age = e.target.value;
    console.log(user);
  };

  return (
    <div>
      <h1>User Profile</h1>
      <p>Name: {user.name}</p>
      <p>Age: {user.age}</p>
      <p>City: {user.city}</p>

      <h2>Update User Age </h2>
      <input type="number" value={user.age} onChange={handleAgeChange} />
    </div>
  );
}

export default Profile;
```

Ce code ne marchera pas car tu modifies directement la propriété `user.age`.

Même si `console.log(user)` montrera le nouvel âge dans la console, React ne re-rendra pas le composant pour l'afficher dans l'interface utilisateur car tu n'as pas utilisé la fonction setter, `setUser`.

Pour mettre à jour un objet directement dans le state, tu dois utiliser la fonction setter pour créer un nouvel objet avec la valeur mise à jour. Par exemple :

```js
const handleAgeChange = (e) => {
  setUser({
    age: e.target.value,
  });
};
```

Ça marche. Mais si tu regardes la page maintenant, l'âge de l'utilisateur est mis à jour, mais les valeurs pour le nom et la ville sont perdues.

C'est parce que le nouvel objet que tu as passé à la fonction setter ne contenait qu'une paire clé/valeur pour `age`.

Pour empêcher cela, tu peux d'abord copier l'objet existant, puis mettre à jour uniquement la propriété que tu veux mettre à jour, dans ce cas, `age`.

Pour cela, tu peux passer une fonction spéciale appelée updater function à ta fonction setter, `setUser`. L'updater function prend le state en attente comme argument, ici appelé `prevUser`, et devrait renvoyer le prochain state :

```js
const handleAgeChange = (e) => {
  setUser((prevUser) => {
    const updatedUser = { ...prevUser, age: e.target.value };
    console.log('Previous State:', prevUser);
    console.log('Updated State:', updatedUser);
    return updatedUser;
  });
};
```

Comme tu peux le voir, nous créons un nouvel objet utilisateur appelé `updatedUser` en utilisant la syntaxe spread pour copier l'objet utilisateur en attente, `...prevUser`. Nous mettons ensuite à jour l'âge d'après la saisie du formulaire et renvoyons `updatedUser` en bas de la fonction comme prochain state.

Maintenant ton projet fonctionne comme prévu, et les mises à jour de la saisie d'âge n'affectent pas le nom de l'utilisateur ni le nom de la ville. Tu peux aussi voir les états précédent et mis à jour dans la console.

C'est la façon idéale de mettre à jour un objet dans le state, surtout quand tu ne mets pas à jour toutes les propriétés.

Pour mettre à jour les propriétés restantes `name` et `city`, tu peux les écrire comme des fonctions de définition séparées et les connecter à leurs saisies respectives :

```js
const handleNameChange = (e) => {
  setUser((prevUser) => ({
    ...prevUser,
    name: e.target.value,
  }));
};

const handleCityChange = (e) => {
  setUser((prevUser) => ({
    ...prevUser,
    city: e.target.value,
  }));
};
```

Ou tu peux les combiner en une seule fonction setter comme ceci :

```js
const handleChange = (e) => {
  const { name, value } = e.target;
  setUser((prevUser) => ({
    ...prevUser,
    [name]: value,
  }));
};
```

Pour que ça marche, chaque champ de saisie doit avoir un attribut `name`.

Voici le code complet maintenant :

```jsx
import { useState } from "react";

function Profile() {
  const [user, setUser] = useState({ name: "John Doe", age: 31, city: "LA" });

  const handleChange = (e) => {
    const { name, value } = e.target;

    setUser((prevUser) => ({...prevUser, [name]: value}));
  };

  return (
    <div>
      <h1>User Profile</h1>
      <p>Name: {user.name}</p>
      <p>Age: {user.age}</p>
      <p>City: {user.city}</p>

      <h2>Update User Age </h2>
      <input type="number" name="age" value={user.age} onChange={handleChange} />

      <h2>Update User Name </h2>
      <input type="text" name="name" value={user.name} onChange={handleChange} />

      <h2>Update User City </h2>
      <input type="text" name="city" value={user.city} onChange={handleChange} />
    </div>
  );
}

export default Profile;
```
