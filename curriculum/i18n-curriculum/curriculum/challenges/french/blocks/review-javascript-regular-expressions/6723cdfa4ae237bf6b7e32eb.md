## Expressions régulières et méthodes courantes

- **Définition** : les expressions régulières, ou regex, servent à créer un « motif » (pattern), que tu peux ensuite utiliser pour vérifier une chaîne, en extraire du texte, et plus encore.

```js
const regex = /freeCodeCamp/;
```

- **Méthode `test()`** : cette méthode accepte une chaîne, qui est la chaîne à tester pour des correspondances avec l'expression régulière. Cette méthode renvoie un booléen si la chaîne correspond à la regex.

:::interactive_editor

```js
const regex = /freeCodeCamp/;
const test = regex.test("e");
console.log(test); // false
```

:::

- **Méthode `match()`** : cette méthode accepte une expression régulière, bien que tu puisses aussi passer une chaîne qui sera transformée en expression régulière. La méthode `match` renvoie le tableau de correspondance pour la chaîne.

```js
const regex = /freeCodeCamp/;
const match = "freeCodeCamp".match(regex);
console.log(match); // ['freeCodeCamp', index: 0, input: 'freeCodeCamp', groups: undefined]
```

- **Méthode `replace()`** : cette méthode accepte deux arguments : l'expression régulière à faire correspondre (ou une chaîne), et la chaîne par laquelle remplacer la correspondance (ou une fonction à exécuter sur chaque correspondance).

:::interactive_editor

```js
const regex = /Jessica/;
const str = "Jessica is rly kewl";
const replaced = str.replace(regex, "freeCodeCamp");
console.log(replaced); // "freeCodeCamp is rly kewl"
```

:::

- **Méthode `replaceAll`** : cette méthode sert à remplacer toutes les occurrences d'un motif spécifié par une nouvelle chaîne. Cette méthode lèvera une erreur si tu lui donnes une expression régulière sans le modificateur global.

:::interactive_editor

```js
const text = "I hate JavaScript! I hate programming!";
const newText = text.replaceAll("hate", "love");
console.log(newText);  // "I love JavaScript! I love programming!"
```

:::

- **Méthode `matchAll`** : cette méthode sert à récupérer toutes les correspondances d'une expression régulière donnée dans une chaîne, y compris les groupes de capture, et les renvoie sous forme d'itérateur. Un itérateur est un objet qui te permet de parcourir (ou « itérer ») une collection d'éléments.

:::interactive_editor

```js
const str = "JavaScript, Python, JavaScript, Swift, JavaScript";
const regex = /JavaScript/g;

const iterator = str.matchAll(regex);

for (let match of iterator) {
  console.log(match[0]); // "JavaScript" for each match
}
```

:::

## Modificateurs d'expressions régulières

- **Définition** : les modificateurs, souvent appelés « drapeaux » (flags), modifient le comportement d'une expression régulière.
- **Drapeau `i`** : ce drapeau rend une regex insensible à la casse.

:::interactive_editor

```js
const regex = /freeCodeCamp/i;
console.log(regex.test("freecodecamp")); // true
console.log(regex.test("FREECODECAMP")); // true
```

:::

- **Drapeau `g`** : ce drapeau, ou modificateur global, permet à ton expression régulière de faire correspondre un motif plus d'une fois.

:::interactive_editor

```js
const regex = /freeCodeCamp/gi;
console.log(regex.test("freeCodeCamp")); // true
console.log(regex.test("freeCodeCamp is great")); // false
```

:::

- **Définition des ancres** : l'ancre `^`, au début de l'expression régulière, signifie « correspondre au début de la chaîne ». L'ancre `$`, à la fin de l'expression régulière, signifie « correspondre à la fin de la chaîne ».

:::interactive_editor

```js
const start = /^freeCodeCamp/i;
const end = /freeCodeCamp$/i;
console.log(start.test("freecodecamp")); // true
console.log(end.test("freecodecamp")); // true
```

:::

- **Drapeau `m`** : les ancres cherchent le début et la fin de la chaîne entière. Mais tu peux faire en sorte qu'une regex gère plusieurs lignes avec le drapeau `m`, ou le modificateur multi-ligne.

:::interactive_editor

```js
const start = /^freecodecamp/im;
const end = /freecodecamp$/im;
const str = `I love
freecodecamp
it's my favorite
`;
console.log(start.test(str)); // true
console.log(end.test(str)); // true
```

:::

- **Drapeau `d`** : ce drapeau enrichit les informations que tu obtiens dans un objet de correspondance.

```js
const regex = /freecodecamp/di;
const string = "we love freecodecamp isn't freecodecamp great?";
console.log(string.match(regex));
```

Et le résultat est :

```js
// [
//   'freecodecamp',
//   index: 8,
//   input: "we love freecodecamp isn't freecodecamp great?",
//   groups: undefined,
//   indices: [
//     0: [8, 20],
//     groups: undefined
//   ]
// ]
```

- **Drapeau `u`** : cela étend les fonctionnalités d'une expression régulière pour lui permettre de correspondre à des caractères unicode spéciaux. Le drapeau `u` te donne accès à des classes spéciales comme `Extended_Pictographic` pour correspondre à la plupart des emoji. Il existe aussi un drapeau `v`, qui étend encore les fonctionnalités de la correspondance unicode.
- **Drapeau `y`** : le modificateur sticky se comporte de façon très similaire au modificateur global, mais avec quelques exceptions. La principale est qu'une expression régulière globale commencera à lastIndex et cherchera une autre correspondance dans tout le reste de la chaîne, tandis qu'une expression régulière sticky renverra null et réinitialisera lastIndex à 0 s'il n'y a pas immédiatement de correspondance à lastIndex précédent.
- **Drapeau `s`** : le modificateur single-line permet à un caractère joker, représenté par un `.` en regex, de correspondre aux sauts de ligne — en traitant effectivement la chaîne comme une seule ligne de texte.

## Classes de caractères

- **Joker `.`** : les classes de caractères sont une syntaxe spéciale que tu peux utiliser pour faire correspondre des ensembles ou des sous-ensembles de caractères. La première classe de caractères à apprendre est la classe joker. Le joker est représenté par un point, et correspond à N'IMPORTE QUEL caractère unique SAUF les sauts de ligne. Pour permettre à la classe joker de correspondre aux sauts de ligne, souviens-toi qu'il faut utiliser le drapeau `s`.

```js
const regex = /a./;
```

- **`\d`** : cela correspondra à tous les chiffres (`0-9`) dans une chaîne.

```js
const regex = /\d/;
```

- **`\w`** : cela sert à correspondre à n'importe quel caractère de mot (`a-z0-9_`) dans une chaîne. Un caractère de mot est défini comme n'importe quelle lettre, de a à z, ou un chiffre de 0 à 9, ou le caractère underscore.

```js
const regex = /\w/;
```

- **`\s`** : la classe d'espaces blancs `\s`, représentée par une barre oblique inversée suivie d'un `s`. Cette classe de caractères correspondra à tout espace blanc, y compris les nouvelles lignes, les espaces, les tabulations et les caractères d'espace unicode spéciaux.
- **Négation des classes de caractères spéciales** : pour nier l'une de ces classes de caractères, au lieu d'utiliser une lettre minuscule après la barre oblique inversée, tu peux utiliser l'équivalent en majuscule. L'exemple suivant ne correspond pas à un caractère numérique. Au lieu de cela, il correspond à n'importe quel caractère unique qui N'EST PAS un caractère numérique.

```js
const regex = /\D/;
```

- **Classes de caractères personnalisées** : tu peux créer des classes de caractères personnalisées en plaçant le caractère que tu souhaites faire correspondre à l'intérieur d'un ensemble de crochets.

```js
const regex = /[abcdf]/;
```

## Assertions lookahead et lookbehind

- **Définition** : les assertions lookahead et lookbehind te permettent de faire correspondre des motifs spécifiques selon la présence ou l'absence de motifs environnants.
- **Assertion lookahead positive** : cette assertion fera correspondre un motif lorsque le motif est suivi d'un autre motif. Pour construire un lookahead positif, tu dois commencer par le motif que tu veux faire correspondre. Ensuite, utilise des parenthèses pour envelopper le motif que tu veux utiliser comme condition. Après la parenthèse ouvrante, utilise `?=` pour définir ce motif comme un lookahead positif.

```js
const regex = /free(?=code)/i;
```

- **Assertion lookahead négative** : c'est un type de condition utilisé dans les expressions régulières pour vérifier qu'un certain motif ne se produit pas plus loin dans la chaîne.

```js
const regex = /free(?!code)/i;
```

- **Assertion lookbehind positive** : cette assertion fera correspondre un motif seulement s'il est précédé d'un autre motif spécifique, sans inclure le motif précédent dans la correspondance.

```js
const regex = /(?<=free)code/i;
```

- **Assertion lookbehind négative** : cette assertion garantit qu'un motif n'est pas précédé d'un autre motif spécifique. Elle ne correspond que si le motif spécifié n'est pas immédiatement précédé de la séquence donnée, sans inclure la séquence précédente dans la correspondance.

```js
const regex = /(?<!free)code/i;
```

## Quantificateurs regex

- **Définition** : les quantificateurs dans les expressions régulières précisent combien de fois un motif (ou une partie d'un motif) doit apparaître. Ils aident à contrôler le nombre d'occurrences de caractères ou de groupes dans une correspondance. L'exemple suivant sert à faire correspondre le caractère précédent exactement quatre fois.

```js
const regex = /^\d{4}$/;
```

- **`*`** : correspond à 0 occurrence ou plus de l'élément précédent.
- **`+`** : correspond à 1 occurrence ou plus de l'élément précédent.
- **`?`** : correspond à 0 ou 1 occurrence de l'élément précédent.
- **`{n}`** : correspond à exactement n occurrences de l'élément précédent.
- **`{n,}`** : correspond à n occurrences ou plus de l'élément précédent.
- **`{n,m}`** : correspond à un nombre d'occurrences compris entre n et m de l'élément précédent.

## Groupes de capture et références arrières

- **Groupes de capture** : un groupe de capture te permet de « capturer » une portion de la chaîne correspondante pour l'utiliser comme tu en as besoin. Les groupes de capture sont définis par des parenthèses contenant le motif à capturer, sans caractères initiaux comme un lookahead.

```js
const regex = /free(code)camp/i;
```

- **Groupes non capturants** : un groupe non capturant est similaire à un groupe de capture mais ne stocke pas la portion correspondante de la chaîne pour une utilisation ultérieure. Les groupes non capturants sont définis par `(?:...)`.

```js
const regex = /free(?:code)camp/i;
```

- **Références arrières** : une référence arrière dans les expressions régulières désigne une façon de réutiliser une partie du motif qui a été correspondue plus tôt dans la même expression. Elle te permet de faire référence à un groupe capturé (une partie du motif entre parenthèses) par son numéro. Par exemple, `$1` fait référence au premier groupe capturé.

:::interactive_editor

```js
const regex = /free(co+de)camp/i;
console.log("freecoooooooodecamp".replace(regex, "paid$1world"));
```

:::

- Tu peux utiliser des références arrières au sein de la regex elle-même pour faire correspondre le même texte capturé par un groupe précédent avec une barre oblique inversée et le numéro du groupe de capture. Par exemple :

:::interactive_editor

```js
const regex = /(hello) \1/i;
console.log(regex.test("hello hello")); // true
console.log(regex.test("hello world")); // false
```

:::
