# --description--

Le rendu conditionnel dans React te permet de créer des interfaces utilisateur dynamiques. Il sert à montrer du contenu différent selon certaines conditions ou états dans ton application.

Les approches les plus courantes pour le rendu conditionnel incluent l'utilisation d'instructions `if`, de l'opérateur ternaire (`?:`) et de l'opérateur ET logique (`&&`).

La forme la plus simple de rendu conditionnel utilise une instruction `if`. Voici un exemple :

```jsx
function Greeting({ isLoggedIn }) {
  if (isLoggedIn) {
    return <h1>Welcome back!</h1>;
  }
  return <h1>Please sign in</h1>;
}
```

Dans cet exemple, le composant `Greeting` vérifie la prop `isLoggedIn`. Si elle est `true`, il renvoie un message de bienvenue, sinon il invite l'utilisateur à se connecter.

Voici un exemple utilisant le composant `Greeting` à l'intérieur du composant parent `App` :

```jsx
function App() {
  return (
    <div className="App">
      <Greeting isLoggedIn={false} />
    </div>
  );
}
```

Pour des conditions plus simples, l'opérateur ternaire (`?:`) est souvent utilisé directement dans le JSX. Il permet un rendu conditionnel en ligne, ce qui peut rendre ton code plus concis :

```jsx
function Greeting({ isLoggedIn }) {
  return <h1>{isLoggedIn ? "Welcome back!" : "Please sign in."}</h1>;
}
```

Ce code obtient le même résultat que l'exemple précédent mais sous une forme plus compacte. L'opérateur ternaire vérifie `isLoggedIn` et affiche le message approprié.

Un autre motif courant pour le rendu conditionnel est d'utiliser l'opérateur ET logique (`&&`). C'est particulièrement utile quand tu veux afficher quelque chose, ou rien, selon une condition :

```jsx
function Notification({ message }) {
  return (
    <div>
      {message && <p>{message}</p>}
    </div>
  );
}
```

Dans cet exemple, l'élément paragraphe avec le message n'est affiché que si la prop `message` est truthy. Si `message` est falsy — c'est-à-dire une chaîne vide, `null` ou `undefined` — rien n'est affiché à l'écran.

En maîtrisant ces techniques de rendu conditionnel, tu peux construire des applications plus interactives et agréables qui s'adaptent aux données changeantes et aux interactions utilisateur.
