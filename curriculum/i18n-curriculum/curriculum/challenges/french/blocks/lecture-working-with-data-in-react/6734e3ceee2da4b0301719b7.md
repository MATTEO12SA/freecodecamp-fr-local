# --description--

Dans les leçons précédentes, nous avons appris à construire de petits composants dans React comme ceci :

```jsx
function Greeting() {
  const developerName = "Jessica";
  return <h1>Hi {developerName}!</h1>;
}
```

Nous pouvons choisir d'imbriquer ce composant dans un autre composant parent ou dans le composant racine comme ceci :

```jsx
function App() {
  return <Greeting />;
}

function Greeting() {
  const developerName = "Jessica";
  return <h1>Hi {developerName}!</h1>;
}
```

Bien que ce code fonctionne bien et affiche le résultat `Hi Jessica!` à l'écran, ce n'est pas un composant très flexible.

Et si nous voulions afficher un nom différent comme Naomi, Tom ou Oliver ? C'est là que les props React interviennent. Props, raccourci de properties (propriétés), est la façon pour les composants parents de passer des données au composant enfant. Les props peuvent être de n'importe quel type : chaînes, nombres, booléens, objets ou tableaux.

Mettons à jour notre exemple précédent pour maintenant accepter une prop `name` :

```jsx
function App() {
  return <Greeting name="Jessica" />;
}

export default App;

function Greeting(props) {
  console.log(props);
  return <h1>Hi {props.name}!</h1>;
}
```

Pour le composant enfant appelé `Greeting`, nous utilisons maintenant `props.name` au lieu de coder en dur le nom `"Jessica"`. Nous journalisons aussi `props` dans la console, qui s'affiche comme un objet.

Ensuite, à l'intérieur du composant parent `App`, nous passons la valeur à la prop `name` pour qu'elle puisse être transmise à l'enfant. Le résultat sera le même à l'écran qu'auparavant, mais nous avons maintenant créé un composant plus flexible.

Nous avons maintenant la capacité de réutiliser le composant enfant plusieurs fois et de passer des noms différents à chaque fois :

```jsx
function App() {
  return (
    <>
      <Greeting name="Naomi" />
      <Greeting name="Tom" />
      <Greeting name="Jessica" />
      <Greeting name="Oliver" />
    </>
  );
}
```

Tu peux aussi choisir d'utiliser la déstructuration d'objet dans les props pour la rendre plus lisible. Voici comment tu pourrais réécrire le composant `Greeting` :

```jsx
function Greeting({ name }) {
  return <h1>Hi {name}!</h1>;
}
```

Ce code obtient le même résultat mais rend plus clair quelles props le composant s'attend à recevoir.

React fournit aussi une prop spéciale appelée `children`. Tout JSX que tu places entre les balises d'ouverture et de fermeture d'un composant est passé au composant comme `children`.

Par exemple :

```jsx
function Card({ children }) {
  return <div className="card">{children}</div>;
}

function App() {
  return (
    <Card>
      <h2>Hello</h2>
    </Card>
  );
}
```

Dans ce cas, le JSX à l'intérieur de `<Card>...</Card>` devient la prop `children`. La sortie affichée dans le DOM sera :

```html
<div class="card">
  <h2>Hello</h2>
</div>
```

Ce motif est souvent utilisé pour la composition de composants, où un composant enveloppe d'autres éléments d'UI.

Parfois, tu peux avoir beaucoup de propriétés à passer comme props. Au lieu de les passer une par une, tu peux utiliser l'opérateur de propagation (`...`), après les avoir converties en objet.

Voici un exemple d'un nouveau composant enfant appelé `DeveloperCard` :

```jsx
function DeveloperCard({ name, age, country }) {
  return (
    <div className="developer-card">
      <h1>Developer: {name}</h1>
      <p>Age: {age}</p>
      <p>Country: {country}</p>
    </div>
  );
}
```

Ce composant `DeveloperCard` accepte trois props : `name`, `age` et `country`.

Dans le composant parent `App`, nous pouvons utiliser la syntaxe de propagation pour passer toutes les propriétés d'un objet comme props individuelles au composant enfant :

```jsx
function App() {
  const developerObj = {
    name: "Alice",
    age: 30,
    country: "USA",
  };

  return (
    <div className="App">
      <DeveloperCard {...developerObj} />
    </div>
  );
}
```

C'est particulièrement utile quand tu travailles avec des tableaux d'objets et que tu passes plusieurs ensembles de propriétés à des composants enfants. Par exemple, tu pourrais avoir une liste de développeurs où chaque objet du tableau a la même structure mais représente une personne différente.

Tu en apprendras plus sur l'affichage de listes dans des tableaux dans les prochaines leçons.

Utiliser les props dans React rend tes composants plus flexibles et réutilisables, te permettant de construire des UI plus complexes. Cependant, il est important de noter que les props sont immuables, ce qui signifie qu'elles ne peuvent pas être modifiées une fois passées à un composant. Si tu as besoin de gérer la saisie utilisateur et de modifier des données, tu devrais utiliser l'état à la place. Tu en apprendras plus sur la gestion de l'état dans les prochaines leçons.
