# --description--

Dans les leçons précédentes, tu as appris que React est une application monopage. Les applications monopages sont des applications qui contiennent un fichier HTML et utilisent JavaScript pour mettre à jour dynamiquement tout contenu sur la page.

Alors que se passe-t-il quand tu dois ajouter plusieurs « pages » à ton application React ? Comment naviguerais-tu vers ces différentes vues ?

Eh bien, c'est là qu'intervient React Router.

React Router est une bibliothèque tierce qui te permet d'ajouter du routage à tes applications React. Pour commencer, tu devras installer React Router dans un projet React existant comme ceci :

```sh
npm i react-router
```

Si tu vérifies le fichier `package.json`, tu verras que `react-router` a été ajouté à la liste des dépendances :

```json
"dependencies": {
  "react": "^18.3.1",
  "react-dom": "^18.3.1",
  "react-router": "^7.2.0"
}
```

Ensuite, dans ton fichier `main.jsx` ou `index.jsx`, tu devras importer `BrowserRouter` et rendre `BrowserRouter` autour de ton composant `App` :

```jsx
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import { BrowserRouter } from "react-router";
import App from "./App.jsx";

import "./index.css";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>
);
```

Pour activer les routes dans ton application, tu devras mettre à jour ton instruction `import` pour inclure les composants `Routes` et `Route` comme ceci :

```js
import { BrowserRouter, Routes, Route } from "react-router";
```

Ensuite, à l'intérieur de `BrowserRouter`, ajoute les composants `Routes` et `Route` :

```jsx
createRoot(document.getElementById("root")).render(
  <StrictMode>
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<App />} />
      </Routes>
    </BrowserRouter>
  </StrictMode>
);
```

Le `path` et l'`element` servent à coupler l'URL et les composants UI. Dans ce cas, on configure une route pour la page d'accueil qui pointe vers le composant `App`.

Il est courant dans les plus grandes applications d'avoir plusieurs vues et routes configurées comme ceci :

```jsx
<Routes>
  <Route index element={<Home />} />
  <Route path="about" element={<About />} />

  <Route path="products">
    <Route index element={<ProductsHome />} />
    <Route path=":category" element={<Category />} />
    <Route path=":category/:productId" element={<ProductDetail />} />
    <Route path="trending" element={<Trending />} />
  </Route>
</Routes>
```

La prop `index` dans ces exemples représente la route par défaut pour un segment de chemin donné. Donc le composant `Home` sera affiché au chemin racine (`/`) tandis que le composant `ProductsHome` sera affiché au chemin `products`.

Tu as peut-être aussi remarqué qu'on imbrique quelques routes à l'intérieur d'une autre route comme ceci :

```jsx
<Route path="products">
  <Route path="trending" element={<Trending />} />
</Route>
```

Cela signifie que le chemin de la route enfant sera ajouté au chemin de la route parent. Donc dans cet exemple, le `path` pour les produits tendance sera `products/trending`.

Si le `path` commence par un deux-points (`:`) alors cela représente un segment dynamique dans la route :

```jsx
<Route path=":category" element={<Category />} />
```

Dans cet exemple on a un segment dynamique appelé `category`. Quand un utilisateur navigue vers une URL comme `products/brass-instruments`, alors la vue changera vers le composant `Category` et tu pourras récupérer dynamiquement les données appropriées selon le segment.

Tu peux accéder à la valeur du segment dynamique en utilisant le Hook `useParams` dans le composant enfant comme ceci :

```jsx
import { useParams } from "react-router";

export default function Category() {
  let params = useParams();
   {/* Accessing the category param: params.category */}
   {/* rest of code goes here */}
}
```

Les routes dynamiques sont utiles car elles te permettent de créer des composants flexibles et réutilisables qui peuvent rendre un contenu différent selon les paramètres dans l'URL. Au lieu de définir une liste fixe de chemins pour chaque route possible, tu peux utiliser des segments dynamiques pour rendre divers contenus selon ce que l'utilisateur a demandé.
