# --description--

Jusqu'ici, tu as utilisé React pour construire des interfaces utilisateur. Si tu avais besoin de fonctionnalités supplémentaires comme le routage, tu devais importer une bibliothèque tierce comme React Router pour pouvoir basculer entre les différentes vues.

Mais que se passe-t-il quand tu dois construire une application web full-stack ? Eh bien tu pourrais utiliser React pour le front-end et Node et Express pour la logique back-end si tu veux rester avec JavaScript. Ou tu pourrais utiliser d'autres langages comme Go, Python ou Java pour ton back-end.

Bien que toutes ces options soient viables, il y a des moments où tu pourrais vouloir utiliser un framework React à la place. Les frameworks React fournissent des fonctionnalités comme le routage, l'optimisation d'images, la récupération de données, l'authentification et plus. Cela signifie que tu pourrais ne pas avoir besoin de configurer des applications front-end et back-end séparées pour certains cas d'usage.

Regardons de plus près Next.js qui est un framework React populaire. Une des fonctionnalités principales de Next.js est le routeur basé sur le système de fichiers. Ce système de routage inclut le support des routes dynamiques, routes parallèles, gestionnaires de routes, redirections, internationalisation et plus.

Voici un exemple de création d'un gestionnaire de requête personnalisé :

```js
export async function GET() {
  const res = await fetch("https://example-api.com");
  const data = await res.json();

  return Response.json({ data });
}
```

Tu peux définir des gestionnaires de routes comme des requêtes GET ou POST dans un fichier appelé `route.js` dans le répertoire `app/api`.

Une autre fonctionnalité de Next.js sont les optimisations automatiques d'images et de polices.

Voici un exemple de travail avec le composant `Image` dans un fichier `page.js` :

```jsx
import Image from "next/image";

export default function Page() {
  return (
    <Image src="link-to-image-goes-here" alt="descriptive-title-goes-here" />
  );
}
```

Le composant `Image` étend l'élément HTML natif `img` et permet des chargements de page plus rapides et des optimisations de taille. Cela signifie que les images ne se chargeront que quand elles entrent dans le viewport et le composant `Image` servira automatiquement des images correctement dimensionnées pour chaque appareil.

Bien que ce ne soient que quelques fonctionnalités de Next.js, il y en a bien d'autres que tu peux utiliser pour construire des applications web full-stack robustes. Il y a aussi d'autres frameworks React comme Remix qui fourniront la même capacité à construire des applications web full-stack modernes.

Même si le paysage des bibliothèques et frameworks JavaScript évolue constamment, il est important d'être conscient des options disponibles et d'apprendre les avantages et inconvénients de chaque framework.
