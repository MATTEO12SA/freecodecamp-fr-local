## Travailler avec les événements en React

- **Système d'événements synthétiques** : C'est la façon dont React gère les événements. Il sert d'enveloppe autour des événements natifs comme `click`, `keydown` et `submit`. Les gestionnaires d'événements en React utilisent la convention camelCase. (Ex. `onClick`, `onSubmit`, etc.)

Voici un exemple d'utilisation de l'attribut `onClick` pour un élément `button` en React :

```jsx
function handleClick() {
  console.log("Button clicked!");
}

<button onClick={handleClick}>Click Me</button>;
```

En React, les fonctions gestionnaires d'événements commencent en général par le préfixe `handle` pour indiquer qu'elles gèrent des événements, comme `handleClick` ou `handleSubmit`.

Quand une action utilisateur déclenche un événement, React passe un objet Synthetic Event à ton gestionnaire. Cet objet se comporte beaucoup comme l'objet Event natif en JavaScript vanilla, avec des propriétés comme `type`, `target` et `currentTarget`.

Pour empêcher les comportements par défaut comme le rechargement du navigateur lors d'un événement `onSubmit`, par exemple, tu peux appeler la méthode `preventDefault()` :

```jsx
function handleSubmit(event) {
  event.preventDefault();
  console.log("Form submitted!");
}

<form onSubmit={handleSubmit}>
  <input type="text" />
  <button>Submit</button>
</form>;
```

Tu peux aussi envelopper une fonction gestionnaire dans une fonction fléchée comme ceci :

```jsx
function handleDelete(id) {
  console.log("Deleting item:", id);
}

<button onClick={() => handleDelete(1)}>Delete Item</button>;
```

## Travailler avec l'état et le Hook `useState`

- **Définition de l'état** : En React, l'état est un objet qui contient des données pour un composant. Quand l'état est mis à jour, le composant se réaffiche. React traite l'état comme immuable : tu ne dois pas le modifier directement.
- **Hook `useState()`** : Le hook `useState` est une fonction qui te permet de déclarer des variables d'état dans des composants fonctionnels. Voici la syntaxe de base :

```js
const [stateVariable, setStateFunction] = useState(initialValue);
```

Dans la variable d'état, tu as ce qui suit :

- `stateVariable` contient la valeur d'état actuelle
- `setStateFunction` (la fonction setter) met à jour la variable d'état
- `initialValue` définit l'état initial

Voici un exemple complet pour un composant `Counter` :

```jsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h2>{count}</h2>

      <button onClick={() => setCount(count - 1)}>Decrement</button>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}

export default Counter;
```

## Rendu et composants React

- **Définition** : En React, le rendu est le processus par lequel les composants apparaissent dans l'interface utilisateur (UI), en général le navigateur. Le processus de rendu comporte trois étapes : trigger, render et commit.

L'étape trigger survient quand React détecte qu'un changement s'est produit et que l'interface utilisateur (UI) pourrait devoir être mise à jour. Ce changement vient souvent d'une mise à jour de l'état ou des props.

Une fois le trigger déclenché, React entre dans l'étape render. Ici, React réévalue tes composants et détermine quoi afficher. Pour cela, React utilise une copie légère du « vrai » DOM appelée le virtual DOM. Avec le virtual DOM, React peut rapidement vérifier ce qui doit changer dans le composant.

L'étape commit est celle où React prend les changements préparés depuis le virtual DOM et les applique au vrai DOM. Autrement dit, c'est l'étape où tu vois le résultat final à l'écran.

## Mettre à jour des objets et des tableaux dans l'état

- **Mettre à jour des objets dans l'état** : Si tu dois mettre à jour un objet dans l'état, crée d'abord un nouvel objet ou copie un objet existant, puis définis l'état avec ce nouvel objet. Tout objet placé dans l'état doit être considéré en lecture seule. Voici un exemple pour définir le nom, l'âge et la ville d'un utilisateur. La fonction `handleChange` gère les mises à jour des informations de l'utilisateur :

```jsx
import { useState } from "react";

function Profile() {
  const [user, setUser] = useState({ name: "John Doe", age: 31, city: "LA" });

  const handleChange = (e) => {
    const { name, value } = e.target;

    setUser((prevUser) => ({...prevUser, [name]: value}));
  };

  return (
    <div>
      <h1>User Profile</h1>
      <p>Name: {user.name}</p>
      <p>Age: {user.age}</p>
      <p>City: {user.city}</p>

      <h2>Update User Age </h2>
      <input type="number" name="age" value={user.age} onChange={handleChange} />

      <h2>Update User Name </h2>
      <input type="text" name="name" value={user.name} onChange={handleChange} />

      <h2>Update User City </h2>
      <input type="text" name="city" value={user.city} onChange={handleChange} />
    </div>
  );
}

export default Profile;
```

- **Mettre à jour des tableaux dans l'état** : Quand tu mets à jour des tableaux dans l'état, il est important de ne pas modifier le tableau directement avec des méthodes comme `push()` ou `pop()`. Tu dois plutôt créer un nouveau tableau lors de la mise à jour de l'état :

```js
const addItem = () => {
  const newItem = {
    id: items.length + 1,
    name: `Item ${items.length + 1}`,
  };

  // Creates a new array
  setItems((prevItems) => [...prevItems, newItem]);
};
```

Si tu veux retirer des éléments d'un tableau, tu dois utiliser la méthode `filter()`, qui renvoie un nouveau tableau après avoir filtré ce que tu veux retirer :

```js
const removeItem = (id) => {
  setItems((prevItems) => prevItems.filter((item) => item.id !== id));
};
```

## Référencer des valeurs avec les refs

- **Attribut `ref`** : Tu peux accéder à un nœud DOM en React avec l'attribut `ref`. Voici un exemple qui montre un `ref` pour donner le focus à un élément `input`. La propriété `current` sert à accéder à la valeur actuelle de ce `ref` :

```jsx
import { useRef } from "react";

const Focus = () => {
  const inputRef = useRef(null);

  const handleFocus = () => {
    if (inputRef.current) {
      inputRef.current.focus();
    }
  };

  return (
    <div>
      <input ref={inputRef} type="text" placeholder="Enter text" />
      <button onClick={handleFocus}>Focus Input</button>
    </div>
  );
};

export default Focus;
```

## Travailler avec le Hook `useEffect`

- **Hook `useEffect()`** : En React, un effet est tout ce qui se produit en dehors du processus de rendu du composant. C'est-à-dire tout ce que React ne gère pas directement dans le rendu de l'UI. Des exemples courants : récupérer des données, mettre à jour le titre de l'onglet du navigateur, lire ou écrire dans le local storage du navigateur, obtenir la localisation de l'utilisateur, et bien plus. Ces opérations interagissent avec le monde extérieur et sont appelées effets de bord. React fournit le hook `useEffect` pour gérer ces effets de bord. `useEffect` te laisse exécuter une fonction après que le composant s'affiche ou se met à jour.

```js
import { useEffect } from "react";

useEffect(() => {
 // Your side effect logic (usually a function) goes here
}, [dependencies]);
```

La fonction d'effet s'exécute après le rendu du composant, tandis que l'argument optionnel `dependencies` contrôle quand l'effet s'exécute.

Note que `dependencies` peut être un tableau de « valeurs réactives » (état, props, fonctions, variables, etc.), un tableau vide, ou être omis entièrement. Voici comment chacune de ces options contrôle le fonctionnement de `useEffect` :

- Si `dependencies` est un tableau qui inclut une ou plusieurs valeurs réactives, l'effet s'exécutera dès qu'elles changent.

- Si `dependencies` est un tableau vide, `useEffect` ne s'exécute qu'une fois au premier rendu du composant.

- Si tu omets `dependencies`, l'effet s'exécute à chaque fois que le composant s'affiche ou se met à jour.

## Comment créer des Hooks personnalisés

- **Hooks personnalisés** : Un hook personnalisé te permet d'extraire de la logique réutilisable des composants, comme la récupération de données, la gestion d'état, le basculement, et des effets de bord comme le suivi du statut en ligne. En React, tous les hooks intégrés commencent par le mot `use`, donc ton hook personnalisé doit suivre la même convention.

Voici un exemple de création d'un hook `useDebounce` :

```js
function useDebounce(value, delay) {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const handler = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    return () => {
      clearTimeout(handler);
    };
  }, [value, delay]);

  return debouncedValue;
}

export { useDebounce };
```
