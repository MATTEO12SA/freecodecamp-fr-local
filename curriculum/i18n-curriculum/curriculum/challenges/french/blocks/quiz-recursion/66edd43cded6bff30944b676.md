### --question--

#### --text--

Qu'est-ce que la récursion en programmation ?

#### --distractors--

Une méthode de tri des tableaux.

---

Une boucle qui ne se termine jamais.

---

Une fonction qui renvoie `undefined`.

#### --answer--

Un processus dans lequel une fonction s'appelle elle-même.

### --question--

#### --text--

Laquelle des propositions suivantes est un exemple de récursion ?

#### --distractors--

```js
function factorial(n) {
  let result = 1;

  while (n > 0) {
    result = result * n;
    n--;
  }

  return result;
}
```

---

```js
function factorial(n) {
  const arr = Array(n).fill().map((_, i) => i + 1);
  return arr.reduce((acc, curr) => acc * curr, 1);
}
```

---

```js
function factorial(n) {
  let result = 1;

  for (let i = n; i > 0; i--) {
    result *= i;
  }

  return result;
}
```

#### --answer--

```js
function factorial(n) {
  if (n === 0 || n === 1) {
    return 1;
  }
  return n * factorial(n - 1);
}
```

### --question--

#### --text--

Pourquoi la récursion doit-elle avoir un cas de base ?

#### --distractors--

Pour s'assurer que la fonction a toujours une valeur de retour.

---

Pour réduire le nombre d'appels de fonction.

---

Pour s'assurer que tous les appels récursifs sont exécutés dans le bon ordre et qu'une `RecursionError` n'est pas levée.

Pour fournir un moyen à la fonction de sortir de ses appels récursifs et d'éviter les boucles infinies.
