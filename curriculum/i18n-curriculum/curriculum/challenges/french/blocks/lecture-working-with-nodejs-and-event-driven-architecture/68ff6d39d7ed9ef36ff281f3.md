# --description--

Tu es maintenant prêt à faire tes premiers pas dans le monde de Node.js en l'installant sur ton ordinateur. Mais d'abord, avant d'installer Node.js, nous recommandons d'installer un outil appelé NVM (Node Version Manager). Comme son nom l'indique, NVM est un outil pour gérer plusieurs versions de Node.js sur le même ordinateur.

Mettre en place cet outil dès le début t'aidera à l'avenir, car tu pourrais avoir besoin de basculer entre différentes versions de Node.js pour différents projets. Avec NVM, tu peux le faire très facilement.

Voyons comment installer NVM sur macOS/Linux et Windows, et comment l'utiliser pour installer Node.js.

## Comment installer NVM sur macOS/Linux

Sur macOS et Linux, tu peux installer NVM directement via un script shell.

Mais pour macOS, note que la documentation officielle de NVM mentionne que « tu dois installer manuellement les outils en ligne de commande Xcode avant d'exécuter le script d'installation, sinon il échouera ».

Sur macOS, tu peux installer les outils en ligne de commande Xcode en exécutant cette commande dans ton terminal :

```bash
xcode-select --install
```

Une fois l'installation terminée, tu peux vérifier le numéro de version et confirmer l'installation avec cette commande :

```bash
xcode-select --version
```

Ensuite, il est temps d'installer NVM. Tu peux télécharger et exécuter le script d'installation de NVM en lançant l'une de ces commandes :

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

```bash
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

Pour obtenir la dernière version de NVM au moment où tu lis cet article, consulte la documentation officielle de NVM : `https://github.com/nvm-sh/nvm?tab=readme-ov-file#install--update-script`. Tu y trouveras ces commandes avec le dernier numéro de version.

Tu pourrais devoir redémarrer ton terminal une fois le processus terminé pour charger la nouvelle commande et la nouvelle configuration.

Ensuite, exécute cette commande pour confirmer que NVM a été installé correctement et pour vérifier ta version actuelle :

```bash
nvm -v
```

Tu devrais voir ta version de NVM dans la sortie.

## Comment installer Node.js avec NVM sur macOS/Linux

Maintenant que tu as NVM installé sur macOS/Linux, tu peux installer Node.js.

Pour installer la dernière version Long-Term Support (LTS) de Node.js, exécute cette commande :

```bash
nvm install --lts
```

Remarque le drapeau `--lts`. Ce drapeau indique que tu veux installer la version Long-Term Support (LTS) actuelle de Node.js. Cette version est généralement recommandée parce qu'elle priorise la stabilité, la fiabilité et la sécurité plutôt que les fonctionnalités nouvelles ou expérimentales. Elle est soigneusement testée et prête pour la production. Elle est aussi garantie d'avoir des périodes de support plus longues, avec un focus sur les corrections de bugs et les correctifs de sécurité.

Alternativement, tu peux installer une version spécifique de Node.js en précisant le numéro de version dans la commande :

```bash
nvm install <version>
```

Par exemple, voici comment installer Node.js v20 :

```bash
nvm install 20
```

Une fois que tu as fini d'installer une version de Node.js, tu peux basculer vers cette version avec cette commande :

```bash
nvm use <version>
```

Par exemple, voici comment basculer vers la version 20 :

```bash
nvm use 20
```

Enfin, tu peux vérifier la version actuelle de Node.js avec cette commande :

```bash
node -v
```

## Comment installer NVM sur Windows

Voyons maintenant comment installer et utiliser NVM sur Windows.

Les versions officielles de NVM ne prennent en charge Windows que dans des cas spécifiques. Si tu as Windows Subsystem for Linux (WSL) configuré sur ton appareil, tu peux suivre le guide macOS/Linux ci-dessus pour installer et utiliser NVM.

Cependant, pour Windows lui-même, il existe quelques alternatives. L'une d'elles est `nvm-windows`, un utilitaire de gestion de versions Node.js pour Windows. C'est un projet complètement séparé du projet NVM officiel. Mais le but de ces outils est le même — t'aider à travailler avec plusieurs versions de Node.js sur le même appareil.

Avant d'installer `nvm-windows`, tu dois savoir que le dépôt officiel recommande de désinstaller toute installation Node préalable avant d'installer NVM for Windows. Si c'est ta première installation de Node.js, tu devrais être bon. Si tu as déjà d'autres versions de Node.js installées, il est recommandé de les désinstaller d'abord.

Pour installer `nvm-windows` :

- Va dans la section Releases du dépôt officiel : `https://github.com/coreybutler/nvm-windows/releases`.
- Télécharge le dernier installateur.
- Suis les instructions.

Après avoir terminé l'installation, tu pourrais devoir redémarrer ton terminal si la commande `nvm` n'est pas immédiatement disponible.

Tu peux vérifier si l'installation a réussi et voir ta version actuelle de `nvm-windows` en exécutant cette commande :

```powershell
nvm -v
```

## Comment installer Node.js avec NVM for Windows

Maintenant que tu as `nvm-windows` installé sur Windows, tu es prêt à installer Node.js.

Pour installer la dernière version Long-Term Support (LTS) de Node.js, exécute cette commande :

```powershell
nvm install lts
```

La version Long-Term Support (LTS) est généralement recommandée, mais tu peux installer une version différente en précisant son numéro de version dans la commande :

```powershell
nvm install <version>
```

Par exemple :

```powershell
nvm install 20
```

Quand l'installation est terminée, tu peux basculer vers cette version de Node.js avec cette commande :

```powershell
nvm use <version>
```

Par exemple :

```powershell
nvm use 20
```

Tu peux aussi vérifier ta version actuelle de Node.js avec cette commande :

```bash
node -v
```

## Commandes de base

Maintenant que tu sais comment installer NVM et Node.js, voyons quelques commandes de base qui te seront utiles quand tu travailleras avec Node.js et NVM.

Aussi, bien que toutes ces commandes fonctionnent pour NVM installé sur macOS/Linux, y compris WSL, elles peuvent fonctionner différemment ou ne pas fonctionner du tout pour `nvm-windows`. Nous indiquerons des commandes alternatives pour `nvm-windows` quand c'est possible.

### Comment ajuster la stratégie d'exécution de Powershell

Si tu es sous Windows et que tu suis avec Powershell et `nvm-windows`, tu pourrais devoir ajuster la stratégie d'exécution de Powershell. La stratégie d'exécution par défaut de Powershell est `Restricted`, ce qui est une mesure de sécurité pour empêcher l'exécution de scripts.

D'abord, lance Powershell en tant qu'administrateur en faisant un clic droit sur Powershell, puis en cliquant sur « Run as Administrator ».

Ensuite, pour voir la stratégie d'exécution actuelle de la session Powershell en cours, exécute la commande suivante :

```powershell
Get-ExecutionPolicy
```

Enfin, pour définir la stratégie d'exécution de Powershell sur `RemoteSigned`, ce qui permet aux scripts locaux et à `npm` de s'exécuter, utilise la commande suivante :

```powershell
Set-ExecutionPolicy RemoteSigned
```

Une fois que tu as exécuté la commande ci-dessus, tu peux fermer la fenêtre administrateur de Powershell, et ouvrir une fenêtre Powershell non administrateur.

### Lister toutes les versions

Pour lister toutes les versions installées de Node.js et vérifier celle qui est actuellement utilisée, exécute cette commande :

```bash
nvm ls
```

### Définir la version Node.js par défaut (NVM sur macOS/Linux uniquement)

Cette commande définit la version par défaut de Node.js qui sera utilisée pour les nouvelles sessions de terminal :

```bash
nvm alias default <version>
```

Par exemple :

```bash
nvm alias default 22.20.0
```

Tu peux aussi créer des alias personnalisés pour attribuer un nom plus spécifique à une version :

```bash
nvm alias <new_name> <version>
```

Par exemple :

```bash
nvm alias new-api 18.20.8
```

Après avoir configuré l'alias, tu peux utiliser ce nouveau nom pour basculer vers cette version :

```bash
nvm use <new_name>
```

Par exemple :

```bash
nvm use new-api
```

### Supprimer une version de Node.js

Pour supprimer une version de Node.js, exécute cette commande :

```bash
nvm uninstall <version>
```

Par exemple :

```bash
nvm uninstall 20.19.5
```

Avec NVM pour macOS/Linux, tu peux supprimer une version de Node.js en exécutant la commande `uninstall` avec une version majeure comme `22` ou `20`. Par exemple :

```bash
nvm uninstall 20
```

Si tu as plusieurs versions pour cette version majeure installées, comme `20.14.0` et `20.12.2`, la dernière version sera supprimée en premier. Dans ce cas, exécuter `nvm uninstall 20` supprimera d'abord `20.14.0`.

### Vérifier ta version de Node.js

Pour vérifier ta version actuelle de Node.js, tu peux utiliser ce qui suit :

```bash
node -v
```

### Vérifier ta version de npm

`npm` est un gestionnaire de paquets pour Node.js. Tu peux l'utiliser pour installer, publier et gérer des paquets logiciels. Il est automatiquement installé quand tu installes Node.js.

Pour vérifier ta version actuelle de `npm`, exécute cette commande :

```bash
npm -v
```

### Exécuter un fichier JavaScript

Cette commande exécute le fichier JavaScript que tu spécifies dans l'environnement d'exécution Node.js actuellement actif :

```bash
node <file.js>
```

Par exemple :

```bash
node app.js
```

### Créer un projet Node.js

Cette commande crée un nouveau projet Node.js en créant un fichier `package.json` qui suit ses détails et dépendances.

```bash
npm init
```

Quand tu exécutes la commande `npm init`, elle te guide à travers un guide CLI interactif pour configurer le fichier `package.json`. Elle te posera des questions sur le nom du projet, la description, la version, etc. Si tu veux démarrer avec un fichier `package.json` par défaut, tu peux utiliser la commande `npm init -y` ou `npm init --yes`.

### Installer un paquet

Pour installer un paquet spécifique, exécute :

```bash
npm install <package>
```

Par exemple :

```bash
npm install express
```

### Installer les dépendances

Pour installer toutes les dépendances listées dans le fichier `package.json` d'un projet, exécute :

```bash
npm install
```
