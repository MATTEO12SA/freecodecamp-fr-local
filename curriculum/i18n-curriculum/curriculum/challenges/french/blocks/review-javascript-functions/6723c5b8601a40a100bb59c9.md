# --interactive--

## Les fonctions JavaScript

- Les fonctions sont des blocs de code réutilisables qui effectuent une tâche précise.
- Les fonctions peuvent être définies à l'aide du mot-clé `function` suivi d'un nom, d'une liste de paramètres et d'un bloc de code qui effectue la tâche.

:::interactive_editor

```js
function addNumbers(x, y, z) {
  return x + y + z;
}

console.log(addNumbers(5, 3, 8)); // Output: 16
```

:::

- Les arguments sont les valeurs passées à une fonction lorsqu'elle est appelée.
- Un appel de fonction est le processus d'exécution d'une fonction dans un programme, qui consiste à indiquer le nom de la fonction suivi de parenthèses, en incluant éventuellement des arguments à l'intérieur des parenthèses.
- Lorsqu'une fonction termine son exécution, elle retourne toujours une valeur.
- Par défaut, la valeur retournée par une fonction est `undefined`.
- Le mot-clé `return` est utilisé pour spécifier la valeur à retourner depuis la fonction et met fin à l'exécution de la fonction.
- Les paramètres par défaut permettent aux fonctions d'avoir des valeurs prédéfinies qui seront utilisées si un argument n'est pas fourni lors de l'appel de la fonction. Cela rend les fonctions plus flexibles et évite les erreurs dans les cas où certains arguments pourraient être omis.

:::interactive_editor

```js
const calculateTotal = (amount, taxRate = 0.05) => {
  return amount + (amount * taxRate);
};

console.log(calculateTotal(100)); // Output: 105
```

:::

- Les fonctions anonymes sont des fonctions sans nom qui peuvent être affectées à des variables. En les affectant à des variables, tu peux les réutiliser partout où la variable est accessible.

:::interactive_editor

```js
const multiplyNumbers = function(firstNumber, secondNumber) {
  return firstNumber * secondNumber;
};

console.log(multiplyNumbers(4, 5)); // Output: 20
```

:::

## Les fonctions fléchées

- Les fonctions fléchées sont une façon plus concise d'écrire des fonctions en JavaScript.

:::interactive_editor

```js
const calculateArea = (length, width) => {
  const area = length * width;
  return `The area of the rectangle is ${area} square units.`;
};

console.log(calculateArea(5, 10)); // Output: "The area of the rectangle is 50 square units."
```

:::

- Lorsque tu définis une fonction fléchée, tu n'as pas besoin du mot-clé `function`.
- Si tu utilises un seul paramètre, tu peux omettre les parenthèses autour de la liste de paramètres.

:::interactive_editor

```js
const cube = x => {
  return x * x * x;
};

console.log(cube(3)); // Output: 27
```

:::

- Si le corps de la fonction se compose d'une seule expression, tu peux omettre les accolades et le mot-clé `return`.

:::interactive_editor

```js
const square = number => number * number;

console.log(square(5)); // Output: 25
```

:::

## La portée en programmation

- **Portée globale** : c'est la portée la plus externe en JavaScript. Les variables déclarées dans la portée globale sont accessibles depuis n'importe où dans le code et sont appelées variables globales.
- **Portée locale** : cela désigne les variables déclarées à l'intérieur d'une fonction. Ces variables ne sont accessibles qu'à l'intérieur de la fonction où elles sont déclarées et sont appelées variables locales.
- **Portée de bloc** : un bloc est un ensemble d'instructions entourées d'accolades `{}`, comme dans les instructions `if` ou les boucles.
- La portée de bloc avec `let` et `const` offre un contrôle encore plus fin sur l'accessibilité des variables, ce qui aide à prévenir les erreurs et à rendre ton code plus prévisible.
