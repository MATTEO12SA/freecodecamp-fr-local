## Les variables

- **Déclarer des variables** : Pour déclarer une variable, tu commences par le nom de la variable, suivi de l'opérateur d'affectation (`=`), puis de la valeur. Ce peut être un nombre, une chaîne, un booléen, etc. Voici quelques exemples :

```py
name = 'John Doe'
age = 25
```

- **Conventions de nommage des variables** : Voici les conventions de nommage que tu dois utiliser pour les variables :

  - Les noms de variables ne peuvent commencer que par une lettre ou un tiret bas (_), pas par un chiffre.
  - Les noms de variables ne peuvent contenir que des caractères alphanumériques (a-z, A-Z, 0-9) et des tirets bas (_).
  - Les noms de variables sont sensibles à la casse — `age`, `Age` et `AGE` sont tous considérés comme distincts.
  - Les noms de variables ne peuvent pas être l'un des mots-clés réservés de Python comme `if`, `class` ou `def`.
  - Les noms de variables de plusieurs mots sont séparés par des tirets bas. Ex. : `snake_case`.

## Types de données courants en Python

- **Introduction** : Python est un langage à typage dynamique comme JavaScript, ce qui signifie que tu n'as pas besoin de déclarer explicitement les types des variables. Le langage connaît le type d'une variable d'après ce que tu lui assignes.
- **Integer** : Un nombre entier sans décimales :

```py
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- **Float** : Un nombre avec des décimales :

```py
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- **String** : Une séquence de caractères entourée de guillemets :

```py
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- **Boolean** : Une valeur qui représente soit `True` soit `False` :

```py
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

- **Set** : Une collection non ordonnée d'éléments uniques :

```py
my_set_var = {7, 5, 8}
print('Set:', my_set_var) # Set: {7, 5, 8}
```

- **Dictionary** : Une collection de paires clé-valeur, entre accolades :

```py
my_dictionary_var = {"name": "Alice", "age": 25}
print('Dictionary:', my_dictionary_var) # Dictionary: {'name': 'Alice', 'age': 25}
```

- **Tuple** : Une collection ordonnée immuable, entre parenthèses :

```py
my_tuple_var = (7, 5, 8)
print('Tuple:', my_tuple_var) # Tuple: (7, 5, 8)
```

- **Range** : Une séquence de nombres, souvent utilisée dans les boucles :

```py
my_range_var = range(5)
print(my_range_var) # range(0, 5)
```

- **List** : Une collection ordonnée d'éléments qui accepte différents types de données :

```py
my_list = [22, 'Hello world', 3.14, True]
print(my_list) # [22, 'Hello world', 3.14, True]
```

- **None** : Une valeur spéciale qui représente l'absence de valeur :

```py
my_none_var = None
print('None:', my_none_var) # None: None
```

## Types immuables et mutables

- **Types immuables** : Ces types ne peuvent pas changer une fois déclarés, même si tu peux faire pointer leurs variables vers quelque chose de nouveau, ce qu'on appelle une réaffectation. Ils comprennent l'entier, le flottant, le complexe, le booléen, la chaîne, le tuple, le range et `None`.
- **Types mutables** : Ces types peuvent changer une fois déclarés. Tu peux ajouter, retirer ou mettre à jour leurs éléments. Ils comprennent les types de collection comme la liste, l'ensemble et le dictionnaire.
- **Fonction `type()`** : Pour voir le type d'une variable, tu peux utiliser la fonction `type()` comme ceci :

```py
greeting = 'Hello there!'
age = 21

print(type(greeting)) # <class 'str'>
print(type(age)) # <class 'int'>
```

- **Fonction `isinstance()`** : Sert à vérifier si une variable correspond à un type de données précis :

```py
greeting = 'Hello world'
name = 'John Doe'

print(isinstance(greeting, str)) # True
print(isinstance(name, int)) # False
```

## Travailler avec les chaînes

- **Définition** : Comme tu t'en souviens en JavaScript, les chaînes sont immuables, ce qui signifie que tu ne peux pas les modifier après leur création. En Python, tu peux utiliser des guillemets simples ou doubles. Il est recommandé de choisir une règle et de s'y tenir :

```py
developer = 'Jessica'
city = "Los Angeles"
```

- **Accéder aux caractères d'une chaîne** : Tu peux accéder aux caractères d'une chaîne avec la notation entre crochets, comme ceci :

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **Échapper les chaînes** : Tu peux utiliser une barre oblique inverse (`\`) si ta chaîne contient des guillemets, comme ceci :

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **Concaténation de chaînes** : Pour concaténer des chaînes, tu peux utiliser l'opérateur `+` comme ceci :

```py
developer = 'Jessica'
print('My name is ' + developer + '.') # My name is Jessica.
```

Une autre façon de concaténer des chaînes est d'utiliser l'opérateur `+=`. Il sert à faire la concaténation et l'affectation en une seule étape, comme ceci :

```py
greeting = 'My name is '
developer = 'Jessica.'

greeting += developer
print(greeting) # My name is Jessica.
```

- **`f-strings`** : Abréviation de formatted string literals (littéraux de chaînes formatées). Elles te permettent de gérer l'interpolation et aussi un peu de concaténation avec une syntaxe compacte et lisible :

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

- **Découpage de chaînes** : Cela te permet d'extraire des portions d'une chaîne. Voici la syntaxe de base :

```py
str[start:stop:step]
```

La position de début représente l'indice où l'extraction doit commencer. La position de fin est l'endroit où le découpage doit s'arrêter. Cette position n'est pas incluse. La position de pas représente l'intervalle d'incrémentation pour le découpage. Voici quelques exemples :

```py
message = 'Python is fun!'

print(message[0:6])  # Python
print(message[7:])  # is fun!
print(message[::2])  # Pto sfn
```

- **Obtenir la longueur d'une chaîne** : La fonction `len()` sert à renvoyer le nombre de caractères de la chaîne :

```py
developer = 'Jessica'

print(len(developer)) # 7
```

## Travailler avec l'opérateur `in`

- **Opérateur `in`** : Renvoie un booléen qui indique si le ou les caractères existent dans la chaîne ou non :

```py
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

## Méthodes de chaîne courantes

- **`str.upper()`** : Renvoie une nouvelle chaîne avec tous les caractères convertis en majuscules :

```py
developer = 'Jessica'

print(developer.upper()) # JESSICA
```

- **`str.lower()`** : Renvoie une nouvelle chaîne avec tous les caractères convertis en minuscules :

```py
developer = 'Jessica'

print(developer.lower()) # jessica
```

- **`str.strip()`** : Renvoie une copie de la chaîne sans les caractères spécifiés au début et à la fin (si aucun argument n'est passé à la méthode, elle retire les espaces au début et à la fin).

```py
greeting = '  hello world  '

trimmed_my_str = greeting.strip()
print(trimmed_my_str)  # 'hello world'
```

- **`replace()`** : Renvoie une nouvelle chaîne où toutes les occurrences de l'ancienne chaîne sont remplacées par une nouvelle.

```py
greeting = 'hello world'

replaced_my_str = greeting.replace('hello', 'hi')
print(replaced_my_str)  # 'hi world'
```

- **`split()`** : Sert à découper une chaîne en une liste selon un séparateur spécifié. Un séparateur est une chaîne qui indique où la division doit se produire.

```py
dashed_name = 'example-dashed-name'

split_words = dashed_name.split('-')
print(split_words)  # ['example', 'dashed', 'name']
```

- **`join()`** : Sert à joindre les éléments d'un itérable en une chaîne avec un séparateur. Un itérable est une collection d'éléments que tu peux parcourir en boucle, comme une liste, une chaîne ou un tuple.

```py
example_list = ['example', 'dashed', 'name']

joined_str = ' '.join(example_list)
print(joined_str)  # example dashed name
```

- **`str.startswith(prefix)`** : Renvoie un booléen indiquant si une chaîne commence par le préfixe spécifié :

```py
developer = 'Naomi'

result = developer.startswith('N')
print(result)  # True
```

- **`str.endswith(suffix)`** : Renvoie un booléen indiquant si une chaîne se termine par le suffixe spécifié :

```py
developer = 'Naomi'

result = developer.endswith('N')
print(result)  # False
```

- **`str.find()`** : Renvoie l'indice de la première occurrence d'une sous-chaîne. Si aucune n'est trouvée, `-1` est renvoyé :

```py
developer = 'Naomi'

result = developer.find('N')
print(result)  # 0

city = 'Los Angeles'
print(city.find('New')) # -1
```

- **`str.count(substring)`** : Compte le nombre de fois qu'une sous-chaîne apparaît dans une chaîne :

```py
city = 'Los Angeles'
print(city.count('e')) # 2
```

- **`str.capitalize()`** : Renvoie une nouvelle chaîne avec le premier caractère en majuscule et les autres en minuscules :

```py
dessert = 'chocolate cake'
print(dessert.capitalize()) # Chocolate cake
```

- **`str.isupper()`** : Renvoie `True` si toutes les lettres de la chaîne sont en majuscules et `False` sinon :

```py
dessert = 'chocolate cake'
print(dessert.isupper()) # False
```

- **`str.islower()`** : Renvoie `True` si toutes les lettres de la chaîne sont en minuscules et `False` sinon :

```py
dessert = 'chocolate cake'
print(dessert.islower()) # True
```

- **`str.title()`** : Renvoie une nouvelle chaîne avec la première lettre de chaque mot en majuscule :

```py
city = 'los angeles'
print(city.title()) # Los Angeles
```

- **`str.maketrans()`** : Cette méthode sert à créer une table de correspondances un-à-un entre caractères pour la traduction. On l'utilise souvent avec la méthode `translate()`, qui applique cette table à une chaîne et renvoie le résultat traduit.

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc'.translate(trans_table)
print(result)  # 123123
```

## Opérations courantes avec les entiers et les flottants

- **Opérations mathématiques de base** : En Python, tu peux faire des opérations mathématiques de base avec les entiers et les flottants, comme l'addition, la soustraction, la multiplication et la division :

```py
int_1 = 56
int_2 = 12
float_1 = 5.4
float_2 = 12.0

# Addition

print('Integer Addition:', int_1 + int_2) # Integer Addition: 68
print('Float Addition:', float_1 + float_2) # Float Addition: 17.4

# Subtraction

print('Int Subtraction:', int_1 - int_2) # Int Subtraction: 44
print('Float Subtraction:',  float_2 - float_1) # Float Subtraction: 6.6

# Multiplication

print('Int Multiplication:', int_1 * int_2) # Int Multiplication: 672
print('Float Multiplication:', float_2 * float_1) # Float Multiplication: 64.80000000000001

# Division

print('Int Division:', int_1 / int_2) # Int Division: 4.666666666666667
print('Float Division:', float_2 / float_1) # Float Division: 2.222222222222222
```

Quand tu additionnes un flottant et un entier, le résultat est converti en flottant, comme ceci :

```py
int_1 = 56
float_1 = 5.4

print(int_1 + float_1) # 61.4
```

- **Opérateur modulo (`%`)** : Renvoie le reste de la division d'un nombre par un autre :

```py
int_1 = 56
int_2 = 12

print(int_1 % int_2) # 8
```

- **Division entière (`//`)** : Cet opérateur sert à diviser deux nombres et à arrondir le résultat à l'entier inférieur :

```py
int_1 = 56
int_2 = 12

print(int_1 // int_2) # 4
```

- **Opérateur d'exponentiation (`**`)** : Cet opérateur sert à élever un nombre à la puissance d'un autre :

```py
int_1 = 4
int_2 = 2

print(int_1 ** int_2) # 16
```

- **Fonction `float()`** : Tu peux utiliser cette fonction pour convertir un entier en flottant.

```py
num = 4

print(float(num)) # 4.0
```

- **Fonction `int()`** : Tu peux utiliser cette fonction pour convertir un flottant en entier.

```py
num = 4.0

print(int(num)) # 4
```

- **Fonction `round()`** : Sert à arrondir un nombre à l'entier le plus proche :

```py
num_1 = 3.4
num_2 = 7.7

print(round(num_1)) # 3
print(round(num_2)) # 8
```

- **Fonction `abs()`** : Sert à renvoyer la valeur absolue d'un nombre :

```py
num = -13

print(abs(num)) # 13
```

- **Fonction `pow()`** : Sert à élever un nombre à la puissance d'un autre :

```py
result = pow(2, 3)
print(result)  # 8
```

## Affectations augmentées

- **Définition** : L'affectation augmentée combine une opération binaire et une affectation en une seule étape. Elle prend une variable, lui applique une opération avec une autre valeur, et stocke le résultat dans la même variable.

```py
# Addition assignment
my_var = 10
my_var += 5

print(my_var) # 15

# Subtraction assignment
count = 14
count -= 3

print(count) # 11

# Multiplication assignment
product = 65
product *= 7

print(product) # 455

# Division assignment
price = 100
price /= 4

print(price) # 25.0

# Floor Division assignment
total_pages = 23
total_pages //= 5

print(total_pages) # 4

# Modulo assignment
bits = 35
bits %= 2

print(bits) # 1

# Exponentiation assignment
power = 2
power **= 3

print(power) # 8
```

Il existe aussi d'autres opérateurs d'affectation augmentée, comme ceux des opérateurs bit à bit. Ils incluent `&=`, `^=`, `>>=` et `<<=`.

## Travailler avec les fonctions

- **Définition** : Les fonctions sont des morceaux de code réutilisables qui prennent des entrées (arguments) et renvoient une sortie. Pour appeler une fonction, tu dois indiquer le nom de la fonction suivi d'une paire de parenthèses :

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

Si une fonction ne renvoie pas explicitement une valeur, la valeur renvoyée par défaut est `None` :

```py
def greet():
    print('hello')

result = greet() # hello
print(result) # None
```

Tu peux aussi fournir des valeurs par défaut aux paramètres, comme ceci :

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```

Si tu appelles la fonction sans le bon nombre d'arguments, tu obtiendras une `TypeError` :

```py
def calculate_sum(a, b):
    print(a + b)

calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

## La portée en Python

- **Portée locale** : C'est le cas d'une variable déclarée à l'intérieur d'une fonction ou d'une classe : elle n'est accessible que dans cette fonction ou cette classe.

```py
def my_func():
    num = 10
    print(num)
```

- **Portée englobante** : C'est le cas d'une fonction imbriquée dans une autre : elle peut accéder aux variables de la fonction qui l'englobe.

```py
def outer_func():
    msg = 'Hello there!'

    def inner_func():
        print(msg)
    inner_func()

print(outer_func()) # Hello there!
```

- **Portée globale** : Cela désigne les variables déclarées en dehors de toute fonction ou classe, accessibles depuis n'importe où dans le programme.

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + (subtotal * tax)
    return total

print(get_total(100))  # 170.0
```

- **Portée intégrée** : Noms réservés en Python pour les fonctions, modules, mots-clés et objets prédéfinis.

```py
print(str(45)) # '45'
print(type(3.14)) # <class 'float'>
print(isinstance(3, str)) # False
```

## Travailler avec les instructions `if`, `elif` et `else`

- **Instructions `if`** : Ce sont des conditions utilisées pour déterminer si quelque chose est vrai ou non. Si la condition s'évalue à `True`, ce bloc de code s'exécute.

```py
age = 18

if age >= 18:
    print('You are an adult') # You are an adult
```

- **Clause `elif`** : Ce sont des conditions qui viennent après une instruction `if`. Une clause `elif` ne s'exécute que si toutes les conditions précédentes s'évaluent à `False` et que sa propre condition s'évalue à `True`.

```py
age = 16

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')  # You are a teenager
```

- **Clause `else`** : Celle-ci s'exécute si aucune autre condition ne s'évalue à `True`.

```py
age = 12

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')
else:
    print('You are a child')  # You are a child
```

Tu peux aussi utiliser des instructions `if` imbriquées comme ceci :

```py
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

## Valeurs truthy et falsy

- **Définition** : En Python, chaque valeur a une valeur booléenne inhérente, c'est-à-dire un sens intégré qui indique si elle doit être traitée comme `True` ou `False` dans un contexte logique. Beaucoup de valeurs sont considérées comme truthy, c'est-à-dire qu'elles s'évaluent à `True` dans un contexte logique. D'autres sont falsy, ce qui signifie qu'elles s'évaluent à `False`. Voici quelques exemples de valeurs falsy :

```md
None
False
Integer 0
Float 0.0
Empty strings ''
```

D'autres valeurs comme les nombres non nuls et les chaînes non vides sont truthy.

## Travailler avec la fonction `bool()`

- **Définition** : Si tu veux vérifier si une valeur est truthy ou falsy, tu peux utiliser la fonction intégrée `bool()`. Elle convertit explicitement une valeur en son équivalent booléen et renvoie `True` pour les valeurs truthy et `False` pour les valeurs falsy. Voici quelques exemples :

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

## Opérateurs booléens et court-circuit

- **Définition** : Ce sont des opérateurs spéciaux qui te permettent de combiner plusieurs expressions pour créer une logique de décision plus complexe dans ton code. Il y a trois opérateurs booléens en Python : `and`, `or` et `not`.
- **Opérateur `and`** : Cet opérateur prend deux opérandes et renvoie le premier s'il est falsy, sinon il renvoie le second. Les deux opérandes doivent être truthy pour qu'une expression donne une valeur truthy.

```py
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

Tu peux aussi utiliser l'opérateur `and` dans des conditions comme ceci :

```py
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

- **Opérateur `or`** : Cet opérateur renvoie le premier opérande s'il est truthy, sinon il renvoie le second. Une expression `or` donne une valeur truthy si au moins un opérande est truthy. Voici un exemple :

```py
age = 19
is_employed = False

print(age or is_employed) # 19
```

Comme pour l'opérateur `and`, tu peux utiliser l'opérateur `or` dans des conditions comme ceci :

```py
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

- **Court-circuit** : Les opérateurs `and` et `or` sont des opérateurs en court-circuit. Le court-circuit signifie que Python vérifie les valeurs de gauche à droite et s'arrête dès qu'il détermine le résultat final.
- **Opérateur `not`** : Cet opérateur prend un seul opérande et inverse sa valeur booléenne. Il convertit les valeurs truthy en `False` et les valeurs falsy en `True`. Contrairement aux opérateurs précédents, `not` renvoie toujours `True` ou `False`. Voici quelques exemples :

```py
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

is_admin = False

    print('Access denied for non-administrators.') # Access denied for non-administrators.
