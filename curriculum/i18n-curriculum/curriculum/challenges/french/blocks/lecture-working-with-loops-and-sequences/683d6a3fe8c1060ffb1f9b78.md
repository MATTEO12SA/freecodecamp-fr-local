# --description--

Dans la leçon précédente, tu as appris à travailler avec le type de données tuple. Dans cette leçon, tu vas découvrir quelques méthodes courantes que tu utiliseras en travaillant avec les tuples.

La première méthode que nous allons couvrir est `count()`. Cette méthode sert à déterminer combien de fois un élément apparaît dans un tuple. Voici un exemple pour vérifier combien de fois la chaîne `Rust` apparaît dans un tuple nommé `programming_languages` :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.count('Rust') # 2
```

Comme `Rust` apparaît deux fois dans le tuple, la méthode `count()` renvoie le nombre `2`. Si l'élément spécifié dans la fonction `count()` n'est pas du tout présent dans le tuple, alors la valeur renvoyée est `0` :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.count('JavaScript') # 0
```

Si aucun argument n'est passé à la fonction `count()`, Python lève une `TypeError` :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.count()

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: tuple.count() takes exactly one argument (0 given)
"""
```

La méthode suivante que nous allons voir est la méthode `index()`. Cette méthode sert à trouver l'indice où un élément particulier est présent dans un tuple. Voici un exemple d'utilisation de la méthode `index()` pour trouver l'indice de la chaîne `Java` :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.index('Java') # 1
```

Si l'élément spécifié est introuvable, Python lève une `ValueError` :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.index('JavaScript')

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
ValueError: tuple.index(x): x not in tuple
"""
```

Une autre chose que tu peux faire avec la méthode `index()` est de passer des arguments optionnels d'indice de début et de fin. Voici un exemple de passage d'un indice de départ optionnel :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python')
programming_languages.index('Python', 3) # 5
```

Dans cet exemple, nous spécifions où commencer la recherche de la chaîne `Python`. En passant le nombre `3` comme second argument de la fonction `index()`, nous indiquons de commencer la recherche à l'indice `3`. Comme `Python` apparaît deux fois dans le tuple, la fonction `index()` renverra l'indice `5` au lieu de l'indice `2` à cause de l'utilisation de l'argument optionnel d'indice de départ.

Tu peux aussi passer un indice de fin optionnel. Voici un exemple modifié spécifiant un indice de départ et un indice de fin :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python', 'JavaScript', 'Python')
programming_languages.index('Python', 2, 5) # 2
```

Maintenant, le résultat est l'indice `2` parce que nous commençons la recherche à l'indice `2`, et que nous cherchons jusqu'à, mais sans inclure, l'indice `5`.

Une autre fonction couramment utilisée avec les tuples est la fonction `sorted()`. Dans une leçon précédente, tu as appris la méthode `sort()` pour les listes. Eh bien, la fonction `sorted()` peut s'utiliser sur n'importe quel itérable, y compris les tuples.

Voici un exemple de création d'une nouvelle liste de nombres avec la fonction `sorted()` :

```py
numbers = (13, 2, 78, 3, 45, 67, 18, 7)
sorted(numbers) # [2, 3, 7, 13, 18, 45, 67, 78]
```

La fonction `sorted()` créera toujours une nouvelle liste des valeurs triées. Cela diffère de la méthode `sort()` qui trie les éléments d'une liste sur place et ne renvoie pas de nouvelle liste.

Si tu as besoin de personnaliser le comportement du tri pour un itérable, tu peux utiliser les arguments optionnels `reverse` et `key`. Voici un exemple d'utilisation de l'argument `key` pour trier les éléments d'un tuple par longueur :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python')
sorted(programming_languages, key=len)

# Result
# ['C++', 'Rust', 'Java', 'Rust', 'Python', 'Python']
```

Si tu veux créer une nouvelle liste de valeurs en ordre inverse, tu peux utiliser l'argument `reverse` comme ceci :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python')

print(sorted(programming_languages, reverse=True))

# Result
# ['Rust', 'Rust', 'Python', 'Python', 'Java', 'C++']
```

Les tuples sont un type de données courant en Python. Comprendre comment travailler avec eux, ainsi qu'avec quelques méthodes et fonctions utiles, t'aidera à écrire un code plus efficace.
