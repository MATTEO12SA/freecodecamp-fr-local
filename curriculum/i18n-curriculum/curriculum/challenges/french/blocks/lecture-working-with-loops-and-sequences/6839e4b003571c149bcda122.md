# --description--

Dans les leçons précédentes, tu as appris à travailler avec la boucle `for`, qui sert à répéter un bloc de code un nombre défini de fois. Voici un exemple d'utilisation d'une boucle `for` pour afficher chaque langage de la liste `languages` dans la console :

```py
languages = ['Spanish', 'English', 'Russian', 'Chinese']

for language in languages:
    print(language)
```

Mais si tu voulais suivre l'indice de chaque élément ? Eh bien, une option est de créer une variable `index` et de l'incrémenter de `1` à chaque itération de la boucle, comme ceci :

```py
languages = ['Spanish', 'English', 'Russian', 'Chinese']

index = 0

for language in languages:
    print(f'Index {index} and language {language}')
    index += 1
```

Même si cela fonctionne, un moyen plus simple est d'utiliser la fonction `enumerate()`. La fonction `enumerate()` suit l'indice d'un itérable et renvoie un objet enumerate.

Si nous passons la liste `languages` à la fonction `enumerate()` et convertissons la valeur renvoyée en liste avec la fonction `list()`, voici à quoi ça ressemble :

```python
languages = ['Spanish', 'English', 'Russian', 'Chinese']

list(enumerate(languages))
# [(0, 'Spanish'), (1, 'English'), (2, 'Russian'), (3, 'Chinese')]
```

Chaque entrée de l'objet enumerate (devenu une liste) est un tuple contenant un compteur, suivi d'une valeur de l'itérable passé à la fonction `enumerate()`.

Maintenant, refactorisons l'exemple précédent pour utiliser la fonction `enumerate()` :

```python
languages = ['Spanish', 'English', 'Russian', 'Chinese']

for index, language in enumerate(languages):
    print(f'Index {index} and language {language}')
```

Nous déballons le compteur et la valeur de chaque tuple de l'objet enumerate dans des variables nommées `index` et `language`, respectivement. Enfin, ces deux variables sont utilisées dans une f-string affichée dans la console à chaque itération de la boucle.

```md
Index 0 and language Spanish
Index 1 and language English
Index 2 and language Russian
Index 3 and language Chinese
```

Cela évite d'avoir à créer et mettre à jour manuellement une variable `index`.

La fonction `enumerate()` accepte aussi un argument optionnel `start` qui spécifie la valeur de départ du compteur. Si cet argument est omis, le compteur commencera à `0`. Voici un exemple d'utilisation de l'argument optionnel `start` :

```python
languages = ['Spanish', 'English', 'Russian', 'Chinese']

for index, language in enumerate(languages, 1):
    print(f'Index {index} and language {language}')
```

Et voici à quoi ressemblera le résultat dans la console :

```md
Index 1 and language Spanish
Index 2 and language English
Index 3 and language Russian
Index 4 and language Chinese
```

Jusqu'ici, nous n'avons parcouru qu'une seule liste. Mais si tu as besoin de parcourir plusieurs itérables en parallèle ? Eh bien, tu peux utiliser la fonction `zip()` pour cela : elle combine des listes en paires d'éléments et renvoie un itérateur de tuples.

Si nous passons une liste `developers` et une liste `ids` à la fonction `zip()` et convertissons la valeur renvoyée en liste avec la fonction `list()`, voici à quoi ça ressemble :

```python
developers = ['Naomi', 'Dario', 'Jessica', 'Tom']
ids = [1, 2, 3, 4]

list(zip(developers, ids))
# [('Naomi', 1), ('Dario', 2), ('Jessica', 3), ('Tom', 4)]
```

Et voici un exemple d'utilisation de la fonction `zip()` avec une boucle `for` pour parcourir `developers` et `ids` :

```python
developers = ['Naomi', 'Dario', 'Jessica', 'Tom']
ids = [1, 2, 3, 4]

for name, id in zip(developers, ids):
    print(f'Name: {name}')
    print(f'ID: {id}')
```

Dans cet exemple, `zip()` combine les deux listes en paires d'éléments et renvoie un itérateur de tuples. La boucle `for` déballe ensuite chaque tuple dans `name` et `id`. Enfin, pour chaque instruction print, nous affichons chaque `name` et `id` provenant des listes `ids` et `developers` respectivement. Voici à quoi ressemble le résultat dans la console :

```md
Name: Naomi
ID: 1
Name: Dario
ID: 2
Name: Jessica
ID: 3
Name: Tom
ID: 4
```

Les fonctions `enumerate()` et `zip()` sont très puissantes, et combinées avec des boucles, elles peuvent rendre ton code beaucoup plus concis.
