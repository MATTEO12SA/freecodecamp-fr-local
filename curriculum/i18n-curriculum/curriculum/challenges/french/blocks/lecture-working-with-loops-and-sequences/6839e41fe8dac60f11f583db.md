# --description--

La fonction `range()` sert à générer une séquence d'entiers. Voici la syntaxe de base de la fonction `range()` :

```py
range(start, stop, step)
```

L'argument obligatoire `stop` est un entier qui représente le point d'arrivée de la séquence de nombres générée. Voici un exemple d'utilisation de la fonction `range()` :

```py
for num in range(3):
    print(num)
```

Le code suivant génère une séquence de nombres entre `0` et `2`. L'entier `3` n'est pas inclus parce que l'argument `stop` est non inclusif.

Si un argument `start` n'est pas spécifié, la valeur par défaut est `0`. Sinon, tu peux utiliser l'argument optionnel `start` pour commencer la séquence d'entiers à un entier autre que `0`. Voici un exemple de génération d'une séquence d'entiers entre `1` et `4` :

```py
for num in range(1, 5):
    print(num)
```

Par défaut, la séquence d'entiers s'incrémente de `1`. Mais si tu veux changer cette valeur par défaut, tu peux utiliser l'argument optionnel `step`. Voici un exemple de génération d'une séquence d'entiers pairs entre `2` et `10` :

```py
for num in range(2, 11, 2):
    print(num)
```

Comme mentionné plus tôt, il n'y a qu'un seul argument obligatoire pour la fonction `range()`. Si tu ne fournis aucun argument à `range()`, tu obtiendras une `TypeError` :

```md
ERROR!
Traceback (most recent call last):
  File "<main.py>", line 1, in <module>
TypeError: range expected at least 1 argument, got 0
```

Il est important de noter que la fonction `range()` n'accepte que des entiers comme arguments, pas des flottants. Souviens-toi que les flottants sont des nombres avec une partie décimale, comme `3.4`. Si tu essaies de passer des flottants comme arguments, tu obtiendras une `TypeError` :

```md
ERROR!
Traceback (most recent call last):
  File "<main.py>", line 1, in <module>
TypeError: 'float' object cannot be interpreted as an integer
```

Si tu veux générer une séquence d'entiers en ordre décroissant, tu peux utiliser un entier négatif pour l'argument `step`, comme ceci :

```py
for num in range(40, 0, -10):
    print(num)
```

Le code suivant affiche les nombres `40`, `30`, `20` et `10` dans cet ordre dans la console.

Une autre chose que tu peux faire avec la fonction `range()` est de créer une liste d'entiers en l'utilisant avec le constructeur `list`. Le constructeur `list` sert à convertir un itérable en liste. Voici un exemple de génération d'une liste d'entiers pairs entre `2` et `10` :

```py
numbers = list(range(2, 11, 2))
print(numbers) # [2, 4, 6, 8, 10]
```

La fonction `range()` est un moyen très pratique de générer une séquence d'entiers en Python. Une fois que tu l'auras bien en main, tu te retrouveras probablement à l'utiliser beaucoup dans tes programmes Python.
