# --description--

Depuis quelques leçons, tu t'habitues à travailler avec des boucles comme celle-ci :

```py
even_numbers = []

for num in range(21):
    if num % 2 == 0:
        even_numbers.append(num)

print(even_numbers)
```

Cet exemple crée une nouvelle liste vide appelée `even_numbers` et parcourt une séquence de nombres entre `0` et `20`. À l'intérieur de la boucle, une condition vérifie si le nombre actuel a un reste de `0` lorsqu'il est divisé par `2`. Cela sert à déterminer si le nombre est pair. Si la condition est `True`, alors le `num` actuel est ajouté à la fin de la liste `even_numbers`. Enfin, nous affichons la liste `even_numbers` dans la console.

Même si ce code fonctionne, il existe une façon plus concise de l'écrire, qui utilise une compréhension de liste à la place. La compréhension de liste te permet de créer une nouvelle liste en une seule ligne en combinant une boucle et une condition directement entre crochets. Cela rend le code plus court et souvent plus facile à lire.

Voici l'exemple précédent refactorisé en utilisant des crochets :

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

Dans cet exemple refactorisé, la liste `even_numbers` est créée en une seule ligne de code. La compréhension de liste parcourt les nombres de `0` à `20`, et n'inclut que ceux qui sont divisibles par `2`. Cette approche est plus compacte et élimine le besoin d'une boucle et d'un bloc conditionnel séparés.

Regardons un autre exemple pour mieux comprendre comment fonctionne la compréhension de liste :

```py
numbers = [1, 2, 3, 4, 5]
result = [(num, 'Even') if num % 2 == 0 else (num, 'Odd') for num in numbers]
print(result)
```

Dans cet exemple, nous avons une liste de nombres et voulons créer une nouvelle liste de tuples indiquant quels nombres sont pairs ou impairs. Dans la première partie de la compréhension de liste, nous utilisons une instruction `if` pour vérifier si le nombre est divisible par `2`. Si c'est le cas, le résultat est un tuple de ce nombre suivi du mot `Even`. Sinon, le résultat est un tuple avec le nombre suivi du mot `Odd`.

Voici à quoi ressemble le résultat affiché dans la console :

```py
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

Une autre façon de créer une liste à partir d'un itérable existant est la fonction `filter()`. Voici un exemple de création d'une nouvelle liste contenant seulement les mots de plus de quatre caractères :

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

La fonction `filter()` sert à sélectionner les éléments d'un itérable qui satisfont une condition précise. La fonction `filter()` accepte une fonction et un itérable comme arguments. Dans cet exemple, nous passons une fonction `is_long_word` à la fonction `filter()` pour vérifier si le nombre de caractères du mot actuel est supérieur à `4`. Tous les mots dont le nombre de caractères est supérieur à `4` sont ajoutés dans une nouvelle liste et affectés à la variable `long_words`.

Outre la fonction `filter()`, quelques autres fonctions sont utiles quand tu travailles avec des listes. Une autre fonction à connaître est la fonction `map()`, qui prend un itérable et applique une fonction à chacun de ses éléments. Voici un exemple d'utilisation de la fonction `map()` pour convertir une liste de températures de Celsius en Fahrenheit :

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

Comme la fonction `filter()`, `map()` accepte une fonction et un itérable comme arguments. La fonction `to_fahrenheit` prend une température et la convertit de Celsius en Fahrenheit.

La dernière fonction que nous allons voir est la fonction `sum()`. Cette fonction sert à obtenir la somme d'un itérable comme une liste ou un tuple. Voici un exemple d'utilisation de la fonction `sum()` :

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

Tu peux aussi passer un argument optionnel `start` qui définit la valeur initiale de la sommation. Voici un exemple mis à jour utilisant l'argument `start` comme argument positionnel :

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

Tu peux aussi choisir d'utiliser l'argument `start` comme argument nommé, comme ceci :

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

Les deux versions produiront le même résultat, mais l'argument nommé est un peu plus explicite.

La compréhension de liste ainsi que d'autres fonctions comme `map()`, `filter()` et `sum()` peuvent sembler un peu déroutantes au début. Mais avec assez de pratique et de temps, tu commenceras à te sentir plus à l'aise pour les utiliser dans tes programmes Python.
