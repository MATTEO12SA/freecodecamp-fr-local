# --description--

Dans les prochaines leçons, nous allons découvrir les listes, les tuples et les ranges, trois types de séquences de base utilisés en Python.

Le type de données liste est une séquence ordonnée d'éléments qui peut être composée de chaînes, de nombres, ou même d'autres listes. Les listes sont mutables et utilisent une indexation commençant à zéro, ce qui signifie que le premier élément de la liste se trouve à l'indice zéro.

Voici la syntaxe de base d'une liste :

```py
cities = ['Los Angeles', 'London', 'Tokyo']
```

Pour accéder à un élément de la liste `cities`, tu peux indiquer son numéro d'indice dans la séquence. Voici un exemple d'accès au premier élément de la liste `cities` :

```py
cities = ['Los Angeles', 'London', 'Tokyo']
cities[0] # 'Los Angeles'
```

L'indexation négative sert à accéder aux éléments en partant de la fin de la liste plutôt que du début à l'indice `0`. Pour accéder au dernier élément de n'importe quelle liste, tu peux utiliser `-1` comme ceci :

```py
cities = ['Los Angeles', 'London', 'Tokyo']
cities[-1] # 'Tokyo'
```

Une autre façon de créer une liste est d'utiliser le constructeur `list()`. Le constructeur `list()` sert à convertir un itérable en liste comme ceci :

```py
developer = 'Jessica'
list(developer) # ['J', 'e', 's', 's', 'i', 'c', 'a']
```

Un itérable est un type d'objet spécial que l'on peut parcourir élément par élément. Tu en apprendras plus sur les boucles en Python plus tard.

Pour obtenir le nombre total d'éléments d'une liste, tu peux utiliser la fonction `len()` comme ceci :

```py
numbers = [1, 2, 3, 4, 5]
len(numbers) # 5
```

Si tu veux mettre à jour une valeur à un indice particulier, tu peux faire quelque chose comme ceci :

```py
programming_languages = ['Python', 'Java', 'C++', 'Rust']
programming_languages[0] = 'JavaScript'
print(programming_languages) # ['JavaScript', 'Java', 'C++', 'Rust']
```

Comme les listes sont mutables, tu peux mettre à jour n'importe quel élément de la liste tant que tu passes un numéro d'indice valide. Si tu passes un indice (positif ou négatif) qui est hors des limites de la liste, tu recevras une `IndexError` :

```py
programming_languages = ['Python', 'Java', 'C++', 'Rust']
programming_languages[10] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: list assignment index out of range
"""
```

Si tu veux supprimer un élément d'une liste, tu peux utiliser le mot-clé `del` comme ceci :

```py
developer = ['Jane Doe', 23, 'Python Developer']
del developer[1]
print(developer) # ['Jane Doe', 'Python Developer']
```

Parfois, il est utile de vérifier si un élément se trouve dans la liste. Pour cela, tu peux utiliser le mot-clé `in` comme ceci :

```py
programming_languages = ['Python', 'Java', 'C++', 'Rust']

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

Il est parfois courant d'avoir des listes imbriquées dans d'autres listes comme ceci :

```py
developer = ['Alice', 25, ['Python', 'Rust', 'C++']]
```

Dans cet exemple, nous avons une liste imbriquée contenant trois langages de programmation populaires. Pour accéder à la liste imbriquée, tu devras l'atteindre avec l'indice `2`, car les listes sont indexées à partir de zéro :

```py
developer = ['Alice', 25, ['Python', 'Rust', 'C++']]
developer[2] # ['Python', 'Rust', 'C++']
```

Ensuite, pour accéder au deuxième langage de cette liste imbriquée, tu devras l'atteindre avec l'indice `1` comme ceci :

```py
developer = ['Alice', 25, ['Python', 'Rust', 'C++']]
developer[2][1] # 'Rust'
```

Une autre technique courante avec les listes est le déballage de valeurs.

Déballer les valeurs d'une liste est une technique qui consiste à affecter les valeurs d'une liste à de nouvelles variables. Voici un exemple de déballage d'une liste `developer` dans de nouvelles variables appelées `name`, `age` et `job`.

```py
developer = ['Alice', 34, 'Rust Developer']
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

Ici, `name` a la valeur `'Alice'`, `age` a la valeur `34`, et `job` a la valeur `'Rust Developer'`.

Si tu as besoin de collecter les éléments restants d'une liste, tu peux utiliser l'opérateur astérisque (`*`) comme ceci :

```py
developer = ['Alice', 34, 'Rust Developer']
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

Dans cet exemple, `name` aura toujours la valeur `'Alice'`, et `rest` est une liste de deux éléments : le nombre `34` et la chaîne `'Rust Developer'`.

Si le nombre de variables à gauche de l'opérateur d'affectation ne correspond pas au nombre total d'éléments de la liste, tu recevras une `ValueError` :

```py
developer = ['Alice', 34, 'Rust Developer']
name, age, job, city = developer

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
ValueError: not enough values to unpack (expected 4, got 3)
"""
```

Le dernier concept que nous allons voir est l'opérateur de tranche (`:`). Comme pour les chaînes, tu peux accéder à des portions d'une liste avec l'opérateur de tranche comme ceci :

```py
desserts = ['Cake', 'Cookies', 'Ice Cream', 'Pie', 'Brownies']
desserts[1:4] # ['Cookies', 'Ice Cream', 'Pie']
```

Dans cet exemple, l'indice de départ est `1` puisqu'il pointe vers le deuxième élément de la liste. Ensuite, nous utilisons l'opérateur de tranche suivi d'un indice de fin de `4`, qui inclut tout jusqu'à (mais sans inclure) l'élément à cet indice.

Une autre chose que tu peux faire avec l'opérateur de tranche `:` est de spécifier un intervalle de pas, qui détermine de combien incrémenter entre les indices. Disons que tu as une liste de nombres comme ceci :

```py
numbers = [1, 2, 3, 4, 5, 6]
```

Si tu veux extraire une liste contenant seulement les nombres pairs, tu peux utiliser l'opérateur de tranche comme ceci :

```py
numbers = [1, 2, 3, 4, 5, 6]
numbers[1::2] # [2, 4, 6]
```

Le premier nombre pair se trouve à l'indice `1`, ce sera donc l'indice de départ. Comme nous voulons aller jusqu'à la fin de la liste, nous omettons l'indice de fin. Enfin, nous spécifions `2` pour l'intervalle de pas optionnel, afin d'incrémenter seulement de `2` au lieu de la valeur par défaut `1`.

Les listes sont une structure de données utile et flexible que tu utiliseras beaucoup dans tes programmes Python. Dans la prochaine leçon, tu apprendras les méthodes courantes que tu peux utiliser avec les listes.
