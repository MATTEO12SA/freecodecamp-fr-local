# --description--

Tout au long des leçons précédentes, tu as pris l'habitude de définir des fonctions avec le mot-clé `def` comme ceci :

```py
def square(num):
    return num ** 2

print(square(4)) # 16
```

Mais quand il s'agit de travailler avec des fonctions d'ordre supérieur comme `map()` et `filter()`, tu peux utiliser une fonction anonyme en ligne. C'est là qu'interviennent les fonctions lambda.

Voici à quoi ressemble la fonction `square()` une fois refactorisée en fonction lambda :

```py
lambda num: num ** 2
```

Comme mentionné plus tôt, les fonctions lambda sont anonymes, donc cette fonction n'a plus le nom `square` associé. Les fonctions lambda sont très utiles quand tu as besoin de les utiliser dans des fonctions d'ordre supérieur comme ceci :

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

Dans cet exemple, nous avons une liste de nombres et voulons créer une nouvelle liste de nombres pairs. Nous passons donc une fonction lambda comme l'un des arguments de la fonction `filter()` pour obtenir une nouvelle liste contenant les nombres `2` et `4`.

Quand tu travailles avec des fonctions lambda, il est important de connaître les bonnes pratiques. Par exemple, ce n'est pas une bonne pratique d'affecter une fonction lambda à une variable comme ceci :

```py
numbers = [1, 2, 3, 4, 5]

square = lambda x: x ** 2
squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Cela va à l'encontre de l'intérêt des fonctions anonymes. Dans ce cas, tu devrais utiliser une fonction ordinaire, comme ceci :

```py
numbers = [1, 2, 3, 4, 5]

def square(num):
    return num ** 2

squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Tu devrais aussi éviter de créer des fonctions lambda difficiles à lire ou inutilement compliquées, comme ceci :

```py
result = (lambda x: (x**2 + 2*x - 1) if x > 0 else (x**3 - x + 4))(3)
print(result)  # 14
```

Même si cette fonction s'exécute correctement et produit le bon résultat de `14`, elle n'est pas facile à lire ni à regarder. Dans ce cas, il vaudrait mieux créer une fonction séparée avec une instruction `if/else`, puis appeler cette fonction :

```py
def calculate_expression(x):
    if x > 0:
        return x**2 + 2*x - 1
    else:
        return x**3 - x + 4

print(calculate_expression(3))  # 14
```

Les fonctions ordinaires et les fonctions lambda ont chacune leurs cas d'usage dans les programmes Python. Si tu as affaire à une seule expression en ligne, tu pourrais envisager d'utiliser une fonction lambda. Sinon, utiliser une fonction ordinaire serait le bon choix.
