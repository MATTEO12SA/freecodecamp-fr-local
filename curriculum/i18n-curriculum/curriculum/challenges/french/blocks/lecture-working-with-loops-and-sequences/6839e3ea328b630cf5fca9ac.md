# --description--

Comme tu l'as appris dans les modules précédents, les boucles servent à répéter un bloc de code un nombre défini de fois. Dans cette leçon, tu apprendras à travailler avec différents types de boucles en Python.

La première boucle que nous allons voir est la boucle `for`. Voici un exemple d'utilisation d'une boucle `for` pour parcourir une liste et afficher chaque élément dans la console :

```py
programming_languages = ['Rust', 'Java', 'Python', 'C++']

for language in programming_languages:
    print(language)
```

Le résultat serait :

```md
Rust
Java
Python
C++
```

Remarque que `print(language)` est indenté à l'intérieur de la boucle. Sans cette indentation, tu obtiendrais une `IndentationError` :

```python
"""
Traceback (most recent call last):
  File "<stdin>", line 4, in <module>
IndentationError: expected an indented block after 'for' statement on line 3
"""
```

Tu peux aussi utiliser une boucle `for` pour parcourir d'autres itérables comme une chaîne. Voici un exemple d'utilisation d'une boucle `for` pour parcourir la chaîne `code` et afficher chaque caractère :

```py
for char in 'code':
    print(char)
```

Le résultat serait :

```md
c
o
d
e
```

Comme en JavaScript, tu peux aussi imbriquer des boucles `for` en Python. Voici un exemple d'utilisation d'une boucle `for` imbriquée :

```py
categories = ['Fruit', 'Vegetable']
foods = ['Apple', 'Carrot', 'Banana']

for category in categories:
    for food in foods:
        print(category, food)
```

La boucle externe parcourra chaque `category` de la liste `categories`. Pour chaque `category`, la boucle interne parcourra chaque `food` de la liste `foods`. Voici le résultat qui s'affichera dans la console :

```md
Fruit Apple
Fruit Carrot
Fruit Banana
Vegetable Apple
Vegetable Carrot
Vegetable Banana
```

Un autre type de boucle que tu peux utiliser en Python est la boucle `while`. Ce type de boucle répète un bloc de code jusqu'à ce que la condition soit `False`. Voici un exemple d'utilisation d'une boucle `while` pour un jeu de devinettes :

```py
secret_number = 3
guess = 0

while guess != secret_number:
    guess = int(input('Guess the number (1-5): '))
    if guess != secret_number:
        print('Wrong! Try again.')

print('You got it!')
```

Dans cet exemple, nous avons une variable `secret_number` de valeur `3` et une tentative initiale de `0`. Ensuite, nous utilisons la fonction `input` pour obtenir une saisie de l'utilisateur, puis nous convertissons la chaîne saisie en entier avec la fonction `int()`, et nous l'affectons à la variable `guess`. Si l'utilisateur trouve la bonne réponse en saisissant `3`, on sort de la boucle `while` et le message `You got it!` s'affiche dans la console. Sinon, le message `Wrong! Try again.` s'affiche dans la console, et la boucle se répète, invitant l'utilisateur à essayer à nouveau.

Voici un exemple de résultat :

```md
Guess the number (1-5): 2
Wrong! Try again.
Guess the number (1-5): 1
Wrong! Try again.
Guess the number (1-5): 3
You got it!
```

Comme en JavaScript, Python prend en charge les instructions `break` et `continue`.

L'instruction `break` sert à arrêter l'exécution d'une boucle. Voici un exemple d'utilisation de l'instruction `break` avec une liste `developer_names` :

```py
developer_names = ['Jess', 'Naomi', 'Tom']

for developer in developer_names:
    if developer == 'Naomi':
        break
    print(developer)
```

Dans cet exemple, nous parcourons une liste `developer_names` et affichons chaque nom dans la console. Si le nom est égal à `Naomi`, alors nous sortons de la boucle. Il en résulte que seul le nom `Jess` s'affiche dans la console.

L'instruction `continue` sert à sauter l'itération actuelle d'une boucle et à passer à l'itération suivante. Modifions l'exemple précédent pour utiliser l'instruction `continue` au lieu de `break` :

```py
developer_names = ['Jess', 'Naomi', 'Tom']

for developer in developer_names:
    if developer == 'Naomi':
        continue
    print(developer)
```

Maintenant, le résultat dans la console sera différent. Les noms `Jess` et `Tom` s'affichent parce que l'instruction `continue` saute la deuxième itération de la boucle lorsque `developer` est égal à `Naomi`, et n'affiche pas ce nom dans la console.

Les boucles `for` et `while` peuvent toutes les deux être combinées avec une clause `else`, qui ne s'exécute que lorsque la boucle n'est pas interrompue par une instruction `break`. Voici un exemple d'utilisation de plusieurs boucles `for` :

```python
words = ['sky', 'apple', 'rhythm', 'fly', 'orange']

for word in words:
    for letter in word:
        if letter.lower() in 'aeiou':
            print(f"'{word}' contains the vowel '{letter}'")
            break
    else:
        print(f"'{word}' has no vowels")
```

Dans cet exemple, nous avons une liste de mots aléatoires, et une boucle `for` parcourt chaque mot. À l'intérieur de la boucle `for` externe, nous avons une autre boucle `for` pour parcourir chaque lettre de chaque mot. Si la version en minuscules de la lettre est une voyelle, nous affichons le mot suivi des voyelles qu'il contient, puis nous sortons de la boucle interne. Si le mot ne contient aucune voyelle, nous affichons un message l'indiquant.

Voici à quoi ressemble le résultat dans la console :

```md
'sky' has no vowels
'apple' contains the vowel 'a'
'rhythm' has no vowels
'fly' has no vowels
'orange' contains the vowel 'o'
```

Les boucles sont très courantes en Python, il est donc important de te sentir à l'aise avec elles. Dans les prochaines leçons, tu apprendras à utiliser les fonctions `enumerate()` et `range()` dans les boucles.
