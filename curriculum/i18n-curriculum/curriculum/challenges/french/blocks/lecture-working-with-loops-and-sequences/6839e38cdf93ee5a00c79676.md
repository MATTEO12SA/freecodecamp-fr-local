# --description--

Dans la leçon précédente, tu as découvert le type de données liste et appris à accéder aux éléments d'une liste ainsi qu'aux tranches de liste. Dans cette leçon, tu vas continuer à apprendre les listes et quelques méthodes courantes associées, comme `append()`, `pop()` et `sort()`.

La première méthode que nous allons voir est la méthode `append()`. Elle sert à ajouter un élément à la fin de la liste. Voici un exemple d'utilisation de la méthode `append()` pour ajouter le nombre `6` à une liste de nombres :

```py
numbers = [1, 2, 3, 4, 5]
numbers.append(6)
print(numbers) # [1, 2, 3, 4, 5, 6]
```

Si tu veux ajouter une liste à la fin d'une autre, tu peux aussi utiliser la méthode `append()` comme ceci :

```py
numbers = [1, 2, 3, 4, 5]
even_numbers = [6, 8, 10]

numbers.append(even_numbers)
print(numbers) # [1, 2, 3, 4, 5, [6, 8, 10]]
```

Remarque que la liste `even_numbers` entière est imbriquée dans la liste `numbers`.

Mais si tu veux ajouter tous les nombres individuels de la liste `even_numbers` à la fin de la liste `numbers`, tu peux utiliser la méthode `extend()`.

La méthode `extend()` ressemble à la méthode `append()`, mais avec `extend()` tu peux ajouter plusieurs éléments d'une liste à une autre. Voici un exemple d'ajout des nombres `6`, `8` et `10` d'une liste à la fin de la liste `numbers` :

```py
numbers = [1, 2, 3, 4, 5]
even_numbers = [6, 8, 10]

numbers.extend(even_numbers)
print(numbers) # [1, 2, 3, 4, 5, 6, 8, 10]
```

Comme tu peux le voir, la liste imbriquée a disparu et ce n'est plus qu'une liste de nombres.

Pour insérer un élément à un indice précis dans une liste, tu peux utiliser la méthode `insert()`. Cette méthode accepte deux arguments : l'indice où tu souhaites insérer le nouvel élément, et l'élément que tu veux insérer.

Voici un exemple d'utilisation de la méthode `insert()` :

```py
numbers = [1, 2, 3, 4, 5]
numbers.insert(2, 2.5)

print(numbers) # [1, 2, 2.5, 3, 4, 5]
```

Le code suivant insérera le nombre `2.5` à l'indice `2` dans la liste `numbers`.

Si tu veux supprimer un élément d'une liste, tu peux utiliser la méthode `remove()`. La méthode `remove()` prend comme argument la valeur de l'élément à supprimer :

```py
numbers = [10, 20, 30, 40, 50, 50]
numbers.remove(50)

print(numbers) # [10, 20, 30, 40, 50]
```

Il est important de noter que cette méthode ne supprime que la première occurrence d'un élément. Pas toutes :

```py
numbers = [10, 20, 30, 40, 50, 50, 50]
numbers.remove(50)

print(numbers) # [10, 20, 30, 40, 50, 50]
```

Pour supprimer un élément à un indice précis dans la liste, tu peux utiliser la méthode `pop()` comme ceci :

```py
numbers = [1, 2, 3, 4, 5]
numbers.pop(1) # The number 2 is returned
```

Si tu ne spécifies pas d'élément pour la méthode `pop`, alors le dernier élément est supprimé.

```py
numbers = [1, 2, 3, 4, 5]
numbers.pop() # The number 5 is returned
```

Si tu as besoin de vider la liste, tu peux utiliser la méthode `clear()` comme ceci :

```py
numbers = [1, 2, 3, 4, 5]
numbers.clear()

print(numbers) # []
```

La méthode suivante que nous allons voir est la méthode `sort()`. Cette méthode sert à trier les éléments sur place. Voici un exemple de tri d'une liste aléatoire de nombres sur place :

```py
numbers = [19, 2, 35, 1, 67, 41]
numbers.sort()

print(numbers) # [1, 2, 19, 35, 41, 67]
```

Contrairement à la méthode `sort()`, il existe la fonction `sorted()` qui fonctionne pour n'importe quel itérable et renvoie une nouvelle liste triée au lieu de modifier la liste d'origine. Par exemple :

```py
numbers = [19, 2, 35, 1, 67, 41]
sorted_numbers = sorted(numbers)

print(numbers) # [19, 2, 35, 1, 67, 41]
print(sorted_numbers) # [1, 2, 19, 35, 41, 67]
```

Pour rappel, un itérable est un type d'objet spécial que tu peux parcourir en boucle, ce qui te permet d'accéder à chaque élément un par un. Tu en apprendras plus sur le fonctionnement des boucles en Python dans une leçon à venir.

La méthode `sort()` et la fonction `sorted()` acceptent toutes les deux des paramètres optionnels `key` et `reverse`. Tu en apprendras plus sur ces paramètres optionnels dans une leçon à venir, quand tu découvriras les tuples. Tu en apprendras aussi plus sur d'autres fonctions intégrées comme `sorted()` dans les leçons à venir.

La méthode suivante que nous allons voir est la méthode `reverse()`. Cette méthode inverse une liste d'éléments sur place comme ceci :

```py
numbers = [6, 5, 4, 3, 2, 1]
numbers.reverse()

print(numbers) # [1, 2, 3, 4, 5, 6]
```

La dernière méthode que nous allons voir est la méthode `index`. Elle sert à trouver le premier indice où un élément se trouve dans une liste. Voici un exemple d'utilisation de la méthode `index` pour trouver le langage `'Java'` dans une liste `programming_languages` :

```py
programming_languages = ['Rust', 'Java', 'Python', 'C++']
programming_languages.index('Java') # 1
```

Si l'élément est introuvable, Python lève une `ValueError` :

```py
programming_languages = ['Rust', 'Java', 'Python', 'C++']
programming_languages.index('JavaScript')

"""
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: 'JavaScript' is not in list
"""
```

Il existe quelques autres méthodes pour les listes Python, mais cette première liste de méthodes est un bon point de départ.
