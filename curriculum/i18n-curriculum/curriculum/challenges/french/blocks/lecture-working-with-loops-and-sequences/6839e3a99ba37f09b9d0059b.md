# --description--

Un tuple est un type de données Python utilisé pour créer une séquence ordonnée de valeurs. Les tuples peuvent contenir un ensemble mixte de types de données comme ceci :

```py
developer = ('Alice', 34, 'Rust Developer')
```

Les tuples ressemblent aux listes, mais alors que les listes sont un type de données mutable, les tuples sont immuables. Cela signifie que les éléments d'un tuple ne peuvent pas être modifiés une fois qu'il est créé.

Si tu essaies de mettre à jour l'un des éléments du tuple, tu obtiendras une `TypeError` :

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

Pour accéder à un élément d'un tuple, tu peux utiliser la notation entre crochets et le numéro d'indice :

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

Si tu as besoin d'accéder aux éléments en partant de la fin d'un tuple, tu peux utiliser l'indexation négative. Voici un exemple d'utilisation d'un indice négatif pour accéder à l'avant-dernier élément d'un tuple :

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

Si tu essaies de passer un numéro d'indice qui dépasse ou égale la longueur du tuple, tu recevras une `IndexError` comme ceci :

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: list index out of range
"""
```

Une autre façon de créer un tuple est d'utiliser le constructeur `tuple()` comme ceci :

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

Pour le constructeur `tuple()`, tu peux passer différents itérables comme des chaînes, des listes et même d'autres tuples.

Pour vérifier si un élément se trouve dans un tuple, tu peux utiliser le mot-clé `in` comme ceci :

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

Tu peux aussi déballer les éléments d'un tuple, comme tu l'as fait avec les listes :

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

Dans cet exemple, `name` a la valeur `'Alice'`, `age` a la valeur `34`, et `job` a la valeur `'Rust Developer'`.

Si tu as besoin de collecter les éléments restants d'un tuple, tu peux utiliser l'opérateur astérisque (`*`) comme ceci :

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

Ici, `name` a la valeur `'Alice'`, et `rest` est une liste composée du nombre `34` et de la chaîne `'Rust Developer'`.

Comme avec une liste, tu peux utiliser l'opérateur de tranche sur un tuple pour en extraire une portion. Voici un exemple d'extraction des éléments `'pie'` et `'cookies'` dans un tuple séparé :

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

Souviens-toi que le premier nombre représente l'indice de départ de l'extraction, tandis que le second représente l'indice de fin. Mais note que l'élément à l'indice de fin n'est pas inclus dans le tuple extrait.

Si tu as besoin de supprimer un élément d'un tuple, ce n'est pas possible car les tuples sont immuables. Donc cet exemple produira une erreur :

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

Alors, quand pourrais-tu utiliser un tuple plutôt qu'une liste ?

Si tu as besoin d'une collection dynamique d'éléments où tu peux ajouter, supprimer et mettre à jour des éléments, tu devrais utiliser une liste. Si tu sais que tu travailles avec une collection de données fixe et immuable, tu devrais utiliser un tuple.

Dans la prochaine leçon, nous allons voir quelques méthodes courantes que tu utiliseras en travaillant avec les tuples.
