# --interactive--

## Les bases des chaînes

- **Définition** : une chaîne est une séquence de caractères entourée de guillemets simples, de guillemets doubles ou d'accents graves. Les chaînes sont des types de données primitifs et elles sont immuables. L'immuabilité signifie qu'une fois qu'une chaîne est créée, elle ne peut pas être modifiée.
- **Accéder aux caractères d'une chaîne** : pour accéder à un caractère d'une chaîne, tu peux utiliser la notation entre crochets et passer le numéro d'index. Un index est la position d'un caractère au sein d'une chaîne, et il commence à zéro.

:::interactive_editor

```js
const developer = "Jessica";
console.log(developer[0]); // J
```

:::

- **`\n` (caractère de nouvelle ligne)** : tu peux créer un saut de ligne dans une chaîne en utilisant le caractère de nouvelle ligne `\n`.

:::interactive_editor

```js
const poem = "Roses are red,\nViolets are blue,\nJavaScript is fun,\nAnd so are you.";
console.log(poem);
```

:::

- **Échapper des caractères dans une chaîne** : tu peux échapper des caractères dans une chaîne en plaçant des barres obliques inverses (`\`) devant les guillemets.

:::interactive_editor

```js
const statement = "She said, \"Hello!\"";
console.log(statement); // She said, "Hello!"
```

:::

## Les littéraux de modèle (template strings) et l'interpolation de chaînes

- **Définition** : les littéraux de modèle sont définis avec des accents graves (`). Ils facilitent la manipulation des chaînes, notamment en intégrant des variables directement à l'intérieur d'une chaîne, une fonctionnalité connue sous le nom d'interpolation de chaînes.

:::interactive_editor

```js
const name = "Jessica";
const greeting = `Hello, ${name}!`;
console.log(greeting); // "Hello, Jessica!"
```

:::

## ASCII, la méthode `charCodeAt()` et la méthode `fromCharCode()`

- **ASCII** : ASCII (American Standard Code for Information Interchange) est une norme d'encodage de caractères utilisée pour représenter les caractères anglais de base à l'aide de valeurs numériques. Les leçons précédentes présentent `charCodeAt()` et `fromCharCode()` à l'aide d'exemples ASCII.
- **Unicode** : les chaînes JavaScript utilisent Unicode en interne, plus précisément l'encodage UTF-16. Pour les 128 premiers caractères (les lettres latines de base, les chiffres et les symboles courants), les valeurs Unicode correspondent aux codes ASCII. C'est pourquoi les exemples basés sur ASCII continuent de fonctionner en JavaScript.
- **La méthode `charCodeAt()`** : cette méthode renvoie l'unité de code UTF-16 du caractère situé à un index spécifié. Pour les caractères latins de base, cette valeur correspond au code ASCII.

:::interactive_editor

```js
const letter = "A";
console.log(letter.charCodeAt(0));  // 65
```

:::

- **La méthode `fromCharCode()`** : cette méthode convertit un code ASCII en son caractère correspondant.

:::interactive_editor

```js
const char = String.fromCharCode(65);
console.log(char);  // A
```

:::

## D'autres méthodes de chaîne courantes

- **La méthode `indexOf`** : cette méthode est utilisée pour rechercher une sous-chaîne au sein d'une chaîne. Si la sous-chaîne est trouvée, `indexOf` renvoie l'index (ou la position) de la première occurrence de cette sous-chaîne. Si la sous-chaîne n'est pas trouvée, `indexOf` renvoie -1, ce qui indique que la recherche a échoué.

:::interactive_editor

```js
const text = "The quick brown fox jumps over the lazy dog.";
console.log(text.indexOf("fox")); // 16
console.log(text.indexOf("cat")); // -1
```

:::

- **La méthode `includes()`** : cette méthode est utilisée pour vérifier si une chaîne contient une sous-chaîne spécifique. Si la sous-chaîne est trouvée dans la chaîne, la méthode renvoie true. Sinon, elle renvoie false.

:::interactive_editor

```js
const text = "The quick brown fox jumps over the lazy dog.";
console.log(text.includes("fox")); // true
console.log(text.includes("cat")); // false
```

:::

- **La méthode `slice()`** : cette méthode extrait une portion d'une chaîne et renvoie une nouvelle chaîne, sans modifier la chaîne d'origine. Elle prend deux paramètres : l'index de début et l'index de fin facultatif.

:::interactive_editor

```js
const text = "freeCodeCamp";
console.log(text.slice(0, 4));  // "free"
console.log(text.slice(4, 8));  // "Code"
console.log(text.slice(8, 12)); // "Camp"
```

:::

- **La méthode `toUpperCase()`** : cette méthode convertit tous les caractères en lettres majuscules et renvoie une nouvelle chaîne entièrement en majuscules.

:::interactive_editor

```js
const text = "Hello, world!";
console.log(text.toUpperCase()); // "HELLO, WORLD!"
```

:::

- **La méthode `toLowerCase()`** : cette méthode convertit tous les caractères d'une chaîne en minuscules.

:::interactive_editor

```js
const text = "HELLO, WORLD!"
console.log(text.toLowerCase()); // "hello, world!"
```

:::

- **La méthode `replace()`** : cette méthode te permet de trouver une valeur spécifiée (comme un mot ou un caractère) dans une chaîne et de la remplacer par une autre valeur. La méthode renvoie une nouvelle chaîne avec le remplacement et laisse l'originale inchangée, car les chaînes JavaScript sont immuables.

:::interactive_editor

```js
const text = "I like cats";
console.log(text.replace("cats", "dogs")); // "I like dogs"
```

:::

- **La méthode `replaceAll()`** : cette méthode te permet de trouver toutes les occurrences d'une valeur spécifiée (un mot, un caractère ou un motif) dans une chaîne et de les remplacer par une autre valeur. Elle fonctionne comme `replace()`, mais au lieu de s'arrêter après la première correspondance, elle met à jour chaque correspondance trouvée dans la chaîne.

:::interactive_editor

```js
const text = "I love cats and cats are so much fun!";
console.log(text.replaceAll("cats", "dogs")); // "I love dogs and dogs are so much fun!"
```

:::

- **La méthode `repeat()`** : cette méthode est utilisée pour répéter une chaîne un nombre de fois spécifié.

:::interactive_editor

```js
const text = "Hello";
console.log(text.repeat(3)); // "HelloHelloHello"
```

:::

- **La méthode `trim()`** : cette méthode est utilisée pour supprimer les espaces au début et à la fin d'une chaîne.

:::interactive_editor

```js
const text = "  Hello, world!  ";
console.log(text.trim()); // "Hello, world!"
```

:::

- **La méthode `trimStart()`** : cette méthode supprime les espaces au début (ou « start ») de la chaîne.

:::interactive_editor

```js
const text = "  Hello, world!  ";
console.log(text.trimStart()); // "Hello, world!  "
```

:::

- **La méthode `trimEnd()`** : cette méthode supprime les espaces à la fin de la chaîne.

:::interactive_editor

```js
const text = " Hello, world! ";
console.log(text.trimEnd()); // "  Hello, world!"
```

:::

- **La méthode `prompt()`** : cette méthode de l'objet `window` est utilisée pour obtenir des informations de la part d'un utilisateur sous la forme d'une boîte de dialogue. Cette méthode prend deux arguments. Le premier argument est le message qui apparaîtra à l'intérieur de la boîte de dialogue, invitant généralement l'utilisateur à saisir des informations. Le second est une valeur par défaut, qui est facultative et remplira initialement le champ de saisie.

```js
const answer = window.prompt("What's your favorite animal?"); // This will change depending on what the user answers
```
