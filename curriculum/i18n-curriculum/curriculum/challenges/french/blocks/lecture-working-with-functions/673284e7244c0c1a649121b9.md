# --interactive--

La portée en programmation désigne la visibilité et l'accessibilité des variables dans différentes parties de ton code. Elle détermine où les variables peuvent être consultées ou modifiées. En JavaScript, comprendre la portée est crucial pour écrire un code propre, efficace et sans bug. Il existe trois grands types de portée : la portée globale, la portée locale et la portée de bloc.

La portée globale est la portée la plus externe d'un programme JavaScript. Les variables déclarées dans la portée globale sont accessibles depuis n'importe où dans ton code, y compris à l'intérieur des fonctions et des blocs. Ces variables sont souvent appelées variables globales. Même si les variables globales peuvent être pratiques, il faut les utiliser avec parcimonie car elles peuvent entraîner des conflits de noms et rendre ton code plus difficile à maintenir. Voici un exemple de variable globale :

:::interactive_editor

```js
let globalVar = "I'm a global variable";

function printGlobalVar() {
    console.log(globalVar);
}

printGlobalVar(); // "I'm a global variable"
```

:::

Dans cet exemple, `globalVar` est déclarée dans la portée globale et peut être consultée à l'intérieur de la fonction `printGlobalVar`.

La portée locale, en revanche, désigne les variables qui ne sont accessibles qu'à l'intérieur d'une fonction. Voici un exemple de portée locale :

:::interactive_editor

```js
function greet() {
    let message = "Hello, local scope!";
    console.log(message);
}

greet(); // "Hello, local scope!"
// console.log(message); // This will throw an error
```

:::

Dans ce code, `message` est une variable locale à la fonction `greet`. Elle peut être utilisée à l'intérieur de la fonction, mais essayer d'y accéder en dehors de la fonction provoquera une erreur.

La portée de bloc est un concept introduit avec les mots-clés `let` et `const` dans ES6. Un bloc est toute section de code entre accolades, `{}`, comme dans les instructions `if`, les boucles `for` ou les boucles `while`. Le concept de boucles sera enseigné dans une prochaine leçon.

Les variables déclarées avec `let` ou `const` à l'intérieur d'un bloc ne sont accessibles qu'à l'intérieur de ce bloc. Voici un exemple de portée de bloc :

```js
if (true) {
    let blockVar = "I'm in a block";
    console.log(blockVar); // "I'm in a block"
}
console.log(blockVar); // This will throw an error
```

Dans cet exemple, `blockVar` n'est accessible qu'à l'intérieur du bloc `if`. Essayer d'y accéder en dehors du bloc provoquera une erreur. Comprendre ces différents types de portée est essentiel pour gérer l'accessibilité des variables et éviter les effets de bord involontaires dans ton code.

Les variables globales doivent être utilisées avec parcimonie, car elles peuvent entraîner des conflits de noms et rendre ton code plus difficile à maintenir. Les variables locales aident à garder différentes parties de ton code isolées, ce qui est particulièrement utile dans les programmes plus volumineux. La portée de bloc avec `let` et `const` offre un contrôle encore plus fin sur l'accessibilité des variables, ce qui aide à prévenir les erreurs et à rendre ton code plus prévisible. Maîtriser ces concepts de base que sont la portée globale, locale et de bloc te donnera une base solide pour comprendre des sujets plus avancés.
