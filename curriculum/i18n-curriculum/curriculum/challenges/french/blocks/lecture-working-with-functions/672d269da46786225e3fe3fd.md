# --interactive--

Les fonctions sont des morceaux de code réutilisables qui effectuent une tâche précise ou calculent une valeur. Imagine une fonction comme une machine qui prend une entrée, effectue des opérations dessus, puis produit une sortie. Voici un exemple de déclaration d'une fonction :

```js
function greet() {
  console.log("Hello, Jessica!");
}
```

Dans cet exemple, nous avons déclaré une fonction appelée `greet`. À l'intérieur de cette fonction, nous avons un `console.log` qui affiche le message `Hello, Jessica!`. Si nous essayions d'exécuter ce code, nous ne verrions pas le message apparaître dans la console. C'est parce que nous devons appeler la fonction.

Un appel de fonction, ou invocation, c'est lorsqu'on utilise ou exécute réellement la fonction. Pour appeler une fonction, tu devras référencer le nom de la fonction suivi d'une paire de parenthèses :

:::interactive_editor

```js
function greet() {
  console.log("Hello, Jessica!");
}

greet(); // "Hello, Jessica!"
```

:::

Maintenant, le message `Hello, Jessica!` sera affiché dans la console. Mais que faire si nous voulions que le message dise `Hello, Nick!` ou `Hello, Anna!` ? Nous ne voulons pas écrire une nouvelle fonction chaque fois que nous saluons un utilisateur différent. À la place, nous pouvons créer une fonction réutilisable qui utilise des paramètres et des arguments de fonction.

Les paramètres servent d'espaces réservés pour les valeurs qui seront passées à la fonction lorsqu'elle est appelée. Ils permettent aux fonctions d'accepter une entrée et de travailler avec cette entrée. Les arguments sont les valeurs réelles passées à la fonction lorsqu'elle est appelée. Voici une version mise à jour de la fonction `greet` qui utilise des paramètres et des arguments :

:::interactive_editor

```js
function greet(name) {
  console.log("Hello, " + name + "!");
}

greet("Alice"); // Hello, Alice!
greet("Nick"); // Hello, Nick!
```

:::

Le `name` sert de paramètre tandis que les chaînes `Alice` et `Nick` servent d'arguments. Nous avons maintenant une fonction réutilisable qui peut être utilisée des dizaines de fois dans notre code avec des arguments différents.

Lorsqu'une fonction termine son exécution, elle retourne toujours une valeur. Par défaut, la valeur retournée sera `undefined`. Voici un exemple :

:::interactive_editor

```js
function doSomething() {
  console.log("Doing something...");
}

let result = doSomething();
console.log(result); // undefined
```

:::

Si tu as besoin que ta fonction retourne une valeur précise, tu devras alors utiliser l'instruction `return`. Voici un exemple d'utilisation d'une instruction `return` pour retourner la somme de deux valeurs :

:::interactive_editor

```js
function calculateSum(num1, num2) {
  return num1 + num2;
}

console.log(calculateSum(3, 4)); // 7
```

:::

Souvent, tu utiliseras l'instruction `return`, car tu peux réutiliser cette valeur produite par la fonction plus loin dans ton code.

Jusqu'ici, nous avons travaillé avec des fonctions nommées, mais tu peux aussi créer ce qu'on appelle une fonction anonyme. Une fonction anonyme est une fonction sans nom qui peut être affectée à une variable comme ceci :

:::interactive_editor

```js
const sum = function (num1, num2) {
  return num1 + num2;
};

console.log(sum(3, 4)); // 7
```

:::

Dans cet exemple, nous avons une variable `const` appelée `sum` et nous lui affectons une fonction anonyme qui retourne la somme de `num1` et `num2`. Nous pouvons ensuite appeler `sum` et passer les nombres `3` et `4` pour obtenir le résultat `7`.

Les fonctions prennent en charge les paramètres par défaut, ce qui te permet de définir des valeurs par défaut pour les paramètres. Ces valeurs par défaut sont utilisées si la fonction est appelée sans argument pour ce paramètre. Voici un exemple :

:::interactive_editor

```js
function greetings(name = "Guest") {
  console.log("Hello, " + name + "!");
}

greetings(); // Hello, Guest!
greetings("Anna"); // Hello, Anna!
```

:::

Dans cet exemple, si aucun argument n'est fourni pour `name`, il prend par défaut la valeur `Guest`.

En résumé, les fonctions te permettent d'écrire du code réutilisable et organisé. Elles peuvent prendre des entrées (paramètres), effectuer des actions et retourner des sorties.
