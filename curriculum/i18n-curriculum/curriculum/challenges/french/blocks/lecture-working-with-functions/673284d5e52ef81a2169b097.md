# --interactive--

Dans la leçon précédente, tu as appris à travailler avec les fonctions, qui sont des morceaux de code réutilisables permettant de rendre ton code plus modulaire, plus facile à maintenir et plus efficace. Tous les exemples précédents utilisaient la syntaxe de fonction classique, comme ceci :

```js
function greetings(name) {
  console.log("Hello, " + name + "!");
}
```

Mais une autre façon d'écrire des fonctions en JavaScript consiste à créer une expression de fonction fléchée. Voici comment tu peux réécrire l'exemple précédent pour utiliser plutôt la syntaxe de fonction fléchée :

```js
const greetings = (name) => {
  console.log("Hello, " + name + "!");
};
```

Dans cet exemple révisé, nous créons une variable `const` appelée `greetings` et nous lui affectons une fonction anonyme. La plupart de la syntaxe te semblera familière, à l'exception du mot-clé `function` qui est absent et de l'ajout de la flèche (`=>`) entre le paramètre `name` et le corps de la fonction. Si ta liste de paramètres ne contient qu'un seul paramètre, alors tu peux retirer les parenthèses comme ceci :

```js
const greetings = name => {
  console.log("Hello, " + name + "!");
};
```

Si ta fonction fléchée n'a aucun paramètre, alors tu dois utiliser les parenthèses comme ceci :

```js
const greetings = () => {
  console.log("Hello");
};
```

Quand tu as découvert les fonctions, tu devais entourer le corps de la fonction d'accolades. Mais si le corps de ta fonction ne contient qu'une seule ligne de code, tu peux retirer les accolades comme ceci :

```js
const greetings = name => console.log("Hello, " + name + "!");
```

Il est important de noter que retirer les parenthèses et les accolades dans la syntaxe de fonction classique ne fonctionnera pas. Tu obtiendrais des erreurs si tu essayais de faire quelque chose comme ceci :

```js
// This will produce syntax errors
function greetings name console.log("Hello, " + name + "!");
```

Ce type de fonctions sur une seule ligne ne fonctionne que si tu utilises la syntaxe de fonction fléchée. Un autre concept clé est l'instruction `return`. Voici un exemple d'utilisation de la syntaxe de fonction fléchée pour calculer l'aire :

:::interactive_editor

```js
const calculateArea = (width, height) => {
  const area = width * height;
  return area;
};

console.log(calculateArea(5, 3)); // 15
```

:::

Nous créons une variable à l'intérieur de la fonction appelée `area`, puis nous retournons cette variable. Mais nous pourrions alléger un peu notre code et retourner directement le calcul lui-même :

:::interactive_editor

```js
const calculateArea = (width, height) => {
  return width * height;
};

console.log(calculateArea(5, 3)); // 15
```

:::

Si tu essayais de retirer les accolades et de placer le calcul sur la même ligne, tu obtiendrais un message `Uncaught SyntaxError: Unexpected token 'return'` :

```js
const calculateArea = (width, height) => return width * height;
```

La raison pour laquelle tu obtiens cette erreur, c'est que tu dois retirer l'instruction `return`. Lorsque tu retires cette instruction `return`, l'erreur disparaît et la fonction retourne toujours implicitement le calcul.

```js
const calculateArea = (width, height) => width * height;
```

Alors, quand devrais-tu utiliser la syntaxe de fonction fléchée ? Eh bien, ça dépend. Beaucoup de développeurs l'utilisent systématiquement dans leurs projets personnels. Cependant, lorsqu'on travaille en équipe, le choix dépend généralement du fait que la base de code existante utilise des fonctions classiques ou des fonctions fléchées. Dans de futures leçons, nous verrons quand utiliser les fonctions fléchées et quand les éviter.
