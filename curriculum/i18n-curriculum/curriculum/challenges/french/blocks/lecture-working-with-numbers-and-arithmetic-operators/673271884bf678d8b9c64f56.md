# --interactive--

JavaScript fournit des outils pour effectuer des opérations arithmétiques de base sur les nombres, comme l'addition, la soustraction, la multiplication et la division. JavaScript inclut aussi des opérateurs pour des opérations arithmétiques plus complexes, comme le reste et l'exponentiation.

Tous ces outils sont appelés opérateurs arithmétiques. Examinons ces opérateurs en détail, comment les utiliser et comment les combiner.

L'opérateur d'addition est un signe plus (`+`). L'opérateur d'addition te permet de trouver le total de deux nombres ou plus. Dans les opérations d'addition, l'ordre des nombres n'a pas d'importance :

:::interactive_editor

```js
const num1 = 10;
const num2 = 5;
const num3 = 15;

const result1 = num1 + num2;
const result2 = num2 + num1;
const result3 = num2 + num1 + num3;

console.log(result1); // 15
console.log(result2); // 15
console.log(result3); // 30
```

:::

L'opérateur de soustraction est un signe moins (`-`). Il te permet de trouver la différence entre deux nombres. Utilise le signe moins quand tu veux soustraire un nombre d'un autre, généralement un plus petit d'un plus grand :

:::interactive_editor

```js
const difference = 10 - 5;
console.log(difference); // 5
```

:::

Si un nombre plus petit vient en premier, tu obtiendras un résultat négatif :

:::interactive_editor

```js
const difference = 5 - 10;
console.log(difference); // -5
```

:::

Tu peux aussi affecter les nombres à des variables et faire la soustraction avec les noms de variables :

:::interactive_editor

```js
const num1 = 10;
const num2 = 5;
const result = num1 - num2;

console.log(result); // 5
```

:::

En JavaScript, l'opérateur de multiplication est représenté par un astérisque (`*`) et sert à trouver le produit de deux nombres ou plus. L'ordre des nombres que tu multiplies n'a pas d'importance :

:::interactive_editor

```js
const num1 = 10;
const num2 = 5;
const num3 = 15;

const result1 = num1 * num2;
const result2 = num2 * num1;
const result3 = num2 * num1 * num3;

console.log(result1); // 50
console.log(result2); // 50
console.log(result3); // 750
```

:::

En JavaScript, l'opérateur de division est une barre oblique (`/`), qui diffère du symbole de division utilisé en mathématiques traditionnelles (`÷`). Tu effectues les opérations de division avec l'opérateur de division. L'ordre des nombres que tu divises a de l'importance dans ce cas :

:::interactive_editor

```js
const num1 = 10;
const num2 = 5;
const num3 = 15;

const result1 = num1 / num2;
const result2 = num2 / num1;
const result3 = num2 / num1 / num3;

console.log(result1); // 2
console.log(result2); // 0.5
console.log(result3); // 0.03333333333333333
```

:::

Il est important de noter que si tu essaies de diviser par zéro, JavaScript renverra `Infinity` :

:::interactive_editor

```js
const result = 10 / 0;

console.log(result); // Infinity
```

:::

Veille à éviter ce genre de calculs pour ne pas te retrouver avec des résultats inattendus dans ton code.

L'opérateur de reste, représenté par un signe pourcentage (`%`), renvoie le reste d'une division. Le reste, en mathématiques, est la valeur qui subsiste après avoir effectué une division :

:::interactive_editor

```js
const num1 = 10;
const num2 = 3;
const remainder = num1 % num2;

console.log(remainder); // 1
```

:::

L'opérateur d'exponentiation, représenté par un double astérisque (`**`), élève un nombre à la puissance d'un autre :

:::interactive_editor

```js
const num1 = 2;
const num2 = 3;

const exponent = num1 ** num2;
console.log(exponent); // 8
```

:::

Il est possible de mélanger des opérateurs dans une seule opération ou expression :

:::interactive_editor

```js
const result = 10 + 5 * 2 - 8 / 4;
console.log(result); // 18
```

:::

Quand tu mélanges différents opérateurs dans une même expression, le moteur JavaScript suit un système appelé précédence des opérateurs pour déterminer l'ordre des opérations. La précédence des opérateurs détermine l'ordre dans lequel les opérations sont exécutées dans les expressions. Tu en apprendras davantage sur la précédence des opérateurs dans de prochaines leçons.
