# --interactive--

JavaScript est un langage où les choses fonctionnent parfois de manière surprenante, voire bizarre. Une de ces surprises survient quand tu mélanges des nombres et des chaînes dans des calculs. La première chose que tu essaieras probablement est d'additionner un nombre et une chaîne. En JavaScript, l'opérateur `+` joue un double rôle. Il gère à la fois l'addition et la concaténation de chaînes, qui est une façon de joindre deux chaînes ensemble.

Quand tu utilises `+` avec un nombre et une chaîne, JavaScript décide de les traiter tous les deux comme des chaînes et les joint ensemble. Si tu vérifies le type du résultat avec l'opérateur `typeof`, tu verrais que c'est bien une chaîne :

:::interactive_editor

```js
const result = 5 + '10';

console.log(result); // 510
console.log(typeof result); // string
```

:::

Que penses-tu qu'il se passera si tu inverses l'ordre de `5` et `'10'` ?

:::interactive_editor

```js
const result = '10' + 5;

console.log(result); // 105
console.log(typeof result); // string
```

:::

Tu peux voir que la même chose s'est produite. JavaScript voit une chaîne dans `'10'` et un nombre dans `5`, donc il convertit le nombre en chaîne et les concatène. C'est ce qu'on appelle la coercition de type. La coercition de type, c'est quand une valeur d'un type de données est convertie en un autre.

Les choses deviennent plus intéressantes quand tu essaies d'effectuer d'autres opérations arithmétiques comme la soustraction, la multiplication ou la division avec une chaîne et un nombre. Dans ces cas, JavaScript essaie de convertir la chaîne en nombre avant de faire le calcul — encore une coercition de type ! Voici ce qui se passe :

:::interactive_editor

```js
const subtractionResult = '10' - 5;
console.log(subtractionResult); // 5
console.log(typeof subtractionResult); // number

const multiplicationResult = '10' * 2;
console.log(multiplicationResult); // 20
console.log(typeof multiplicationResult); // number

const divisionResult = '20' / 2;
console.log(divisionResult); // 10
console.log(typeof divisionResult); // number
```

:::

Dans les exemples ci-dessus, JavaScript convertit avec succès la chaîne `'10'` ou `'20'` en nombre, puis effectue le calcul. Résultat : `'10' - 5` donne `5`, `'10' * 2` donne `20`, et `'20' / 2` donne `10`.

Mais que se passe-t-il si la chaîne ne ressemble pas à un nombre ? Voyons ce qui se passe dans ce cas :

:::interactive_editor

```js
const subtractionResult = 'abc' - 5;
console.log(subtractionResult); // NaN
console.log(typeof subtractionResult); // number

const multiplicationResult = 'abc' * 2;
console.log(multiplicationResult); // NaN
console.log(typeof multiplicationResult); // number

const divisionResult = 'abc' / 2;
console.log(divisionResult); // NaN
console.log(typeof divisionResult); // number
```

:::

Dans les exemples ci-dessus, la chaîne `'abc'` ne représente pas une valeur numérique valide, donc JavaScript ne peut pas la convertir en un nombre significatif. Quand une telle conversion échoue, JavaScript renvoie `NaN`, qui signifie "Not a Number" (pas un nombre). `NaN` est une valeur spéciale du type `Number` qui représente un nombre invalide ou non représentable.

Et si tu effectues des opérations arithmétiques avec un booléen (`true` ou `false`) ? Voyons ce qui se passe. JavaScript traite les booléens comme des nombres dans les opérations mathématiques : `true` devient `1`, et `false` devient `0`.

:::interactive_editor

```js
const result1 = true + 1;
console.log(result1); // 2
console.log(typeof result1); // number

const result2 = false + 1;
console.log(result2); // 1
console.log(typeof result2); // number

const result3 = 'Hello' + true;
console.log(result3); // "Hellotrue"
console.log(typeof result3); // string
```

:::

Dans les deux premiers exemples, `true + 1` a donné `2`, et `false + 1` a donné `1`. Dans le troisième exemple, `'Hello' + true`, JavaScript a converti `true` en chaîne et l'a concaténée avec `'Hello'`, ce qui donne `'Hellotrue'`, qui est une chaîne.

Pour `null` et `undefined`, JavaScript traite `null` comme `0` et `undefined` comme `NaN` dans les opérations mathématiques :

:::interactive_editor

```js
const result1 = null + 5;
console.log(result1); // 5
console.log(typeof result1); // number

const result2 = undefined + 5;
console.log(result2); // NaN
console.log(typeof result2); // number
```

:::

JavaScript effectue souvent une coercition de type, convertissant automatiquement des types de données comme les nombres, les chaînes et les booléens de manières parfois inattendues. Comprendre ces conversions est crucial pour éviter les bugs et écrire du code robuste dans tes projets.
