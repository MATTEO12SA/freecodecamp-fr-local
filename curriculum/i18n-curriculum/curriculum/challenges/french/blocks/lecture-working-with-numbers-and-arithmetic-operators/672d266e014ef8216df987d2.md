# --interactive--

Le type `Number` est l'un des types de données les plus utilisés en JavaScript et dans d'autres langages de programmation. Les nombres peuvent sembler simples, mais il y a beaucoup à explorer en ce qui concerne les nombres en JavaScript. Alors, regardons cela de plus près. En JavaScript, le type de données `Number` représente une valeur numérique.

Contrairement à beaucoup d'autres langages de programmation qui séparent les entiers et les nombres à virgule flottante en types différents, JavaScript utilise un seul type `Number` unifié pour gérer les nombres. Cela signifie que tu peux travailler avec des nombres entiers, des décimaux, et même des valeurs numériques spéciales, le tout sous la même bannière du type de données `Number`.

Voici un exemple basique qui te montre que les entiers, les nombres à virgule flottante et les nombres négatifs sont tous de type number :

:::interactive_editor

```js
const wholeNumber = 50;
const decimalNumber = 4.5;
const negativeNumber = -7;

console.log(typeof wholeNumber); // number
console.log(typeof decimalNumber); // number
console.log(typeof negativeNumber); // number
```

:::

Le type `Number` de JavaScript inclut différentes sortes de valeurs numériques, allant des simples entiers et nombres à virgule flottante à des cas spéciaux comme `Infinity` et `NaN`, ou "Not a Number". Décomposons les principaux types que tu rencontreras. Les entiers sont des nombres entiers sans aucune partie fractionnaire ou décimale. Ils peuvent être positifs, négatifs ou nuls. Voici quelques exemples :

:::interactive_editor

```js
const positiveInteger = 100;
const negativeInteger = -25;
const zero = 0;

console.log(typeof positiveInteger); // number
console.log(typeof negativeInteger); // number
console.log(typeof zero); // number
```

:::

Les nombres à virgule flottante sont des nombres avec une virgule décimale. Les développeurs JavaScript les appellent souvent simplement "floats". Les floats sont utiles quand tu as besoin de plus de précision, par exemple lorsque tu manipules des mesures ou des devises. Voici quelques exemples :

:::interactive_editor

```js
const floatingPointNumber = 4.5;
const anotherFloat = 89.56;
const oneMoreFloat = 16.462;

console.log(typeof floatingPointNumber); // number
console.log(typeof anotherFloat); // number
console.log(typeof oneMoreFloat); // number
```

:::

JavaScript peut représenter les nombres qui dépassent la limite maximale avec `Infinity`. Tu rencontreras cela quand tu essaies de diviser un nombre par zéro ou, dans de rares cas, quand tu dépasses la limite supérieure du type `Number`. Voici un exemple :

:::interactive_editor

```js
const infiniteNumber = 1 / 0;
console.log(infiniteNumber); // Infinity
console.log(typeof infiniteNumber); // number
```

:::

Parfois en JavaScript, certaines opérations mathématiques ne produisent pas un nombre valide. Par exemple, si tu essaies d'effectuer une opération mathématique sur quelque chose qui n'est pas un nombre, tu obtiendras `NaN`, qui signifie "Not a Number" (pas un nombre) :

:::interactive_editor

```js
const notANumber = 'hello world' / 2;
console.log(notANumber); // NaN
```

:::

Étonnamment, le type de `NaN` est lui aussi `Number` :

:::interactive_editor

```js
const notANumber = 'hello world' / 2;
console.log(typeof notANumber); // number
```

:::

En dehors du système décimal standard (base 10), JavaScript prend aussi en charge les nombres dans différentes bases comme le binaire, l'octal et l'hexadécimal. Le binaire est un système en base 2 qui n'utilise que les chiffres 1 et 0. L'octal est un système en base 8 qui n'utilise que les chiffres 0 à 7. L'hexadécimal est un système en base 16 qui utilise les chiffres 0 à 9 et les lettres a à f, comme tu le vois dans les couleurs hexadécimales CSS.
