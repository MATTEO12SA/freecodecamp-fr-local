# --interactive--

Les opérateurs unaires agissent sur un seul opérande pour effectuer des opérations comme la conversion de type, la manipulation de valeurs ou la vérification de certaines conditions. Examinons quelques opérateurs unaires courants et leur fonctionnement.

L'opérateur plus unaire convertit son opérande en nombre. Si l'opérande est déjà un nombre, il reste inchangé.

:::interactive_editor

```js
const str = '42';
const strToNum = +str;

console.log(strToNum); // 42
console.log(typeof str); // string
console.log(typeof strToNum); // number
```

:::

Le plus unaire est pratique quand tu veux t'assurer de travailler avec une valeur numérique. Comme tu peux le deviner, il existe un opérateur de négation unaire. Il inverse la valeur de l'opérande. Il fonctionne de manière similaire au plus unaire, sauf qu'il change le signe.

:::interactive_editor

```js
const str = '42';
const strToNegativeNum = -str;

console.log(strToNegativeNum); // -42
console.log(typeof str); // string
console.log(typeof strToNegativeNum); // number
```

:::

L'opérateur NON logique, représenté par un point d'exclamation (`!`), est un autre opérateur unaire. Il inverse la valeur booléenne de son opérande. Donc, si l'opérande est `true`, il devient `false`, et s'il est `false`, il devient `true`.

:::interactive_editor

```js
let isOnline = true;
console.log(!isOnline); // false

let isOffline = false;
console.log(!isOffline); // true
```

:::

L'opérateur NON bit à bit est un opérateur unaire moins couramment utilisé. Représenté par un tilde, `~`, il inverse la représentation binaire d'un nombre. Les ordinateurs stockent les nombres au format binaire (des 1 et des 0). L'opérateur `~` inverse chaque bit, c'est-à-dire qu'il change tous les 1 en 0 et tous les 0 en 1. Tu en apprendras davantage sur le binaire et les bits dans une prochaine leçon.

:::interactive_editor

```js
const num = 5; // The binary for 5 is 00000101

console.log(~num); // -6
```

:::

Dans cet exemple, `5` est devenu `-6` car en appliquant l'opérateur `~` à `5`, tu obtiens `- (5 + 1)`, ce qui équivaut à `-6` en raison de la représentation en complément à deux. Le complément à deux est une façon dont les ordinateurs représentent les nombres négatifs en binaire. Tu n'utiliseras probablement pas souvent le NON bit à bit, sauf si tu travailles sur des tâches de programmation bas niveau comme la manipulation directe des bits.

Le mot-clé `void` est un opérateur unaire qui évalue une expression et renvoie `undefined`.

:::interactive_editor

```js
const result = void (2 + 2);

console.log(result); // undefined
```

:::

`void` est aussi couramment utilisé dans les hyperliens pour empêcher la navigation :

```js
<a href="javascript:void(0);">Click Me</a>
```

Enfin, il y a l'opérateur `typeof`, que tu as découvert dans les leçons précédentes. Il renvoie le type de son opérande sous forme de chaîne.

:::interactive_editor

```js
const value = 'Hello world';

console.log(typeof value); // string
```

:::
