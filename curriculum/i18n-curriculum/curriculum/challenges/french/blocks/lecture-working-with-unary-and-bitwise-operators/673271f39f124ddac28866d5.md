# --interactive--

Les opérateurs bit à bit en JavaScript sont des opérateurs spéciaux qui travaillent sur les représentations binaires des nombres. Pour comprendre les opérateurs bit à bit, nous devons d'abord saisir le concept de bits et de nombres binaires. En informatique, un bit est l'unité d'information la plus élémentaire. Il ne peut avoir que deux valeurs : `0` ou `1`. Le binaire est un système de numération qui n'utilise que ces deux chiffres pour représenter tous les nombres.

Par exemple, la représentation binaire du nombre décimal `10` est `1010`. Dans ce système, chaque chiffre représente une puissance de `2`, en commençant par le chiffre le plus à droite et en augmentant à mesure que l'on se déplace vers la gauche.

Maintenant, plongeons dans les opérateurs bit à bit. Ces opérateurs effectuent des opérations sur les représentations binaires des nombres. JavaScript fournit plusieurs opérateurs bit à bit, dont ET (`&`), OU (`|`), OU exclusif (`^`), NON (`~`), décalage à gauche (`<<`) et décalage à droite (`>>`).

L'opérateur ET bit à bit (`&`) renvoie un `1` à chaque position de bit pour laquelle les bits correspondants des deux opérandes sont à `1`. Voici un exemple :

:::interactive_editor

```js
let a = 5;  // Binary: 101
let b = 3;  // Binary: 011
console.log(a & b);  // 1 (Binary: 001)
```

:::

Dans cet exemple, nous effectuons une opération ET bit à bit sur `5` (`101` en binaire) et `3` (`011` en binaire). Le résultat est `1` (`001` en binaire) car seul le bit le plus à droite est à `1` dans les deux nombres.

L'opérateur OU bit à bit (`|`) renvoie un `1` à chaque position de bit pour laquelle les bits correspondants de l'un ou des deux opérandes sont à `1`. Par exemple :

:::interactive_editor

```js
let a = 5;  // Binary: 101
let b = 3;  // Binary: 011
console.log(a | b);  // 7 (Binary: 111)
```

:::

Ici, le résultat est `7` (`111` en binaire) car au moins un des bits est à `1` à chaque position.

L'opérateur OU exclusif bit à bit (`^`) renvoie un `1` à chaque position de bit pour laquelle les bits correspondants de l'un, mais pas des deux, opérandes sont à `1`. Par exemple :

:::interactive_editor

```js
let a = 5;  // Binary: 101
let b = 3;  // Binary: 011
console.log(a ^ b);  // 6 (Binary: 110)
```

:::

Le résultat est `6` (`110` en binaire) car les premier et deuxième bits en partant de la droite sont différents dans les deux nombres.

L'opérateur NON bit à bit (`~`) inverse tous les bits de son opérande. Par exemple :

:::interactive_editor

```js
let a = 5;  // Binary: 101
console.log(~a);  // -6
```

:::

Cela peut sembler surprenant, mais c'est dû à la façon dont les nombres négatifs sont représentés en binaire à l'aide du complément à deux.

L'opérateur de décalage à gauche (`<<`) décale tous les bits vers la gauche d'un nombre de positions spécifié. Par exemple :

:::interactive_editor

```js
let a = 5;  // Binary: 101
console.log(a << 1);  // 10 (Binary: 1010)
```

:::

Ici, tous les bits sont décalés d'une position vers la gauche, ce qui revient à multiplier le nombre par `2`.

L'opérateur de décalage à droite (`>>`) décale tous les bits vers la droite. Par exemple :

:::interactive_editor

```js
let a = 5;  // Binary: 101
console.log(a >> 1);  // 2 (Binary: 10)
```

:::

Ici, tous les bits sont décalés d'une position vers la droite, ce qui revient à diviser le nombre par `2` en arrondissant à l'entier inférieur.

Les opérateurs bit à bit sont souvent utilisés en programmation bas niveau et en cryptographie. Bien qu'ils ne soient pas aussi couramment utilisés dans la programmation JavaScript de tous les jours, les comprendre peut être bénéfique pour certaines tâches spécialisées et peut approfondir ta compréhension du fonctionnement des ordinateurs à un niveau fondamental.
