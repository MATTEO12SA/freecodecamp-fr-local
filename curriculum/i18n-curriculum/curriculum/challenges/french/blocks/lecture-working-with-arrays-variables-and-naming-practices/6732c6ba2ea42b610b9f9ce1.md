# --description--

Dans les leçons précédentes, tu as été introduit à la propriété `length`, qui renvoie le nombre d'éléments dans un tableau. Voici donc un rapide rappel de son fonctionnement :

```js
const fruits = ['apple', 'banana', 'orange'];
console.log(fruits.length); // 3
```

Il est possible d'avoir des tableaux avec des emplacements vides. Les emplacements vides sont définis comme des emplacements ne contenant rien. C'est différent d'un tableau dont les éléments ont la valeur `undefined`. Ces types de tableaux sont appelés tableaux clairsemés. Voici un exemple :

```js
const sparseArray = [1, , , 4];
console.log(sparseArray.length); // 4
```

Dans ce cas, même si nous n'avons que deux éléments définis, `1` et `4`, la longueur est `4` car le plus grand indice (`3`) plus `1` nous donne une longueur de `4`.

Maintenant, voyons comment créer un tableau vide de longueur fixe. Il existe plusieurs façons de le faire en JavaScript, mais une méthode courante consiste à utiliser le constructeur `Array()` avec un argument numérique. Le constructeur `Array()` peut être utilisé avec le mot-clé `new` pour créer un nouveau tableau. Voici un exemple :

```js
const emptyArray = new Array(5);
console.log(emptyArray.length); // 5
console.log(emptyArray); // [ , , , , ]
```

Dans cet exemple, nous créons un nouveau tableau avec `Array(5)`. Cela crée un tableau clairsemé d'une longueur de `5` où tous les emplacements sont vides.

Une autre façon de créer un tableau vide de longueur fixe est d'utiliser la méthode `Array.from()` avec un argument de longueur. Contrairement à `new Array(n)`, cette méthode crée un tableau de la longueur spécifiée où tous les éléments existent et ont une valeur `undefined` :

```js
const fixedLengthArray = Array.from({ length: 5 });
console.log(fixedLengthArray.length); // 5
console.log(fixedLengthArray); // [undefined, undefined, undefined, undefined, undefined]
```

Si tu veux créer un tableau d'une longueur spécifique et le remplir avec une valeur par défaut, tu peux utiliser la méthode `Array.fill()` :

```js
const filledArray = new Array(3).fill(0);
console.log(filledArray); // [0, 0, 0]
```

Cela crée un tableau de longueur trois et remplit tous les éléments avec la valeur `0`. Remarque : lorsque tu remplis avec des objets, tous les emplacements font référence au même objet ; si tu as besoin de copies indépendantes, utilise plutôt un callback ou `Array.from()`.

Comprendre comment obtenir la longueur d'un tableau et créer des tableaux de longueur fixe est important pour de nombreuses tâches de programmation, notamment lorsque tu dois initialiser des tableaux pour des algorithmes ou des structures de données spécifiques.
