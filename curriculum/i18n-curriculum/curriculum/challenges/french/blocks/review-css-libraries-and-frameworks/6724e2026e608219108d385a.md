## Frameworks CSS

- **Frameworks CSS** : Les frameworks CSS peuvent accélérer ton workflow, créer un style visuel uniforme sur un site web, rendre ton design cohérent sur plusieurs navigateurs, et garder ton code CSS plus organisé.
- **Frameworks CSS populaires** : Parmi les frameworks CSS populaires, on trouve Tailwind CSS, Bootstrap, Materialize et Foundation.
- **Inconvénients potentiels** :
  - Le CSS fourni par le framework peut entrer en conflit avec ton CSS personnalisé.
  - Ton site web peut ressembler à d'autres sites qui utilisent le même framework.
  - Les grands frameworks peuvent causer des problèmes de performance.

## Deux types de frameworks CSS

- **Frameworks CSS utility-first** : Ces frameworks ont de petites classes avec des objectifs précis, comme définir la marge, le padding ou la couleur de fond. Tu peux assigner ces petites classes directement aux éléments HTML selon les besoins. Tailwind CSS est classé comme un framework CSS utility-first.

Voici un exemple d'utilisation de Tailwind CSS pour styliser un bouton.

```html
<button class="bg-blue-500 text-white font-bold py-2 px-4 rounded-full hover:bg-blue-700">
  Button
</button>
```

- **Frameworks CSS component-based** : Ces frameworks ont des composants préconstruits avec des styles prédéfinis que tu peux ajouter à ton site web. Les composants sont disponibles dans la documentation officielle du framework CSS, et tu peux les copier-coller dans ton projet. Bootstrap est classé comme un framework CSS component-based.

Voici un exemple d'utilisation de Bootstrap pour créer un list group. Au lieu d'appliquer de petites classes à tes éléments HTML, tu ajouteras le composant entier, y compris la structure HTML.

```html
<div class="card" style="width: 25rem;">
  <ul class="list-group list-group-flush">
    <li class="list-group-item">HTML</li>
    <li class="list-group-item">CSS</li>
    <li class="list-group-item">JavaScript</li>
  </ul>
</div>
```

## Tailwind CSS

Tailwind est un framework CSS utility-first. Au lieu d'écrire des règles CSS personnalisées, tu construis tes designs en combinant de petites classes utilitaires directement dans ton HTML.

### Utilitaires de design responsive

Tailwind utilise des préfixes comme `sm:`, `md:` et `lg:` pour appliquer des styles à différentes tailles d'écran.

```html
<div class="w-full md:w-1/2 lg:flex-row">Responsive layout</div>
```

### Utilitaires Flexbox

Des classes comme `flex`, `flex-col`, `justify-around` et `items-center` facilitent la création de dispositions flexibles.

```html
<div class="flex flex-col md:flex-row justify-around items-center">
  <p>Column on small screens</p>
  <p>Row on medium and larger screens</p>
</div>
```

### Utilitaires Grid

Tailwind inclut des utilitaires pour CSS Grid, comme `grid`, `grid-cols-1` et `md:grid-cols-3`.

```html
<div class="grid grid-cols-1 md:grid-cols-3 gap-8">
  <div class="bg-gray-100 p-4">Column 1</div>
  <div class="bg-gray-100 p-4">Column 2</div>
  <div class="bg-gray-100 p-4">Column 3</div>
</div>
```

### Utilitaires d'espacement

Des utilitaires comme `mt-8`, `mx-auto`, `p-4` et `gap-4` aident à créer un espacement cohérent sans écrire de CSS.

```html
<div class="mt-8 p-4 bg-indigo-600 text-white">Spaced content</div>
```

### Utilitaires de typographie

Des utilitaires comme `uppercase`, `font-bold`, `font-semibold` et `text-4xl` contrôlent l'apparence du texte.

Tu peux définir des tailles de police qui s'ajustent aux breakpoints, comme `text-3xl` `md:text-5xl`.

```html
<h1 class="text-3xl md:text-5xl font-semibold text-center">Responsive Heading
</h1>
```

### Couleurs et états hover

Tailwind fournit une large palette de couleurs, comme `text-red-700`, `bg-indigo-600` et `bg-gray-100`.

Des classes comme `hover:bg-pink-600` rendent les effets interactifs simples.

```html
<a href="#" class="bg-pink-500 hover:bg-pink-600 text-white px-4 py-2 rounded-md">
  Hover Me
</a>
```

### Bordures, rings et effets

- **Bordures** : `border-2 border-red-300` ajoute des bordures avec une épaisseur et des couleurs spécifiées.
- **Rings** : `ring-1 ring-gray-300` crée des effets de type contour souvent utilisés pour le focus ou les cartes.
- **Coins arrondis et mise à l'échelle** : Des classes comme `rounded-md`, `rounded-xl` et `scale-105` ajoutent une finition soignée.

```html
<div class="p-6 rounded-xl ring-2 ring-fuchsia-500 scale-105">
  Highlighted card
</div>
```

### Dégradés

Tailwind prend en charge des utilitaires de dégradé comme `bg-gradient-to-r from-fuchsia-500 to-indigo-600`.

```html
<div class="p-4 text-white bg-gradient-to-r from-fuchsia-500 to-indigo-600">
  Gradient background
</div>
```

## Préprocesseurs CSS

- **Préprocesseur CSS** : Un préprocesseur CSS est un outil qui étend le CSS standard. Il compile le code avec une syntaxe étendue en un fichier CSS natif. Il peut être utile pour écrire un CSS plus propre, réutilisable, moins répétitif et évolutif pour les projets complexes.
- **Fonctionnalités** : Parmi les fonctionnalités que peuvent fournir les préprocesseurs CSS, on trouve les variables, les mixins, l'imbrication et l'héritage de sélecteurs.
- **Préprocesseurs CSS populaires** : Parmi les préprocesseurs CSS populaires, on trouve Sass, Less et Stylus.
- **Inconvénients potentiels** :
  - Compiler les règles CSS en CSS standard peut entraîner une surcharge.
  - Le code compilé peut être difficile à déboguer.

## Sass

- **Sass** : C'est l'un des préprocesseurs CSS les plus populaires. Sass signifie « Syntactically Awesome Style Sheets ».
- **Fonctionnalités prises en charge par Sass** : Sass prend en charge des fonctionnalités comme les variables, les règles CSS imbriquées, les modules, les mixins, l'héritage et les opérateurs pour les opérations mathématiques de base

## Deux syntaxes prises en charge par Sass

- **Syntaxe SCSS** : Le SCSS (Sassy CSS) étend la syntaxe de base du CSS. C'est la syntaxe la plus largement utilisée pour Sass. Les fichiers SCSS ont une extension `.scss`.

Voici un exemple de définition et d'utilisation d'une variable en SCSS.

```scss
$primary-color: #3498eb;

header {
  background-color: $primary-color;
}
```

- **Syntaxe indentée** : La syntaxe indentée était la syntaxe originale de Sass et est aussi connue sous le nom de « syntaxe Sass ».

Voici un exemple de définition et d'utilisation d'une variable dans la syntaxe indentée.

```sass
$primary-color: #3498eb

header
  background-color: $primary-color
```

### Mixins

- **Mixins** : Les mixins te permettent de regrouper plusieurs propriétés CSS et leurs valeurs sous un nom et de réutiliser ce bloc de code CSS dans toute ta feuille de style.

Voici un exemple de définition d'un mixin en syntaxe SCSS. Dans ce cas, le mixin s'appelle `center-flex`. Il a trois propriétés CSS pour centrer les éléments avec Flexbox.

```scss
@mixin center-flex {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

Voici un exemple d'utilisation du mixin que tu as défini.

```scss
section {
  @include center-flex;
  height: 500px;
  background-color: #3289a8;
}
```
