## Les bases des tableaux JavaScript

- **Définition** : un tableau JavaScript est une collection ordonnée de valeurs, chacune identifiée par un index numérique. Les valeurs d'un tableau JavaScript peuvent être de différents types de données, y compris des nombres, des chaînes, des booléens, des objets, et même d'autres tableaux. Les tableaux sont contigus en mémoire, ce qui signifie que tous les éléments sont stockés dans un seul bloc continu d'emplacements mémoire, ce qui permet une indexation efficace et un accès rapide aux éléments par leur index.

```js
const developers = ["Jessica", "Naomi", "Tom"];
```

- **Accéder aux éléments d'un tableau** : pour accéder aux éléments d'un tableau, tu devras référencer le tableau suivi de son numéro d'index entre crochets. Les tableaux JavaScript sont indexés à partir de zéro, ce qui signifie que le premier élément est à l'index 0, le deuxième élément à l'index 1, etc. Si tu essaies d'accéder à un index qui n'existe pas dans le tableau, alors JavaScript retournera `undefined`.

:::interactive_editor

```js
const developers = ["Jessica", "Naomi", "Tom"];
console.log(developers[0]) // "Jessica"
console.log(developers[1]) // "Naomi"

console.log(developers[10]) // undefined
```

:::

- **Propriété `length`** : cette propriété est utilisée pour retourner le nombre d'éléments d'un tableau.

:::interactive_editor

```js
const developers = ["Jessica", "Naomi", "Tom"];
console.log(developers.length) // 3
```

:::

- **Mettre à jour les éléments d'un tableau** : pour mettre à jour un élément d'un tableau, tu utilises l'opérateur d'affectation (`=`) pour affecter une nouvelle valeur à l'élément situé à un index précis.

:::interactive_editor

```js
const fruits = ['apple', 'banana', 'cherry'];
fruits[1] = 'blueberry';

console.log(fruits); // ['apple', 'blueberry', 'cherry']
```

:::

## Les tableaux à deux dimensions

- **Définition** : un tableau à deux dimensions est essentiellement un tableau de tableaux. Il est utilisé pour représenter des données qui ont une structure naturelle en grille, comme un échiquier, un tableur, ou les pixels d'une image. Pour accéder à un élément d'un tableau à deux dimensions, tu as besoin de deux indices : un pour la ligne et un pour la colonne.

:::interactive_editor

```js
const chessboard = [
    ['R', 'N', 'B', 'Q', 'K', 'B', 'N', 'R'],
    ['P', 'P', 'P', 'P', 'P', 'P', 'P', 'P'],
    [' ', ' ', ' ', ' ', ' ', ' ', ' ', ' '],
    [' ', ' ', ' ', ' ', ' ', ' ', ' ', ' '],
    [' ', ' ', ' ', ' ', ' ', ' ', ' ', ' '],
    [' ', ' ', ' ', ' ', ' ', ' ', ' ', ' '],
    ['p', 'p', 'p', 'p', 'p', 'p', 'p', 'p'],
    ['r', 'n', 'b', 'q', 'k', 'b', 'n', 'r']
];

console.log(chessboard[0][3]); // "Q"
```

:::

## La déstructuration de tableaux

- **Définition** : la déstructuration de tableaux est une fonctionnalité de JavaScript qui te permet d'extraire des valeurs des tableaux et de les affecter à des variables d'une façon plus concise et lisible. Elle offre une syntaxe pratique pour décomposer les éléments d'un tableau en variables distinctes.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange"];

const [first, second, third] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(third); // "orange"
```

:::

- **Syntaxe rest** : elle te permet de capturer dans un nouveau tableau les éléments restants d'un tableau qui n'ont pas été déstructurés.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange", "mango", "kiwi"];
const [first, second, ...rest] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(rest); // ["orange", "mango", "kiwi"]
```

:::

## Les méthodes de tableau courantes

- **Méthode `push()`** : cette méthode est utilisée pour ajouter des éléments à la fin du tableau et retourne la nouvelle longueur.

:::interactive_editor

```js
const desserts = ["cake", "cookies", "pie"];
desserts.push("ice cream");

console.log(desserts); // ["cake", "cookies", "pie", "ice cream"];
```

:::

- **Méthode `pop()`** : cette méthode est utilisée pour supprimer le dernier élément d'un tableau et retourne cet élément supprimé. Si le tableau est vide, alors la valeur retournée sera `undefined`.

:::interactive_editor

```js
const desserts = ["cake", "cookies", "pie"];
desserts.pop();

console.log(desserts); // ["cake", "cookies"];
```

:::

- **Méthode `shift()`** : cette méthode est utilisée pour supprimer le premier élément d'un tableau et retourner cet élément supprimé. Si le tableau est vide, alors la valeur retournée sera `undefined`.

:::interactive_editor

```js
const desserts = ["cake", "cookies", "pie"];
desserts.shift();

console.log(desserts); // ["cookies", "pie"];
```

:::

- **Méthode `unshift()`** : cette méthode est utilisée pour ajouter des éléments au début du tableau et retourne la nouvelle longueur.

:::interactive_editor

```js
const desserts = ["cake", "cookies", "pie"];
desserts.unshift("ice cream");

console.log(desserts); // ["ice cream", "cake", "cookies", "pie"];
```

:::

- **Méthode `indexOf()`** : cette méthode est utile pour trouver le premier index d'un élément précis au sein d'un tableau. Si l'élément est introuvable, alors elle retourne `-1`.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange", "banana"];
const index = fruits.indexOf("banana");

console.log(index); // 1
console.log(fruits.indexOf("not found")); // -1
```

:::

- **Méthode `splice()`** : cette méthode est utilisée pour ajouter ou supprimer des éléments à n'importe quelle position d'un tableau. La valeur retournée par la méthode `splice()` sera un tableau des éléments supprimés du tableau. Si rien n'est supprimé, alors un tableau vide est retourné. Cette méthode modifie le tableau d'origine, le modifiant sur place plutôt que de créer un nouveau tableau. Le premier argument indique l'index à partir duquel commencer à modifier le tableau. Le deuxième argument est le nombre d'éléments que tu souhaites supprimer. Les arguments suivants sont les éléments que tu souhaites ajouter.

:::interactive_editor

```js
const colors = ["red", "green", "blue"];
colors.splice(1, 0, "yellow", "purple");

console.log(colors); // ["red", "yellow", "purple", "green", "blue"]
```

:::

- **Méthode `includes()`** : cette méthode est utilisée pour vérifier si un tableau contient une valeur précise. Cette méthode retourne `true` si le tableau contient l'élément spécifié, et `false` sinon.

:::interactive_editor

```js
const programmingLanguages = ["JavaScript", "Python", "C++"];

console.log(programmingLanguages.includes("Python")); // true
console.log(programmingLanguages.includes("Perl")); // false
```

:::

- **Méthode `concat()`** : cette méthode crée un nouveau tableau en fusionnant deux tableaux ou plus.

:::interactive_editor

```js
const programmingLanguages = ["JavaScript", "Python", "C++"];
const newList = programmingLanguages.concat("Perl");

console.log(newList); // ["JavaScript", "Python", "C++", "Perl"]
```

:::

- **Méthode `slice()`** : cette méthode retourne un nouveau tableau contenant une copie superficielle d'une portion du tableau d'origine, spécifiée par des indices de début et de fin. Le nouveau tableau contient des références aux mêmes éléments que le tableau d'origine (pas des doublons). Cela signifie que si les éléments sont des primitifs (comme des nombres ou des chaînes), les valeurs sont copiées ; mais si les éléments sont des objets ou des tableaux, ce sont les références qui sont copiées, pas les objets eux-mêmes.

:::interactive_editor

```js
const programmingLanguages = ["JavaScript", "Python", "C++"];
const newList = programmingLanguages.slice(1);

console.log(newList); // ["Python", "C++"]
```

:::

- **Syntaxe spread** : la syntaxe spread est utilisée pour créer des copies superficielles d'un tableau.

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const shallowCopiedArray = [...originalArray];

shallowCopiedArray.push(4);

console.log(originalArray); // [1, 2, 3]
console.log(shallowCopiedArray); // [1, 2, 3, 4]
```

:::

- **Méthode `split()`** : cette méthode divise une chaîne en un tableau de sous-chaînes et indique où chaque division doit se produire en fonction d'un séparateur donné. Si aucun séparateur n'est fourni, la méthode retourne un tableau contenant la chaîne d'origine comme élément unique.

:::interactive_editor

```js
const str = "hello";
const charArray = str.split("");

console.log(charArray); // ["h", "e", "l", "l", "o"]
```

:::

- **Méthode `reverse()`** : cette méthode inverse un tableau sur place.

:::interactive_editor

```js
const desserts = ["cake", "cookies", "pie"];
console.log(desserts.reverse()); // ["pie", "cookies", "cake"]
```

:::

- **Méthode `join()`** : cette méthode concatène tous les éléments d'un tableau en une seule chaîne, chaque élément étant séparé par un séparateur spécifié. Si aucun séparateur n'est fourni, ou si une chaîne vide (`""`) est utilisée, les éléments seront joints sans aucun séparateur.

:::interactive_editor

```js
const reversedArray = ["o", "l", "l", "e", "h"];
const reversedString = reversedArray.join("");

console.log(reversedString); // "olleh"
```

:::
