# --description--

Tu as peut-être remarqué que `EVAChunks` est essentiellement un tableau contenant des tableaux, c'est-à-dire un tableau à deux dimensions (2D). Une boucle `for` imbriquée peut être utilisée pour afficher les données d'un tableau 2D :

```js
for (let i = 0; i < rootArray.length; i++) {
  console.log(`Group ${i + 1}:`);
  for (let j = 0; j < rootArray[i].length; j++) {
    console.log(rootArray[i][j].property);
  }
}
```

Dans l'exemple ci-dessus, `rootArray` est le tableau principal, `rootArray[i]` est un sous-tableau à l'intérieur du tableau principal, et `rootArray[i][j]` est un objet à l'intérieur de ce sous-tableau, et `.property` accède à une valeur de cet objet.
