## Les listes Python

- **Introduction** : En Python, le type de données liste est une séquence ordonnée d'éléments qui peut être composée de chaînes, de nombres ou même d'autres listes. Les listes sont mutables et indexées à partir de zéro.

```python
cities = ['Los Angeles', 'London', 'Tokyo']
```

- **Accéder aux éléments d'une liste** : Pour accéder à un élément de la liste `cities`, tu peux indiquer son numéro d'indice dans la séquence :

```python
cities = ['Los Angeles', 'London', 'Tokyo']
cities[0] # Los Angeles
```

- **Accéder aux éléments avec l'indexation négative** : Pour accéder au dernier élément de n'importe quelle liste, tu peux utiliser `-1` comme numéro d'indice :

```python
cities = ['Los Angeles', 'London', 'Tokyo']
cities[-1] # Tokyo
```

- L'indexation négative sert à accéder aux éléments en partant de la fin de la liste plutôt que du début à l'indice `0`.

- **Créer des listes avec le constructeur `list()`** : Les listes peuvent aussi être créées avec le constructeur `list()`. Le constructeur `list()` sert à convertir un itérable en liste :

```python
developer = 'Jessica'

print(list(developer))
# Result: ['J', 'e', 's', 's', 'i', 'c', 'a']
```

- **Trouver la longueur d'une liste** : Tu peux utiliser la fonction `len()` pour obtenir la longueur d'une liste :

```python
numbers = [1, 2, 3, 4, 5]
len(numbers) # 5
```

- **Mutabilité des listes** : Les listes sont mutables, ce qui signifie que tu peux mettre à jour n'importe quel élément de la liste tant que tu fournis un numéro d'indice valide. Pour mettre à jour une liste à un indice donné, tu peux assigner une nouvelle valeur à cet indice :

```python
programming_languages = ['Python', 'Java', 'C++', 'Rust']
programming_languages[0] = 'JavaScript'
print(programming_languages) # ['JavaScript', 'Java', 'C++', 'Rust']
```

- **Erreur d'indice hors limites** : Si tu fournis un indice (positif ou négatif) qui dépasse les limites de la liste, tu recevras une `IndexError` :

```python
programming_languages = ['Python', 'Java', 'C++', 'Rust']
programming_languages[10] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: list assignment index out of range
"""
```

- **Retirer des éléments d'une liste** : Les éléments peuvent être retirés d'une liste avec le mot-clé `del` :

```python
developer = ['Jane Doe', 23, 'Python Developer']
del developer[1]
print(developer) # ['Jane Doe', 'Python Developer']
```

- **Vérifier si un élément existe dans une liste** : Le mot-clé `in` peut servir à vérifier si un élément existe dans une liste :

```py
programming_languages = ['Python', 'Java', 'C++', 'Rust']

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

- **Imbriquer des listes** : Les listes peuvent être imbriquées dans d'autres listes :

```python
developer = ['Alice', 25, ['Python', 'Rust', 'C++']]
```

- Pour accéder à la liste imbriquée, tu devras l'atteindre avec l'indice `2`, car les listes sont indexées à partir de zéro.

```python
developer = ['Alice', 25, ['Python', 'Rust', 'C++']]
developer[2] # ['Python', 'Rust', 'C++']
```

- Pour accéder ensuite au deuxième langage de cette liste imbriquée, tu devras l'atteindre avec l'indice `1` :

```python
developer = ['Alice', 25, ['Python', 'Rust', 'C++']]
developer[2][1] # Rust
```

- **Dépaquetage des valeurs d'une liste** : Dépaqueter les valeurs d'une liste est une technique qui consiste à assigner les valeurs d'une liste à de nouvelles variables. Voici un exemple pour dépaqueter la liste `developer` dans de nouvelles variables appelées `name`, `age` et `job` comme ceci :

```py
developer = ['Alice', 34, 'Rust Developer']
name, age, job = developer
```

- Si le nombre de variables à gauche de l'opérateur d'affectation ne correspond pas au nombre total d'éléments dans la liste, tu recevras une `ValueError`.

- **Collecter les éléments restants d'une liste** : Pour collecter les éléments restants d'une liste, tu peux utiliser l'opérateur astérisque (`*`) comme ceci :

```py
developer = ['Alice', 34, 'Rust Developer']
name, *rest = developer
```

- **Découpage des listes** : Le découpage consiste à accéder à une portion d'une liste avec l'opérateur de tranche `:`. Pour découper une liste qui commence à l'indice `1` et se termine avant l'indice `3`, tu peux utiliser la syntaxe suivante :

```python
desserts = ['Cake', 'Cookies', 'Ice Cream', 'Pie']
desserts[1:3] # ['Cookies', 'Ice Cream']
```

- **Intervalles de pas** : Il est aussi possible de spécifier un pas qui détermine de combien incrémenter entre les indices. Voici un exemple si tu veux extraire une liste contenant seulement les nombres pairs grâce au découpage :

```python
numbers = [1, 2, 3, 4, 5, 6]
numbers[1::2] # [2, 4, 6]
```

## Méthodes de liste

- **append()** : Sert à ajouter un élément à la fin de la liste. Voici un exemple d'utilisation de la méthode `append()` pour ajouter le nombre `6` à cette liste `numbers` :

```py
numbers = [1, 2, 3, 4, 5]
numbers.append(6)
print(numbers) # [1, 2, 3, 4, 5, 6]
```

- **Ajout de listes** : La méthode `append()` peut aussi servir à ajouter une liste à la fin d'une autre :

```py
numbers = [1, 2, 3, 4, 5]
even_numbers = [6, 8, 10]

numbers.append(even_numbers)
print(numbers) # [1, 2, 3, 4, 5, [6, 8, 10]]
```

- **extend()** : Sert à ajouter plusieurs éléments à la fin d'une liste. Voici un exemple d'ajout des nombres `6`, `8` et `10` à la fin de la liste `numbers` :

```py
numbers = [1, 2, 3, 4, 5]
even_numbers = [6, 8, 10]

numbers.extend(even_numbers)
print(numbers) # [1, 2, 3, 4, 5, 6, 8, 10]
```

- **insert()** : Sert à insérer un élément à un indice précis dans la liste. Voici un exemple d'utilisation de la méthode `insert()` :

```py
numbers = [1, 2, 3, 4, 5]
numbers.insert(2, 2.5)

print(numbers) # [1, 2, 2.5, 3, 4, 5]
```

- **remove()** : Sert à retirer un élément de la liste. La méthode `remove()` ne retire que la première occurrence d'un élément dans la liste :

```py
numbers = [1, 2, 3, 4, 5, 5, 5]
numbers.remove(5)

print(numbers) # [1, 2, 3, 4, 5, 5]

```

- **pop()** : Sert à retirer un élément précis de la liste et à le renvoyer :

```py
numbers = [1, 2, 3, 4, 5]
numbers.pop(1) # The number 2 is returned
```

- Si tu ne spécifies pas d'élément pour la méthode `pop`, alors le dernier élément est retiré.

```py
numbers = [1, 2, 3, 4, 5]
numbers.pop() # The number 5 is returned
```

- **clear()** : Sert à retirer tous les éléments de la liste :

```py
numbers = [1, 2, 3, 4, 5]
numbers.clear()

print(numbers) # []
```

- **sort()** : La méthode `sort()` sert à trier les éléments en place. Voici un exemple de tri en place d'une liste aléatoire de `numbers` :

```py
numbers = [19, 2, 35, 1, 67, 41]
numbers.sort()

print(numbers) # [1, 2, 19, 35, 41, 67]
```

- **sorted()** : Une fonction intégrée qui renvoie une nouvelle liste triée au lieu de modifier la liste d'origine :

```py
numbers = [19, 2, 35, 1, 67, 41]
sorted_numbers = sorted(numbers)

print(sorted_numbers) # [1, 2, 19, 35, 41, 67]
print(numbers) # [19, 2, 35, 1, 67, 41]
```

- **reverse()** : Sert à inverser l'ordre des éléments d'une liste :

```py
numbers = [6, 5, 4, 3, 2, 1]
numbers.reverse()

print(numbers) # [1, 2, 3, 4, 5, 6]
```

- **index()** : Sert à trouver le premier indice où un élément se trouve dans une liste :

```python
programming_languages = ['Rust', 'Java', 'Python', 'C++']
programming_languages.index('Java') # 1
```

- Si l'élément ne peut pas être trouvé avec la méthode `index()`, le résultat sera une `ValueError`.

## Les tuples en Python

- **Définition** : Un tuple est un type de données Python utilisé pour créer une séquence ordonnée de valeurs. Les tuples peuvent contenir un ensemble mixte de types de données :

```py
developer = ('Alice', 34, 'Rust Developer')
```

- Les tuples sont immuables, ce qui signifie que les éléments du tuple ne peuvent pas être modifiés une fois créés. Si tu essaies de mettre à jour l'un des éléments du tuple, tu obtiendras une `TypeError` :

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: "tuple" object does not support item assignment
"""
```

- **Accéder aux éléments d'un tuple** : Pour accéder à un élément d'un tuple, utilise la notation crochets et le numéro d'indice :

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

- L'indexation négative peut servir à accéder aux éléments en partant de la fin du tuple :

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

- Si tu essaies de fournir un numéro d'indice qui dépasse ou égale la longueur du tuple, tu recevras une `IndexError` :

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: tuple index out of range
"""
```

- Un tuple peut aussi être créé avec le constructeur `tuple()`. Dans le constructeur, tu peux passer différents itérables comme des chaînes, des listes et même d'autres tuples.

```python
developer = 'Jessica'

print(tuple(developer))
# Result: ('J', 'e', 's', 's', 'i', 'c', 'a')
```

- **Vérifier la présence d'éléments dans un tuple** : Pour vérifier si un élément est dans un tuple, tu peux utiliser le mot-clé `in` comme ceci :

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

- **Dépaquetage des tuples** : Les éléments peuvent être dépaquetés d'un tuple comme ceci :

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer
```

- Si tu as besoin de collecter les éléments restants d'un tuple, tu peux utiliser l'opérateur astérisque (`*`) comme ceci :

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer
```

- **Découpage des tuples** : Le découpage peut servir à extraire une portion d'un tuple. Par exemple, les éléments `pie` et `cookies` peuvent être découpés dans un tuple séparé :

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

- **Retirer des éléments d'un tuple** : Retirer un élément d'un tuple lèvera une `TypeError` car les tuples sont immuables :

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

- **Quand utiliser un tuple plutôt qu'une liste ?** : Si tu as besoin d'une collection dynamique d'éléments où tu peux ajouter, retirer et mettre à jour des éléments, alors tu dois utiliser une liste. Si tu sais que tu travailles avec une collection de données fixe et immuable, alors tu dois utiliser un tuple.

## Méthodes courantes des tuples

- **`count()`** : Sert à déterminer combien de fois un élément apparaît dans un tuple. Par exemple, tu peux vérifier combien de fois le langage `'Rust'` apparaît dans le tuple :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.count('Rust') # 2
```

- Si l'élément indiqué dans la méthode `count()` n'est pas du tout présent dans le tuple, alors la valeur renvoyée sera `0` :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.count('JavaScript') # 0
```

- Si aucun argument n'est passé à la méthode `count()`, alors Python renverra une `TypeError`.

- **index()** : Sert à trouver l'indice où un élément particulier est présent dans le tuple. Voici un exemple d'utilisation de la méthode `index()` pour trouver l'indice du langage `'Java'` :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.index('Java') # 1
```

- Si l'élément indiqué ne peut pas être trouvé, alors Python renverra une `ValueError`.

- Tu peux passer un indice de début optionnel à la méthode `index()` pour indiquer où commencer la recherche de l'élément dans le tuple :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python')
programming_languages.index('Python', 3) # 5
```

- Tu peux aussi passer un indice de fin optionnel à la méthode `index()` pour indiquer où arrêter la recherche de l'élément dans le tuple :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python', 'JavaScript', 'Python')
programming_languages.index('Python', 2, 5) # 2
```

- **`sorted()`** : Sert à trier les éléments de n'importe quel itérable et à renvoyer une nouvelle liste triée. Voici un exemple de création d'une nouvelle liste de nombres avec la fonction `sorted()` :

```py
numbers = (13, 2, 78, 3, 45, 67, 18, 7)
sorted(numbers) # [2, 3, 7, 13, 18, 45, 67, 78]
```

- **Modifier le comportement du tri** : Tu peux personnaliser le comportement du tri d'un itérable avec les arguments optionnels `reverse` et `key`. Voici un exemple d'utilisation de l'argument `key` pour trier les éléments d'un tuple par longueur :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python')
sorted(programming_languages, key=len)

# Result
# ['C++', 'Rust', 'Java', 'Rust', 'Python', 'Python']
```

- Tu peux créer une nouvelle liste de valeurs dans l'ordre inverse, avec l'argument `reverse` comme ceci :

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python')

print(sorted(programming_languages, reverse=True))

# Result
# ['Rust', 'Rust', 'Python', 'Python', 'Java', 'C++']
```

## Les boucles en Python

- **Définition** : Les boucles servent à répéter un bloc de code un nombre défini de fois.

- **Boucle `for`** : Sert à parcourir une séquence (comme une liste, un tuple ou une chaîne) et à exécuter un bloc de code pour chaque élément de cette séquence. Voici un exemple d'utilisation d'une boucle `for` pour parcourir une liste et afficher chaque langage dans la console :

```py
programming_languages = ['Rust', 'Java', 'Python', 'C++']

for language in programming_languages:
    print(language)

"""
Result

Rust
Java
Python
C++
"""
```

- Voici un exemple d'utilisation d'une boucle `for` pour parcourir la chaîne `code` et afficher chaque caractère :

```py
for char in 'code':
    print(char)

"""
Result

c
o
d
e
"""
```

- Les boucles `for` peuvent être imbriquées. Voici un exemple d'utilisation d'une boucle `for` imbriquée :

```py
categories = ['Fruit', 'Vegetable']
foods = ['Apple', 'Carrot', 'Banana']

for category in categories:
    for food in foods:
        print(category, food)

"""
Result

Fruit Apple
Fruit Carrot
Fruit Banana
Vegetable Apple
Vegetable Carrot
Vegetable Banana
"""

```

- **Boucle `while`** : Répète un bloc de code jusqu'à ce que la condition soit `False`. Voici un exemple d'utilisation d'une boucle `while` pour un jeu de devinettes :

```py
secret_number = 3
guess = 0

while guess != secret_number:
    guess = int(input('Guess the number (1-5): '))
    if guess != secret_number:
        print('Wrong! Try again.')

print('You got it!')

"""
Result

Guess the number (1-5): 2
Wrong! Try again.
Guess the number (1-5): 1
Wrong! Try again.
Guess the number (1-5): 3
You got it!
"""

```

- **Instructions `break` et `continue`** : Utilisées dans les boucles pour modifier l'exécution d'une boucle.

- L'instruction `break` sert à quitter la boucle immédiatement quand une certaine condition est remplie. Voici un exemple d'utilisation de l'instruction `break` pour une liste de `developer_names` :

```py
developer_names = ['Jess', 'Naomi', 'Tom']

for developer in developer_names:
    if developer == 'Naomi':
        break
    print(developer)
```

- L'instruction `continue` sert à sauter l'itération courante et à passer à l'itération suivante de la boucle. Voici un exemple pour utiliser l'instruction `continue` à la place d'une instruction `break` :

```py
developer_names = ['Jess', 'Naomi', 'Tom']

for developer in developer_names:
    if developer == 'Naomi':
        continue
    print(developer)
```

- Les boucles `for` et `while` peuvent toutes les deux être combinées avec une clause `else`, qui n'est exécutée que lorsque la boucle n'a pas été interrompue par un `break` :

```python
words = ['sky', 'apple', 'rhythm', 'fly', 'orange']

for word in words:
    for letter in word:
        if letter.lower() in 'aeiou':
            print(f"'{word}' contains the vowel '{letter}'")
            break
    else:
        print(f"'{word}' has no vowels")
```

## Les ranges et leur utilisation dans les boucles

- **La fonction `range()`** : Sert à générer une séquence d'entiers.

```py
range(start, stop, step)
```

- L'argument obligatoire `stop` est un entier (non inclus) qui représente le point de fin de la séquence de nombres générée. Voici un exemple d'utilisation de la fonction `range()` :

```py
for num in range(3):
    print(num)
```

- Si un argument `start` n'est pas spécifié, alors la valeur par défaut sera `0`. Par défaut, la séquence d'entiers s'incrémente de `1`. Tu peux utiliser l'argument optionnel `step` pour changer la valeur d'incrément par défaut. Voici un exemple de génération d'une séquence d'entiers pairs de 2 jusqu'à 11 non inclus (c'est-à-dire qu'elle inclut 10).

```py
for num in range(2, 11, 2):
    print(num)
```

- Si tu ne fournis aucun argument à la fonction `range()`, tu obtiendras une `TypeError`.

- La fonction `range()` n'accepte que des entiers comme arguments, pas des flottants. Utiliser des flottants produira aussi une `TypeError` :

```py
ERROR!
Traceback (most recent call last):
  File "<main.py>", line 1, in <module>
TypeError: 'float' object cannot be interpreted as an integer
```

- Tu peux utiliser un entier négatif pour l'argument `step` afin de générer une séquence d'entiers dans l'ordre décroissant :

```py
for num in range(40, 0, -10):
    print(num)
```

- La fonction `range()` peut aussi servir à créer une liste d'entiers en l'utilisant avec le constructeur `list`. Le constructeur `list` sert à convertir un itérable en liste. Voici un exemple de génération d'une liste d'entiers pairs entre 2 et 10 inclus :

```py
numbers = list(range(2, 11, 2))
print(numbers) # [2, 4, 6, 8, 10]
```

## Les fonctions `enumerate()` et `zip()` en Python

- **`enumerate()`** : Sert à parcourir une séquence en suivant l'indice de chaque élément de cette séquence. La fonction `enumerate()` prend un itérable comme argument et renvoie un objet `enumerate` composé de l'indice et de la valeur de chaque élément de l'itérable.

```python
languages = ['Spanish', 'English', 'Russian', 'Chinese']

for index, language in enumerate(languages):
    print(f'Index {index} and language {language}')

# Result
# Index 0 and language Spanish
# Index 1 and language English
# Index 2 and language Russian
# Index 3 and language Chinese

```

- La fonction `enumerate()` peut aussi être utilisée en dehors d'une boucle `for` :

```python
languages = ['Spanish', 'English', 'Russian', 'Chinese']

print(list(enumerate(languages)))
# [(0, 'Spanish'), (1, 'English'), (2, 'Russian'), (3, 'Chinese')]
```

- La fonction `enumerate()` accepte aussi un argument optionnel `start` qui indique la valeur de départ du compteur. Si cet argument est omis, alors le compteur commencera à `0`.

- **`zip()`** : Sert à parcourir plusieurs itérables en parallèle. Voici un exemple d'utilisation de la fonction `zip()` pour parcourir `developers` et `ids` :

```python
developers = ['Naomi', 'Dario', 'Jessica', 'Tom']
ids = [1, 2, 3, 4]

for name, id in zip(developers, ids):
    print(f'Name: {name}')
    print(f'ID: {id}')


"""
Result

Name: Naomi
ID: 1
Name: Dario
ID: 2
Name: Jessica
ID: 3
Name: Tom
ID: 4
"""

```

## Les compréhensions de listes en Python

- **Définition** : Une compréhension de liste te permet de créer une nouvelle liste en une seule ligne en combinant la boucle et la condition directement entre crochets. Cela rend le code plus court et souvent plus facile à lire.

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

## Méthodes d'itérables

- **`filter()`** : Sert à filtrer les éléments d'un itérable selon une condition. Elle renvoie un itérateur qui ne contient que les éléments qui satisfont la condition. Voici un exemple de création d'une nouvelle liste contenant seulement les mots de plus de quatre caractères :

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

- **`map()`** : Sert à appliquer une fonction à chaque élément d'un itérable et à renvoyer un nouvel itérable avec les résultats. Voici un exemple d'utilisation de la fonction `map()` pour convertir une liste de températures Celsius en Fahrenheit :

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

- **`sum()`** : Sert à obtenir la somme d'un itérable comme une liste ou un tuple. Voici un exemple d'utilisation de la fonction `sum()` :

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

- Tu peux aussi passer un argument optionnel `start` qui définit la valeur initiale de la sommation. Voici un exemple mis à jour qui utilise l'argument `start` comme argument positionnel :

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

- Tu peux aussi choisir d'utiliser l'argument `start` comme argument nommé comme ceci à la place :

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

## Les fonctions lambda

- **Définition** : Une fonction lambda en Python est une façon concise de créer une fonction sans nom (une fonction anonyme).
- Les fonctions lambda sont souvent utilisées comme argument d'une autre fonction. Voici un exemple de fonction lambda :

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

- Les bonnes pratiques d'utilisation des fonctions lambda consistent à ne pas les assigner à une variable, à les garder simples et lisibles, et à les utiliser pour des fonctions courtes et ponctuelles.
