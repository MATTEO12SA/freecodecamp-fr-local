# --description--

Tu devrais maintenant voir une seule carte affichée sur la page. Mais il manque un élément dans le composant `Card`.

Comme tu te souviens des leçons précédentes, c'est une bonne pratique d'inclure une prop `key` lors de l'affichage d'une liste de composants comme ceci :

```jsx
<div>
  {fruits.map(fruit => (
    <Card
      key={fruit.id}
      name={fruit.name}
      color={fruit.color}
    />
  ))}
</div>
```

La prop `key` aide React à identifier quels éléments ont changé, sont ajoutés ou sont retirés. Cela améliore la performance et permet des mises à jour plus efficaces.

Mets à jour le composant `Card` pour inclure une prop `key` avec la valeur de `profile.id`.
