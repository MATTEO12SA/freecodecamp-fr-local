# --interactive--

Dans la leçon précédente, tu as appris à travailler avec l'objet `Date` en JavaScript. Mais il y a plusieurs façons de formater les dates en JavaScript.

Dans cette leçon, nous allons voir comment travailler avec les méthodes `toISOString()`, `toString()` et `toLocaleDateString()` pour formater les dates en JavaScript.

Avant de regarder les différentes méthodes, revoyons d'abord à quoi ressemble l'objet `Date` :

:::interactive_editor

```js
const date = new Date();
console.log(date);
```

:::

Quand tu affiches l'objet `date` dans la console, tu verras la date et l'heure actuelles basées sur les paramètres système de l'utilisateur. Voici un exemple de la sortie que tu pourrais voir :

```js
Sun Sep 29 2024 19:45:37 GMT-0700 (Pacific Daylight Time)
```

Si tu utilisais la méthode `toString()` sur l'objet `date`, tu verrais la même sortie que ci-dessus.

Pour formater la date dans un format ISO étendu (ISO 8601), tu peux utiliser la méthode `toISOString()` comme ceci :

:::interactive_editor

```js
const date = new Date();
console.log(date.toISOString());
```

:::

ISO 8601 est une norme internationale pour représenter les dates et heures. Le format est `YYYY-MM-DDTHH:mm:ss.sssZ`.

Voici un exemple de la sortie que tu pourrais voir :

```js
2024-09-30T02:47:20.292Z
```

Une autre façon de formater la date serait d'utiliser la méthode `toLocaleDateString()`. Cette méthode te permet de formater la date selon la locale de l'utilisateur. Voici la syntaxe de base pour utiliser la méthode `toLocaleDateString()` :

:::interactive_editor

```js
const date = new Date();
console.log(date.toLocaleDateString());
```

:::

Voici un exemple de la sortie que tu pourrais voir :

```js
9/29/2024
```

La méthode `toLocaleDateString()` accepte deux paramètres optionnels : `locales` et `options`.

Le paramètre `locales` est une chaîne représentant la locale à utiliser. Par exemple, tu peux passer `en-US` pour l'anglais (États-Unis) ou `fr-FR` pour le français (France). Si tu ne passes pas de paramètre `locales`, la locale par défaut est utilisée. Voici un exemple d'utilisation du paramètre `locales` :

:::interactive_editor

```js
const date = new Date();
console.log(date.toLocaleDateString("fr-FR"));
```

:::

Le second paramètre optionnel est le paramètre `options`. Ce paramètre est un objet qui te permet de spécifier le format de la chaîne de date. Voici un exemple d'utilisation du paramètre `options` :

:::interactive_editor

```js
const date = new Date();
const options = {
  weekday: "long",
  year: "numeric",
  month: "long",
  day: "numeric",
};
console.log(date.toLocaleDateString("en-GB", options));
```

:::

Dans l'exemple ci-dessus, nous avons spécifié les options pour l'anglais (Grande-Bretagne) et pour inclure le jour de la semaine complet, l'année, le mois et le jour.

Voici un exemple de la sortie que tu pourrais voir :

```js
Sunday, September 29, 2024
```

Dans cette leçon, nous n'avons couvert que quelques façons de formater les dates en JavaScript. Il existe bien d'autres méthodes et bibliothèques pour t'aider à formater les dates en JavaScript. Mais les méthodes `toISOString()` et `toLocaleDateString()` sont un bon point de départ pour formater les dates en JavaScript.
