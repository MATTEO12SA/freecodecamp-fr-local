# --interactive--

Les dates et heures en JavaScript n'ont pas toujours été faciles à manipuler. Dans une base de code professionnelle, tu utiliseras probablement une bibliothèque qui a résolu beaucoup de ces problèmes pour toi.

Mais il y aura des moments où tu auras besoin de travailler avec l'objet `Date` intégré de JavaScript.

Dans cette leçon, nous allons couvrir les bases de l'objet `Date` et certaines des méthodes les plus courantes que tu utiliseras lorsque tu travailleras avec les dates et heures en JavaScript.

L'objet `Date` est un objet intégré de JavaScript qui te permet de travailler avec les dates et heures. Voici la syntaxe de base pour créer un nouvel objet `Date` :

```js
const now = new Date();
```

Le mot-clé `new` sert à créer une nouvelle instance de l'objet `Date`, et l'objet `Date` est ensuite assigné à la variable `now`. Si tu affichais la valeur de `now` dans la console, tu verrais la date et l'heure actuelles basées sur l'horloge système de l'ordinateur qui exécute le code.

Voici un exemple de réponse que tu verrais si tu affichais la valeur de `now` dans la console :

:::interactive_editor

```js
const now = new Date();
console.log(now);
```

:::

Pour l'heure, elle utilise le format 24 heures, donc `14:30` correspond à `2:30 PM`. `GMT-0700` est le décalage horaire, et `Pacific Daylight Time` est le nom du fuseau horaire.

Tu peux aussi passer une date et une heure spécifiques à l'objet `Date` en fournissant l'année, le mois, le jour, l'heure, la minute, la seconde et la milliseconde comme arguments.

Voici un exemple de création d'un nouvel objet `Date` avec une date et une heure spécifiques :

:::interactive_editor

```js
const specificDate = new Date("July 4, 1776 12:00:00");

console.log(specificDate);
```

:::

C'est utile quand tu as besoin de travailler avec une date et une heure spécifiques plutôt que la date et l'heure actuelles. L'entrée doit toujours être une chaîne, et le format doit être reconnaissable par l'objet `Date`.

Pour obtenir la date et l'heure actuelles, tu peux utiliser la méthode `Date.now()`, qui renvoie le nombre de millisecondes depuis `January 1, 1970, 00:00:00 UTC`. C'est ce qu'on appelle le temps Unix epoch.

Le temps Unix epoch est une façon courante de représenter les dates et heures dans les systèmes informatiques, car c'est un entier qui peut être facilement stocké et manipulé. UTC signifie Universal Time Coordinated (temps universel coordonné), qui est le standard horaire principal selon lequel le monde règle les horloges et le temps.

Si tu as besoin d'obtenir un jour du mois basé sur la date actuelle, tu peux utiliser la méthode `getDate`. Voici un exemple d'utilisation de la méthode `getDate` :

:::interactive_editor

```js
const now = new Date();
const date = now.getDate();
console.log(date);
```

:::

Dans cet exemple, nous créons une nouvelle instance de date avec l'objet `Date` et l'assignons à la variable `now`. Nous appelons ensuite la méthode `getDate` sur l'objet `now` pour obtenir le jour du mois et l'assignons à la variable `date`. Enfin, nous affichons la valeur de `date` dans la console, qui affichera le jour actuel du mois.

`getDate` renverra une valeur entière entre `1` et `31`, selon le jour du mois. Si la date est invalide, elle renverra `NaN` (Not a Number).

Pour obtenir le mois, tu peux utiliser la méthode `getMonth` comme ceci :

:::interactive_editor

```js
const now = new Date();
const month = now.getMonth();
console.log(month);
```

:::

Le mois est indexé à partir de zéro, donc `January` est `0`, `February` est `1`, et ainsi de suite. Si le mois est invalide, elle renverra `NaN`.

Si tu as besoin d'obtenir l'année complète, tu peux utiliser la méthode `getFullYear` comme ceci :

:::interactive_editor

```js
const now = new Date();
const year = now.getFullYear();
console.log(year);
```

:::

Si l'année est invalide, elle renverra `NaN`.

Il existe bien d'autres méthodes disponibles sur l'objet `Date`, notamment `getHours`, `getMinutes`, `getSeconds`, et ainsi de suite. Je t'encourage à en explorer d'autres par toi-même via la documentation de Mozilla ou d'autres ressources.
