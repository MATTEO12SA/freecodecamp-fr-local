# --description--

Les apps React s'appuient souvent sur des API externes et des bases de données pour du contenu dynamique. Pour accéder aux données de ces API et bases, tu dois utiliser des techniques de récupération de données.

Voyons comment la récupération de données fonctionne en React et les différentes options à ta disposition pour récupérer des données.

React n'impose pas comment tu récupères tes données : à un niveau basique, tu peux utiliser l'API Fetch intégrée, supportée par tous les navigateurs modernes.

Tu peux aussi utiliser Axios et SWR. Axios est une bibliothèque de requêtes HTTP basée sur les promesses, construite sur l'objet XMLHttpRequest, et SWR est un Hook React de récupération de données créé par l'équipe Vercel.

Commençons par un exemple. Tu dois d'abord importer les Hooks `useState` et `useEffect` :

```js
import { useState, useEffect } from "react";
```

Ensuite tu dois créer trois variables d'état appelées `loading`, `data` et `error` :

```js
const [data, setData] = useState(null);
const [loading, setLoading] = useState(true);
const [error, setError] = useState(null);
```

La variable `loading` indique si les données sont encore en cours de récupération. La variable `data` représente les données elles-mêmes, et la variable `error` capturera toute erreur pouvant survenir pendant la récupération.

Comme la récupération de données est un effet de bord, il vaut mieux utiliser l'API Fetch dans un Hook `useEffect`.

Voici un exemple :

```js
useEffect(() => {
  fetch("https://jsonplaceholder.typicode.com/posts")
    .then((res) => res.json())
    .then((data) => {
      setData(data);
      setLoading(false);
    })
    .catch((err) => {
      setError(err);
      setLoading(false);
    });
}, []);
```

Ce `useEffect` récupère les données avec l'API Fetch et met à jour tous les états.

Tu peux améliorer ça en utilisant `async`/`await` au lieu de la syntaxe `.then()`. Cela signifie que tu dois avoir une fonction séparée dans le `useEffect`, car tu ne peux pas préfixer `useEffect` avec le mot-clé `async` :

```js
useEffect(() => {
  const fetchData = async () => {
    try {
      const res = await fetch("https://jsonplaceholder.typicode.com/posts");

      if (!res.ok) {
        throw new Error("Network response was not ok");
      }

      const data = await res.json();
      setData(data);
    } catch (err) {
      setError(err);
    } finally {
      setLoading(false);
    }
  };

  fetchData();
}, []);
```

Tu peux ensuite utiliser tous ces états pour afficher les données de l'API.

Voici le code complet :

```jsx
import { useState, useEffect } from "react";

const FetchPosts = () => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const res = await fetch("https://jsonplaceholder.typicode.com/posts");

        if (!res.ok) {
          throw new Error("Network response was not ok");
        }

        const data = await res.json();
        setData(data);
      } catch (err) {
        setError(err);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, []);

  if (loading) {
    return <p>Loading...</p>;
  }

  if (error) {
    return <p>{error.message}</p>;
  }

  return (
    <ul>
      {data.map((post) => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  );
};

export default FetchPosts;
```

Dans l'UI, tu verrais `Loading...` à l'écran pendant la récupération, puis les données ou l'erreur selon le succès de la récupération.

Souviens-toi qu'on a aussi parlé de récupération avec Axios et SWR. Voyons un exemple avec Axios.

Tu dois d'abord installer Axios depuis la ligne de commande comme ceci :

```sh
npm i axios
```

Ensuite tu dois importer Axios comme ceci :

```js
import axios from "axios";
```

Puis tu peux utiliser les mêmes variables d'état qu'avant et récupérer les données de l'API avec `axios.get` :

```js
const [data, setData] = useState(null);
const [loading, setLoading] = useState(true);
const [error, setError] = useState(null);

useEffect(() => {
  const fetchData = async () => {
    try {
      const res = await axios.get(
        "https://jsonplaceholder.typicode.com/users"
      );
      setData(res.data);
    } catch (err) {
      setError(err);
    } finally {
      setLoading(false);
    }
  };

  fetchData();
}, []);
```

Tu as peut-être remarqué qu'il n'y a pas de ligne `await res.json()` dans cet exemple. C'est parce qu'Axios parse automatiquement le JSON, donc ce n'est pas nécessaire.

Le dernier exemple que nous verrons utilise le Hook `useSWR` pour récupérer des données.

Comme avec Axios, tu dois installer SWR comme ceci :

```sh
npm install swr
```

Ensuite tu dois importer le Hook `useSWR` dans le fichier comme ceci :

```js
import useSWR from "swr";
```

Par rapport aux exemples précédents, la syntaxe SWR est bien plus courte. Tu dois créer une fonction fetcher et la passer au Hook `useSWR` comme second paramètre (l'endpoint est le premier).

Tu peux aussi destructurer les états data et error depuis le Hook `useSWR`, donc tu n'as pas besoin du Hook `useState`.

Voici la syntaxe :

```js
const fetcher = (url) => fetch(url).then((res) => res.json());
const { data, error } = useSWR(endpoint, fetcher);
```

Note que le nom « fetcher » ici n'est qu'une convention, tu es libre de nommer la variable comme tu veux.

Voici un composant qui récupère des todos depuis l'API JSON Placeholder :

```jsx
import useSWR from "swr";

const fetcher = (url) => fetch(url).then((res) => res.json());

const FetchTodos = () => {
  const { data, error } = useSWR(
    "https://jsonplaceholder.typicode.com/todos",
    fetcher
  );

  if (!data) {
    return <h2>Loading...</h2>;
  }
  if (error) {
    return <h2>Error: {error.message}</h2>;
  }

  return (
    <>
      <h2>Todos</h2>
      <div>
        {data.map((todo) => (
          <h3 key={todo.id}>{todo.title}</h3>
        ))}
      </div>
    </>
  );
};

export default FetchTodos;
```

Comme tu l'as appris dans une leçon précédente sur les Hooks personnalisés, la récupération de données est une logique que tu peux extraire dans un Hook personnalisé. Donc, si tu récupères des données dans plusieurs composants et pages, il vaut mieux créer un Hook `useFetch`.

Voici un Hook `useFetch` qui utilise SWR pour la récupération de données :

```jsx
import useSWR from "swr";

const fetcher = (url) => fetch(url).then((res) => res.json());

const useFetch = (url) => {
  const { data, error } = useSWR(url, fetcher);

  return {
    data,
    loading: !data && !error,
    error,
  };
};

export default useFetch;
```

Et voici comment utiliser le Hook `useFetch` pour réécrire le premier exemple qui récupère des posts depuis l'API JSON Placeholder :

```jsx
import useFetch from "./useFetch";

const FetchPosts = () => {
  const { data, loading, error } = useFetch(
    "https://jsonplaceholder.typicode.com/posts"
  );

  if (loading) {
    return <h2>Loading...</h2>;
  }

  if (error) {
    return <h2>{error.message}</h2>;
  }

  return (
    <>
      <h2>Posts</h2>
      <ul>
        {data.map((post) => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </>
  );
};

export default FetchPosts;
```
