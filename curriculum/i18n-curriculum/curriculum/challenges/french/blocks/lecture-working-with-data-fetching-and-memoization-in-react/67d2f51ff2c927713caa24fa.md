# --description--

Dans la leçon précédente, tu as appris la mémoïsation et le fonctionnement du Hook `useMemo`.

Dans cette leçon, tu apprendras comment le Hook `useCallback` et `React.memo` fonctionnent.

Dans la leçon précédente, on a aussi mentionné que `useCallback` sert à mémoïser des références de fonctions.

Pour `React.memo`, il te laisse mémoïser un composant pour éviter des re-rendus inutiles quand sa prop n'a pas changé.

Voici la syntaxe de base du Hook `useCallback` :

```js
const handleClick = useCallback(() => {
  // code goes here
}, [dependency]);
```

Et voici la syntaxe de base de `React.memo` :

```jsx
const MemoizedComponent = React.memo(({ prop }) => {
  return (
    <>
      {/* Presentation */}
    </>
  )
});
```

Voyons un exemple du Hook `useCallback` :

```jsx
import { useState, useEffect } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  const handleClick = () => {
    setCount((prevCount) => prevCount + 1);
  };

  useEffect(() => {
    console.log("useEffect runs");
  }, [handleClick]);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={handleClick}>Increment</button>
    </div>
  );
}

export default Counter;
```

Dans le composant, l'effet s'exécute à chaque fois que `handleClick` change parce que la fonction `handleClick` est recréée à chaque rendu.

Pour corriger ça, tu dois dire à React de traiter la fonction `handleClick` comme la même chose d'un rendu à l'autre en la mémoïsant avec le Hook `useCallback`, pour qu'elle ne soit pas recréée :

```jsx
import { useState, useEffect, useCallback } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  // Memoize the handleClick function with useCallback
  const handleClick = useCallback(() => {
    setCount((prevCount) => prevCount + 1);
  }, []);

  useEffect(() => {
    console.log("useEffect runs");
  }, [handleClick]);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={handleClick}>Increment</button>
    </div>
  );
}

export default Counter;
```

Maintenant la fonction `handleClick` n'est plus recréée à chaque rendu.

Pour te montrer comment la higher-order function `React.memo` (ou `memo`) et le Hook `useCallback` fonctionnent ensemble, voici un composant `Counter` avec une fonction `handleClick` qui a besoin de `useCallback` mais ne l'utilise pas encore :

```jsx
import { useState, useEffect, useCallback } from "react";
import CounterChild from "./CounterChild";

function Counter() {
  const [count, setCount] = useState(0);
  const [timer, setTimer] = useState(new Date().toLocaleTimeString());

  const handleClick = () => {
    setCount(count + 1);
  };

  useEffect(() => {
    const interval = setInterval(() => {
      setTimer(new Date().toLocaleTimeString());
    }, 1000);

    return () => clearInterval(interval);
  }, []);

  return (
    <div>
      <h1>Time: {timer}</h1>
      <p>Count: {count}</p>
      <button onClick={handleClick}>Increment</button>
      <CounterChild onClick={handleClick} />
    </div>
  );
}

export default Counter;
```

Cette fonction a aussi un timer dans l'état qui se met à jour chaque seconde. Cela fait re-rendre le composant à chaque changement de `timer`, ce qui recrée la fonction `handleClick` à chaque rendu.

C'est pourquoi `handleClick` doit être mémoïsé avec `useCallback`.

Voici le composant `CounterChild` :

```jsx
const CounterChild = ({ onClick }) => {
  console.log("CounterChild component rendered");
  return <button onClick={onClick}>Increment from Child</button>;
};

export default CounterChild;
```

Ce composant `CounterChild` prend une prop `onClick`, ce qui te permet aussi d'incrémenter le compteur depuis lui.

Comme `CounterChild` est un enfant de `Counter`, il se rendra aussi chaque fois que `Counter` se re-rend à cause du timer qui change. Donc `CounterChild` doit aussi être mémoïsé.

Sans mémoïsation, parce que le composant se re-rend à cause du timer qui se met à jour chaque seconde, le composant `CounterChild` est aussi re-rendu.

Pour l'éviter, tu dois mémoïser le composant `CounterChild` avec `React.memo` :

```jsx
import React from "react";

const CounterChild = React.memo(({ onClick }) => {
  console.log("CounterChild component rendered");
  return <button onClick={onClick}>Increment from Child</button>;
});

export default CounterChild;
```

Les choses ne fonctionnent pas encore de façon optimale même après avoir mémoïsé `CounterChild` avec `React.memo`.

Cela arrive parce que la fonction `handleClick` est recréée à chaque rendu, donc elle doit aussi être mémoïsée avec `useCallback`, pour dire à React que tu as besoin que la fonction reste la même d'un rendu à l'autre :

```js
const handleClick = useCallback(() => {
  setCount((prevCount) => prevCount + 1);
}, [count]);
```

Maintenant, le composant ne se re-rend que quand l'état `count` change.
