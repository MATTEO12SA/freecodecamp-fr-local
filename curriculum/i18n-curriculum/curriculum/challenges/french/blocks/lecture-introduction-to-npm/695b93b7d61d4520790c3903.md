# --description--

Quand tu construis des projets en JavaScript, tu as souvent besoin d'outils supplémentaires pour t'aider à avancer. Même des apps simples peuvent nécessiter des fonctionnalités comme sauvegarder des données, se connecter, router pour naviguer entre les pages, et ainsi de suite.

Au lieu d'écrire tout ce code de zéro, tu peux utiliser des paquets open source que d'autres développeurs ont déjà construits et partagés.

C'est là qu'intervient npm. npm est un énorme registre en ligne de logiciels open source. Pense-y comme un app store pour le code — tu peux chercher ce dont tu as besoin, l'installer, et commencer à l'utiliser dans ton projet.

Beaucoup de gens pensent que npm signifie « Node Package Manager », mais ce n'est pas sa signification officielle. Dans d'anciennes documentations npm, il était décrit comme une « abréviation bacronymique récursive pour 'npm is not an acronym.' » En d'autres termes, npm ne signifie officiellement rien.

Aujourd'hui, npm désigne trois parties liées :

* Le site web npmjs.com, où tu peux chercher des paquets dans le registre.

* Le registre npm, qui est une grande base de données publique qui stocke tous les paquets.

* L'outil CLI npm installé avec Node.js et qui te permet d'installer et de gérer des paquets.

Par exemple, si tu as besoin de gérer l'état, manipuler des dates, envoyer des e-mails ou faire des requêtes HTTP dans ton projet, il y a probablement un paquet npm qui le fait déjà. Avec une simple commande `npm install`, tu peux commencer à utiliser ce logiciel prêt à l'emploi au lieu de tout faire toi-même.

npm t'aide aussi à gérer les dépendances de ton projet. Cela signifie qu'il suit les paquets que tu utilises dans tes projets, et la version de chacun de ces paquets. Il le fait avec les fichiers `package.json` et `package-lock.json`, que tu découvriras dans de prochaines leçons.

Yarn, PNPM et Bun sont des alternatives à npm qui sont devenues populaires avec le temps. Bien que chacune offre des avantages dans des domaines précis comme la vitesse d'installation et l'efficacité du stockage, npm reste le plus largement utilisé.

Dans les prochaines leçons, tu apprendras diverses commandes npm, comment installer des paquets, les fichiers `package.json` et `package-lock.json`, et même comment publier ton propre paquet sur le registre npm.
