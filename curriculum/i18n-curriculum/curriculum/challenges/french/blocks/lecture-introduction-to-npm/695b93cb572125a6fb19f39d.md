# --description--

Garder tes dépendances à jour—et savoir comment installer une version spécifique—est important pour garder ton projet stable. Cela t'aide à éviter des bugs inattendus et te donne plus de contrôle quand de nouvelles versions sont publiées.

Pour installer une version spécifique d'un paquet, utilise ce format :

```bash
npm install package@version-number
```

Par exemple, si ton projet a besoin d'une ancienne version d'Express, disons `4.21.2`, tu peux l'installer comme ceci :

```bash
npm install express@4.21.2
```

Si tu n'inclus pas de numéro de version, npm installera automatiquement la dernière version disponible.

Si tu n'es pas sûr des versions existantes, tu peux les vérifier avec cette commande :

```bash
npm view package-name versions
```

Par exemple :

```bash
npm view express versions
```

Pour mettre à jour des paquets, tu peux les mettre à jour individuellement ou tous à la fois. Avant cela, il est utile de d'abord voir lesquels sont obsolètes :

```bash
npm outdated
```

Cela te montrera quelles dépendances ont de nouvelles versions disponibles, et tu devrais voir une sortie similaire à ceci :

```bash
user@Kolade ~/Desktop/fCC/script-code/node/npm/install-spec-version  % npm outdated
Package  Current  Wanted  Latest  Location              Depended by
chalk      5.5.0   5.5.0   5.6.2  node_modules/chalk    install-spec-version
cleave     1.0.1   1.0.1   1.0.2  node_modules/cleave   install-spec-version
express   4.21.2  4.21.2   5.2.1  node_modules/express  install-spec-version
```

Une fois que tu as vérifié quelles dépendances sont obsolètes, tu peux commencer à les mettre à jour.

Pour mettre à jour une seule dépendance, utilise ce qui suit :

```bash
npm update package-name
```

Cela met à jour le paquet uniquement dans la plage de versions autorisée par ton fichier `package.json`. Par exemple, pour mettre à jour Express, tu peux utiliser ce qui suit :

```bash
npm update express
```

Si tu veux ignorer la plage de versions et installer la dernière version d'un paquet, utilise la commande suivante :

```bash
npm install package-name@latest
```

Pour mettre à jour toutes les dépendances qui entrent dans les plages de versions autorisées, exécute :

```bash
npm update
```

Cependant, note que `npm update` ne met pas à niveau un paquet vers une nouvelle version majeure si ton `package.json` ne l'autorise pas. Les versions majeures contiennent souvent des breaking changes, donc npm ne les applique pas automatiquement.

Si tu veux spécifiquement la version majeure la plus récente, tu dois exécuter :

```bash
npm install package-name@latest
```

Cela force npm à installer la version la plus récente, quelle que soit la plage de versions dans ton `package.json`.
