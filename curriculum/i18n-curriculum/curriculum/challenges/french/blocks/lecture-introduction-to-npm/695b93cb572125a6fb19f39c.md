# --description--

Dans une leçon précédente, tu as appris ce que sont les dépendances et comment choisir les bonnes pour ton projet.

Dans cette leçon, tu apprendras comment installer et supprimer des dépendances avec npm.

Pour installer une dépendance, utilise la commande `npm install` comme ceci :

```bash
npm install dependencyName
```

Tu peux aussi raccourcir `install` en `i` comme ceci :

```bash
npm i dependencyName
```

Après l'installation d'un paquet, npm ajoute une nouvelle section `dependencies` à ton fichier `package.json` (si elle n'y est pas déjà) et y liste le paquet que tu as installé. Par exemple, voici à quoi cela ressemble quand tu installes le paquet `chalk` :

```json
{
  "name": "install-uninstall-deps",
  "version": "1.0.0",
  "description": "a simple demo on how to install and uninstall dependencies",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "keywords": ["npm", "deps"],
  "author": "Kolade Chris",
  "license": "ISC",
  "dependencies": {
    "chalk": "^5.6.2"
  }
}
```

Quand tu installes une dépendance, deux nouvelles choses apparaissent dans le dossier racine de ton projet :

* `node_modules/` : un dossier qui contient le code réel des paquets que tu as installés.

* `package-lock.json` : un fichier qui stocke des informations détaillées sur les versions exactes de ces paquets, y compris leurs propres dépendances. (Tu en apprendras plus sur ce fichier dans une leçon ultérieure.)

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-can-you-install-and-remove-dependencies-1.png" alt="">

La plupart des projets ont besoin de plus d'une dépendance. Au lieu de les installer une par une, npm te permet d'installer plusieurs paquets à la fois en saisissant une liste de noms de paquets séparés par des espaces :

```bash
npm install express lodash bcrypt
```

Comme avant, quand tu installes plusieurs dépendances à la fois, npm met à jour tes fichiers `package.json` et `package-lock.json` ainsi que ton `node_modules` pour les inclure. Voici à quoi ressemblerait le `package.json` :

```json
{
  "name": "install-uninstall-deps",
  "version": "1.0.0",
  "description": "a simple demo on how to install and uninstall dependencies",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "keywords": ["npm", "deps"],
  "author": "Kolade Chris",
  "license": "ISC",
  "dependencies": {
    "bcrypt": "^6.0.0",
    "chalk": "^5.6.2",
    "express": "^5.1.0",
    "lodash": "^4.17.21"
  }
}
```

Pour installer une `devDependency`, ajoute le drapeau `--save-dev` à la commande `install`. Tu peux aussi utiliser la version plus courte `-D` :

```bash
npm i nodemon -D
```

Après avoir exécuté cette commande, npm met à jour ton fichier `package.json` et ajoute le paquet sous la section `devDependencies`. Voici un exemple de ce à quoi cela ressemble :

```json
{
  "name": "install-uninstall-deps",
  "version": "1.0.0",
  "description": "a simple demo on how to install and uninstall dependencies",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "keywords": ["npm", "deps"],
  "author": "Kolade Chris",
  "license": "ISC",
  "dependencies": {
    "bcrypt": "^6.0.0",
    "chalk": "^5.6.2",
    "express": "^5.1.0",
    "lodash": "^4.17.21"
  },
  "devDependencies": {
    "nodemon": "^3.1.10"
  }
}
```

Chaque fois que tu exécutes une commande `npm install`, npm affichera un message indiquant si l'installation a réussi ou non. Un message de succès ressemble généralement à ceci :

```bash
user@Kolade ~/Desktop/fCC/script-code/node/npm/install-uninstall-deps  % npm install express lodash bcrypt

added 72 packages, and audited 74 in 8s

17 packages are looking for funding
  run `npm fund` for details

found 0 vulnerabilities

user@Kolade ~/Desktop/fCC/script-code/node/npm/install-uninstall-deps  % npm install nodemon -D

added 27 packages, and audited 101 in 16s

21 packages are looking for funding
  run `npm fund` for details

found 0 vulnerabilities
```

Pour désinstaller ou supprimer un paquet, utilise la commande `npm uninstall` :

```bash
npm uninstall dependencyName
```

Par exemple, pour retirer `chalk` de ton projet, tu exécuterais cette commande :

```bash
npm uninstall chalk
```

Tu peux aussi désinstaller plusieurs paquets à la fois en les listant avec des espaces entre chaque nom de paquet :

```bash
npm uninstall express lodash bcrypt
```

Tu obtiendras aussi un message indiquant si la commande uninstall a réussi ou échoué :

```bash
user@Kolade ~/Desktop/fCC/script-code/node/npm/install-uninstall-deps  % npm uninstall chalk

added 1 package, removed 1 package, and audited 101 packages in 1s

20 packages are looking for funding
  run `npm fund` for details

found 0 vulnerabilities

user@Kolade ~/Desktop/fCC/script-code/node/npm/install-uninstall-deps  % npm uninstall express lodash bcrypt

removed 70 packages, and audited 31 in 1s

4 packages are looking for funding
  run `npm fund` for details

found 0 vulnerabilities
```

Et ton fichier `package.json` sera mis à jour automatiquement :

```json
{
  "name": "install-uninstall-deps",
  "version": "1.0.0",
  "description": "a simple demo on how to install and uninstall dependencies",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "keywords": ["npm", "deps"],
  "author": "Kolade Chris",
  "license": "ISC",
  "devDependencies": {
    "nodemon": "^3.1.10"
  }
}
```

Pour désinstaller une `devDependency`, tu peux simplement exécuter :

```bash
npm uninstall nodemon
```

Note que tu n'as pas besoin du drapeau `-D` lors de la désinstallation. npm retirera automatiquement le paquet de la bonne section, `devDependencies` dans ce cas.

Après la désinstallation de la `devDependency`, ton `package.json` sera à nouveau mis à jour :

```json
{
  "name": "install-uninstall-deps",
  "version": "1.0.0",
  "description": "a simple demo on how to install and uninstall dependencies",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "keywords": ["npm", "deps"],
  "author": "Kolade Chris",
  "license": "ISC"
}
```
