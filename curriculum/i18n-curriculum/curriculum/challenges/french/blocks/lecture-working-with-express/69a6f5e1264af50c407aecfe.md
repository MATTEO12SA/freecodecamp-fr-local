# --description--

Dans la leçon précédente, tu as créé un dossier de projet et installé Express :

```bash
mkdir my-app
cd my-app
npm init -y
npm install express
```

Pour rappel, ces commandes créent un nouveau dossier de projet, font un `cd` dans le dossier du projet, initialisent le projet et créent un fichier `package.json` de base, et installent Express.

Ensuite, ouvre un éditeur de code, crée un fichier nommé `index.js`, et écris ton premier serveur Express :

```javascript
const express = require("express");
const app = express();
const port = 3000;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

Tu peux exécuter ton code avec la commande suivante dans le terminal :

```bash
node index.js
```

Ouvre ton navigateur sur [http://localhost:3000](http://localhost:3000) et tu verras le message **"Hello World!"**

C'est aussi rapide que ça pour démarrer avec Express ! Maintenant parcourons le code étape par étape.

Dans la première ligne de code, tu charges la bibliothèque Express et tu l'assignes à une variable appelée `express` :

```javascript
const express = require("express");
```

La variable `express` est une fonction factory. Quand tu l'appelles, elle crée et renvoie une nouvelle instance d'application Express :

```javascript
const app = express();
```

`app` a maintenant accès à toutes les méthodes fournies par Express, comme `.get()`, `.post()`, `.listen()`, et ainsi de suite. C'est ton objet serveur principal.

La ligne suivante définit la variable `port`. Un port est un point d'accès réseau sur lequel ton application écoute, et `3000` est un port couramment utilisé pour le développement local :

```javascript
const port = 3000;
```

Maintenant, regardons la partie suivante ici :

```javascript
app.get("/", (req, res) => {
  res.send("Hello World!");
});
```

Ce bloc de code définit une route et dit au serveur comment répondre aux requêtes. `app.get()` enregistre un gestionnaire pour les requêtes HTTP GET. Une requête GET est une méthode HTTP couramment utilisée pour récupérer des données.

L'argument `"/"` dans `app.get()` représente le chemin de la route. Dans ce cas, il pointe vers l'URL racine de l'application.

La partie `(req, res) => { ... }` est une fonction callback qui s'exécute quand une requête correspond à cette route. L'objet `req` contient des informations sur la requête entrante, et l'objet `res` est utilisé pour envoyer une réponse au client.

Enfin, `res.send("Hello World!")` envoie une réponse au client. Dans cet exemple, la réponse est le texte brut `"Hello World!"`.

Maintenant, regardons le dernier morceau de code ici :

```javascript
app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

La méthode `app.listen()` démarre l'application Express et dit à Node d'écouter les requêtes HTTP entrantes sur le port spécifié, dans ce cas `3000`.

Une fois le serveur démarré, la fonction callback s'exécute et le message `Example app listening on port 3000` est journalisé dans la console, confirmant que l'app Express a démarré avec succès et est prête à recevoir des requêtes.
