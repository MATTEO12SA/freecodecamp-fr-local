# --description--

Express.js, ou Express en abrégé, est un framework web minimal et flexible construit **par-dessus** Node.js. Il simplifie le processus de construction de serveurs web et d'API.

Au lieu d'écrire des tonnes de code boilerplate avec le module natif `http` de Node, Express te laisse créer des applications web robustes avec juste quelques lignes.

Tu peux le voir comme la couche rapide et non opinionnée qui rend Node.js plus facile et plus puissant.

Voici trois raisons clés pour lesquelles les développeurs aiment Express :

1. **Minimal et rapide** – Express fournit seulement l'essentiel, te donnant un contrôle total tout en te laissant ajouter des fonctionnalités au besoin via le middleware et les plugins.

2. **Écosystème massif** – Il a une énorme collection de middleware et de plugins pour le logging, l'authentification, la sécurité, les sessions, et plus encore.

3. **Idéal pour les API** – Son modèle simple de routage et de gestion des requêtes rend Express particulièrement adapté à la construction d'API RESTful.

Avec Express, tu peux créer :

* Des apps web

* Des API RESTful

* Des backends d'applications monopages (SPA)

* Des services riches en middleware

* Tout ce qui est côté serveur avec HTTP


## Comment installer Express

D'abord, assure-toi d'avoir Node.js et npm installés. Voici comment vérifier si node et npm sont installés :

```bash
node -v
npm -v
```

Si tu vois un numéro de version, cela signifie que c'est installé. Sinon, tu devras les installer. Tu peux trouver les instructions d'installation dans une leçon précédente, ou sur le site officiel de Node.js.

Ensuite, dans ton terminal, écris les commandes suivantes :

```bash
mkdir my-app
cd my-app
npm init -y
npm install express
```

Tu en apprendras plus sur le middleware et les plugins dans de futures leçons, mais en bref, le middleware est du code qui s'exécute entre la réception d'une requête et l'envoi d'une réponse. Il est couramment utilisé pour la gestion d'erreurs, la validation d'entrée, la modification des données dans la requête ou la réponse, et plus encore. Tu peux enchaîner du middleware pour construire une logique flexible et réutilisable pour gérer les requêtes.

Les plugins sont typiquement des modules Node.js externes tiers qui étendent les fonctionnalités d'Express. Tu peux les installer séparément avec npm, et la plupart sont implémentés comme du middleware utilisable dans ton app avec juste un peu de configuration. Au lieu d'écrire des fonctionnalités courantes from scratch, tu peux utiliser un plugin pour gérer des choses comme le logging, l'authentification, ou les bonnes pratiques de sécurité.

Express est un framework populaire pour le développement côté serveur en Node.js. Il te donne les briques pour rapidement lancer un serveur, gérer les routes, gérer le middleware, et construire des API — le tout avec un code propre et lisible.
