## Introduction aux modules de base de Node.js

- **Modules de base Node.js** : Modules intégrés livrés préinstallés avec Node.js, fournissant des fonctionnalités essentielles pour les opérations sur fichiers, la cryptographie, les interactions avec le système d'exploitation, et plus encore.
- **Modules standard** : Pas besoin d'installation séparée ; disponibles tant que Node.js est installé.
- **Syntaxe d'import** : Utilise `require()` pour importer les modules de base dans ton application.

```javascript
const fs = require("fs");
const crypto = require("crypto");
const os = require("os");
```

## Module File System (fs)

- **Objectif** : Fournit des méthodes pour travailler avec les fichiers et dossiers, notamment ouvrir, fermer, lire, écrire et supprimer.
- **Import** : `const fs = require("fs");`
- **Flexibilité** : Méthodes disponibles sous trois formes : callbacks, promises et synchrone.

### Modèles d'utilisation des méthodes

- **Asynchrone avec callbacks** : Comportement par défaut, non bloquant.

```javascript
fs.writeFile("filePath", "content", "utf8", (err) => {
  if (err) throw err;
  console.log("File written to!");
});
```

- **Basé sur les promises** : Préféré pour les applications modernes, utilise `async/await`.

```javascript
const fs = require("fs/promises");

async function writeToFile() {
  try {
    await fs.writeFile("article.md", "## Node fs Module");
    console.log("File written to!");
  } catch (err) {
    console.error(err);
  }
}
```

- **Synchrone** : Opération bloquante, adaptée aux scripts simples.

```javascript
try {
  fs.writeFileSync("article.md", "## Node fs Module", "utf8");
  console.log("File written to!");
} catch (err) {
  console.error(err);
}
```

### Opérations fichiers essentielles

- **Méthode `writeFile()`** : Crée ou écrase un fichier avec le contenu spécifié.

```javascript
await fs.writeFile("article.md", "## Node fs Module: The Complete Guide");
```

- **Méthode `appendFile()`** : Ajoute du contenu à la fin d'un fichier existant.

```javascript
await fs.appendFile("article.md", "\n\nIn this article, you will learn...");
```

- **Méthode `readFile()`** : Lit le contenu d'un fichier.

```javascript
const content = await fs.readFile("article.md", "utf8");
console.log("File content:", content);
```

- **Méthode `unlink()`** : Supprime un fichier du système de fichiers.

```javascript
await fs.unlink("article.md");
console.log("File deleted successfully");
```

### Encodage des caractères

- **Encodage UTF-8** : Spécifie `"utf8"` pour lire les fichiers comme des chaînes de texte.
- **Format Buffer** : Sans spécification d'encodage, les fichiers sont lus comme des objets buffer binaires.

```javascript
// Returns string
const textContent = await fs.readFile("file.txt", "utf8");

// Returns Buffer
const bufferContent = await fs.readFile("file.txt");
```

## Module Buffer

- **Objectif** : Gère les données binaires directement en mémoire pour les fichiers, images et flux réseau.
- **Import** : `const { Buffer } = require("buffer");`
- **Cas d'usage** : I/O fichiers, flux TCP, traitement d'images et manipulation de données binaires.

### Création de Buffer

- **Méthode `Buffer.from()`** : Crée un buffer à partir de chaînes, tableaux ou autres données.

```javascript
// From string
const myStrBuffer = Buffer.from("freeCodeCamp");
console.log(myStrBuffer); // <Buffer 66 72 65 65 43 6f 64 65 43 61 6d 70>

// From array of numbers
const myNumBuffer = Buffer.from([70, 82, 69, 69, 67, 79, 68, 69, 67, 65, 77, 80]);
```

- **Méthode `Buffer.alloc()`** : Crée un buffer de taille spécifiée rempli de zéros.

```javascript
const someBuffer = Buffer.alloc(10);
console.log(someBuffer); // <Buffer 00 00 00 00 00 00 00 00 00 00>
```

### Opérations Buffer

- **Accès de type tableau** : Accède aux éléments individuels du buffer avec la notation d'index.

```javascript
console.log(myStrBuffer[0]); // 102 (byte value for 'f')
```

- **Méthode `toString()`** : Convertit un buffer en chaîne lisible.

```javascript
console.log(myStrBuffer.toString()); // "freeCodeCamp"
```

- **Méthode `Buffer.write()`** : Écrit des données dans un buffer alloué.

```javascript
someBuffer.write("Hello fCC");
console.log(someBuffer.toString()); // "Hello fCC"
```

- **Méthode `Buffer.byteLength()`** : Renvoie le nombre d'octets nécessaires pour stocker une chaîne.

```javascript
console.log(Buffer.byteLength("Hello freeCodeCamp")); // 18
```

### Méthodes Buffer supplémentaires

- **`Buffer.isBuffer()`** : Vérifie si un objet est un buffer.
- **`Buffer.compare()`** : Compare deux buffers et renvoie l'ordre de tri.
- **`Buffer.concat()`** : Joint plusieurs buffers en un seul.

## Module Crypto

- **Objectif** : Fournit des fonctionnalités cryptographiques, notamment hachage, chiffrement, déchiffrement et signatures numériques.
- **Import** : `const crypto = require("crypto");`
- **Note de sécurité** : Utilise des bibliothèques bien testées comme `bcrypt` ou `jsonwebtoken` pour l'authentification en production.

### Méthodes de hachage

- **Méthode `createHash()`** : Crée un hachage à sens unique avec des algorithmes comme SHA256, SHA512 ou MD5.

```javascript
const hashedPassword = crypto
  .createHash("sha256")
  .update("myPassword123")
  .digest("hex");

console.log("createHash result:", hashedPassword);
```

- **Méthode `createHmac()`** : Crée un hachage avec une clé secrète pour l'authentification et l'intégrité des données.

```javascript
const hashedMessage = crypto
  .createHmac("sha256", "secret-key")
  .update("Hello World")
  .digest("hex");
```

### Chiffrement et déchiffrement

- **Méthodes `createCipheriv()` et `createDecipheriv()`** : Chiffrent et déchiffrent des données avec algorithmes, clés et vecteurs d'initialisation.

```javascript
const key = Buffer.from("12345678901234567890123456789012"); // 32 bytes for AES-256
const iv = Buffer.from("1234567890123456"); // 16 bytes for AES

// Encryption
const cipher = crypto.createCipheriv("aes-256-cbc", key, iv);
let encrypted = cipher.update("Hello campers!", "utf8", "hex");
encrypted += cipher.final("hex");

// Decryption
const decipher = crypto.createDecipheriv("aes-256-cbc", key, iv);
let decrypted = decipher.update(encrypted, "hex", "utf8");
decrypted += decipher.final("utf8");
```

### Génération de valeurs aléatoires

- **Méthode `randomBytes()`** : Génère des octets aléatoires cryptographiquement sécurisés.

```javascript
console.log("Random Bytes:", crypto.randomBytes(16).toString("hex"));
// Output: a6154ef5a296fa176ad0f332bd94d712
```

- **Méthode `randomInt()`** : Génère des entiers aléatoires sécurisés dans une plage spécifiée.

```javascript
console.log("Random Int:", crypto.randomInt(0, 100)); // Random number 0-99
```

### Gestion des clés

- **Méthode `createSecretKey()`** : Crée des objets de clé cryptographique à partir d'octets bruts.

```javascript
const secret = crypto.createSecretKey(crypto.randomBytes(32));
console.log(secret.export().toString('hex'));
```

### Signatures numériques

- **Méthodes `sign()` et `verify()`** : Créent et valident des signatures numériques avec des paires de clés privée/publique.
- **Cas d'usage** : Prouve l'authenticité et l'intégrité des données.

### Méthodes Crypto supplémentaires

- **`createPublicKey()` et `createPrivateKey()`** : Travaillent avec des clés générées ailleurs.
- **`createDiffieHellman()`** : Permet la génération sécurisée d'un secret partagé.
- **`Certificate()`** : Gère les opérations sur les certificats HTTPS.

## Module OS

- **Objectif** : Fournit des utilitaires liés au système d'exploitation pour les infos système et la compatibilité multiplateforme.
- **Import** : `const os = require("os");`
- **Cas d'usage** : Surveillance système, scripts multiplateformes, informations matérielles.

### Méthodes d'information système

- **Méthode `platform()`** : Renvoie la plateforme du système d'exploitation.

```javascript
console.log(os.platform()); // 'darwin', 'win32', 'linux', etc.

// Cross-platform usage
if (os.platform() === 'win32') {
  // Windows-specific code
} else {
  // Unix-like systems
}
```

- **Méthode `arch()`** : Renvoie l'architecture CPU.

```javascript
console.log(os.arch()); // 'arm64', 'x64', 'arm', 'ia32', etc.
```

- **Méthode `type()`** : Renvoie le nom officiel du système d'exploitation.

```javascript
console.log(os.type()); // 'Darwin', 'Linux', 'Windows_NT'
```

### Informations de version

- **Méthode `release()`** : Affiche la version du noyau OS.

```javascript
console.log(os.release()); // '25.0.0'
```

- **Méthode `version()`** : Renvoie des informations détaillées sur la version de l'OS.

```javascript
console.log(os.version());
// Darwin Kernel Version 25.0.0: Wed Sep 17 21:41:39 PDT 2025
```

### Informations matérielles

- **Méthode `cpus()`** : Renvoie un tableau d'informations sur les cœurs CPU.

```javascript
console.log(os.cpus()); // Array of CPU core objects with model, speed, times
```

- **Méthode `uptime()`** : Renvoie le temps de fonctionnement du système en secondes.

```javascript
console.log(os.uptime()); // 23047 (seconds since system boot)
```

### Informations mémoire

- **Méthode `totalmem()`** : Renvoie la mémoire système totale en octets.
- **Méthode `freemem()`** : Renvoie la mémoire système disponible en octets.

## Bonnes pratiques

### Considérations de performance

- **Évite les méthodes synchrones** : Utilise les méthodes asynchrones dans les applications de production pour éviter le blocage.
- **Préfère les promises** : Utilise `async/await` avec l'API basée sur les promises pour un code plus propre et maintenable.
- **Gestion des erreurs** : Implémente toujours une gestion d'erreurs correcte avec des blocs try-catch ou des callbacks d'erreur.

### Guidelines de sécurité

- **Module Crypto** : Utilise des bibliothèques établies pour l'authentification plutôt que de construire des solutions crypto personnalisées.
- **Validation des entrées** : Valide les chemins de fichiers et les entrées utilisateur pour prévenir les vulnérabilités de sécurité.
- **Gestion des clés** : Stocke les clés cryptographiques de façon sécurisée, ne les code jamais en dur dans le code source.

### Développement multiplateforme

- **Usage du module OS** : Utilise les méthodes du module OS pour la compatibilité multiplateforme.
- **Gestion des chemins** : Utilise le module `path` pour les opérations de chemins de fichiers multiplateformes.
- **Variables d'environnement** : Vérifie les variables d'environnement et configurations spécifiques à la plateforme.
