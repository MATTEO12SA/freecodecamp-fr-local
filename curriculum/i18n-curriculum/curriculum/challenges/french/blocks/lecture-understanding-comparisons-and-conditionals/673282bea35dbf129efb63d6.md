# --interactive--

Les instructions `switch` et les chaînes `if/else if/else` sont toutes deux des structures de flux de contrôle en programmation qui nous permettent d'exécuter différents blocs de code en fonction de certaines conditions. Cependant, elles ont des caractéristiques et des cas d'usage distincts.

Une instruction `switch` évalue une expression et compare sa valeur à une série de clauses `case`. Quand une correspondance est trouvée, le bloc de code associé à ce `case` est exécuté. Voici une structure de base d'une instruction `switch` :

```js
switch (expression) {
  case value1:
    // code to be executed if expression === value1
    break;
  case value2:
    // code to be executed if expression === value2
    break;
  default:
    // code to be executed if expression doesn't match any case
}
```

L'instruction `break` à la fin de chaque `case` est cruciale. Elle indique au programme de sortir du bloc switch une fois qu'un `case` correspondant a été exécuté. Sans elle, le programme continuerait à exécuter les cas suivants, un comportement connu sous le nom de « fall-through » (enchaînement).

Les instructions `switch` sont généralement utilisées quand tu compares une seule variable à plusieurs valeurs possibles. Elles sont particulièrement utiles quand tu as de nombreuses conditions potentielles à vérifier par rapport à une seule variable. Voici un exemple utilisant une instruction `switch` pour les jours de la semaine :

:::interactive_editor

```js
let dayOfWeek = 3;

switch (dayOfWeek) {
    case 1:
        console.log("It's Monday! Time to start the week strong.");
        break;
    case 2:
        console.log("It's Tuesday! Keep the momentum going.");
        break;
    case 3:
        console.log("It's Wednesday! We're halfway there.");
        break;
    case 4:
        console.log("It's Thursday! Almost the weekend.");
        break;
    case 5:
        console.log("It's Friday! The weekend is near.");
        break;
    case 6:
        console.log("It's Saturday! Enjoy your weekend.");
        break;
    case 7:
        console.log("It's Sunday! Rest and recharge.");
        break;
    default:
        console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

:::

Les instructions `switch` peuvent être plus lisibles et concises quand on traite de nombreuses valeurs possibles pour une seule variable.

Les instructions `if/else if`, en revanche, sont plus flexibles. Elles peuvent évaluer des conditions complexes et différentes variables dans chaque clause. Cela les rend adaptées à un plus large éventail de scénarios. Voici un exemple de cas où tu pourrais utiliser une instruction `if/else` plutôt qu'une instruction `switch` :

:::interactive_editor

```js
let creditScore = 720;
let annualIncome = 60000;
let loanAmount = 200000;

let eligibilityStatus;

if (creditScore >= 750 && annualIncome >= 80000) {
    eligibilityStatus = "Eligible for premium loan rates.";
} else if (creditScore >= 700 && annualIncome >= 50000) {
    eligibilityStatus = "Eligible for standard loan rates.";
} else if (creditScore >= 650 && annualIncome >= 40000) {
    eligibilityStatus = "Eligible for subprime loan rates.";
} else if (creditScore < 650) {
    eligibilityStatus = "Not eligible due to low credit score.";
} else {
    eligibilityStatus = "Not eligible due to insufficient income.";
}

console.log(eligibilityStatus);
```

:::

Dans cet exemple, nous avons le revenu annuel et le score de crédit d'une personne et nous vérifions à quels types de prêt elle serait admissible. Comme nous traitons des évaluations logiques plus complexes et plusieurs variables, il est préférable d'utiliser ici une instruction `if/else` plutôt qu'une instruction `switch`.

Il convient de noter que les instructions `switch` en JavaScript utilisent la comparaison stricte (`===`), ce qui signifie qu'elles n'effectuent pas de coercition de type. Cela peut être un avantage en termes de prévisibilité et pour éviter les bugs subtils.

En résumé, bien que les instructions `switch` et les chaînes `if/else if` permettent toutes deux une logique à branches multiples dans ton code, elles ont des forces différentes. Les instructions `switch` excellent dans la gestion de plusieurs valeurs possibles pour une seule variable, tandis que les chaînes `if/else if` offrent plus de flexibilité pour les conditions complexes. Le choix entre les deux dépend souvent des exigences spécifiques de ton code et des préférences de style de codage personnelles ou de l'équipe.
