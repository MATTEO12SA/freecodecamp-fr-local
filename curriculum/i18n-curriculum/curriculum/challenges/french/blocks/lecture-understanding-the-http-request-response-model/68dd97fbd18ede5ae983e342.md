# --description--

Dans la dernière leçon, tu as appris que le serveur traite une requête HTTP et renvoie une réponse. Cette réponse inclut divers assets que tu vois sur le web.

Les assets renvoyés par une réponse HTTP incluent des assets textuels, des assets média, des polices, et ainsi de suite. Chacun de ces assets est accompagné d'un en-tête **Content-Type**, qui indique au navigateur comment traiter et afficher correctement l'asset.

Les assets textuels ont toujours été une partie fondamentale du web. En fait, le web a commencé comme du texte pur. De nos jours, les assets textuels incluent les suivants :

* **HTML (Hypertext Markup Language)** : La structure de base de toute page web. Sans HTML, une page web ne peut pas exister.

* **CSS (Cascading Stylesheet)** : L'asset qui contrôle l'apparence d'une page web. Avec CSS, tu appliques des styles comme les couleurs, les polices et la mise en page au HTML.

* **JavaScript** : JavaScript ajoute de l'interactivité et du contenu dynamique au HTML et au CSS.

* **JSON et XML** : Ces deux formats te permettent de transférer des données structurées entre serveurs et navigateurs.

Les assets média incluent les images, les audios et les vidéos. Ils donnent vie au web avec des visuels et du son.

De nombreux sites web s'appuient sur les images pour communiquer des informations visuelles. Les images existent dans différents formats comme `JPG`, `JPEG`, `PNG`, `WEBP` et `GIF`.

Des sites comme YouTube et Vimeo servent du contenu vidéo avec des formats comme `MP4`, `MOV`, `AVI`, `WebM`, et plus encore.

L'audio est une partie clé de nombreuses plateformes car il permet aux utilisateurs de streamer de la musique, des podcasts et d'autres contenus sonores. Les formats audio courants incluent `MP3`, `AAC`, Ogg et `WAV`. Des plateformes comme Spotify et YouTube Music s'appuient sur ces formats pour offrir des expériences audio de haute qualité.

D'autres assets renvoyés dans une réponse HTTP sont des documents comme `PDF`, `DOCX` et `PAGES`, des archives compressées comme `ZIP` et `RAR`, des fichiers de police comme `WOFF`, `WOFF2` et `TTF`, et des exécutables comme `EXE`.

Voici un tableau de ces assets courants et de leurs types de contenu :

| Asset Type | Content-Type Header |
| --- | --- |
| HTML | text/html |
| CSS | text/css |
| JavaScript | application/javascript |
| JPEG | image/jpeg |
| PNG | image/png |
| GIF | image/gif |
| SVG | image/svg+xml |
| WebP | image/webp |
| WOFF | font/woff |
| WOFF2 | font/woff2 |
| TTF | font/ttf |
| OTF | font/otf |
| MP4 | video/mp4 |
| WebM | video/webm |
| Ogg (Video) | video/ogg |
| MP3 | audio/mpeg |
| AAC | audio/aac |
| WAV | audio/wav |
| Ogg (Audio) | audio/ogg |
| JSON | application/json |
| XML | application/xml |
| PDF | application/pdf |
| ZIP | application/zip |
