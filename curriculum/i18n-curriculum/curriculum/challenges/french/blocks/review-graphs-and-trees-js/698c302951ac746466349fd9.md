## Vue d'ensemble des graphes

Un graphe est un ensemble de nœuds (sommets) reliés par des arêtes (connexions). Chaque nœud peut se connecter à plusieurs autres nœuds, formant un réseau. Les différents types de graphes incluent :

- Orienté : les arêtes ont une direction (d'un nœud vers un autre), souvent représentées avec des lignes droites et des flèches.
- Non orienté : les arêtes n'ont pas de direction, représentées avec de simples lignes.
- Sommets étiquetés : chaque nœud est associé à une étiquette ou un identifiant.
- Cyclique : contient des cycles (un chemin qui commence et se termine au même nœud).
- Acyclique (DAG) : ne contient pas de cycles.
- Arêtes étiquetées : chaque arête a une étiquette généralement dessinée à côté de l'arête correspondante.
- Pondéré : les arêtes ont des poids (valeurs) associés, utilisables pour des opérations arithmétiques.
- Déconnecté : contient deux nœuds ou plus qui ne sont reliés par aucune arête.

Les graphes sont utilisés dans diverses applications comme les cartes, les réseaux, les systèmes de recommandation, la résolution de dépendances.

## Parcours de graphes

Cela consiste à visiter tous les nœuds d'un graphe. Les deux algorithmes principaux sont :

- **Parcours en largeur (BFS)**
  - Utilise une file.
  - Explore niveau par niveau.
  - Trouve le plus court chemin dans les graphes non pondérés.

- **Parcours en profondeur (DFS)**
  - Utilise une pile (ou la récursion).
  - Explore une branche entièrement avant de revenir en arrière.
  - Utile pour la détection de cycles et la recherche de chemins.

## Représentations de graphes

Les graphes peuvent être représentés de deux façons principales :

- **Liste d'adjacence**
  - Chaque nœud a une liste de ses voisins.
  - Économe en espace pour les graphes creux.
  - Facile d'itérer sur les voisins.

- **Matrice d'adjacence**
  - Un tableau 2D où les lignes et colonnes représentent les nœuds.
  - Coûteux en espace pour les grands graphes.
  - Rapide pour vérifier si une arête existe entre deux nœuds.

## Arbres

Un arbre est un type spécial de graphe qui est acyclique et connecté. Les propriétés clés incluent :

- Ils n'ont ni boucles ni cycles (chemins où les nœuds de début et de fin sont les mêmes).
- Ils doivent être connectés (chaque nœud peut être atteint depuis tout autre nœud).

### Types d'arbres courants

Les types d'arbres les plus courants sont :

- Arbres binaires
  - Chaque nœud a au plus deux enfants, un enfant gauche et un enfant droit.

- Arbres binaires de recherche (BST)
  - Un arbre binaire dans lequel chaque enfant gauche est inférieur à son parent, et chaque enfant droit est supérieur à son parent.


## Tries

Aussi connus sous le nom d'arbres de préfixes, ils servent à stocker des ensembles de chaînes, où chaque nœud représente un caractère.

Les préfixes partagés ne sont stockés qu'une seule fois, ce qui les rend efficaces pour des tâches comme l'autocomplétion et la vérification orthographique.

Les opérations de recherche et d'insertion ont une complexité temporelle de O(L), où L est la longueur de la chaîne.

## Files de priorité

Une file de priorité est un type abstrait de données où chaque élément a une priorité.

Les files et les piles ne considèrent que l'ordre d'insertion, tandis que les files de priorité considèrent la priorité des éléments.

Les files standard suivent FIFO (First In First Out) et les piles suivent LIFO (Last In First Out). Cependant, dans une file de priorité, les éléments de priorité plus élevée sont servis avant ceux de priorité plus basse, indépendamment de leur ordre d'insertion.

## Tas (Heaps)

C'est une structure de données spécialisée basée sur un arbre avec une propriété très spécifique appelée la propriété de tas.

La propriété de tas détermine la relation entre les nœuds parents et enfants. Il existe deux types de tas :

- Max-Heap
  - La valeur de chaque nœud parent est supérieure ou égale aux valeurs de ses enfants.
  - Le plus grand élément est à la racine.

- Min-Heap
  - La valeur de chaque nœud parent est inférieure ou égale aux valeurs de ses enfants.
  - Le plus petit élément est à la racine.


JavaScript n'a pas de module de tas intégré, mais tu peux implémenter un min-heap avec un tableau.
