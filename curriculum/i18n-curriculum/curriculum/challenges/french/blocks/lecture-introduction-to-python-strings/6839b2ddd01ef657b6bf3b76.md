# --description--

Python fournit plusieurs méthodes intégrées qui facilitent le travail avec les chaînes. Elles incluent, entre autres, les suivantes :

- `upper()` : renvoie une nouvelle chaîne avec tous les caractères convertis en majuscules.

```python
my_str = 'hello world'

uppercase_my_str = my_str.upper()
print(uppercase_my_str)  # HELLO WORLD
```

- `lower()` : renvoie une nouvelle chaîne avec tous les caractères convertis en minuscules.

```python
my_str = 'Hello World'

lowercase_my_str = my_str.lower()
print(lowercase_my_str)  # hello world
```

- `strip()` : renvoie une nouvelle chaîne sans les caractères spécifiés au début et à la fin. Si aucun argument n'est passé, elle supprime les espaces au début et à la fin.

```python
my_str = '  hello world  '

trimmed_my_str = my_str.strip()
print(trimmed_my_str)  # "hello world"
```

- `replace(old, new)` : renvoie une nouvelle chaîne où toutes les occurrences de `old` sont remplacées par `new`.

```python
my_str = 'hello world'

replaced_my_str = my_str.replace('hello', 'hi')
print(replaced_my_str)  # hi world
```

- `split(separator)` : divise une chaîne selon un séparateur spécifié en une liste de chaînes. Si aucun séparateur n'est spécifié, elle divise sur les espaces.

```python
my_str = 'hello world'

split_words = my_str.split()
print(split_words)  # ['hello', 'world']
```

- `join(iterable)` : joint les éléments d'un itérable en une chaîne avec un séparateur.

```python
my_list = ['hello', 'world']

joined_my_str = ' '.join(my_list)
print(joined_my_str)  # hello world
```

- `startswith(prefix)` : renvoie un booléen indiquant si une chaîne commence par le préfixe spécifié.

```python
my_str = 'hello world'

starts_with_hello = my_str.startswith('hello')
print(starts_with_hello)  # True
```

- `endswith(suffix)` : renvoie un booléen indiquant si une chaîne se termine par le suffixe spécifié.

```python
my_str = 'hello world'

ends_with_world = my_str.endswith('world')
print(ends_with_world)  # True
```

- `find(substring)` : renvoie l'indice de la première occurrence de `substring`, ou `-1` si elle n'en trouve pas.

```python
my_str = 'hello world'

world_index = my_str.find('world')
print(world_index)  # 6
```

- `count(substring)` : renvoie le nombre de fois qu'une sous-chaîne apparaît dans une chaîne.

```python
my_str = 'hello world'

o_count = my_str.count('o')
print(o_count)  # 2
```

- `capitalize()` : renvoie une nouvelle chaîne avec le premier caractère en majuscule et les autres en minuscules.

```python
my_str = 'hello world'

capitalized_my_str = my_str.capitalize()
print(capitalized_my_str)  # Hello world
```

- `isupper()` : renvoie `True` si toutes les lettres de la chaîne sont en majuscules et `False` sinon.

```python
my_str = 'hello world'

is_all_upper = my_str.isupper()
print(is_all_upper)  # False
```

- `islower()` : renvoie `True` si toutes les lettres de la chaîne sont en minuscules et `False` sinon.

```python
my_str = 'hello world'

is_all_lower = my_str.islower()
print(is_all_lower)  # True
```

- `title()` : renvoie une nouvelle chaîne avec la première lettre de chaque mot en majuscule.

```python
my_str = 'hello world'

title_case_my_str = my_str.title()
print(title_case_my_str)  # Hello World
```
