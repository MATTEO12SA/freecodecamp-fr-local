# --description--

Quand tu travailles avec des chaînes, combiner différents morceaux de texte est une opération courante à laquelle tu te retrouveras souvent confronté.

En Python, tu peux combiner plusieurs chaînes avec l'opérateur plus (`+`). Ce processus s'appelle la **concaténation de chaînes**. Voici comment concaténer deux chaînes avec l'opérateur plus :

```python
my_str_1 = 'Hello'
my_str_2 = "World"

str_plus_str = my_str_1 + ' ' + my_str_2
print(str_plus_str) # Hello World
```

Mais note que cela ne fonctionne qu'avec des chaînes. Si tu essaies de concaténer une chaîne avec un nombre, tu obtiendras une `TypeError` :

```python
name = 'John Doe'
age = 26

name_and_age = name + age
print(name_and_age) # TypeError: can only concatenate str (not "int") to str
```

Cela se produit parce que Python ne convertit pas automatiquement d'autres types de données comme les entiers en chaînes quand tu les concatènes. Python exige que tous les éléments soient des chaînes avant de pouvoir les concaténer. Pour corriger cela, tu peux convertir le nombre en chaîne avec la fonction intégrée `str()`, qui renvoie la représentation en chaîne de l'objet donné sans modifier l'objet original :

```python
name = 'John Doe'
age = 26

name_and_age = name + str(age)
print(name_and_age) # John Doe26
```

Tu peux aussi utiliser l'opérateur d'affectation augmentée pour la concaténation. Il est représenté par un plus et un signe égal (`+=`) et effectue à la fois la concaténation et l'affectation en une seule étape. Voici comment il fonctionne :

```py
name = 'John Doe'
age = 26

name_and_age = name  # Start with the name
name_and_age += str(age)  # Append the age as string

print(name_and_age)  # John Doe26
```

Le processus d'insertion de variables et d'expressions dans une chaîne s'appelle l'**interpolation de chaînes**. Python a une catégorie de chaînes appelée **f-strings** (abréviation de formatted string literals), qui te permet de gérer l'interpolation avec une syntaxe compacte et lisible.

Les f-strings commencent par `f` (minuscule ou majuscule) avant les guillemets, et te permettent d'intégrer des variables ou des expressions dans des champs de remplacement indiqués par des accolades (`{}`). Voici un exemple :

```python
name = 'John Doe'
age = 26
name_and_age = f'My name is {name} and I am {age} years old'
print(name_and_age) # My name is John Doe and I am 26 years old

num1 = 5
num2 = 10
print(f'The sum of {num1} and {num2} is {num1 + num2}') # The sum of 5 and 10 is 15
```

Remarque que tu n'as pas besoin de convertir les types non-chaînes avec la fonction `str()`. Dans l'exemple ci-dessus, la valeur des variables `age`, `num1` et `num2` est convertie en chaîne en coulisse pendant le processus d'interpolation.
