# --description--

Dans une leçon précédente, tu as appris comment chaque caractère d'une chaîne peut être identifié par son indice (en commençant à zéro) et accessible avec la notation entre crochets :

```python
my_str = "Hello world"

print(my_str[0])  # H
print(my_str[6])  # w
print(my_str[-1]) # d
```

Le **découpage de chaîne** te permet d'extraire une portion d'une chaîne ou de travailler avec seulement une partie spécifique. Voici la syntaxe de base :

```python
string[start:stop]
```

Si tu veux extraire des caractères d'un certain indice à un autre, sépare simplement les indices `start` et `stop` par deux-points :

```python
my_str = 'Hello world'
print(my_str[1:4]) # ell
```

Note que l'indice `stop` est non inclusif, donc `[1:4]` a simplement extrait les caractères de l'indice `1` jusqu'à, mais sans inclure, le caractère à l'indice `4`.

Tu peux aussi omettre les indices `start` et `stop`, et Python utilisera par défaut `0` ou la fin de la chaîne, respectivement. Par exemple, voici ce qui se passe si tu omets l'indice `start` :

```python
my_str = 'Hello world'
print(my_str[:7])  # Hello w
```

Cela extrait tout de l'indice `0` jusqu'à (mais sans inclure) le caractère à l'indice `7`. Et voici ce qui se passe si tu omets l'indice `stop` :

```python
my_str = 'Hello world'
print(my_str[8:])  # rld
```

Cela extrait tout du caractère à l'indice `8` jusqu'à la fin de la chaîne.

Note que découper une chaîne ne modifie pas la chaîne originale :

```py
my_str = 'Hello world'
print(my_str[8:])  # rld
print(my_str)  # Hello world
```

Tu peux aussi omettre les indices `start` et `stop`, ce qui extraira toute la chaîne :

```python
my_str = 'Hello world'
print(my_str[:])  # Hello world
```

Outre les indices `start` et `stop`, il y a aussi un paramètre optionnel `step`, utilisé pour spécifier l'incrément entre chaque indice dans la tranche.

Voici la syntaxe pour cela :

```python
string[start:stop:step]
```

Dans l'exemple ci-dessous, le découpage commence à l'indice `0`, s'arrête avant `11`, et extrait un caractère sur deux :

```python
my_str = 'Hello world'
print(my_str[0:11:2])  # Hlowrd
```

Une astuce utile avec le paramètre `step` consiste à inverser une chaîne en définissant step à `-1` et en laissant `start` et `stop` vides :

```python
my_str = 'Hello world'
print(my_str[::-1]) # dlrow olleH
```
