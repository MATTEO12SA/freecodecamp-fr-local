# --description--

Une chaîne est une séquence de caractères entourée de guillemets simples ou doubles. Dans certains langages de programmation, les caractères entourés de guillemets simples sont traités différemment de ceux entourés de guillemets doubles, mais en Python, ils sont traités de la même manière. Tu peux donc utiliser l'un ou l'autre quand tu travailles avec des chaînes. Voici quelques exemples de chaînes :

```python
my_str_1 = 'Hello'
my_str_2 = "World"
```

Si tu as besoin d'une chaîne multiligne, tu peux utiliser des triples guillemets doubles ou simples :

```python
my_str_3 = """Multiline
string"""
my_str_4 = '''Another
multiline
string'''
```

Si ta chaîne contient des guillemets simples ou doubles, tu as deux options :

- Utilise le type de guillemets opposé. C'est-à-dire, si ta chaîne contient des guillemets simples, utilise des guillemets doubles pour entourer la chaîne, et vice versa :

```python
msg = "It's a sunny day"
quote = 'She said, "Hello World!"'
```

- Échappe le guillemet simple ou double dans la chaîne avec une barre oblique inverse (`\`). Avec cette méthode, tu peux utiliser des guillemets simples ou doubles pour entourer la chaîne elle-même :

```python
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

Parfois, tu peux avoir besoin de vérifier si une chaîne contient un ou plusieurs caractères. Pour cela, Python fournit l'opérateur `in`, qui renvoie un booléen indiquant si le ou les caractères existent dans la chaîne ou non.

Voici quelques exemples :

```python
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

Maintenant, voyons comment obtenir la longueur d'une chaîne et travailler avec les caractères individuels d'une chaîne, un processus appelé **indexation**. Pour obtenir la longueur d'une chaîne, tu peux utiliser la fonction intégrée `len()`. Voici un exemple :

```python
my_str = 'Hello world'
print(len(my_str))  # 11
```

Chaque caractère d'une chaîne a une position appelée indice. L'indice commence à zéro, ce qui signifie que l'indice du premier caractère d'une chaîne est `0`, l'indice du deuxième caractère est `1`, et ainsi de suite. Pour accéder à un caractère par son indice, tu utilises des crochets (`[]`) avec l'indice du caractère auquel tu veux accéder à l'intérieur. Voici quelques exemples :

```python
my_str = "Hello world"

print(my_str[0])  # H
print(my_str[6])  # w
```

L'indexation négative est aussi autorisée, donc tu peux obtenir le dernier caractère de n'importe quelle chaîne avec `-1`, l'avant-dernier avec `-2`, et ainsi de suite :

```python
my_str = 'Hello world'
print(my_str[-1])  # d
print(my_str[-2]) # l
```

Beaucoup d'autres langages de programmation regroupent les types de données en types primitifs ou types de référence. Les types primitifs sont simples et immuables, ce qui signifie qu'ils ne peuvent pas être modifiés une fois déclarés. Les types de référence peuvent contenir plusieurs valeurs et sont mutables ou immuables. Mais Python ne trace pas une ligne dure entre ces deux groupes. Au lieu de cela, toutes les données sont traitées comme des objets, et certains objets sont immuables tandis que d'autres sont mutables.

Les types de données immuables ne peuvent pas être modifiés ou altérés une fois déclarés. Tu peux faire pointer leurs variables vers quelque chose de nouveau, ce qu'on appelle une réaffectation, mais tu ne peux pas modifier l'objet original lui-même en ajoutant, supprimant ou remplaçant ses éléments.

Les chaînes sont des types de données immuables en Python. Cela signifie que tu peux réaffecter une chaîne différente à une variable :

```python
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello
```

Mais la modification directe d'une chaîne n'est pas autorisée :

```python
greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```

Exemples d'autres types de données immuables en Python : entier, flottant, booléen, tuple et range. Tu découvriras chacun de ces types dans les leçons à venir.
