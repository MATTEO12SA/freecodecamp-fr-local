# --description--

Dans Express, les **gestionnaires de route** (aussi appelés fonctions callback de route ou fonctions contrôleur) sont des fonctions qui définissent ce qui se passe quand un client envoie une requête à une route spécifique.

Un gestionnaire de route traite la requête entrante, exécute toute logique nécessaire comme interroger une base de données ou faire des calculs, puis envoie une réponse au client.

Décomposons cela avec un exemple simple (que tu as en fait utilisé tout du long) :

```javascript
app.get("/menu", (req, res) => {
  res.send("Welcome to the menu!");
});
```

La méthode `.get()` est l'une des méthodes de route d'Express. Elle écoute les requêtes **GET** à une route spécifiée. Dans cet exemple, elle écoute les requêtes vers `/menu`.

La fonction `(req, res) => { ... }` est le **gestionnaire de route**. Elle s'exécute dès qu'un client envoie une requête GET vers `/menu`.

À l'intérieur du gestionnaire :

* `req` (request) est un objet qui contient des informations sur la requête entrante, comme les paramètres de route, les chaînes de requête, les en-têtes et les données du corps.

* `res` (response) est un objet utilisé pour envoyer une réponse au client.

Dans ce cas, `res.send("Welcome to the menu!")` envoie une réponse en texte brut au client.

Quand un utilisateur navigue vers `/menu` dans le navigateur — ou envoie une requête GET vers cette route — le serveur exécute ce gestionnaire et répond avec le message `Welcome to the menu!`.

Les gestionnaires de route sont le cœur d'une application Express. Ils te laissent définir comment les différentes routes de ton application web répondront aux requêtes. Tu peux aussi ajouter de la logique à ces gestionnaires, comme traiter des données de formulaire, interagir avec des bases de données, ou effectuer une validation.
