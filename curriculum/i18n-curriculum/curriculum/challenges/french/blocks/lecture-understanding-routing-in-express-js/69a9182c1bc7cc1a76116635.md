# --description--

Dans Express, les **chemins de route** sont les motifs d'URL qui déterminent comment le serveur répond aux requêtes entrantes. Quand un utilisateur demande une URL spécifique, Express fait correspondre cette URL à un chemin de route et exécute le gestionnaire correspondant.

Les chemins de route sont définis dans des méthodes de route comme `app.get()`, `app.post()`, et ainsi de suite. Ces chemins peuvent être statiques, comme `/home`, ou dynamiques, où des paramètres sont utilisés pour capturer des valeurs depuis l'URL, comme `/user/:id`.

Dans cette leçon, on se concentrera sur les routes statiques. Voici un exemple :

```javascript
// Static route
app.get("/home", (req, res) => {
  res.send("Welcome to the homepage!");
});
```

Dans cet exemple, le serveur écoute les requêtes GET vers `/home` et répond avec un message simple.

La méthode `app.get()` prend deux arguments :

* Le premier argument, `"/home"`, est le chemin de route statique (ou URL) que le serveur écoute.

* Le second argument est une fonction callback qui s'exécute quand une requête GET est faite vers ce chemin.

Dans le callback, `res.send()` envoie une réponse au client. Dans ce cas, il envoie le texte `Welcome to the homepage!`, qui s'affiche dans le navigateur.

Voici un autre exemple de route statique :

```javascript
// Static route
app.get("/menu/drinks", (req, res) => {
  res.send("Welcome to the drinks menu!");
});
```

Dans ce cas, le serveur écoute les requêtes GET vers l'URL `/menu/drinks` et renvoie un message quand cette route est demandée.

Tu pourrais utiliser des routes comme celles-ci quand ton site a plusieurs pages liées regroupées sous un chemin commun. Par exemple, un site de restaurant pourrait organiser ses pages de menu comme ceci :

* `/menu/food`

* `/menu/drinks`

* `/menu/desserts`

Cette approche aide à garder tes URL claires et significatives, et elle rend aussi tes routes plus faciles à organiser et maintenir à mesure que ton application grandit.

Dans la prochaine leçon, on regardera les chemins de route dynamiques avec des paramètres.
