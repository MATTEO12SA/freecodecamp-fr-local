# --description--

Dans Express, l'objet `res` (response) est utilisé pour envoyer des réponses au client après le traitement des requêtes entrantes. Express fournit plusieurs méthodes intégrées pour envoyer différents types de réponses. Par exemple, tu peux envoyer du texte brut, des données JSON, rediriger un utilisateur vers une autre URL, ou rendre un template.

Une des méthodes de réponse les plus couramment utilisées est `res.send()` :

```javascript
app.get("/text", (req, res) => {
  res.send("Hello, World!");
});
```

La méthode `res.send()` envoie une réponse au client. Elle peut envoyer du texte brut, du HTML, du JSON, ou même des données binaires. Dans cet exemple, quand un client visite `/text`, le serveur répond avec le texte `Hello, World!`.

Une autre méthode de réponse couramment utilisée est `res.json()`.

Cette méthode envoie une réponse JSON au client. Elle est particulièrement utile pour construire des API, où tu as souvent besoin de renvoyer des données structurées comme des objets ou des tableaux. Express convertit automatiquement un objet JavaScript en une chaîne formatée JSON :

```javascript
app.get("/user", (req, res) => {
  res.json({ name: "John Doe", age: 30 });
});
```

Si un client envoie une requête vers `/user`, le serveur répond avec ce qui suit :

```json
{
  "name": "John Doe",
  "age": 30
}
```

Quand tu as besoin de contrôler le code de statut HTTP d'une réponse, tu peux utiliser `res.status()`. Cette méthode définit le code de statut et est typiquement enchaînée avec une autre méthode de réponse comme `res.send()` ou `res.json()` :

```javascript
app.get("/notfound", (req, res) => {
  res.status(404).send("Not Found");
});
```

Ici, le serveur définit le code de statut à `404` et envoie le message `Not Found` au client.

Si tu veux envoyer l'utilisateur vers une URL différente, tu peux utiliser `res.redirect()` :

```javascript
app.get("/oldpage", (req, res) => {
  res.redirect("/newpage");
});
```

Quand un client visite `/oldpage`, il est automatiquement redirigé vers `/newpage`.

Enfin, `res.render()` est utilisé quand on travaille avec des moteurs de templates comme Pug, EJS ou Handlebars. Il rend un template de vue et envoie le HTML résultant au client :

```javascript
app.get("/profile", (req, res) => {
  res.render("profile", { username: "john_doe" });
});
```

Dans cet exemple, le serveur rend une vue `profile` et lui passe une variable `username`, qui peut ensuite être affichée dans le HTML.

Ces méthodes de réponse te laissent renvoyer différents types de données selon la nature de la requête. Que tu envoies du texte, des données JSON, ou que tu rediriges le client, Express a un ensemble flexible d'outils pour le gérer.
