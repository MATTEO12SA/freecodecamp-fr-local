# --description--

Dans Express, `express.Router()` est une fonctionnalité puissante qui t'aide à organiser tes routes en morceaux plus petits et modulaires. C'est particulièrement utile à mesure que ton application grandit.

Au lieu de définir toutes tes routes dans un seul grand fichier, tu peux les séparer en fichiers distincts avec des routers. Cela garde ton code plus facile à lire, maintenir et faire évoluer.

La méthode `express.Router()` crée un nouvel objet router.

Un router fonctionne comme une mini-application Express. Il peut gérer ses propres routes et middleware, mais ce n'est pas une application Express complète. Une fois que tu définis des routes sur un router, tu peux le monter dans ton app principale avec `app.use()`.

En d'autres termes, un router te laisse regrouper des routes liées puis les intégrer plus tard dans ton application principale.

Utiliser des routers a plusieurs avantages :

**Séparation des préoccupations**

Tu peux définir des routes dans des fichiers séparés, ce qui améliore l'organisation et la lisibilité de ton application.

**Réutilisabilité du code**
Les routers peuvent être réutilisés dans différentes parties d'une application ou même entre projets.

**Fichier principal plus propre**
Au lieu de remplir ton fichier principal `app.js` ou `server.js` avec beaucoup de définitions de routes, tu peux les déplacer dans des routers et garder ton fichier principal concentré sur la configuration et la mise en place.

Regardons un exemple simple où on utilise `express.Router()` pour définir des routes pour le chemin `/users`.

D'abord, voici le fichier `app.js` :

```javascript
const express = require("express");
const app = express();
const port = 3000;

// Importing the user routes
const userRoutes = require("./userRoutes");

// Using the userRoutes router for /users path
app.use("/users", userRoutes);

app.listen(port, () => {
  console.log(`Server running at http://localhost:${port}`);
});
```

Et voici `userRoutes.js` :

```javascript
const express = require("express");
const router = express.Router();

// GET request for /users
router.get("/", (req, res) => {
  res.send("List of users");
});

// POST request for /users
router.post("/", (req, res) => {
  res.send("Creating a new user");
});

// GET request for /users/:id
router.get("/:id", (req, res) => {
  const userId = req.params.id;
  res.send(`User details for user with id: ${userId}`);
});

module.exports = router;
```

Maintenant regardons de plus près comment tout fonctionne.

Dans `app.js`, on importe `express` et on crée une instance de l'application Express qu'on assigne à une variable nommée `app`.

Ensuite, on importe le router `userRoutes` depuis `userRoutes.js` et on utilise `app.use("/users", userRoutes)` pour monter le router. Cela dit à Express que, si une requête commence par `/users`, il faut la passer au router `userRoutes`.

Puis dans `userRoutes.js`, on crée un nouveau router avec `express.Router()` et on définit des routes avec `router.get()`, `router.post()` et `router.get("/:id")`.

Note que les routes définies ici sont relatives à `/users` parce que c'est là que le router est monté. Donc :

*   `router.get("/")` → `GET /users` : Répond avec une liste d'utilisateurs

*   `router.post("/")` → `POST /users` : Répond avec un message sur la création d'un nouvel utilisateur

*   `router.get("/:id")` → `GET /users/:id` : Répond avec les détails d'utilisateur pour un ID donné

Utiliser `express.Router()` garde ton fichier principal propre et concentré sur la configuration. Toutes les routes liées aux utilisateurs sont regroupées dans `userRoutes.js`.

À mesure que ton application grandit, tu peux créer des routers supplémentaires pour d'autres sections, comme `/products`, `/orders` ou `/auth`.

Chaque section reste organisée dans son propre fichier, ce qui rend l'application plus facile à maintenir et faire évoluer.
