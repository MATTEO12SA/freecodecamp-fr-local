# --description--

Maintenant que tu as construit une app Express de base, il est temps de regarder de plus près le routage et son fonctionnement.

Dans Express, le routage est la façon dont tu définis les endpoints d'une application web. Tu peux voir les routes comme des règles qui disent à l'app comment répondre quand un utilisateur visite une URL spécifique.

Regardons à nouveau notre app Express simple :

```javascript
const express = require("express");
const app = express();
const port = 3000;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

Dans cet exemple, l'app définit une route pour l'URL racine (`/`). Quand un client envoie une requête GET à ce chemin, le serveur répond avec le texte `Hello World!`. L'app commence ensuite à écouter les requêtes entrantes sur le port `3000`.

Mais il y a d'autres méthodes de route.

Express te laisse gérer différents types de requêtes HTTP en utilisant différentes méthodes de routage. Les plus courantes sont :

* `app.get()` – récupère des données

* `app.post()` – crée de nouvelles données

* `app.put()` – met à jour des données existantes

* `app.delete()` – supprime des données

Chaque méthode définit comment ton application devrait répondre à une requête HTTP spécifique sur une route spécifique.

Voici quelques exemples simples :

```javascript
app.post("/submit", (req, res) => {
  res.send("Form submitted!");
});

app.put("/update", (req, res) => {
  res.send("Item updated!");
});

app.delete("/delete", (req, res) => {
  res.send("Item deleted!");
});
```

Dans chaque cas, Express écoute une requête avec une méthode HTTP et un chemin d'URL particuliers, puis exécute la fonction gestionnaire correspondante pour envoyer une réponse au client.

Tu peux tester ces routes avec des outils comme Postman ou `curl`, qui te laissent envoyer différents types de requêtes HTTP à ton serveur.

Et voilà le routage dans Express — il s'agit simplement de définir comment ton application répond aux différentes requêtes.
