# --description--

React fournit de nombreux hooks intégrés qui te permettent d'implémenter différentes fonctionnalités dans tes projets. Parmi eux : `useState`, `useEffect`, `useContext`, et d'autres.

Mais parfois, tu auras besoin d'ajouter une fonctionnalité qu'aucun des hooks intégrés ne peut aider. Heureusement, tu peux créer tes propres hooks personnalisés en React.

Les hooks personnalisés ne sont pas aussi compliqués qu'ils peuvent sembler. Ce sont juste des fonctions réutilisables qui te permettent de partager de la logique entre plusieurs composants. Cela signifie que la réutilisabilité est une autre raison pour laquelle tu voudrais construire ton propre hook.

Avec un hook personnalisé, tu peux extraire la logique hors de tous les composants qui l'utilisent, comme la récupération de données, la gestion du state, le basculement, des side effects comme vérifier le statut en ligne ou hors ligne des utilisateurs, et ainsi de suite.

Tu peux ensuite importer le hook pour l'utiliser dans n'importe quel composant, afin de te concentrer sur le rendu et la présentation dans ces composants. Cela signifie moins de répétitions et moins de duplication, donc moins d'endroits à modifier quand tu veux faire des mises à jour.

Maintenant, regardons comment tu peux créer ton propre hook personnalisé.

En React, tous les hooks intégrés commencent par le mot `use`, donc ton hook personnalisé devrait suivre la même convention. Le nom de ton hook personnalisé devrait aussi communiquer clairement ce qu'il fait.

Donc, si ton hook personnalisé…

- récupère des données, tu peux l'appeler `useFetch`

- bascule quelque chose on et off, tu peux l'appeler `useToggle`

- ou s'il implémente le debouncing, `useDebounce` est un bon nom

Disons que tu veux construire un hook personnalisé pour ajouter le debouncing à ton app.

Le debouncing est une technique de programmation qui limite la fréquence d'exécution d'une fonction. Elle fonctionne en attendant que l'utilisateur arrête une action pendant une période spécifiée avant d'exécuter la fonction. Par exemple, dans une boîte de recherche, au lieu de faire un appel API à chaque frappe, le debouncing attend que l'utilisateur pause la saisie pendant, disons, 500 millisecondes.

Pour créer un hook personnalisé de debouncing, tu dois d'abord créer un fichier `useDebounce.jsx` ou `useDebounce.js`. Conventionnellement, les fichiers pour tous les hooks personnalisés que tu crées sont enregistrés dans un dossier `hooks`.

Tu peux utiliser certains hooks intégrés dans ton propre hook personnalisé. Pour le debouncing, tu as besoin des hooks `useState` et `useEffect`, donc importe-les en haut de ton fichier :

```js
import { useState, useEffect } from "react";
```

Ensuite, crée une fonction `useDebounce` qui prend `value` et `delay` comme paramètres. `value` est la ressource pour laquelle tu veux attendre, et `delay` est la période d'attente. Comme tu veux attendre un certain temps, les fonctions `setTimeout` et `clearTimeout` seraient utiles :

```js
function useDebounce(value, delay) {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const handler = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    return () => {
      clearTimeout(handler);
    };
  }, [value, delay]);

  return debouncedValue;
}

export { useDebounce };
```

Le state `debouncedValue` détient et renvoie la valeur retardée, qui ne se met à jour qu'après la période de timeout spécifiée.

`useEffect` est là où la magie opère vraiment. Si tu te souviens de la leçon précédente, tout ce qui existe en dehors du cycle de rendu React, comme définir et effacer un timer, est un side effect, et tu devrais utiliser le hook `useEffect` pour les gérer.

Dans le hook `useEffect` ici, tu utilises `setTimeout` pour définir le `debouncedValue`. Tu renvoies ensuite une fonction de nettoyage qui utilise `clearTimeout` pour effacer le timeout précédent chaque fois que `value` ou `delay` change, ou que le composant se démonte.

Et voici un composant `FootballerSearch` qui utilise le hook `useDebounce` pour retarder la recherche de 1 seconde après que l'utilisateur arrête de taper :

```jsx
import { useState, useEffect } from "react";
import { useDebounce } from "./hooks/useDebounce";
import footballers from "./footballers";

const FootballerSearch = () => {
  const [query, setQuery] = useState("");
  const debouncedQuery = useDebounce(query, 1000); // Start searching 1 second after the user stops typing

  useEffect(() => {
    if (debouncedQuery) {
      const results = footballers.filter((footballer) =>
        footballer.toLowerCase().includes(debouncedQuery.toLowerCase()),
      );
      console.log("Search results:", results);
    } else {
      console.log("Search results: []");
    }
  }, [debouncedQuery]);

  return (
    <>
      <h1 style={{ textAlign: "center" }}>Footballer Search App</h1>
      <div style={{ textAlign: "center" }}>
        <input
          style={{ padding: "0.5rem", width: "30%" }}
          type="text"
          value={query}
          onChange={(e) => setQuery(e.target.value)}
          placeholder="Search for a footballer..."
        />
      </div>
    </>
  );
};

export default FootballerSearch;
```

Comme tu peux le voir, la variable `debouncedQuery` est ce qui initialise le hook `useDebounce` avec le state query (ce que l'utilisateur tape), et le délai de 1 000 millisecondes, ou 1 seconde. La recherche elle-même est gérée dans le hook `useEffect`, et les résultats de recherche sont journalisés dans la console.
