# --description--

En React, il peut y avoir des situations où tu as besoin d'un accès direct à un élément du DOM. C'est là que les « refs » sont utiles. Les refs peuvent aussi stocker des valeurs mutables, mais le state est un meilleur choix pour cela.

En JavaScript vanilla, tu utilisais les méthodes `getElementById()` et `querySelector()` pour accéder aux éléments du DOM. Mais en React, tu utilises les refs pour accéder aux éléments dans le DOM.

Une des principales différences est qu'avec les refs, tu n'as pas besoin d'identifiants comme des IDs et des classes pour référencer les éléments.

Alors, comment peux-tu créer et utiliser des refs ? React fournit un hook `useRef()` qui te permet de faire exactement cela.

La première étape est d'importer le hook depuis React :

```js
import { useRef } from "react";
```

Ensuite, tu dois créer une variable qui détient la ref avec la valeur initiale de la ref à l'intérieur du hook `useRef`, disons une `sectionRef` initialisée à `null` :

```js
const sectionRef = useRef(null);
```

La dernière chose à faire est d'attacher la variable ref à l'élément dans ton JSX en utilisant l'attribut `ref` :

```jsx
<section ref={sectionRef}>
  {/* Section content */}
</section>
```

Si tu journalises la ref dans la console, tu verras que c'est un objet avec la valeur actuelle, dans ce cas, `null` :

```js
console.log(sectionRef); // { current: null }
```

Tu peux aussi journaliser la valeur actuelle dans la console avec la propriété `current` pour voir la valeur directement :

```js
console.log(sectionRef.current); // null
```

Les valeurs suivantes de la ref dépendent du cycle de vie du composant.

Par exemple, la valeur initiale de `sectionRef` sera toujours `null` car c'est à cela qu'elle a été initialisée. Après le montage du composant, la valeur de la ref sera l'élément `section` auquel la ref est attachée.

Si le composant est démonté, la valeur de la ref revient à la valeur initiale de `null`.

Un exemple typique pour illustrer une ref est de mettre le focus sur un élément input au rendu, ou en cliquant sur un bouton.

Voici comment le faire quand tu cliques sur un bouton :

```jsx
import { useRef } from "react";

const Focus = () => {
  const inputRef = useRef(null);

  const handleFocus = () => {
    if (inputRef.current) {
      inputRef.current.focus();
    }
  };

  return (
    <div>
      <input ref={inputRef} type="text" placeholder="Enter text" />
      <button onClick={handleFocus}>Focus Input</button>
    </div>
  );
};

export default Focus;
```

Dans le code ci-dessus, la `inputRef` est créée et attachée à l'élément `input`. Il y a aussi un bouton avec un événement `onClick` qui appelle une fonction `handleFocus`.

Tout ce que fait la fonction `handleFocus`, c'est appeler la méthode `focus()` sur l'élément `input`. Note que, comme `input` est un composant intégré fourni avec React, l'élément DOM `input` réel est défini sur la propriété `current` de la ref. Tu appelles donc la méthode `focus()` avec `input.current.focus()`.

Voici quelques bonnes pratiques dont tu devrais être conscient en travaillant avec les refs :

- Utilise les refs surtout pour interagir avec le DOM. Tu peux aussi les utiliser pour des données mutables, mais le state est un meilleur choix pour cela.

- N'utilise pas les refs pour la gestion basique du state – c'est à cela que sert `useState`.

- Assure-toi de vérifier que `ref.current` existe avant d'accéder à ses propriétés. Voici comment le faire à nouveau :

```js
const handleFocus = () => {
  if (inputRef.current) {
    inputRef.current.focus();
  }
};
```

Cela évite les erreurs au cas où la ref serait accédée avant d'être attachée au DOM ou après avoir été retirée.
