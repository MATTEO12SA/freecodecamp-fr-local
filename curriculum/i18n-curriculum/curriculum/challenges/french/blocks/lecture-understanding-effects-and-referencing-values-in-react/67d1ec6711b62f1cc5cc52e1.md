# --description--

En React, un effet est tout ce qui se produit en dehors du processus de rendu du composant. C'est-à-dire, tout ce que React ne gère pas directement dans le cadre du rendu de l'UI.

Des exemples courants incluent la récupération de données, la mise à jour du titre de l'onglet du navigateur, la lecture ou l'écriture dans le local storage du navigateur, obtenir la localisation de l'utilisateur, et bien plus. Ces opérations interagissent avec le monde extérieur et sont appelées side effects.

React fournit le hook `useEffect` pour te laisser gérer ces side effects. `useEffect` te permet d'exécuter une fonction après que le composant se rende ou se mette à jour.

Voyons comment le hook `useEffect` fonctionne et pourquoi il est essentiel pour le développement React moderne.

Pour utiliser le hook `useEffect`, tu dois d'abord l'importer :

```js
import { useEffect } from "react";
```

Ensuite tu l'utilises comme une fonction, comme ceci :

```js
useEffect(() => {
  // Your side effect logic (usually a function) here
}, [dependencies]);
```

La fonction d'effet s'exécute après le rendu du composant, tandis que l'argument optionnel `dependencies` contrôle quand l'effet s'exécute.

Note que `dependencies` peut être un tableau de « valeurs réactives » (state, props, fonctions, variables, et ainsi de suite), un tableau vide, ou entièrement omis. Voici comment toutes ces options contrôlent le fonctionnement de `useEffect` :

- Si `dependencies` est un tableau qui inclut une ou plusieurs valeurs réactives, l'effet s'exécutera chaque fois qu'elles changent.

- Si `dependencies` est un tableau vide, `useEffect` ne s'exécute qu'une fois quand le composant se rend pour la première fois.

- Si tu omets `dependencies`, l'effet s'exécute à chaque fois que le composant se rend ou se met à jour.

Par exemple, dans cette application `Counter`, nous ne passons pas d'argument `dependencies`, donc l'effet s'exécute quand le composant se rend et à chaque mise à jour :

```jsx
import { useState, useEffect } from "react";

const Counter = () => {
  const [count, setCount] = useState(0);

  useEffect(() => {
    console.log("Component renders");
  });

  return (
    <div
      style={{
        display: "flex",
        alignItems: "center",
        flexDirection: "column",
      }}
    >
      <h2>{count}</h2>
      <div>
        <button onClick={() => setCount(count + 1)}>Increase</button>
        <button onClick={() => setCount(count - 1)}>Decrease</button>
      </div>
    </div>
  );
};

export default Counter;
```

Mais si nous passons un tableau vide comme dépendance, l'effet ne s'exécute que lors du premier rendu :

```js
useEffect(() => {
  console.log('Component renders');
}, []);
```

Si tu passes le state `count` comme dépendance, l'effet s'exécute quand le composant se rend pour la première fois, et quand `count` change :

```js
useEffect(() => {
  document.title = `The current count is ${count}`;
  console.log('component renders');
}, [count]);
```

Note que, si l'effet que tu configures persiste au-delà du cycle de vie de rendu du composant, tu pourrais avoir besoin d'une autre fonction pour « nettoyer » cette fonction après que le composant se rende ou se mette à jour.

Par exemple, si ta fonction d'effet utilise `setInterval()`, définit un écouteur d'événement comme `window.addEventListener()`, ou se connecte à un serveur, tu auras besoin d'une fonction de nettoyage pour exécuter `clearInterval()`, `window.removeEventListener()`, et te déconnecter du serveur, respectivement.

Voici la syntaxe pour renvoyer une fonction de nettoyage depuis le hook `useEffect` :

```js
useEffect(() => {
  // Your side effect logic here
  return () => {
    // Cleanup logic here (optional)
  };
}, [dependencies]);
```

Par exemple, si tu ajoutes un écouteur d'événement scroll, tu peux le nettoyer en le retirant dans ta fonction de nettoyage :

```js
useEffect(() => {
  const handleScroll = () => {
    // Handle scroll logic
  };
  window.addEventListener("scroll", handleScroll);

  return () => {
    window.removeEventListener("scroll", handleScroll);
  };
}, []);
```
