## JavaScript côté client

- **JavaScript côté client** : Code qui s'exécute côté client d'une application web, généralement dans un navigateur web.
- **Limites du JavaScript côté client** : Bien que puissant, le JavaScript côté client a certaines limites :
  - Accès très restreint aux fichiers locaux.
  - Non conçu pour gérer une logique applicative complexe.
  - Risques de sécurité potentiels (par ex. exposer des informations sensibles comme des identifiants de base de données).
- **Raison des limites** : Ces limites existent parce que le JavaScript côté client a été conçu initialement pour s'exécuter exclusivement dans les navigateurs web.

## Environnement du navigateur

- **Moteur JavaScript** : Les navigateurs web fournissent l'environnement nécessaire pour exécuter du code JavaScript, y compris le moteur JavaScript.
- **Document Object Model (DOM)** : Les navigateurs donnent accès au DOM, ce qui te permet d'accéder aux éléments HTML dans ton code.
- **Contexte historique** : Auparavant, JavaScript ne pouvait pas s'exécuter hors d'un navigateur, mais maintenant il le peut avec Node.js.

## Qu'est-ce que Node.js ?

- **Node.js** : Un environnement d'exécution JavaScript. Officiellement défini comme « un environnement d'exécution JavaScript open source et multiplateforme ».
- **Open source** : Le code de Node.js est accessible publiquement et maintenu par une large communauté de développeurs.
- **Multiplateforme** : Fonctionne sur n'importe quel système d'exploitation, y compris Windows, macOS et Linux.
- **Environnement d'exécution JavaScript** : Te permet d'exécuter du code JavaScript en dehors d'un navigateur.

## Cas d'usage de Node.js

- **Applications courantes** : Node.js est utilisé dans un large éventail d'industries pour :
  - Construire des serveurs web et des API qui gèrent des requêtes HTTP.
  - Développer des applications web et mobiles.
  - Gérer des données complexes et des interactions avec des bases de données.
- **Adoption dans l'industrie** : Si tu utilises ou développes un site ou une application web qui interagit avec une base de données ou gère des données complexes, il y a de fortes chances que tu utilises Node.js en coulisses.
- **Caractéristiques clés** : Node.js est efficace, scalable, et dispose d'une large communauté de développeurs et de mainteneurs dans le monde entier.

## Navigateur vs environnement d'exécution Node

- **Environnement du navigateur** : Principalement conçu pour le développement web front-end, exécute du JavaScript côté client.
- **Environnement d'exécution Node** : Principalement conçu pour le développement web back-end, exécute du JavaScript côté serveur.
- **Différences d'API** : L'environnement détermine les API disponibles :
  - **Navigateur** : Accès à l'API DOM, mais des restrictions pour accéder au système de fichiers local.
  - **Node** : Accès à presque toutes les ressources système, y compris le système de fichiers, mais pas au DOM.

## Objets globaux

- **Objet global du navigateur (`window`)** : Donne accès à des fonctionnalités liées au navigateur :
  - Méthodes pour manipuler le DOM.
  - Gestion des cookies.
  - Traitement des événements du navigateur.

- **Objet global de Node.js (`global`)** : Donne accès à des fonctionnalités spécifiques à Node.js :
  - Modules intégrés pour travailler avec les fichiers locaux.
  - Capacités réseau.
  - Interaction avec le système d'exploitation.

## Contrôle des versions

- **Version du navigateur** : Tu n'as aucun contrôle sur la version de l'environnement du navigateur que tes utilisateurs utiliseront pour visiter ton site.
- **Version de Node.js** : Tu peux choisir la version de Node.js que tu veux utiliser sur ton serveur.

## Importance de Node.js

- **Développement full-stack** : Node.js a transformé le développement web en permettant aux développeurs d'utiliser JavaScript pour construire à la fois le front-end et le back-end d'applications full-stack.
- **Efficacité** : Le processus de développement est plus efficace parce que les développeurs n'ont pas besoin d'apprendre un nouveau langage de programmation uniquement pour développer le back-end.
- **Impact** : Node.js est un outil puissant, scalable et polyvalent qui est devenu très important pour les développeurs du monde entier.

## Avantages de Node.js

- **Un seul langage pour le full-stack** : Tu peux implémenter à la fois le front-end et le back-end d'une application web en JavaScript.
  - Réduit la courbe d'apprentissage initiale.
  - Pas besoin de basculer entre les langages de programmation.
  - Augmente l'efficacité et la productivité.

- **Architecture non bloquante et orientée événements** : Idéale pour développer des applications temps réel où la réactivité et l'efficacité sont essentielles pour créer une bonne expérience utilisateur.

- **Thread unique et boucle d'événements** : Peut gérer efficacement un grand nombre de requêtes simultanées et d'opérations d'entrée-sortie.
  - Parfait pour les applications qui doivent gérer plusieurs requêtes en même temps.

- **Large communauté** : Des milliers de développeurs dans le monde entier maintiennent constamment Node.js et y ajoutent de nouvelles fonctionnalités.
  - De nombreuses ressources d'apprentissage disponibles.
  - Facile de trouver des réponses aux questions.

- **npm (Node Package Manager)** : Un outil puissant qui te permet d'installer et de gérer des paquets et des modules pour tes projets.
  - Paquets disponibles pour de nombreux usages : gérer des requêtes HTTP, travailler avec des bases de données, formater des dates et heures, tester du code, et plus encore.
  - Réutiliser du code écrit, testé et partagé par d'autres développeurs.
  - Rend le flux de travail plus rapide et plus efficace.

- **Rentable** : Node.js est gratuit et open source.
  - Les paquets, bibliothèques et outils associés sont aussi principalement gratuits.
  - Facteur important quand on optimise un budget.

## Inconvénients de Node.js

- **Limite mono-thread** : N'exécute qu'un seul thread à la fois, ce qui signifie qu'il ne peut gérer qu'une opération à la fois.
  - Bien que l'architecture permette une gestion efficace des requêtes concurrentes (simultanées), les tâches intensives en CPU peuvent bloquer le thread principal et entraîner des problèmes de performance.
  - Exemples de tâches intensives en CPU : opérations mathématiques complexes, traitement d'images et de vidéos, cryptographie.
  - Des moyens de contourner cela existent, mais ils augmentent généralement la complexité de l'application.

- **Programmation asynchrone** : Node.js repose sur la programmation asynchrone.
  - Une tâche qui peut prendre du temps à s'exécuter est démarrée, mais au lieu d'attendre qu'elle soit terminée, le programme principal continue de s'exécuter pendant que la tâche asynchrone tourne en parallèle.
  - Quand la tâche est terminée, le programme traite le résultat.
  - Implique souvent des « callbacks », qui sont des fonctions qui définissent ce qui se passe quand les opérations asynchrones sont terminées.
  - Peut potentiellement rendre le code plus difficile à lire, comprendre et déboguer.

- **Préoccupations sur la qualité des paquets** : Quand tu choisis des paquets depuis npm, certains peuvent ne pas être maintenus en permanence et peuvent introduire des vulnérabilités dans ton application.
  - Les développeurs doivent évaluer chaque paquet avec soin.
  - Vérifier si les paquets suivent les bonnes pratiques de qualité et de sécurité.

## Threads

- **Thread** : Un chemin d'exécution au sein d'un processus, comme un programme informatique actuellement en cours d'exécution.

## NVM (Node Version Manager)

- **NVM** : Un outil pour gérer plusieurs versions de Node.js sur le même ordinateur.
- **Objectif** : T'aide à basculer facilement entre différentes versions de Node.js pour différents projets.
- **Recommandation** : Installer NVM avant Node.js est recommandé pour plus de flexibilité à l'avenir.

## Installer NVM sur macOS/Linux

- **Outils en ligne de commande Xcode (macOS)** : Doivent être installés manuellement avant d'exécuter le script d'installation de NVM sur macOS.

```bash
xcode-select --install
```

- **Vérifier l'installation de Xcode** :

```bash
xcode-select --version
```

- **Télécharger et exécuter le script d'installation de NVM** : Exécute l'une de ces commandes :

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

```bash
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

- **Redémarrage du terminal** : Tu pourrais devoir redémarrer ton terminal une fois le processus terminé pour charger la nouvelle commande et la configuration.

- **Vérifier l'installation de NVM** :

```bash
nvm -v
```

## Installer Node.js avec NVM sur macOS/Linux

- **Installer la dernière version LTS** : Pour installer la dernière version Long-Term Support (LTS) de Node.js :

```bash
nvm install --lts
```

- **LTS (Long-Term Support)** : Cette version est généralement recommandée parce qu'elle priorise la stabilité, la fiabilité et la sécurité plutôt que les fonctionnalités nouvelles ou expérimentales.
  - Soigneusement testée et prête pour la production.
  - Garantie d'avoir des périodes de support plus longues, avec un focus sur les corrections de bugs et les correctifs de sécurité.

- **Installer une version spécifique** : Tu peux installer une version spécifique de Node.js en précisant le numéro de version :

```bash
nvm install <version>
```

Exemple :

```bash
nvm install 20
```

- **Basculer vers une version** :

```bash
nvm use <version>
```

Exemple :

```bash
nvm use 20
```

- **Vérifier la version actuelle de Node.js** :

```bash
node -v
```

## Installer NVM sur Windows

- **Support officiel de NVM** : Les versions officielles de NVM ne prennent en charge Windows que dans des cas spécifiques.
  - Si tu as Windows Subsystem for Linux (WSL), tu peux suivre le guide macOS/Linux ci-dessus.

- **nvm-windows** : Un utilitaire de gestion de versions Node.js pour Windows.
  - Projet complètement séparé du projet NVM officiel.
  - Même objectif : t'aider à travailler avec plusieurs versions de Node.js sur le même appareil.

- **Avant l'installation** : Il est recommandé de désinstaller toute installation Node préalable avant d'installer NVM for Windows.

- **Étapes d'installation** :
  - Va dans la section Releases du dépôt officiel : `https://github.com/coreybutler/nvm-windows/releases`.
  - Télécharge le dernier installateur.
  - Suis les instructions.

- **Redémarrage du terminal** : Tu pourrais devoir redémarrer ton terminal si la commande `nvm` n'est pas immédiatement disponible.

- **Vérifier l'installation** :

```powershell
nvm -v
```

## Commandes de base NVM et Node.js

- **Note sur les commandes** : Toutes les commandes fonctionnent pour NVM installé sur macOS/Linux, y compris WSL. Elles peuvent fonctionner différemment ou ne pas fonctionner du tout pour `nvm-windows`. Des commandes alternatives pour `nvm-windows` sont fournies quand c'est possible.

### Stratégie d'exécution PowerShell (Windows)

- **Stratégie d'exécution par défaut** : La stratégie d'exécution par défaut de PowerShell est `Restricted`, ce qui empêche l'exécution de scripts comme mesure de sécurité.

- **Lancer PowerShell en tant qu'administrateur** : Fais un clic droit sur PowerShell, puis clique sur « Run as Administrator ».

- **Vérifier la stratégie d'exécution actuelle** :

```powershell
Get-ExecutionPolicy
```

- **Définir la stratégie d'exécution sur RemoteSigned** : Permet aux scripts locaux et à `npm` de s'exécuter :

```powershell
Set-ExecutionPolicy RemoteSigned
```

- **Après avoir défini la stratégie** : Ferme la fenêtre administrateur de PowerShell et ouvre une fenêtre PowerShell non administrateur.

### Lister toutes les versions installées

- **Lister les versions installées** : Pour lister toutes les versions installées de Node.js et vérifier celle qui est actuellement utilisée :

```bash
nvm ls
```

### Définir la version Node.js par défaut (NVM sur macOS/Linux uniquement)

- **Définir la version par défaut** : Définit la version par défaut de Node.js pour les nouvelles sessions de terminal :

```bash
nvm alias default <version>
```

Exemple :

```bash
nvm alias default 22.20.0
```

- **Créer des alias personnalisés** : Attribuer un nom plus spécifique à une version :

```bash
nvm alias <new_name> <version>
```

Exemple :

```bash
nvm alias new-api 18.20.8
```

- **Utiliser un alias personnalisé** :

```bash
nvm use <new_name>
```

Exemple :

```bash
nvm use new-api
```

### Supprimer une version de Node.js

- **Désinstaller une version** :

```bash
nvm uninstall <version>
```

Exemple :

```bash
nvm uninstall 20.19.5
```

- **Supprimer par version majeure (NVM sur macOS/Linux)** : Tu peux supprimer une version en exécutant la commande `uninstall` avec une version majeure comme `22` ou `20` :

```bash
nvm uninstall 20
```

Si tu as plusieurs versions pour cette version majeure installées, comme `20.14.0` et `20.12.2`, la dernière version sera supprimée en premier. Exécuter `nvm uninstall 20` supprimera d'abord `20.14.0`.

### Vérifier la version de Node.js

- **Vérifier la version actuelle** :

```bash
node -v
```

### Vérifier la version de npm

- **npm** : Un gestionnaire de paquets pour Node.js utilisé pour installer, publier et gérer des paquets logiciels. Automatiquement installé quand tu installes Node.js.

- **Vérifier la version de npm** :

```bash
npm -v
```

### Exécuter un fichier JavaScript

- **Exécuter un fichier JavaScript** : Exécute le fichier JavaScript dans l'environnement d'exécution Node.js actuellement actif :

```bash
node <file.js>
```

Exemple :

```bash
node app.js
```

### Créer un projet Node.js

- **Initialiser un projet** : Crée un nouveau projet Node.js en créant un fichier `package.json` qui suit ses détails et dépendances :

```bash
npm init
```

- **Configuration interactive** : La commande `npm init` te guide à travers un guide CLI interactif pour configurer le fichier `package.json`.
  - Pose des questions sur le nom du projet, la description, la version, etc.

- **Configuration par défaut** : Pour démarrer avec un fichier `package.json` par défaut :

```bash
npm init -y
```

ou

```bash
npm init --yes
```

### Installer un paquet

- **Installer un paquet spécifique** :

```bash
npm install <package>
```

Exemple :

```bash
npm install express
```

### Installer toutes les dépendances

- **Installer les dépendances** : Pour installer toutes les dépendances listées dans le fichier `package.json` d'un projet :

```bash
npm install
```
