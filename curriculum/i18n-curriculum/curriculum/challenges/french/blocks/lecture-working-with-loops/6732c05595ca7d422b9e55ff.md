# --interactive--

Une boucle `for...in` est le mieux adaptée lorsque tu as besoin de parcourir les propriétés d'un objet. Cette boucle itérera sur toutes les propriétés énumérables d'un objet, y compris les propriétés héritées et les propriétés non numériques.

Une propriété héritée est une propriété qui est héritée de la chaîne de prototypes de l'objet. Une propriété non numérique est une propriété qui n'est pas un nombre ni une chaîne pouvant être convertie en nombre.

Voici la syntaxe de base d'une boucle `for...in` :

```js
for (variable in object) {
  // code block to be executed
}
```

La variable dans l'exemple représente la propriété courante de l'objet qui est parcouru.

Regardons quelques exemples pour que tu comprennes mieux comment fonctionne la boucle `for...in`.

Dans ce premier exemple, nous avons un objet `fruit` et nous voulons parcourir chaque propriété et afficher la valeur dans la console.

:::interactive_editor

```js
const fruit = {
  name: 'apple',
  color: 'red',
  price: 0.99
};

for (const prop in fruit) {
  console.log(fruit[prop]);
}
```

:::

La variable `prop` représente la propriété courante de l'objet. `fruit[prop]` est utilisé pour accéder à la valeur de chaque propriété.

Pour la première itération, `prop` sera `name`. Pour la deuxième itération, `prop` sera `color`, et ainsi de suite.

Les résultats affichés dans la console seront `apple`, `red` et `0.99`.

Dans ce deuxième exemple, nous avons un objet imbriqué et nous voulons parcourir chaque propriété et afficher la valeur dans la console.

:::interactive_editor

```js
const person = {
  name: 'John',
  age: 30,
  address: {
    street: '123 Main St',
    city: 'Anytown',
    state: 'CA'
  }
};

for (const prop in person) {
  console.log(person[prop]);
}
```

:::

La propriété `address` est elle-même un objet. La boucle `for...in` parcourra aussi les propriétés de l'objet `person` et affichera l'objet `address` entier dans la console.

Voici à quoi ressemblera le résultat dans la console :

```md
John
30
{ street: '123 Main St', city: 'Anytown', state: 'CA' }
```

Si tu veux parcourir les propriétés de l'objet `address`, tu peux imbriquer une autre boucle `for...in` à l'intérieur de la première.

:::interactive_editor

```js
const person = {
  name: 'John',
  age: 30,
  address: {
    street: '123 Main St',
    city: 'Anytown',
    state: 'CA'
  }
};

function isObject(obj) {
  return typeof obj === 'object' && !Array.isArray(obj) && obj !== null;
}

for (const prop in person) {
  if (isObject(person[prop])) {
    for (const nestedProp in person[prop]) {
      console.log(person[prop][nestedProp]);
    }
  } else {
    console.log(person[prop]);
  }
}
```

:::

Dans cet exemple, nous avons une fonction personnalisée `isObject` qui vérifie si la valeur est un objet.

La méthode `Array.isArray` est utilisée pour vérifier si la valeur est un tableau. En plaçant l'opérateur logique NON (`!`) devant la méthode, nous vérifions si la valeur n'est pas un tableau.

La raison pour laquelle nous ne pouvons pas simplement utiliser `typeof` égal à `'object'` est que les tableaux sont aussi considérés comme des objets en JavaScript. Nous voulons exclure les tableaux de la vérification.

De plus, à cause d'un bug historique en JavaScript, `typeof null` retourne `'object'`. Nous voulons donc aussi exclure les valeurs `null` de la vérification.

Si la condition est vraie, nous imbriquons une autre boucle `for...in` qui parcourra les propriétés de l'objet imbriqué et affichera la valeur dans la console.

La variable `nestedProp` représente la propriété courante de l'objet imbriqué.

Voici à quoi ressemblera le résultat modifié dans la console :

```md
"John"
30
"123 Main St"
"Anytown"
"CA"
```

Une boucle `for...in` est utile lorsque tu as besoin de parcourir les propriétés d'un objet.

Il n'est pas recommandé d'utiliser une boucle `for...in` pour parcourir les éléments d'un tableau. À la place, utilise une boucle `for...of` ou d'autres méthodes de tableau comme `forEach`, `map`, `filter` et `reduce`, que tu découvriras dans de futures leçons.

Pourquoi n'est-il généralement pas recommandé d'utiliser une boucle `for...in` pour itérer sur les éléments d'un tableau ?

## --answers--

`for...in` n'itère que sur les méthodes du tableau, pas sur les éléments.
