# --interactive--

Une instruction `break` est utilisée pour sortir d'une boucle de façon anticipée, tandis qu'une instruction `continue` est utilisée pour passer l'itération courante d'une boucle et passer à la suivante.

Voici un exemple d'utilisation d'une instruction `break` dans une boucle `for` :

:::interactive_editor

```js
for (let i = 0; i < 10; i++) {
  if (i === 5) {
    break;
  }
  console.log(i);
}
```

:::

Dans l'exemple ci-dessus, la boucle commence à compter à `0` et tant que `i` est inférieur à `10`, la boucle continuera de s'exécuter.

À l'intérieur de la boucle, nous vérifions si `i` est égal à `5`. Si c'est le cas, nous utilisons l'instruction `break` pour sortir de la boucle de façon anticipée. Sinon, nous affichons la valeur de `i` dans la console. Donc la sortie du code affichera les nombres `0`, `1`, `2`, `3` et `4`.

L'instruction `break` est utile lorsque tu veux sortir d'une boucle de façon anticipée en fonction d'une certaine condition. Par exemple, si tu recherches une valeur précise dans un tableau, tu peux utiliser une instruction `break` pour sortir de la boucle une fois que tu as trouvé la valeur.

Parfois, tu peux vouloir sauter une itération particulière d'une boucle sans sortir entièrement de la boucle. C'est là qu'intervient l'instruction `continue`. Voici un exemple d'utilisation d'une instruction `continue` dans une boucle `for` :

:::interactive_editor

```js
for (let i = 0; i < 10; i++) {
  if (i === 5) {
    continue;
  }
  console.log(i);
}
```

:::

Comme précédemment, nous avons initialisé `i` à `0` et nous avons une condition qui exécutera la boucle tant que `i` est inférieur à `10`.

À l'intérieur de la boucle, lorsque `i` est égal à `5`, nous utilisons l'instruction `continue` pour sauter l'itération courante et passer à la suivante.

La sortie de ce code affichera les nombres `0`, `1`, `2`, `3`, `4`, `6`, `7`, `8` et `9`. Le nombre `5` est sauté à cause de l'instruction `continue`.

Une autre chose que tu peux faire avec les instructions `break` et `continue` est d'utiliser des étiquettes (labels) pour spécifier de quelle boucle tu veux sortir ou continuer.

C'est utile lorsque tu as des boucles imbriquées et que tu veux contrôler le déroulement de la boucle externe depuis l'intérieur de la boucle interne.

Voici un exemple d'utilisation des étiquettes avec l'instruction `break` :

:::interactive_editor

```js
outerLoop: for (let i = 0; i < 3; i++) {
  innerLoop: for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) {
      break outerLoop;
    }
    console.log(`i: ${i}, j: ${j}`);
  }
}
```

:::

Dans cet exemple, nous avons une boucle `for` externe étiquetée `outerLoop` et une boucle `for` interne étiquetée `innerLoop`.

Lorsque `i` est égal à `1` et `j` est égal à `1`, nous utilisons l'instruction `break` avec l'étiquette `outerLoop` pour sortir de la boucle externe de façon anticipée. Cela fera sortir à la fois de la boucle interne et de la boucle externe.

La sortie de ce code affichera ce qui suit dans la console :

```md
"i: 0, j: 0"
"i: 0, j: 1"
"i: 0, j: 2"
"i: 1, j: 0"
```

La plupart du temps, tu n'auras pas besoin d'utiliser les étiquettes avec les instructions `break` et `continue`, mais il est bon de savoir que tu disposes de cette option si jamais tu en as besoin.
