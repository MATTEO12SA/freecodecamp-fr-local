# --interactive--

Une boucle `for...of` est utilisée lorsque tu as besoin de parcourir les valeurs d'un itérable. Les tableaux et les chaînes sont des exemples d'itérables.

Voici la syntaxe de base d'une boucle `for...of` :

```js
for (variable of iterable) {
  // code block to be executed
}
```

La variable dans l'exemple représente la valeur courante de l'itérable qui est parcouru.

Si tu as un tableau de nombres, la variable serait le nombre courant du tableau. Si tu as une chaîne, la variable serait le caractère courant de la chaîne.

Regardons quelques exemples pour que tu comprennes mieux comment fonctionne la boucle `for...of`.

Dans ce premier exemple, nous avons un tableau de nombres et nous voulons parcourir chaque nombre et l'afficher dans la console.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];

for (const num of numbers) {
  console.log(num);
}
```

:::

Nous avons créé une variable appelée `num` qui représentera le nombre courant du tableau. Pour l'itération 1, `num` sera `1`, pour l'itération 2, `num` sera `2`, et ainsi de suite.

À l'intérieur de la boucle, nous affichons le nombre courant dans la console.

Voici un autre exemple où nous avons une chaîne et nous voulons parcourir chaque caractère et l'afficher dans la console.

:::interactive_editor

```js
const str = 'freeCodeCamp';

for (let char of str) {
  console.log(char);
}
```

:::

Dans cet exemple, nous avons créé une variable appelée `char` qui représentera le caractère courant de la chaîne.

À chaque itération, la boucle affichera le caractère courant dans la console.

Il est important de noter que tu peux utiliser `let` ou `const` lors de la déclaration de la variable dans une boucle `for...of`.

Cependant, si tu vas utiliser `const`, assure-toi que la valeur de la variable ne change pas à l'intérieur de la boucle. Si elle change, tu obtiendras une erreur.

Voici un exemple d'utilisation de `const` qui provoque une erreur :

```js
const numbers = [1, 2, 3, 4, 5];

for (const num of numbers) {
  console.log(num);
  num = num + 1; // This will cause an error
}
```

Dans cet exemple, nous essayons de changer la valeur de `num` à l'intérieur de la boucle. Comme nous avons déclaré `num` avec `const`, nous obtiendrons une erreur. Donc, si tu as besoin de changer la valeur de la variable à l'intérieur de la boucle, utilise `let` à la place.

Regardons un dernier exemple qui traite d'un tableau d'objets.

:::interactive_editor

```js
const people = [
  { name: 'John', age: 30 },
  { name: 'Jane', age: 25 },
  { name: 'Jim', age: 40 }
];

for (const person of people) {
  console.log(`${person.name} is ${person.age} years old`);
}
```

:::

Dans cet exemple, nous avons un tableau d'objets appelé `people`. Chaque objet a une propriété `name` et une propriété `age`.

Lorsque nous parcourons le tableau, nous créons une variable appelée `person` qui représentera l'objet courant du tableau.

À l'intérieur de la boucle, nous affichons un message dans la console.

Le premier message sera `John is 30 years old`, le deuxième message sera `Jane is 25 years old`, et le troisième message sera `Jim is 40 years old`.

Les boucles `for...of` sont vraiment utiles lorsque tu as besoin de parcourir les valeurs d'un itérable comme un tableau ou une chaîne. Elles sont aussi faciles à lire et peuvent rendre ton code plus concis.
