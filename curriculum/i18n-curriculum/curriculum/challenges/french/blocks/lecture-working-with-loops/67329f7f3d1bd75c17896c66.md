# --interactive--

Les boucles en programmation sont utilisées pour répéter un bloc de code plusieurs fois.

Un exemple de boucle serait lorsque tu conçois un programme qui doit afficher une liste d'éléments. Tu pourrais utiliser une boucle pour afficher chacun des éléments de la liste.

Un autre exemple serait lorsque tu conçois un jeu et que tu veux déplacer un personnage à travers l'écran. Tu pourrais utiliser une boucle pour déplacer le personnage d'un certain nombre de pixels à chaque exécution de la boucle.

En JavaScript, il existe plusieurs types de boucles que tu peux utiliser. Dans cette leçon, nous allons couvrir la boucle `for`. Voici la syntaxe de base d'une boucle `for` :

```js
for (initialization; condition; increment or decrement) {
  // code block to be executed
}
```

L'instruction d'initialisation est exécutée avant le début de la boucle. Elle est généralement utilisée pour initialiser une variable compteur. Une variable compteur est une variable utilisée pour garder la trace du nombre de fois que la boucle a été exécutée.

L'instruction de condition est évaluée avant chaque itération de la boucle. Une itération est un seul passage à travers la boucle.

Si la condition est vraie, le bloc de code à l'intérieur de la boucle est exécuté. Si la condition est fausse, la boucle s'arrête et tu passes au bloc de code suivant.

La dernière partie de la boucle est l'instruction d'incrémentation/décrémentation. Cette instruction est exécutée après chaque itération de la boucle. Elle est généralement utilisée pour incrémenter ou décrémenter la variable compteur.

:::interactive_editor

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

:::

Dans la première partie de l'exemple ci-dessus, nous initialisons une variable compteur `i` à `0`. C'est une convention courante d'utiliser `i` comme variable compteur dans une boucle `for`.

L'étape suivante consiste à vérifier la condition. Dans ce cas, la condition vérifie si `i` est inférieur à `5`. Comme `i` vaut `0`, la condition est vraie, et le bloc de code à l'intérieur de la boucle est exécuté.

Le bloc de code à l'intérieur de la boucle consiste à afficher la valeur de `i` dans la console. La valeur de `i` est `0`, donc la console affichera la valeur `0`.

Ensuite, l'instruction d'incrémentation est exécutée. Dans ce cas, nous incrémentons `i` de `1`. Donc `i` vaut maintenant `1`.

Ensuite, nous vérifions à nouveau la condition, qui consiste à vérifier si `i` est inférieur à `5`. Comme `i` vaut maintenant `1`, la condition est toujours vraie, et le bloc de code à l'intérieur de la boucle est exécuté à nouveau.

Nous continuons de répéter ce processus jusqu'à ce que la condition soit fausse. Dans ce cas, lorsque `i` vaut `5`, la condition est fausse, et la boucle s'arrête.

Lorsque tu travailles avec des boucles, tu dois faire attention à ne pas créer une condition qui est toujours vraie. Si tu le fais, la boucle s'exécutera indéfiniment et ton programme plantera. C'est ce qu'on appelle une boucle infinie.

Il est possible de créer des boucles `for` imbriquées. Une boucle imbriquée, c'est lorsque tu places une boucle à l'intérieur d'une autre. Nous verrons plus tard des exemples de cas où tu pourrais vouloir le faire.

Les boucles peuvent être bénéfiques en programmation lorsque tu as besoin de répéter un bloc de code un certain nombre de fois. Même si travailler avec les boucles `for` peut être délicat au début, avec de la pratique tu finiras par les maîtriser.
