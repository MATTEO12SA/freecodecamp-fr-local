# --interactive--

Dans les leçons précédentes, tu as appris à travailler avec les boucles `for`, les boucles `for...in` et les boucles `for...of`. Dans cette leçon, tu découvriras la boucle `while` et la boucle `do...while`.

Une boucle `while` exécute un bloc de code tant que la condition est vraie. Voici la syntaxe de base d'une boucle `while` :

```js
while (condition) {
  // code block to be executed
}
```

La condition est vérifiée avant l'exécution du bloc de code. Si la condition est fausse, le bloc de code ne sera pas exécuté.

Les boucles `while` sont utiles lorsque tu ne sais pas combien de fois tu dois exécuter le bloc de code. Voici un exemple d'utilisation d'une boucle `while` :

:::interactive_editor

```js
let counter = 0;
while(counter < 5) {
  console.log(counter);
  counter++;
}
```

:::

Dans cet exemple, nous avons une variable appelée `counter` qui est initialisée à `0`. La boucle `while` continuera de s'exécuter tant que la valeur de `counter` est inférieure à `5`. À l'intérieur de la boucle, nous affichons la valeur de `counter` dans la console puis nous incrémentons `counter` de `1`.

Une autre boucle similaire à la boucle `while` serait la boucle `do...while`. Voici la syntaxe de base :

```js
do {
  // code block to be executed
} while (condition);
```

Une différence clé entre une boucle `do...while` et une boucle `while` est que la boucle `do...while` exécutera le bloc de code au moins une fois avant de vérifier la condition.

Si la condition est vraie, le bloc de code continuera de s'exécuter. Si la condition est fausse, le bloc de code cessera de s'exécuter.

Voici un exemple d'utilisation d'une boucle `do...while` :

:::interactive_editor

```js
let counter = 0;
do {
  console.log(counter);
  counter++;
} while (counter < 5);
```

:::

Dans cet exemple, nous avons une variable appelée `counter` qui est initialisée à `0`. La boucle `do...while` affichera la valeur de `counter` dans la console puis incrémentera `counter` de `1`. Après l'exécution du bloc de code, elle vérifie si la valeur de `counter` est inférieure à `5`. Si c'est le cas, la boucle continuera de s'exécuter. Sinon, la boucle s'arrêtera.

Dans la plupart des cas, tu utiliseras probablement la boucle `while` plus souvent que la boucle `do...while`. Cependant, il est bon de connaître les deux types de boucles et de savoir quand les utiliser.
