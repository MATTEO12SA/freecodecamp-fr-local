# --description--

Dans la leçon précédente, tu as appris ce qu'est Python et ce que tu peux en faire. Maintenant, voyons comment installer Python sur ta machine locale.

Le moyen le plus simple d'installer Python sur Windows et Mac est de télécharger l'installateur depuis le site officiel de Python. Nous verrons aussi comment lancer Python sur Linux plus loin dans cette leçon.

Va sur `https://www.python.org/` et survole « Downloads ». Une fenêtre modale apparaîtra avec la version actuelle de Python pour ton système d'exploitation (OS).

Nous allons d'abord voir comment installer Python sur un ordinateur sous macOS :

- Clique sur le bouton qui affiche la version actuelle de Python (dans la fenêtre précédente), et le téléchargement d'un fichier d'installation `.pkg` commencera automatiquement.
- Une fois le téléchargement de l'installateur `.pkg` terminé, ouvre-le, puis clique sur « Continue » dans la fenêtre qui s'ouvre.
- Continue à cliquer sur le bouton « Continue » jusqu'à arriver à la section « Installation Type ». Là, clique sur le bouton « Install ».
- Saisis ton mot de passe si nécessaire, puis lance l'installation.
- Ensuite, tu devrais voir un message de félicitations indiquant que Python a été installé avec succès.
- Clique sur le bouton « Close », et c'est terminé !

Tu peux vérifier l'installation en ouvrant ton terminal et en lançant `python --version` ou `python3 --version`.

Tu peux aussi ouvrir l'interpréteur Python en lançant `python` ou `python3` dans le terminal.

Un <dfn>terminal</dfn> est une interface textuelle qui te permet d'interagir avec ton ordinateur en tapant des commandes. Chaque système d'exploitation fournit une application terminal par défaut. Sur macOS, tu peux utiliser l'app Terminal. Sur Windows, tu peux utiliser l'Invite de commandes ou PowerShell. Sur Linux, chaque environnement de bureau a sa propre app terminal par défaut, comme GNOME Terminal ou Konsole.

Note que, sur certains anciens systèmes macOS et Linux, `python` peut être réservé à Python 2, tandis que `python3` désigne Python 3 spécifiquement. Si tu lances `python --version` et que tu vois une version de Python 2 comme `Python 2.7.18`, il est possible que ton OS dépende d'un logiciel écrit dans l'ancienne version de Python. Dans ce cas, tu devrais utiliser `python3` pour exécuter ton code Python par la suite. Python 2 est en fin de vie et ne devrait plus être utilisé pour aucun nouveau développement.

Pour installer Python sur Windows, suis ces étapes :

- Va sur `https://www.python.org/` et survole « Downloads ». Tu devrais voir une fenêtre qui dit « Download for Windows » et un bouton de téléchargement avec la version actuelle de Python.
- Clique sur le numéro de version, et le téléchargement d'un fichier exécutable Windows (`.exe`) commencera automatiquement.
- Une fois le téléchargement de l'installateur Python pour Windows terminé, double-clique dessus et suis les instructions.
- Quand tu vois l'option `Add python.exe to Path`, coche cette option, puis clique sur `Install Now`. Cela te simplifiera la suite.


Tu peux vérifier l'installation en ouvrant un interpréteur de commandes comme PowerShell et en lançant `python --version`. Tu peux aussi ouvrir l'interpréteur Python en lançant `python`.

Pour Python sur Linux, la plupart des distributions majeures comme Ubuntu, Debian et Fedora fournissent déjà Python.

Ouvre simplement un terminal et lance `python --version`, ou `python3 --version` :

Si aucune des deux commandes n'affiche une version de Python, tu peux chercher un paquet d'installation pour ta distribution Linux sur `https://www.python.org`, ou chercher en ligne la méthode recommandée pour installer Python sur ta distro.
