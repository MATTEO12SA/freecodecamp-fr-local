# --interactive--

La curryfication est une technique où l'on transforme une fonction qui prend plusieurs arguments en une séquence de fonctions, chacune prenant un seul argument.

Commençons par un exemple basique. Imagine que nous avons une fonction qui additionne deux nombres :

:::interactive_editor

```js
function add(a, b) {
  return a + b;
}

console.log(add(3, 4)); // 7
```

:::

C'est une fonction qui prend deux arguments et renvoie leur somme. Voyons maintenant comment on peut curryfier cette fonction :

:::interactive_editor

```js
function curriedAdd(a) {
  return function(b) {
    return a + b;
  }
}

console.log(curriedAdd(3)(4)); // 7
```

:::

Dans ce code curryfié, au lieu de prendre deux arguments à la fois, on a une fonction qui prend le premier argument et renvoie une autre fonction. Cette fonction renvoyée prend ensuite le second argument et effectue l'addition. On l'appelle comme `curriedAdd(3)(4)`, où chaque paire de parenthèses représente un appel de fonction.

Mais pourquoi voudrait-on faire cela ?

La curryfication nous permet de créer facilement des fonctions spéciales. Par exemple, on pourrait créer une fonction qui ajoute toujours cinq à n'importe quel nombre :

:::interactive_editor

```js
function curriedAdd(a) {
  return function(b) {
    return a + b;
  }
}

const addFive = curriedAdd(5);
console.log(addFive(10)); // 15
console.log(addFive(20)); // 25
```

:::

Ici, `addFive` est une fonction toujours prête à ajouter cinq à n'importe quel nombre qu'on lui donne. C'est un exemple simple d'application partielle, où l'on fixe un certain nombre d'arguments d'une fonction, produisant une autre fonction qui prend moins d'arguments.

Bien que nos exemples se soient concentrés sur des fonctions à deux arguments, la curryfication peut s'appliquer à des fonctions avec n'importe quel nombre d'arguments.

Au fur et à mesure de ton parcours en JavaScript, tu trouveras probablement de nombreuses situations où la curryfication peut rendre ton code plus propre et plus expressif.

## --text--

Lequel des éléments suivants est un exemple de fonction curryfiée en JavaScript ?

## --answers--

```js
function add(a, b, c) {
  return a + b + c;
}
```

### --feedback--

C'est une fonction classique qui prend tous les paramètres à la fois.

---

```js
function add(a) {
  return function (b) {
    return function (c) {
      return a + b + c;
    };
  };
}
```

---

```js
function add(a, b, c) {
  return a() + b() + c();
}
```

### --feedback--

Cette fonction accepte tous les paramètres à la fois et les appelle comme des fonctions, ce qui ne suit pas la définition d'une fonction curryfiée.

---

```js
function add(a) {
  function inner(b) {
    return a + b;
  }
}
```

### --feedback--

La fonction interne n'est jamais renvoyée, donc `add(2)` renverra `undefined` et `add(2)(3)` lèvera une erreur.
