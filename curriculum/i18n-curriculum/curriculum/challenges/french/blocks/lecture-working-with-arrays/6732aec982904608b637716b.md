# --interactive--

Les tableaux en JavaScript sont dynamiques, ce qui signifie que tu peux facilement y ajouter ou en supprimer des éléments. Il existe quatre méthodes principales pour ajouter et supprimer des éléments au début et à la fin d'un tableau : `push()`, `pop()`, `shift()` et `unshift()`. Explorons chacune de ces méthodes en détail.

La méthode `push()` est utilisée pour ajouter un ou plusieurs éléments à la fin d'un tableau. La valeur retournée par la méthode `push()` est la nouvelle longueur du tableau. Voici un exemple d'ajout d'un nouveau fruit au tableau `fruits` existant :

:::interactive_editor

```js
const fruits = ["apple", "banana"];
const newLength = fruits.push("orange");
console.log(newLength); // 3
console.log(fruits); // ["apple", "banana", "orange"]
```

:::

Dans cet exemple, nous partons d'un tableau appelé `fruits` qui contient deux éléments. Nous utilisons ensuite la méthode `push()` pour ajouter la chaîne `orange` à la fin du tableau.

Tu as peut-être remarqué que nous utilisons `const` lors de la déclaration du tableau `fruits`. Mais pourquoi est-il possible d'ajouter d'autres éléments à ce tableau `fruits` alors que `fruits` est une constante ? C'est possible parce que déclarer un tableau avec le mot-clé `const` crée une référence vers le tableau. Bien que le tableau lui-même soit mutable et puisse être modifié, tu ne peux pas réaffecter une nouvelle valeur à la constante `fruits`, comme ceci :

```js
const fruits = ["apple", "banana"];
fruits = ["This", "will", "not", "work"];
console.log(fruits); // Uncaught TypeError: Assignment to constant variable.
```

La méthode suivante que nous allons examiner est la méthode `pop()`. La méthode `pop()` supprime le dernier élément d'un tableau et retourne cet élément. Elle modifie aussi le tableau d'origine. Voici comment elle fonctionne :

:::interactive_editor

```js
let fruits = ["apple", "banana", "orange"];
let lastFruit = fruits.pop();
console.log(fruits); // ["apple", "banana"]
console.log(lastFruit); // "orange"
```

:::

Dans cet exemple, nous partons d'un tableau de trois fruits. La méthode `pop()` supprime le dernier élément (`orange`) du tableau et le retourne. Le tableau `fruits` d'origine est modifié et ne contient plus que deux éléments.

La méthode `unshift()` ajoute un ou plusieurs éléments au début d'un tableau et retourne sa nouvelle longueur. Elle fonctionne de manière similaire à `push()`, mais modifie le début du tableau plutôt que la fin. Voici un exemple :

:::interactive_editor

```js
let numbers = [2, 3];
let newLength = numbers.unshift(1);
console.log(numbers); // [1, 2, 3]
console.log(newLength); // 3
```

:::

Dans cet exemple, nous utilisons `unshift()` pour ajouter le nombre `1` au début du tableau `numbers`. La méthode retourne la nouvelle longueur du tableau, qui est `3`.

Enfin, la méthode `shift()` supprime le premier élément d'un tableau et retourne cet élément. Elle est similaire à `pop()`, mais elle agit au début du tableau plutôt qu'à la fin. Voici comment elle fonctionne :

:::interactive_editor

```js
let colors = ["red", "green", "blue"];
let firstColor = colors.shift();
console.log(colors); // ["green", "blue"]
console.log(firstColor); // "red"
```

:::

Dans cet exemple, nous partons d'un tableau de trois couleurs. La méthode `shift()` supprime le premier élément (`red`) du tableau et le retourne. Le tableau `colors` d'origine est modifié pour ne plus contenir que deux éléments.

Note que si `push()` et `unshift()` peuvent ajouter plusieurs éléments à la fois, `pop()` et `shift()` ne suppriment qu'un seul élément à la fois.
