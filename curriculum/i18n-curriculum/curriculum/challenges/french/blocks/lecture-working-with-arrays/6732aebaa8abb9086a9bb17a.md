# --interactive--

Dans la leçon précédente, tu as découvert pour la première fois le travail avec les tableaux et l'accès aux différents éléments d'un tableau. Voici un rappel de comment accéder au deuxième élément d'un tableau :

:::interactive_editor

```js
const fruits = ["apple", "banana", "cherry"];

console.log(fruits[1]); // "banana"
```

:::

Comme les tableaux sont indexés à partir de zéro, le premier élément sera à l'index `0`, le deuxième à l'index `1`, etc. Il est important de noter que si tu essaies d'accéder à un index qui n'existe pas dans le tableau, JavaScript retournera `undefined`.

:::interactive_editor

```js
let fruits = ["apple", "banana", "cherry"];
console.log(fruits[3]); // undefined
```

:::

Dans cet exemple, il n'y a pas d'index `3` pour le tableau `fruits`. Donc l'affichage montrera `undefined`. Maintenant, regardons comment mettre à jour les éléments d'un tableau. Tu peux mettre à jour un élément en affectant une nouvelle valeur à un index précis.

:::interactive_editor

```js
let fruits = ["apple", "banana", "cherry"];
fruits[1] = "blueberry";
console.log(fruits); // ["apple", "blueberry", "cherry"]
```

:::

Dans cet exemple, nous avons remplacé `banana` par `blueberry` à l'index `1`. Cette méthode te permet de modifier n'importe quel élément du tableau, tant que tu connais son index. Tu peux aussi ajouter de nouveaux éléments à un tableau en affectant une valeur à un index qui n'existe pas encore :

:::interactive_editor

```js
let fruits = ["apple", "banana", "cherry"];
fruits[3] = "date";
console.log(fruits); // ["apple", "banana", "cherry", "date"]
```

:::

Cependant, sois prudent en faisant cela. Si tu affectes une valeur à un index bien plus grand que la longueur actuelle du tableau, tu créeras des éléments undefined pour les indices intermédiaires, ce qui peut entraîner un comportement inattendu. Au fur et à mesure que tu continueras à travailler avec JavaScript, tu constateras que ces façons d'accéder aux éléments d'un tableau et de les mettre à jour sont fondamentales pour de nombreuses tâches de programmation. Que tu construises une simple liste de tâches ou que tu traites des structures de données complexes, ces compétences seront précieuses.
