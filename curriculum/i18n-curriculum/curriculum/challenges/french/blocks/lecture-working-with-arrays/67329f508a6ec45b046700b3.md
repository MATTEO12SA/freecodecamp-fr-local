# --interactive--

Un tableau en JavaScript est une collection ordonnée de valeurs, chacune identifiée par un index numérique. Les valeurs d'un tableau JavaScript peuvent être de différents types de données, y compris des nombres, des chaînes, des booléens, des objets, et même d'autres tableaux.

Pour créer un tableau en JavaScript, tu peux utiliser des crochets, `[]`, et séparer les valeurs par des virgules. Voici un exemple :

```js
let fruits = ["apple", "banana", "orange"];
```

Dans cet exemple, nous déclarons une variable `fruits` et lui affectons un tableau contenant trois valeurs de type chaîne : `apple`, `banana` et `orange`.

L'une des caractéristiques clés des tableaux est qu'ils sont indexés à partir de zéro, ce qui signifie que le premier élément d'un tableau a un index de `0`, le deuxième élément a un index de `1`, et ainsi de suite. Tu peux accéder aux éléments individuels d'un tableau en utilisant leur index. Par exemple :

:::interactive_editor

```js
let fruits = ["apple", "banana", "orange"];
console.log(fruits[0]); // "apple"
console.log(fruits[2]); // "orange"
```

:::

Dans cet exemple, nous utilisons l'index `0` pour accéder au premier élément (`apple`) et l'index `2` pour accéder au troisième élément (`orange`).

Les tableaux en JavaScript ont une propriété spéciale `length` qui retourne le nombre d'éléments du tableau. Tu peux accéder à cette propriété en utilisant le mot-clé `length`. Par exemple :

:::interactive_editor

```js
let fruits = ["apple", "banana", "orange"];
console.log(fruits.length); // 3
```

:::

Une autre caractéristique clé des tableaux en JavaScript est qu'ils sont dynamiques, ce qui signifie que leur taille peut changer après leur création. Tu peux ajouter ou supprimer des éléments d'un tableau en utilisant diverses méthodes de tableau, comme `push()`, `pop()`, `shift()`, `unshift()`, `splice()`, et bien d'autres. Ces méthodes seront enseignées dans les prochaines leçons.

Les tableaux JavaScript sont polyvalents et utiles lorsqu'il s'agit de stocker des données dans tes programmes. Tout au long de ce module, tu verras par toi-même comment le travail avec les tableaux t'aidera à gérer et à manipuler efficacement des collections de données.
