# --interactive--

## L'objet `date()` et les méthodes courantes

- **Définition** : l'objet `date()` sert à créer, manipuler et formater les dates et heures en JavaScript. Dans l'exemple suivant, le mot-clé `new` est utilisé pour créer une nouvelle instance de l'objet `Date`, et l'objet `Date` est ensuite assigné à la variable `now`. Si tu affichais la valeur de `now` dans la console, tu verrais la date et l'heure actuelles basées sur l'horloge système de l'ordinateur qui exécute le code.

:::interactive_editor

```js
const now = new Date();
console.log(now); // prints the current date and time
```

:::

- **Méthode `Date.now()`** : cette méthode sert à obtenir la date et l'heure actuelles. `Date.now()` renvoie le nombre de millisecondes depuis January 1, 1970, 00:00:00 UTC. C'est ce qu'on appelle le temps Unix epoch. Le temps Unix epoch est une façon courante de représenter les dates et heures dans les systèmes informatiques, car c'est un entier qui peut être facilement stocké et manipulé. UTC signifie Universal Time Coordinated (temps universel coordonné), qui est le standard horaire principal selon lequel le monde règle les horloges et le temps.
- **Méthode `getDate()`** : cette méthode sert à obtenir un jour du mois basé sur la date actuelle. `getDate()` renvoie une valeur entière entre 1 et 31, selon le jour du mois. Si la date est invalide, elle renvoie `NaN` (Not a Number).

:::interactive_editor

```js
const now = new Date("2014-10-15");
const date = now.getDate();
console.log(date); // 15
```

:::

- **Méthode `getMonth()`** : cette méthode sert à obtenir le mois. Le mois est indexé à partir de zéro, donc January est 0, February est 1, et ainsi de suite. Dans cet exemple, la sortie est 9, ce qui correspond à October. Si le mois est invalide, elle renvoie `NaN`.

:::interactive_editor

```js
const now = new Date("2014-10-15");
const month = now.getMonth();
console.log(month); // 9
```

:::

- **Méthode `getFullYear()`** : cette méthode sert à obtenir l'année complète. Si l'année est invalide, elle renvoie `NaN`.

:::interactive_editor

```js
const now = new Date("2014-10-15");
const year = now.getFullYear();
console.log(year); // 2014
```

:::

## Différentes façons de formater les dates

- **Méthode `toISOString()`** : cette méthode sert à formater la date dans un format `ISO` étendu (ISO 8601). ISO 8601 est une norme internationale pour représenter les dates et heures. Le format est `YYYY-MM-DDTHH:mm:ss.sssZ`.

:::interactive_editor

```js
const date = new Date("2014-10-15");
console.log(date.toISOString()); // "2014-10-15T00:00:00.000Z"
```

:::

- **Méthode `toLocaleDateString()`** : cette méthode sert à formater la date selon la locale de l'utilisateur.

:::interactive_editor

```js
const date = new Date("2014-10-15");
console.log(date.toLocaleDateString("en-US"));  // "10/15/2014"
```

:::

La méthode `toLocaleDateString()` accepte deux paramètres optionnels : locales et options.

Le paramètre locales est une chaîne représentant la locale à utiliser. Par exemple, tu peux passer `"en-US"` pour l'anglais (États-Unis) ou `"fr-FR"` pour le français (France). Si tu ne passes pas de paramètre locales, la locale par défaut est utilisée. Le second paramètre optionnel est le paramètre options. Ce paramètre est un objet qui te permet de spécifier le format de la chaîne de date.

:::interactive_editor

```js
const date = new Date("2014-10-15");
const options = {
  weekday: "long",
  year: "numeric",
  month: "long",
  day: "numeric",
};
console.log(date.toLocaleDateString("en-GB", options)); // "Wednesday, 15 October 2014"
```

:::
