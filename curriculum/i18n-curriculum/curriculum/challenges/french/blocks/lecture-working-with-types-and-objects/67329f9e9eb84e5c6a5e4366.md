# --interactive--

Dans les modules précédents, tu as l'habitude de travailler avec des littéraux de chaîne comme ceci :

```js
const greeting = "Hello, World!";
```

Mais JavaScript possède aussi des objets `String`. Les objets `String` et les primitives `string` servent tous deux à manipuler du texte, mais ils fonctionnent différemment en interne. Un objet `String` est créé à l'aide de la fonction constructeur `String`, qui enveloppe la valeur primitive dans un objet. Voici comment tu peux créer un objet `String` :

:::interactive_editor

```js
const greetingObject = new String("Hello, World!");

console.log(typeof greetingObject); // "object"
```

:::

Lorsque nous utilisons l'opérateur `typeof`, nous pouvons voir que le résultat est de type `object` au lieu de type `string`. Tu te demandes peut-être comment tu peux utiliser des propriétés comme la propriété `.length` sur des primitives `string`.

Lorsque tu utilises la propriété `length` sur une primitive `string`, JavaScript enveloppe temporairement la primitive `string` dans un objet `String` pour effectuer l'opération. C'est pourquoi tu peux utiliser la propriété `length` et les différentes méthodes comme `repeat()`, `concat()` et `slice()`. Ces types de méthodes et propriétés sont appelés méthodes d'instance, propriétés d'instance et méthodes statiques. Tu apprendras en détail comment cela fonctionne dans les modules suivants.

Une différence clé entre un objet `String` et une primitive `string` concerne la mémoire et les performances. Les primitives `string` sont généralement plus efficaces en mémoire et plus rapides que les objets `String`. Bien que tu travailles principalement avec des primitives `string` dans ton code, il reste utile de comprendre comment fonctionnent les objets `String`.

## --answers--

Les primitives `string` sont des objets, tandis que les objets `String` ne le sont pas.
