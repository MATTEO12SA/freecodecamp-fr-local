# --interactive--

Le constructeur `Number()` sert à créer un objet `Number`. L'objet `Number` contient quelques propriétés et méthodes utiles, comme `isNaN` et la méthode `toFixed`. Voici un exemple utilisant le constructeur `Number()` avec le mot-clé `new` :

:::interactive_editor

```js
const myNum = new Number("34");
console.log(typeof myNum); // "object"
```

:::

Dans cet exemple, nous passons un littéral de chaîne au constructeur `Number()` et le type renvoyé est de type `object` au lieu de `string`.

Lorsque le constructeur `Number()` est appelé comme une fonction sans le mot-clé `new`, la valeur renvoyée sera du type primitif `number`. La plupart du temps, tu utiliseras le constructeur `Number()` pour convertir d'autres types de données en type `number`. Voici un exemple de conversion d'une chaîne en nombre :

:::interactive_editor

```js
const myNum = Number("100");
console.log(myNum); // 100

console.log(typeof myNum); // number
```

:::

C'est utile lorsque tu récupères une saisie de l'utilisateur et que tu dois convertir cette chaîne en nombre pour effectuer des calculs mathématiques.

Si tu appelles le constructeur `Number()` avec une chaîne vide, le résultat sera le nombre `0` :

:::interactive_editor

```js
const num = Number("");
console.log(num); // 0
```

:::

C'est parce que JavaScript essaiera d'analyser la chaîne et, comme elle ne contient aucun chiffre, le résultat sera zéro.

Si tu passes une chaîne avec des caractères aléatoires, le résultat sera `NaN` ou « Not a Number ».

:::interactive_editor

```js
const num = Number("random");
console.log(num); // NaN
```

:::

Lorsque tu travailles avec des booléens, `true` renvoie `1` car `true` est converti en un et `false` renvoie `0` car `false` est converti en zéro.

:::interactive_editor

```js
const boolTrue = Number(true);
const boolFalse = Number(false);

console.log(boolTrue); // 1
console.log(boolFalse); // 0
```

:::

Si tu passes `null`, le résultat sera `0` et si tu passes `undefined`, le résultat sera `NaN`.

:::interactive_editor

```js
const undefinedNum = Number(undefined);
const nullNum = Number(null);

console.log(undefinedNum); // NaN
console.log(nullNum); // 0
```

:::

Lorsque tu travailles avec des tableaux, il y a quelques points à prendre en compte.

Un tableau vide renverra `0`. Un tableau avec un seul nombre renverra ce nombre. Un tableau avec plusieurs nombres renvoie `NaN`. Et un tableau avec une ou plusieurs chaînes renverra aussi `NaN`.

:::interactive_editor

```js
const emptyArr = Number([]);
const arrOneNum = Number([7]);
const arrMultiNum = Number([7, 36, 12]);
const arrStr = Number(["str1"]);
const arrMultiStr = Number(["str1", "str2"]);

console.log(emptyArr); // 0
console.log(arrOneNum); // 7
console.log(arrMultiNum); // NaN
console.log(arrStr); // NaN
console.log(arrMultiStr); // NaN
```

:::

Lorsque tu travailles avec des objets, le résultat est toujours `NaN`.

:::interactive_editor

```js
const obj1 = Number({});
const obj2 = Number({2: 2});
const obj3 = Number({key: "val"});
const obj4 = Number({key: true});

console.log(obj1); // NaN
console.log(obj2); // NaN
console.log(obj3); // NaN
console.log(obj4); // NaN
```

:::

En conclusion, tu utiliseras surtout le constructeur `Number()` pour la conversion de type plutôt que pour créer un nombre ou un objet `Number`.
