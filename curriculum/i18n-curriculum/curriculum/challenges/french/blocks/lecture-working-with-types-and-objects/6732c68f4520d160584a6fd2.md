# --interactive--

La méthode `toString()` est une fonctionnalité fondamentale en JavaScript qui convertit une valeur en sa représentation sous forme de chaîne. C'est une méthode que tu peux utiliser pour les nombres, les booléens, les tableaux et les objets. L'une des utilisations les plus courantes de `toString()` est de convertir un nombre en sa représentation sous forme de chaîne. Voici un exemple :

:::interactive_editor

```js
const num = 10;
console.log(num.toString()); // "10"
```

:::

Cette méthode accepte un radix optionnel, qui est un nombre de `2` à `36`. Ce radix représente la base, comme la base 2 pour le binaire ou la base 8 pour l'octal. Si le radix n'est pas spécifié, il est par défaut en base 10, soit décimal. Voici un exemple en passant `2` comme argument à la méthode `toString()` :

:::interactive_editor

```js
const num = 10;
console.log(num.toString(2)); // "1010"
```

:::

Le résultat sera `1010`, qui est la représentation binaire du nombre décimal `10`.

Tu peux aussi utiliser la méthode `toString()` pour convertir des tableaux et des objets en chaînes. Les tableaux ont une implémentation personnalisée de `toString()` qui convertit chaque élément en chaîne et les joint avec des virgules. Voici un exemple :

:::interactive_editor

```js
const arr = [1, 2, 3];
console.log(arr.toString()); // "1,2,3"
```

:::

Dans cet exemple, tous les éléments du tableau sont joints pour former la chaîne `1,2,3`.

Lorsque la méthode `toString()` est utilisée avec des objets, le résultat ne sera pas une version en chaîne des propriétés de l'objet.

:::interactive_editor

```js
const person = {
  name: "John",
  age: 30,
  isStudent: true
};

console.log(person.toString()); // "[object Object]"
```

:::

Dans cet exemple, le résultat sera la représentation par défaut de l'objet, soit `[object Object]`. Pour obtenir une version en chaîne des propriétés de l'objet `person`, tu devras utiliser `JSON.stringify()`, que tu découvriras plus en détail dans les leçons suivantes.

En conclusion, la méthode `toString()` sert à convertir des valeurs en chaînes. Comprendre comment elle fonctionne avec différents types de données et comment la personnaliser pour tes propres objets peut grandement améliorer ta capacité à manipuler et afficher des données dans tes applications JavaScript.
