## Les Sets en JavaScript

- Un `Set` est une option intégrée pour gérer une collection de données.
- Les Sets garantissent que chaque valeur n'y apparaît qu'une seule fois, ce qui les rend utiles pour éliminer les doublons d'un tableau ou gérer des collections de valeurs distinctes.
- Tu peux créer un `Set` avec le constructeur `Set()` :

:::interactive_editor

```js
const set = new Set([1, 2, 3, 4, 5]);
console.log(set); // Set { 1, 2, 3, 4, 5 }
```

:::

- Les Sets peuvent être manipulés avec ces méthodes :

  - `add()` : ajoute un nouvel élément au `Set`.
  - `delete()` : retire un élément du `Set`.
  - `has()` : vérifie si un élément existe dans le `Set`.
  - `clear()` : retire tous les éléments du `Set`.
  - `keys()` et `values()` : renvoient toutes deux un `SetIterator` qui contient les valeurs du `Set`. Elles sont identiques car `keys()` est un alias de `values()`.
  - `forEach()` : pour parcourir les valeurs du `Set`.

## Les WeakSets en JavaScript

- Un `WeakSet` est une collection d'objets qui te permet de stocker des objets détenus faiblement.

## Sets vs WeakSets

- Contrairement aux Sets, un `WeakSet` ne prend pas en charge les primitives comme les nombres ou les chaînes.
- Un `WeakSet` ne stocke que des objets, et les références à ces objets sont « faibles », ce qui signifie que si l'objet n'est utilisé nulle part ailleurs dans ton code, il est retiré automatiquement pour libérer de la mémoire.

## Les Maps en JavaScript

- Un `Map` est un objet intégré qui stocke des paires clé-valeur, comme un objet.
- Les Maps diffèrent des objets JavaScript standard par leur capacité à autoriser des clés de n'importe quel type, y compris des objets et des fonctions.
- Un `Map` offre de meilleures performances qu'un objet standard pour les ajouts et suppressions fréquents de paires clé-valeur.
- Tu peux créer un `Map` avec le constructeur `Map()` :

:::interactive_editor

```js
const map = new Map([
  ['flower', 'rose'],
  ['fruit', 'apple'],
  ['vegetable', 'carrot']
]);
console.log(map); // Map(3) { 'flower' => 'rose', 'fruit' => 'apple', 'vegetable' => 'carrot' }
```

:::

- Les Maps peuvent être manipulés avec ces méthodes :

  - `set()` : ajoute une nouvelle paire clé-valeur au `Map`.
  - `get()` : récupère la valeur d'une clé dans le `Map`.
  - `delete()` : retire une paire clé-valeur du `Map`.
  - `has()` : vérifie si une clé existe dans le `Map`.
  - `clear()` : retire toutes les paires clé-valeur du `Map`.

Note que les Maps et les Sets ont tous deux la propriété `size`, qui renvoie le nombre d'éléments uniques qu'ils contiennent.

## Les WeakMaps en JavaScript

- Un `WeakMap` est une collection de paires clé-valeur comme un `Map`, mais avec des références faibles aux clés. Les clés doivent être des objets et les valeurs peuvent être de n'importe quel type.

## Maps vs WeakMaps

- Les WeakMaps sont similaires aux WeakSets : ils ne stockent que des objets et les références à ces objets sont « faibles ».
