# --description--

Tu as appris les API `HTMLMediaElement` et MediaStreams, mais il y a encore quelques API qui peuvent être très utiles pour travailler avec la vidéo et l'audio.

La première est la Screen Capture API. Comme le nom peut le suggérer, cette API te permet d'enregistrer l'écran d'un utilisateur. Cette API est exposée en appelant la méthode `getDisplayMedia()` de l'objet `mediaDevices` et en consommant le flux média renvoyé.

Ensuite, il y a la MediaStream Recording API. Cette API fonctionne de concert avec les API MediaStreams, te permettant d'enregistrer un MediaStream (ou même un `HTMLMediaElement` directement). Elle déclenche ensuite des événements `dataavailable` avec des charges utiles Blob que tu peux écrire dans le stockage de fichiers local.

Sous-jacente à toute cette technologie se trouve la Media Source Extensions API. La Media Source Extensions API est ce qui te permet, par exemple, de passer directement le flux de la webcam d'un utilisateur à un élément vidéo avec la propriété `srcObject`.

Et enfin, la Web Audio API qui alimente tout ce qui est audible sur le web. Cette API inclut des objets importants comme un `AudioBuffer` (représentant un Buffer contenant spécifiquement des données audio) ou l'`AudioContext`.

Et cela conclut nos leçons sur l'audio et la vidéo !
