# --description--

Au lieu de lire de l'audio et de la vidéo, tu peux parfois vouloir capturer de l'audio ou de la vidéo. L'API Media Capture and Streams, ou l'API MediaStream, te permet de le faire.

Pour utiliser l'API, cependant, tu dois créer l'objet `MediaStream`. Tu pourrais le faire avec le constructeur, mais il ne serait pas lié au matériel de l'utilisateur. À la place, la propriété `mediaDevices` de l'objet global `navigator` a une méthode `getUserMedia()` à utiliser.

Cette méthode accepte un seul objet `constraints` qui définit le type de média que tu veux recevoir. Cet objet a une propriété `audio` et une propriété `video`, qui reflètent les flux audio et vidéo. Ces propriétés peuvent être `false`, si tu ne veux pas recevoir ce type de flux, `true` si tu le veux, ou des objets définissant des contraintes supplémentaires.

Par exemple, tu peux exiger une résolution spécifique de sortie vidéo :

```js
window.navigator.mediaDevices.getUserMedia({
  audio: true,
  video: {
    width: {
      min: 1280,
      ideal: 1920,
      max: 3840
    },
    height: {
      min: 720,
      ideal: 1080,
      max: 2160
    }
  }
});
```

Cet objet de contraintes spécifie les résolutions minimale et maximale pour le flux vidéo. La propriété `ideal` spécifie la résolution que tu aimerais le plus avoir – et le flux fournira la résolution la plus proche de ton idéal.

Une fois que tu as créé ton MediaStream (en supposant que l'utilisateur approuve la demande automatisée d'accès à son matériel), tu peux utiliser les données du flux comme tu en as besoin.

Note que `getUserMedia()` renvoie une Promise, ce qui signifie que tu auras soit besoin d'une fonction de rappel pour consommer le flux, soit d'utiliser la syntaxe async/await. Tu en apprendras davantage sur les Promises et la programmation asynchrone dans de futures leçons.

Voici un exemple basique qui affiche le flux de la webcam de l'utilisateur sur la page.

```js
const video = document.querySelector("video");
const stream =
  await window.navigator.mediaDevices.getUserMedia({ video: true });
video.srcObject = stream;
await video.play();
```

Il vaut la peine de noter que cette API n'offre pas d'accès à la capture d'écran. Tu apprendras cette API dans la prochaine leçon.
