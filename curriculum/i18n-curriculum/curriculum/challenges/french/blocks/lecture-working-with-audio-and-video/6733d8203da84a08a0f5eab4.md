# --description--

Apprenons les différents types de formats audio et vidéo.

Tu as probablement déjà entendu parler, ou même utilisé, de quelques formats courants. Si les termes MP3, MP4, MOV ou WebM te sont familiers, ce sont tous des formats différents pour la vidéo et l'audio. Et il en existe bien d'autres encore.

Avant de plonger dans les formats de fichiers, il faut parler des types MIME. Un type MIME, pour Multipurpose Internet Mail Extensions, est une façon standardisée d'indiquer programmatiquement un type de fichier.

Presque chaque format de fichier a un type MIME. HTML, par exemple, a le type `text/html`. Un objet JSON a le type `application/json`. Même un installateur Windows `.exe` a un type MIME : `application/vnd.microsoft.portable-executable`.

Le type MIME peut indiquer à une application, comme ton navigateur, comment gérer un fichier spécifique. Dans le cas de l'audio et de la vidéo, le type MIME indique qu'il s'agit d'un format multimédia qui peut être intégré dans la page web.

Un fichier MP3 a le type MIME `audio/mpeg`. Un MP4, en revanche, peut avoir le type MIME `audio/mp4` OU `video/mp4`, selon qu'il s'agit d'un fichier vidéo ou audio uniquement. Cette distinction indique au navigateur comment gérer le fichier.

Il existe de nombreux autres formats de fichiers, comme le format waveform WAV, le polyvalent OGG, WMV pour le lecteur multimédia Windows, le MKV open source, et bien d'autres.

Connaître les différences entre ces formats de fichiers peut t'aider à garantir la meilleure expérience à tes utilisateurs, mais parfois tu ne peux pas savoir quel format l'ordinateur d'un utilisateur prendra en charge (ou non). Heureusement, les éléments `video` et `audio` prennent tous deux en charge l'élément `source`.

Avec l'élément `source`, tu peux spécifier un type de fichier et une `source`, et tu peux inclure plusieurs types différents en utilisant plusieurs éléments `source`. Quand tu fais cela, le navigateur déterminera le meilleur format à utiliser pour l'environnement actuel de l'utilisateur.

Cela élimine le travail de conjecture et te permet de te concentrer sur la création d'applications engageantes.
