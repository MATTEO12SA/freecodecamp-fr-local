# --description--

Apprenons les codecs et comment ils fonctionnent.

Si tu as déjà travaillé avec des vidéos ou de l'audio, tu as peut-être entendu parler des codecs. Un codec, abréviation de « encoder/decoder », est un algorithme ou un logiciel qui peut convertir l'audio et la vidéo entre formats analogiques et numériques.

Les codecs peuvent être spécifiés dans le type MIME. La syntaxe de base pour définir un codec est d'ajouter un point-virgule après le type de média, puis `codecs=` et le codec.

Par exemple, un fichier audio OGG qui utilise le codec Vorbis pourrait avoir un type MIME de `audio/ogg; codecs=vorbis`. Ou, si un fichier prend en charge plusieurs codecs, tu peux les spécifier séparés par des virgules, mais tu dois les entourer de guillemets : `video/webm; codecs="vp8, vorbis"`.

Mais certains types de fichiers ont une syntaxe bien plus compliquée pour les codecs. Par exemple, un MP4 pourrait avoir un codec `codecs="avc1.4d002a"`, indiquant qu'il a été encodé avec H.264.

Mais quand pourrais-tu réellement les utiliser ? Eh bien, tu peux les inclure dans l'attribut `type` d'un élément `source`. Cela te permet de spécifier différents codecs pour le même format, en donnant au navigateur des options plus précises pour déterminer quel format utiliser pour l'environnement de cet utilisateur.

Mais tu peux aussi les utiliser dans le type MIME que tu passes à la méthode globale `MediaSource.isTypeSupported()`. Cette méthode accepte un type MIME, et renvoie `true` si l'environnement est susceptible de le prendre en charge. Ou plutôt, elle renvoie `false` si elle échoue à instancier un buffer pour ce type de fichier. Cette approche te permet de sélectionner programmatiquement une source toi-même, plutôt que de te fier à ce que le navigateur détermine comme « meilleur ».
