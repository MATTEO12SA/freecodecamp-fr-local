# --interactive--

En JavaScript, la méthode `indexOf()` est utile pour trouver le premier index d'un élément précis au sein d'un tableau. Si l'élément est introuvable, alors elle retourne `-1`. Voici la syntaxe de base :

```js
array.indexOf(element, fromIndex)
```

`element` représente la valeur que tu veux rechercher dans le tableau, et le paramètre `fromIndex` est la position à partir de laquelle la recherche doit commencer. Le paramètre `fromIndex` est optionnel. Si `fromIndex` n'est pas fourni, la recherche commence au début du tableau. Regardons un exemple :

:::interactive_editor

```js
let fruits = ["apple", "banana", "orange", "banana"];
let index = fruits.indexOf("banana");
console.log(index); // 1
```

:::

Dans cet exemple, nous avons un tableau `fruits` contenant divers noms de fruits. Nous utilisons la méthode `indexOf()` pour trouver l'index de la chaîne `banana` dans le tableau `fruits`. Comme `banana` est présent à l'index `1`, la méthode retourne `1`, qui est stocké dans la variable `index` et affiché dans la console.

Si l'élément que tu recherches est introuvable dans le tableau, `indexOf()` retourne `-1`. Par exemple :

:::interactive_editor

```js
let fruits = ["apple", "banana", "orange"];
let index = fruits.indexOf("grape");
console.log(index); // -1
```

:::

Ici, nous recherchons la chaîne `grape` dans le tableau de fruits en utilisant `indexOf()`. Comme `grape` n'est pas présent dans le tableau, la méthode retourne `-1`, qui est stocké dans la variable `index` et affiché dans la console.

Si tu veux commencer à chercher un élément après un numéro d'index précis, tu peux passer un second argument comme dans cet exemple :

:::interactive_editor

```js
let colors = ["red", "green", "blue", "yellow", "green"];
let index = colors.indexOf("green", 3);
console.log(index); // 4
```

:::

Dans cet exemple, la recherche ne commence pas au début du tableau, mais plutôt à partir de l'index numéro `3` qui est `yellow`, et obtient la sortie `4`.
