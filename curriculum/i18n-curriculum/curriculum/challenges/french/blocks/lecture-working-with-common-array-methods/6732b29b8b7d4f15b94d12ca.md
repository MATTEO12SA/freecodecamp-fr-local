# --interactive--

Une copie superficielle d'un tableau est un nouveau tableau qui a les mêmes éléments que l'original. Si le tableau ne contient que des valeurs primitives comme des nombres ou des chaînes, le nouveau tableau est complètement indépendant. Mais si le tableau contient d'autres tableaux à l'intérieur, l'original et la copie ont tous deux des références aux mêmes tableaux internes. Cela signifie que si tu modifies quelque chose à l'intérieur d'un tableau interne partagé, tu verras ce changement dans les deux tableaux.

Les copies superficielles sont utiles lorsque tu as besoin de modifier la structure de premier niveau, comme ajouter, supprimer ou réorganiser des éléments, sans modifier le tableau d'origine ni le tableau interne.

Il existe plusieurs méthodes pour créer des copies superficielles de tableaux, et nous allons explorer certaines des plus courantes : `concat()`, `slice()` et l'opérateur spread.

Commençons par la méthode `concat()`. Cette méthode crée un nouveau tableau en fusionnant deux tableaux ou plus. Lorsqu'elle est utilisée avec un seul tableau, elle crée en fait une copie superficielle. Voici un exemple :

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const copyArray = [].concat(originalArray);

console.log(copyArray); // [1, 2, 3]
console.log(copyArray === originalArray); // false
```

:::

Dans cet exemple, nous utilisons la méthode `concat()` pour concaténer un tableau vide à `originalArray`. Cela créera un nouveau tableau qui est une copie superficielle de `originalArray`.

Le `copyArray` contient les mêmes éléments que `originalArray`, mais c'est un objet tableau différent, ce qui explique pourquoi la vérification d'égalité stricte (`===`) retourne `false`.

Une autre méthode pour créer une copie superficielle est la méthode `slice()`. Lorsqu'elle est appelée sans arguments, `slice()` retourne une copie superficielle du tableau entier. Voici comment elle fonctionne :

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const copyArray = originalArray.slice();

console.log(copyArray); // [1, 2, 3]
console.log(copyArray === originalArray); // false
```

:::

Dans ce cas, `originalArray.slice()` crée un nouveau tableau qui est une copie superficielle de `originalArray`. Là encore, le `copyArray` contient les mêmes éléments mais c'est un objet tableau différent.

L'opérateur spread (`...`), introduit dans ES6, offre une autre façon concise de créer des copies superficielles de tableaux. Voici un exemple :

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const copyArray = [...originalArray];

console.log(copyArray); // [1, 2, 3]
console.log(copyArray === originalArray); // false
```

:::

L'opérateur spread (`...`) répand les éléments de `originalArray` dans un nouveau tableau, créant en fait une copie superficielle. Il est important de noter que toutes ces méthodes créent de nouveaux objets tableau, ce qui signifie que tu peux modifier la copie sans affecter le tableau d'origine. Par exemple :

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const copyArray = [...originalArray];

copyArray.push(4);
console.log(originalArray); // [1, 2, 3]
console.log(copyArray);     // [1, 2, 3, 4]
```

:::

Dans cet exemple, ajouter un élément à `copyArray` n'affecte pas `originalArray`.

En résumé, les copies superficielles de tableaux peuvent être facilement créées en utilisant des méthodes comme `concat()`, `slice()` ou l'opérateur spread. Ces méthodes sont utiles pour créer de nouveaux tableaux qui peuvent être manipulés indépendamment du tableau d'origine.
