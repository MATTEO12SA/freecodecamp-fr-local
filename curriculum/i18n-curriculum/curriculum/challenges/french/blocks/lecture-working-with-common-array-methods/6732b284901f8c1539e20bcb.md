# --interactive--

La méthode `splice()` en JavaScript est un moyen puissant de modifier les tableaux. Elle te permet d'ajouter ou de supprimer des éléments à n'importe quelle position d'un tableau, y compris au milieu. La valeur retournée par la méthode `splice()` sera un tableau des éléments supprimés du tableau. Si rien n'a été supprimé, alors un tableau vide est retourné.

Il est important de noter que cette méthode modifie le tableau d'origine, le modifiant sur place plutôt que de créer un nouveau tableau. C'est quelque chose dont il faut être conscient lorsqu'on travaille avec `splice()`. Voici la syntaxe de base :

```js
array.splice(startIndex, itemsToRemove, item1, item2)
```

`startIndex` indique l'index à partir duquel commencer à modifier le tableau, tandis que `itemsToRemove` est un paramètre optionnel indiquant combien d'éléments supprimer. Si `itemsToRemove` est omis, `splice()` supprimera tous les éléments de `startIndex` jusqu'à la fin du tableau. Les paramètres suivants (`item1`, `item2`, et ainsi de suite) sont les éléments à ajouter au tableau, à partir de l'index de départ.

Commençons par un exemple de suppression d'éléments au milieu d'un tableau :

:::interactive_editor

```js
let fruits = ["apple", "banana", "orange", "mango", "kiwi"];
let removed = fruits.splice(2, 2);

console.log(fruits);  // ["apple", "banana", "kiwi"]
console.log(removed); // ["orange", "mango"]
```

:::

Dans cet exemple, `splice(2, 2)` commence à l'index `2` et supprime `2` éléments. Le tableau modifié ne contiendra plus que `apple`, `banana` et `kiwi`. Maintenant, regardons comment ajouter des éléments au milieu d'un tableau :

:::interactive_editor

```js
let colors = ["red", "green", "blue"];
colors.splice(1, 0, "yellow", "purple");

console.log(colors); // ["red", "yellow", "purple", "green", "blue"]
```

:::

Ici, `splice(1, 0, "yellow", "purple")` commence à l'index `1`, supprime `0` élément, et insère `yellow` et `purple`. Le deuxième paramètre (`0`) signifie qu'aucun élément n'est supprimé avant l'insertion. Tu peux aussi utiliser `splice()` pour supprimer et ajouter des éléments simultanément :

:::interactive_editor

```js
let numbers = [1, 2, 3, 4, 5];
numbers.splice(1, 2, 6, 7, 8);

console.log(numbers); // [1, 6, 7, 8, 4, 5]
```

:::

Dans ce cas, `splice(1, 2, 6, 7, 8)` commence à l'index `1`, supprime `2` éléments (`2` et `3`), et insère `6`, `7` et `8`. Si tu as besoin de conserver le tableau d'origine inchangé, tu devrais créer une copie avant d'utiliser `splice()` :

:::interactive_editor

```js
let original = [1, 2, 3, 4, 5];
let copy = [...original];
copy.splice(2, 1, 6);

console.log(original); // [1, 2, 3, 4, 5]
console.log(copy);     // [1, 2, 6, 4, 5]
```

:::

Dans cet exemple, pour créer une copie du tableau `original` sans le modifier, nous utilisons l'opérateur spread (`...`). L'opérateur spread crée une copie superficielle des éléments du tableau `original` dans un nouveau tableau. Tu en apprendras davantage à ce sujet dans de futures leçons.

Lorsque nous utilisons `copy.splice(2, 1, 6)`, cela modifie le tableau copy en supprimant l'élément à l'index `2` (qui est `3`) et en insérant le nouvel élément `6` à cette position.

Un cas d'usage courant de `splice()` est de supprimer un seul élément d'un tableau lorsque tu connais son index :

:::interactive_editor

```js
let fruits = ["apple", "banana", "orange", "mango"];
let indexToRemove = fruits.indexOf("orange");
if (indexToRemove !== -1) {
    fruits.splice(indexToRemove, 1);
}

console.log(fruits); // ["apple", "banana", "mango"]
```

:::

Dans cet exemple, nous utilisons d'abord la méthode `indexOf()` pour trouver l'index de l'élément `orange` dans le tableau `fruits`. La méthode `indexOf()` retourne l'index de la première occurrence de l'élément donné ou `-1` si l'élément est introuvable dans le tableau.

Nous comparons ensuite `indexToRemove` avec `-1` pour nous assurer que l'élément existe dans le tableau avant d'essayer de le supprimer. Si `indexToRemove` n'est pas égal à `-1` (ce qui signifie que l'élément est trouvé), nous utilisons `splice()` pour supprimer un élément à partir de la position `indexToRemove`.

Tu peux aussi utiliser `splice()` pour vider un tableau en supprimant tous les éléments :

:::interactive_editor

```js
let array = [1, 2, 3, 4, 5];
array.splice(0);

console.log(array); // []
```

:::

Bien que `splice()` soit puissante, il est utile de noter que pour de très grands tableaux, elle peut être moins efficace que d'autres méthodes, surtout lors de la modification du début du tableau. C'est parce que `splice()` peut avoir besoin de décaler tous les éléments suivants. Dans de tels cas, si tu ne fais qu'ajouter ou supprimer des éléments à la fin du tableau, des méthodes comme `push()`, `pop()`, `unshift()` et `shift()` pourraient être plus appropriées.

En conclusion, la méthode `splice()` est un moyen polyvalent de modifier les tableaux en JavaScript. Elle permet un contrôle précis de l'ajout et de la suppression d'éléments à n'importe quelle position d'un tableau. Comprendre comment utiliser `splice()` efficacement peut grandement améliorer ta capacité à manipuler les tableaux dans ton code JavaScript.
