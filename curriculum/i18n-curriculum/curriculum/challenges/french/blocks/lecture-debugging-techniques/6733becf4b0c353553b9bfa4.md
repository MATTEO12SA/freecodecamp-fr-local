# --description--

L'instruction `debugger` est un outil JavaScript puissant qui te permet de mettre en pause ton code à une ligne précise pour examiner ce qui se passe dans le programme. Utilisée correctement, l'instruction `debugger` peut te faire gagner beaucoup de temps pour comprendre pourquoi quelque chose ne fonctionne pas comme prévu.

JavaScript exécute ton code de haut en bas. Quand JavaScript exécute ton code et rencontre une instruction `debugger`, il met immédiatement en pause l'exécution à cette ligne. Cela te donne la possibilité d'inspecter les variables, de vérifier les fonctions et le flux du code en général.

Ainsi, tu peux voir exactement ce qui se passe correctement ou non. Cependant, cela n'arrive que si les outils de développement de ton navigateur sont ouverts. Sinon, l'instruction `debugger` est ignorée et le code continue de s'exécuter normalement.

De plus, quand tu utilises l'instruction `debugger`, les navigateurs modernes mettent en pause l'exécution du code à la ligne indiquée. Ils te permettent aussi de reprendre l'exécution en cliquant sur le bouton lecture, mais la page elle-même ne se recharge pas automatiquement sauf si tu le déclenches manuellement.

Pour utiliser l'instruction `debugger`, place-la à la ligne où tu veux que l'exécution du code se mette en pause. Voici un exemple :

```js
let firstNumber = 5;
let secondNumber = 10;
debugger; // Code execution pauses here
let sum = firstNumber + secondNumber;
console.log(sum);
```

Avec cet exemple, si tu n'as pas la console ouverte avant que le code ne s'exécute et que tu l'ouvres ensuite, tu y verras `15`. Si la console est ouverte et que tu recharges la page, l'exécution est mise en pause pour que tu puisses inspecter le code.

Voici un exemple plus complexe :

```js
function calculateTotalPrice(price, discountPercentage) {
 debugger
 let discountAmount = (price * discountPercentage) / 100
 let totalPrice = price - discountAmount

 console.log(`Original Price: ${price}`)
 console.log(`Discount Amount: ${discountAmount}`)
 console.log(`Total Price after Discount: ${totalPrice}`)

 return totalPrice
}

let price = 100
let discount = 15

let finalPrice = calculateTotalPrice(price, discount)
console.log(`Final Price: ${finalPrice}`);
```

Dans cet exemple, l'instruction `debugger` est placée en haut de `calculateTotalPrice`. Quand la fonction est appelée, l'exécution de la fonction sera mise en pause.

Si tu recharges la page avec la console ouverte, tu verras que la page continue de se recharger, ce qui confirme que l'exécution du code est seulement en pause, pas arrêtée. Si tu veux que l'exécution continue, tu peux cliquer sur le bouton lecture.

Au fur et à mesure que tu construis tes programmes JavaScript, teste l'instruction `debugger` dans ton code pour voir comment elle peut t'aider à mieux comprendre le flux d'exécution, inspecter les variables en temps réel et identifier rapidement où les choses pourraient mal tourner.
