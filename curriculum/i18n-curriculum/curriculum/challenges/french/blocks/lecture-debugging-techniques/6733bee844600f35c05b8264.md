# --interactive--

Dans la leçon précédente, tu as appris à lever des exceptions dans tes programmes. Dans cette leçon, nous allons voir comment gérer ces erreurs de façon élégante dans un bloc `try…catch…finally`.

Le bloc `try` sert à envelopper du code qui pourrait lever une erreur. Il agit comme un espace sûr pour essayer quelque chose qui pourrait échouer.

Le bloc `catch` capture et gère les erreurs qui surviennent dans le bloc `try`. Tu peux utiliser l'objet `Error` à l'intérieur de `catch` pour examiner ce qui s'est mal passé.

Le bloc `finally` s'exécute après les blocs `try` et `catch`, qu'une erreur se soit produite ou non. Il est couramment utilisé pour des tâches de nettoyage, comme fermer des fichiers ou libérer des ressources.

Voici un exemple d'utilisation d'un bloc `try…catch` :

:::interactive_editor

```js
function processInput(input) {
  if (typeof input !== "string") {
    throw new TypeError("Input must be a string.");
  }

  return input.toUpperCase();
}

try {
  console.log("Starting to process input...");
  const result = processInput(9);
  console.log("Processed result:", result);
} catch (error) {
  console.error("Error occurred:", error.message);
}
```

:::

Dans cet exemple, nous avons une fonction appelée `processInput` qui vérifie d'abord si `input` n'est pas de type `string`. Si c'est le cas, alors on lève une erreur. Sinon, on renvoie le résultat de l'utilisation de la méthode `toUpperCase` sur `input`.

On appelle la fonction à l'intérieur d'un bloc `try`. Comme l'appel de fonction lève une erreur, celle-ci sera capturée dans le bloc `catch` et le message d'erreur sera affiché dans la console.

L'erreur passée au bloc `catch` est un objet `Error` qui contient des informations sur cette erreur. Dans ce cas, on utilise la propriété `message` qui affiche des informations lisibles pour l'utilisateur.

On utilise `console.error` car il est conçu spécifiquement pour journaliser les erreurs. Dans de nombreux navigateurs modernes, la sortie de `console.error()` apparaît en rouge dans la console.

L'instruction `finally` s'exécute qu'une exception ait été levée ou non.

```js
try {
  // Code that might throw an error
} catch (error) {
  // Code to handle the error
} finally {
  // Code that runs regardless of whether an error occurred or not
}
```

Un bon cas d'usage pour l'instruction `finally` est si tu travailles avec des fichiers. En JavaScript, tu peux ouvrir un fichier, utiliser un bloc `try` pour écrire des données dans le fichier. S'il y a des erreurs, tu peux utiliser le `catch` pour les capturer. Puis utiliser l'instruction `finally` pour fermer le fichier.
