# --description--

L'instruction `throw` en JavaScript sert à lever une exception définie par l'utilisateur. Une exception en programmation, c'est quand un événement inattendu se produit et perturbe le flux normal du programme.

En tant que programmeurs, il est important de gérer ces exceptions pour que tes programmes ne plantent pas de façon inattendue quand des erreurs surviennent. Voici la syntaxe de base de l'instruction `throw` :

```js
throw expression;
```

L'`expression` dans ce cas est l'objet ou la valeur qui représente l'exception que tu veux lever. Des exemples seraient les classes d'exception intégrées comme `Error`, `TypeError` ou `RangeError`. Voici un exemple d'utilisation de l'instruction `throw` pour lever une `TypeError` :

```js
function validateNumber(input) {
  if (typeof input !== "number") {
    throw new TypeError("Expected a number, but received " + typeof input);
  }
  return input * 2;
}
```

Dans cet exemple, on vérifie si le type de `input` n'est pas de type `number`. Sinon, on lève une `TypeError` avec un message personnalisé. Autrement, la fonction renvoie le résultat de la multiplication de `input` par `2`.

Si tu veux lever un message d'erreur plus générique, tu peux faire référence au constructeur `Error` comme ceci :

```js
function divide(numerator, denominator) {
  if (denominator === 0) {
    throw new Error("Cannot divide by zero");
  }
  return numerator / denominator;
}
```

Voici un exemple de fonction qui vérifie si le dénominateur est `0`. Si c'est le cas, elle lève un message d'erreur personnalisé disant `Cannot divide by zero`.

Dans la prochaine leçon, nous verrons comment lever des messages d'erreur dans le contexte du bloc `try`/`catch`, qui sert à gérer les exceptions de façon élégante en JavaScript.
