# --description--

Au fil de ta programmation en JavaScript, tu as forcément croisé des messages d'erreur. Comprendre les messages d'erreur courants t'aidera à déboguer plus efficacement et à devenir un programmeur plus solide. Les quatre types d'erreurs courants sont `SyntaxError`, `ReferenceError`, `TypeError` et `RangeError`.

Une `SyntaxError` survient quand tu écris quelque chose d'incorrect dans ton code, comme une parenthèse ou un crochet manquant. Pense-y comme à une faute de grammaire dans une phrase. Voici une erreur courante que font les développeurs en créant des tableaux :

```js
const arr = ["Beau", "Quincy" "Tom"]
```

Chaque élément d'un tableau doit être séparé par une virgule, sinon cela produira un message d'erreur.

La deuxième erreur JavaScript courante est une `ReferenceError`. Il existe plusieurs types de `ReferenceError`, déclenchés de différentes manières. Le premier type de `ReferenceError` concerne les variables non définies.

```js
console.log(price);
```

Dans cet exemple, on essaie d'afficher la variable `price` dans la console, mais elle n'a pas été définie. Cela produira une `ReferenceError`.

Un autre exemple de `ReferenceError` consiste à accéder à une variable, déclarée avec `let` ou `const`, avant qu'elle n'ait été définie :

```js
console.log(b);
const b = 50;
```

L'exemple ci-dessus produira une erreur `Cannot access 'b' before initialization`.

La troisième erreur courante est une `TypeError`. Ces erreurs surviennent quand tu essaies d'effectuer une opération sur le mauvais type. Voici un exemple où l'on essaie d'utiliser la méthode `map` sur un objet :

```js
const developerObj = {
  name: "Jessica",
  country: "USA",
  isEmployed: true
};

developerObj.map()
```

Cet exemple produira une erreur `developerObj.map is not a function` car la méthode `map` s'utilise sur les tableaux et non sur les objets.

La dernière erreur courante que nous allons examiner est la `RangeError`.

Une `RangeError` survient quand ton code essaie d'utiliser une valeur qui est en dehors de la plage que JavaScript peut gérer. Voici un exemple d'affectation d'une valeur invalide à la longueur d'un tableau :

```js
const arr = [];
arr.length = -1;
```

Comme la propriété `length` d'un tableau doit être un entier non négatif, la définir à `-1` déclenche une `RangeError`.

Au fur et à mesure que tu continues à programmer en JavaScript, reste attentif à ces différents types d'erreurs que tu rencontreras probablement, et à pourquoi elles se produisent.
