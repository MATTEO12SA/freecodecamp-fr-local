# --description--

Les composants sont les briques de construction des applications React qui permettent aux développeurs de découper des interfaces utilisateur complexes en plus petites pièces gérables, ce qui facilite le développement et la maintenance d'applications à grande échelle.

Les deux types de composants dans React sont les composants fonctionnels et les composants basés sur les classes. Dans React moderne, les développeurs utiliseront des composants fonctionnels et tous les exemples que nous verrons aujourd'hui seront des composants fonctionnels.

À un niveau plus élevé, tu peux penser aux composants comme des fonctions JavaScript qui renvoient des éléments décrivant l'UI.

Cette UI est décrite avec JSX, une extension de syntaxe pour JavaScript qui ressemble à du HTML mais te permet d'écrire des éléments d'UI de façon plus déclarative.

Regardons un exemple de composant React :

```jsx
function Greeting() {
  const name = "John"
  {/* The result will be Hello John*/}
  return <h1 className="title">Hello {name}</h1>;
}
```

Dans cet exemple, nous avons défini un composant appelé `Greeting`. Les accolades `{}` à l'intérieur des balises `h1` nous permettent d'intégrer des expressions JavaScript, ce qui nous laisse accéder à la variable `name` dans l'élément `h1`.

Nous appliquons aussi un `className` appelé `title` à l'élément `h1`.

Mais pourquoi utilisons-nous `className` au lieu de `class` comme avec les éléments HTML ordinaires ?

Eh bien, c'est parce qu'en JavaScript, `class` est un nom réservé. Nous devons donc utiliser `className` à la place.

Nous utilisons aussi un commentaire en JSX montrant ce que sera le résultat. Il est important de noter que tu peux utiliser la syntaxe de commentaire ordinaire comme ceci, mais elle doit être enveloppée dans des accolades pour fonctionner :

```jsx
{/* Block Comments */}
```

Autre chose que tu as peut-être remarquée : nous utilisons une majuscule au début du nom du composant. Mais pourquoi ne pouvons-nous pas utiliser uniquement des lettres minuscules ?

C'est parce que React traite les composants avec une majuscule comme des composants personnalisés, tandis que les éléments en minuscules sont considérés comme des éléments HTML intégrés.

Quand React rencontre une balise en minuscules, comme `<div>` ou `<span>`, il suppose que c'est un élément HTML standard. En revanche, si le nom du composant commence par une majuscule, React le traitera comme un composant défini par l'utilisateur et l'affichera en conséquence. Cette distinction aide React à différencier les balises HTML natives et les composants que tu crées.

Pour utiliser ce composant `Greeting` dans notre application, nous écririons quelque chose comme ceci :

```jsx
<Greeting />
```

Cela afficherait un élément `h1` avec le texte `Hello John` sur la page. Mais regarde de plus près la syntaxe ici. Quand nous utilisons le composant, il se termine par une barre oblique puis le symbole supérieur à.

Quand tu travailles avec JSX, toutes les balises et utilisations de composants doivent être explicitement fermées. Donc si le composant ou la balise n'a pas d'enfants, tu dois le fermer explicitement comme montré ici :

```jsx
<Greeting /> {/* /> is required */}
```

Jusqu'ici, nous n'avons regardé que comment afficher un seul élément `h1`. Mais tu peux en fait afficher plusieurs éléments.

Regardons l'exemple de code suivant ici :

```jsx
function Greeting() {
  const name = "John";
  {/* This will throw an error */}
  return <h1>Hello {name}</h1>
  <p>Nice to meet you.</p>
}
```

Nous essayons d'ajouter une autre phrase `Nice to meet you` mais elle ne s'affiche pas correctement sur la page.

Il semble y avoir un message d'erreur à la place. Le message d'erreur dit `Adjacent JSX elements must be wrapped in an enclosing tag.`

La raison pour laquelle tu reçois ce message d'erreur est que plusieurs éléments frères doivent être enveloppés dans un élément parent. Bien que tu puisses envelopper les éléments `h1` et `p` dans un simple `div`, il y a une autre façon de faire taire l'erreur.

Les fragments React servent à grouper des éléments ensemble. Voici à quoi ressemblera l'exemple révisé :

```jsx
function Greeting() {
  const name = "John";
  return (
    <Fragment>
      <h1>Hello {name}</h1>
      <p>Nice to meet you.</p>
    </Fragment>
  );
}
```

Tu peux aussi choisir d'utiliser des balises JSX vides qui peuvent servir de raccourci pour les fragments :

```jsx
function Greeting() {
  const name = "John";
  return (
    <>
      <h1>Hello {name}</h1>
      <p>Nice to meet you.</p>
    </>
  );
}
```

Dans les prochaines leçons, nous continuerons à apprendre comment travailler avec les composants et JSX. Mais pour l'instant, tu as acquis une solide introduction à la construction d'interfaces utilisateur avec des composants, posant une base solide pour la suite.
