# --description--

Contrairement au travail sur de plus petits projets HTML, CSS et JavaScript vanilla, démarrer un nouveau projet React inclut quelques étapes de plus pour s'assurer que tout fonctionne correctement. Au lieu d'essayer de configurer toi-même toutes les configurations nécessaires, il existe des outils qui le font pour toi.

L'un des outils les plus populaires pour configurer des projets est Vite. Vite, qui signifie « rapide » en français, est un outil de build qui vise à offrir une expérience de développement plus rapide pour les projets web modernes. Vite peut être utilisé avec React, ainsi qu'avec d'autres bibliothèques et frameworks comme Vue ou Svelte. Tu peux même l'utiliser avec des projets JavaScript vanilla.

Pour créer un nouveau projet avec Vite, tu auras besoin d'utiliser la ligne de commande. Si tu utilises une machine Windows, tu peux utiliser l'Invite de commandes ou Windows PowerShell. Si tu utilises un Mac, tu peux utiliser l'app Terminal.

Au cas où tu n'aurais pas Node.js installé, ce qui est nécessaire pour que npm fonctionne, voici un lien vers la page officielle de Node.js : https://nodejs.org. Suis les instructions d'installation puis reviens ici pour reprendre ton installation React.

Une fois la ligne de commande ouverte, tu peux utiliser la commande suivante :

```bash
npm create vite@latest my-react-app -- --template react
```

Cette commande crée un nouveau projet React nommé `my-react-app` en utilisant le template React de Vite.

Tu peux ensuite ouvrir le nouveau projet et voir le code de base React que Vite a fourni pour toi.

Le grand avantage de Vite est qu'il ne fournit que les fichiers absolument nécessaires pour démarrer ton projet React.

Pour réellement lancer le projet tel quel, tu devras installer les dépendances avec les commandes suivantes dans la ligne de commande :

```bash
cd my-react-app
npm install
```

La commande `cd my-react-app` s'assure que tu changes vers le bon répertoire où se trouve ton projet.

La commande `npm install` sert à installer les dépendances nécessaires pour faire tourner correctement ton projet React. Les dépendances sont des bibliothèques ou packages dont ton projet React a besoin pour fonctionner correctement, comme React lui-même, ReactDOM, ou d'autres packages tiers qui fournissent des fonctionnalités supplémentaires.

Exécuter `npm install` lira le fichier `package.json` dans le répertoire de ton projet et installera toutes les dépendances listées là, te permettant de construire et lancer ton app React sans manquer aucun composant nécessaire.

Le fichier `package.json` est un fichier de configuration clé dans les projets qui contient des métadonnées sur ton projet, y compris son nom, sa version et ses dépendances. Il définit aussi des scripts, des informations de licence et d'autres réglages qui aident à gérer le projet et ses dépendances.

Une fois les dépendances installées, tu devrais remarquer un nouveau dossier dans ton projet appelé `node_modules`.

Le dossier `node_modules` est l'endroit où tous les packages et bibliothèques requis par ton projet sont stockés. Ce dossier contient le code réel des dépendances listées dans ton fichier `package.json`, y compris à la fois les dépendances directes de ton projet et toutes les dépendances de ces dépendances.

Pour lancer ton projet, exécute la commande `npm run dev` et ouvre un nouvel onglet de navigateur à `http://localhost:5173/`.

Tu devrais voir le template de démarrage que Vite a fourni pour toi.

Si tu as besoin d'arrêter le serveur local, appuie sur `CTRL + C` dans la ligne de commande.

Pour réellement voir le code de ce template de démarrage, tu peux aller dans ton projet dans le dossier `src` et tu devrais voir le fichier `App.jsx`.

À partir de là, tu peux commencer à modifier le fichier, enregistrer tes changements et voir les nouveaux changements s'afficher dans le navigateur.

Et avec ça, tu es prêt à commencer à construire ton application React !
