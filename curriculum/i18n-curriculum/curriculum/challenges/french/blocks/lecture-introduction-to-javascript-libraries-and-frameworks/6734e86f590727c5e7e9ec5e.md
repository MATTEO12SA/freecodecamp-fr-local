# --description--

React est l'une des bibliothèques JavaScript les plus populaires pour construire des interfaces utilisateur et des applications web. Développé et maintenu à l'origine par Facebook, React a gagné une énorme popularité en développement web grâce à son efficacité, sa flexibilité et ses fonctionnalités.

Un concept fondamental dans React est la création de composants d'UI réutilisables. Ces composants, comme des boutons, des cartes et des composants avatar, peuvent être facilement réutilisés dans toute ton application. Tu peux imbriquer ces composants les uns dans les autres pour construire des interfaces plus complexes et dynamiques.

L'un des avantages clés de React est que ces composants personnalisés peuvent se mettre à jour et s'afficher indépendamment quand les données changent.

Contrairement au JavaScript traditionnel, qui exige une manipulation directe du DOM (Document Object Model), React utilise un DOM virtuel, ce qui améliore la performance et l'efficacité. Tu en apprendras plus sur le DOM virtuel et son fonctionnement dans les prochaines leçons.

En plus des composants réutilisables, React fournit aussi une façon puissante de gérer l'état de ton application. L'état désigne les données qui déterminent comment un composant s'affiche et se comporte.

Avec React, tu peux facilement suivre et mettre à jour l'état des composants, en veillant à ce que l'UI reflète les données les plus récentes. Tu en apprendras plus sur le travail avec l'état dans les prochaines leçons.

Bien qu'il y ait de nombreuses bibliothèques dans l'écosystème JavaScript, freeCodeCamp se concentrera surtout sur l'enseignement de React en raison de son usage répandu et de la demande dans l'industrie.

Nos prochaines leçons approfondiront la construction de composants personnalisés, la gestion de l'état, et plus encore.
