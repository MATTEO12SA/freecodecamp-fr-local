# --description--

Chaque projet est unique et tu devrais soigneusement considérer lesquelles de ces techniques seront les plus utiles pour ton application web.

D'abord, comme tous les styles sont parsés, tu devrais retirer tout style inutile de tes feuilles de style CSS.

Tu devrais aussi découper tes styles CSS en plusieurs fichiers. Ainsi, si un fichier n'est pas requis pour rendre une page spécifique, il ne sera pas chargé et ne bloquera pas le processus de rendu.

Par défaut, le navigateur suppose que toutes les feuilles de style doivent bloquer le rendu. Mais tu peux lui dire quand une feuille de style doit être chargée en utilisant l'attribut `media` et une media query.

Dans cet exemple, la feuille de style `print.css` ne sera appliquée que lorsque le document est imprimé, car elle a l'attribut `media` avec la valeur `print` :

```html
<link rel="stylesheet" href="print.css" media="print" />
```

Tu peux aussi minifier automatiquement tes fichiers CSS pour réduire leur taille pendant le build, et compresser ces fichiers sur le serveur où tu héberges ton application web.

Essaie de garder tes sélecteurs CSS aussi simples que possible et ne sélectionne pas plus d'éléments que nécessaire.

Profite de la nature en cascade du CSS dès que possible. Certains styles seront hérités.

Précharger les ressources avec `rel="preload"` est une autre technique importante. Les assets critiques devraient être chargés en premier.

Souviens-toi que les animations CSS peuvent avoir un impact sur la performance.

Animer certaines propriétés CSS, comme les dimensions, la position et la mise en page, déclenche un processus appelé « reflow », pendant lequel le navigateur recalcule la position et la géométrie de certains éléments. Cela nécessite un repaint, coûteux en calcul.

Il est donc recommandé de réduire le nombre d'animations CSS autant que possible, ou au moins de laisser l'utilisateur les activer ou les désactiver.

Et même si les polices peuvent enrichir la présentation visuelle de ton application, elles peuvent impacter la performance. Certaines polices ont de gros fichiers, jusqu'à plusieurs mégaoctets. Essaie d'utiliser deux ou trois polices au maximum et utilise des polices web-safe dès que possible.

Tu peux aussi envisager de précharger les polices les plus importantes pour les avoir prêtes à l'emploi rapidement.

Voici quelques-unes des techniques les plus importantes et couramment utilisées pour optimiser le CSS en développement web. En les intégrant, tu peux optimiser la performance de ton site pour créer une expérience utilisateur fluide.
