# --description--

Améliorer le « time to usable », autrement dit l'intervalle entre la demande d'une page par l'utilisateur et le moment où il peut interagir utilement avec elle, est crucial pour améliorer l'expérience utilisateur.

Explorons des stratégies efficaces pour obtenir un time to usable plus rapide.

Commence par te concentrer sur le contenu que l'utilisateur voit en premier. Cela signifie charger immédiatement les éléments essentiels et différer les composants non critiques.

Par exemple, tu pourrais essayer d'implémenter le lazy loading.

On a déjà couvert le lazy loading, mais voici un exemple de lazy load d'images en rappel :

```html
<img src="image.jpg" loading="lazy" alt="Description">
```

Il te suffit d'ajouter l'attribut `loading="lazy"` aux balises image. Cela diffère le chargement des images jusqu'à ce qu'elles soient nécessaires, typiquement quand elles entrent dans le viewport de l'utilisateur. En chargeant images et vidéos seulement quand elles entrent dans le viewport, on économise de la bande passante et on accélère le rendu initial.

Normalement, une page charge toutes les images d'un coup, même celles qui ne sont pas visibles à l'écran. Avec le lazy loading, les images sous la ligne de flottaison, autrement dit hors écran, ne sont chargées que lorsque l'utilisateur défile jusqu'à elles.

Et voici un exemple de lazy load d'iframes :

```html
<iframe src="video.html" loading="lazy"></iframe>
```

Tu peux appliquer le même attribut qu'avant, mais cette fois aux iframes, et le même concept s'appliquera.

Tu peux aussi utiliser l'attribut `defer` pour différer le JavaScript non critique jusqu'après le chargement initial de la page. Voici un exemple où on fait exactement cela :

```html
<script src="non-critical.js" defer></script>
```

Tu pourrais aussi envisager de minimiser les ressources qui bloquent le rendu.

Les ressources qui bloquent le rendu retardent le moment où la page devient interactive.

Pour l'éviter, tu pourrais essayer de charger le CSS de façon asynchrone. Pour le CSS non critique, utilise l'attribut `media` pour charger les feuilles de style conditionnellement. Voici un exemple où on fait exactement cela :

```html
<link rel="stylesheet" href="print.css" media="print">
```

En spécifiant la valeur média `print`, le fichier `print.css` ne sera chargé que lorsque la page est imprimée ou prévisualisée à l'écran. Dans l'exemple suivant, en passant `min-width: 800px` comme valeur à l'attribut `media`, on dit qu'on ne veut charger `desktop.css` que pour les écrans plus larges que 800 px :

```html
<!-- This stylesheet is only loaded on screens wider than 800px -->
<link rel="stylesheet" href="desktop.css" media="(min-width: 800px)">
```

Cela économise de la bande passante en sautant les styles inutiles.

En conclusion, en appliquant ces stratégies, tu peux nettement réduire le « time to usable » de ton site, en t'assurant que les utilisateurs peuvent interagir rapidement avec ton contenu.
