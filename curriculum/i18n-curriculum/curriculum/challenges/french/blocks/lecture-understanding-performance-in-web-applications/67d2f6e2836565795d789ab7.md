# --description--

T'es-tu déjà demandé ce qui se passe en coulisses quand tu saisis une URL et appuies sur Entrée ? Comment le navigateur transforme-t-il le code en pages interactives que l'on voit ?

Comprendre comment un navigateur rend une page web est essentiel pour les développeurs qui veulent optimiser la performance et améliorer l'expérience utilisateur.

Dans cette leçon, on démystifiera le processus de rendu, en le découpant en étapes claires et digestes.

D'abord, le navigateur parse le HTML et construit le DOM.

Le processus commence quand le navigateur récupère le contenu HTML de la page. Il parse ce HTML pour construire le Document Object Model, ou DOM — une structure en arbre qui représente le contenu de la page.

Regarde ce simple extrait HTML :

```html
<html>
  <body>
    <h1>Hello, World!</h1>
    <p>Welcome to our website.</p>
  </body>
</html>
```

Le navigateur le parse pour créer un arbre DOM avec `html` comme racine, contenant `body`, qui contient à son tour des éléments `h1` et `p`.

Ensuite, le navigateur traite le CSS et construit le CSS Object Model, ou CSSOM. C'est une autre structure en arbre qui dicte comment les éléments doivent être stylés.

Avec ce CSS :

```css
h1 {
  color: blue;
}
p {
  font-size: 16px;
}
```

Le CSS Object Model spécifie que les éléments `h1` sont bleus et que les éléments `p` ont une taille de police de 16 pixels.

Le navigateur combine ensuite le DOM et le CSS Object Model pour former l'arbre de rendu. Cet arbre n'inclut que les nœuds nécessaires pour rendre la page, chacun associé à ses styles correspondants.

Dans notre exemple, l'arbre de rendu se compose des éléments `h1` et `p`, stylés correctement.

Avec l'arbre de rendu en main, le navigateur calcule la position et la taille exactes de chaque élément dans un processus appelé layout ou reflow. Cela garantit que les éléments apparaissent au bon endroit et avec les bonnes dimensions à l'écran.

Enfin, le navigateur peint les pixels à l'écran, en rendant chaque élément selon les styles et la mise en page calculés. Sur des pages complexes, cela peut impliquer plusieurs couches composées ensemble pour former le rendu final.

En conclusion, du parsing HTML et CSS jusqu'à la peinture des pixels à l'écran, le processus de rendu du navigateur est une séquence sophistiquée d'étapes.
