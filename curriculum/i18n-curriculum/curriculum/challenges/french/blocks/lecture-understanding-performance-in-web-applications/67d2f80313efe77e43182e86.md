# --description--

Révisons quelques-unes des techniques les plus importantes pour améliorer spécifiquement la performance JavaScript.

Tu pourrais trouver cela surprenant, mais la première technique est d'utiliser moins de JavaScript dès que possible.

Si tu développes un site statique simple, tu pourrais peut-être faire exactement la même chose sans frameworks qui dépendent de JavaScript.

Tu devrais aussi essayer de retirer tout code JavaScript inutilisé et utiliser des solutions plus simples, si possible.

Par exemple, tu peux envisager d'utiliser des fonctionnalités intégrées au navigateur plutôt que des solutions personnalisées. Ces fonctionnalités incluent la validation de formulaires, le lecteur vidéo intégré du navigateur, et les animations CSS plutôt que des animations JavaScript personnalisées.

Utilise aussi peu d'animations que possible.

Réduis la quantité de manipulations DOM dans ton code JavaScript, car c'est coûteux en calcul.

Découper ton code JavaScript en modules pour les tâches critiques et non critiques est aussi utile. Ainsi, tu pourras précharger les modules critiques dès que possible et différer les non critiques pour rendre la page plus vite.

Précharger des fichiers ne garantit pas qu'ils seront disponibles quand tu les utilises, mais le téléchargement commencera plus tôt, donc le temps d'attente global devrait être plus court.

Une fois ton code découpé en plusieurs fichiers, tu peux les minifier automatiquement pendant le build pour réduire leur taille et optimiser leur temps de chargement.

Si un écouteur d'événements n'est plus nécessaire, tu devrais le retirer :

```js
element.removeEventListener("mousemove", handleMouseMove);
```

Dans cet exemple, on retire l'écouteur d'événements pour l'événement `mousemove`, donc la fonction `handleMouseMove` n'est plus appelée quand l'événement est déclenché. Si tu gardes l'écouteur, le programme continuera à faire des calculs qui ne sont plus nécessaires, ce qui affecte la performance globale. Cet effet sera encore plus visible si tu as plusieurs écouteurs actifs simultanément.

Et puisqu'on parle d'événements, il est recommandé d'utiliser la délégation d'événements dès que possible.

Cela signifie que tu n'as pas besoin de poser les écouteurs sur chaque élément enfant individuellement. Tu peux le poser directement sur le parent, et l'événement remontera jusqu'à trouver un parent qui peut le gérer.

Optimiser le JavaScript est crucial pour développer des applications web rapides et réactives. Dans un projet réel, tu analyseras constamment la performance de ton site pour trouver des axes d'amélioration.
