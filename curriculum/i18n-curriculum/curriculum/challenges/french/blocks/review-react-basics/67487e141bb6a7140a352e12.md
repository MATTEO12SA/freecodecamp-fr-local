## Bibliothèques et frameworks JavaScript

- Les bibliothèques et frameworks JavaScript offrent des solutions rapides aux problèmes courants et accélèrent le développement en fournissant du code déjà prêt.
- Les bibliothèques se concentrent en général sur des tâches précises, comme manipuler le DOM, gérer les événements ou les requêtes AJAX.
- Deux exemples de bibliothèques JavaScript sont jQuery et React.
- Les frameworks, eux, fournissent une structure plus définie pour construire des applications. Ils s'accompagnent souvent de règles et de conventions que les développeurs doivent suivre.
- Parmi les frameworks, on trouve Angular et Next.js, un méta-framework pour React.
- Les **applications monopage** (SPA) sont des applications web qui chargent une seule page HTML et mettent à jour cette page dynamiquement quand l'utilisateur interagit avec l'application, sans recharger toute la page.
- Les SPA utilisent JavaScript pour gérer l'état de l'application et afficher le contenu. On le fait souvent avec des frameworks qui fournissent d'excellents outils pour construire des interfaces complexes.
- Voici quelques problèmes liés aux SPA :

  - Les lecteurs d'écran peinent avec le contenu mis à jour dynamiquement.
  - L'URL ne change pas quand l'utilisateur navigue dans l'application, ce qui rend difficile de mettre en favori, revenir en arrière ou partager des pages précises.
  - Le temps de chargement initial peut être long si l'application est volumineuse, car tous les assets doivent être chargés d'emblée.

## React

- React est une bibliothèque JavaScript populaire pour construire des interfaces utilisateur et des applications web.
- Un concept central de React est la création de composants d'UI réutilisables qui peuvent se mettre à jour et s'afficher indépendamment quand les données changent.
- React permet aux développeurs de décrire à quoi l'UI doit ressembler selon l'état de l'application. React met alors à jour et affiche les bons composants quand les données ou l'état changent.

## Composants React

- Les composants sont les briques de base des applications React : ils permettent de découper des interfaces complexes en morceaux plus petits et gérables.
- L'UI se décrit avec JSX, une extension de la syntaxe JavaScript, qui permet d'écrire du code semblable à du HTML dans JavaScript.
- Les composants sont en gros des fonctions ou des classes JS qui renvoient un morceau d'UI.

Voici un exemple de composant React simple qui affiche un message de salutation :

```jsx
function Greeting() {
  const name = 'Anna';
  return <h1>Welcome, {name}!</h1>;
}
```

Pour utiliser le composant, tu peux simplement appeler :
```jsx
  <Greeting />
```

## Importer et exporter des composants React

- Un export rend un composant disponible pour d'autres fichiers. Un import permet à un fichier d'utiliser un composant exporté ailleurs.
- Il existe deux types d'exports en React : les exports par défaut et les exports nommés.

**Exports par défaut**

- Un fichier ne peut avoir qu'un seul export par défaut. C'est idéal pour un fichier qui contient surtout un seul composant.
- Tu peux exporter un composant en export par défaut comme ceci :

```jsx
// City.js
function City() {
  return <p>New York</p>;
}

export default City;
```

- Tu peux aussi exporter sur la même ligne que la définition du composant :

```jsx
export default function City() {
  return <p>New York</p>;
}
```

- Pour importer un export par défaut, utilise le mot-clé `import` sans accolades :

```jsx
// App.js
import City from './City';

function App() {
  return (
    <div>
      <h1>My favorite city is:</h1>
      <City />
    </div>
  );
}
```

**Exports nommés**

- Les exports nommés permettent à un fichier de partager plusieurs composants. Contrairement aux exports par défaut, ils doivent être importés avec le nom exact sous lequel ils ont été exportés.
- Tu peux exporter plusieurs composants depuis le même fichier comme ceci :

```jsx
// Animals.jsx
export function Cat() {
  return <h2>Mr. Whiskers</h2>;
}

export function Dog() {
  return <h2>Fido</h2>;
}
```

- Pour importer des exports nommés, utilise des accolades avec les noms exacts exportés :

```jsx
import { Cat, Dog } from './Animals';
```

- Tu peux renommer un export nommé à l'import avec le mot-clé `as` :

```jsx
import { Cat as Kitty } from './Animals';
```

**Exports par défaut et nommés mélangés**

- Un fichier peut avoir un export par défaut et plusieurs exports nommés en même temps :

```jsx
// Animals.jsx
export default function Cat() {
  return <h2>Mr. Whiskers</h2>;
}

export function Dog() {
  return <h2>Fido</h2>;
}
```

- Quand tu importes des exports mélangés, l'export par défaut vient en premier (sans accolades), puis les exports nommés (entre accolades) :

```jsx
import Cat, { Dog } from './Animals';
```

## Créer un projet React avec Vite

- Les outils de mise en place de projet et les CLI offrent un moyen rapide et simple de démarrer de nouveaux projets, pour que tu te concentres sur le code plutôt que sur la configuration.
- Vite est un outil de mise en place de projet populaire et peut s'utiliser avec React.
- Pour créer un nouveau projet avec Vite, tu peux utiliser la commande suivante dans ton terminal :

```bash
npm create vite@latest my-react-app -- --template react
```

Cette commande crée un nouveau projet React nommé `my-react-app` avec le modèle React de Vite. Dans le répertoire du projet, tu verras un fichier `package.json` listant les dépendances et les commandes du projet.

- Pour lancer le projet, va dans le répertoire du projet et exécute les commandes suivantes :

```bash
cd my-react-app # path to the project directory
npm install # installs the dependencies listed in the package.json file
```

- Une fois les dépendances installées, tu devrais voir un nouveau dossier dans ton projet appelé `node_modules`.

- Le dossier `node_modules` est l'endroit où sont stockés tous les paquets et bibliothèques requis par ton projet.

- Pour lancer ton projet, utilise la commande suivante :

```bash
npm run dev
```

- Ensuite, ouvre ton navigateur et va sur `http://localhost:5173` pour voir ton application React en cours d'exécution.

- Pour voir le code du modèle de départ, entre dans ton projet dans le dossier `src` : tu devrais y trouver le fichier `App.jsx`.

## Passer des props dans les composants React

- En React, les props (abréviation de properties) permettent de passer des données d'un composant parent à un composant enfant. Ce mécanisme est nécessaire pour créer des éléments d'UI réutilisables et dynamiques.
- Les props peuvent être n'importe quelle valeur JavaScript. Pour passer des props d'un parent à un enfant, tu ajoutes les props comme attributs quand tu utilises le composant enfant dans le JSX du parent. Voici un exemple simple :

```jsx
// Parent component
function Parent() {
  const name = 'Anna';
  return <Child name={name} />;
}

// Child component
function Child(props) {
  return <h1>Hello, {props.name}!</h1>;
}
```

Tu peux passer plusieurs props avec l'opérateur de décomposition `(...)`, après les avoir converties en objet. Voici un exemple :
```jsx
// Parent component
function Parent() {
  const person = {
    name: 'Anna',
    age: 25,
    city: 'New York'
  };
  return <Child {...person} />;
}
```

Dans ce code, l'opérateur de décomposition `{...person}` convertit l'objet person en props individuelles passées au composant Child.

## Affichage conditionnel en React

- L'affichage conditionnel en React te permet de créer des interfaces dynamiques. Il sert à montrer un contenu différent selon certaines conditions ou états dans ton application.
- Il existe plusieurs façons d'afficher du contenu de façon conditionnelle en React. Une approche courante est d'utiliser l'opérateur ternaire. Voici un exemple :

```jsx
function Greeting({ isLoggedIn }) {
  return (
    <div>
      {isLoggedIn ? <h1>Welcome back!</h1> : <h1>Please log in</h1>}
    </div>
  );
}
```

- Une autre façon d'afficher du contenu conditionnellement est d'utiliser l'opérateur logique ET (`&&`). C'est utile quand tu veux afficher du contenu seulement si une certaine condition est remplie. Voici un exemple :

```jsx
function Greeting({ user }) {
  return (
    <div>
      {user && <h1>Welcome, {user.name}!</h1>}
    </div>
  );
}
```

Dans le code ci-dessus, l'élément `h1` n'est affiché que si l'objet user est truthy.

Tu peux aussi utiliser une instruction `if` directe de cette façon :

```jsx
function Greeting({ isLoggedIn }) {
  if (isLoggedIn) {
    return <h1>Welcome back!</h1>;
  }
  return <h1>Please sign in</h1>;
}
```

## Afficher des listes en React

- Afficher des listes en React est une tâche courante quand on construit des interfaces.
- Les listes peuvent s'afficher avec la méthode de tableau JS `map()` pour parcourir un tableau d'éléments et renvoyer un nouveau tableau d'éléments JSX.
- Par exemple, si tu as un tableau de noms que tu veux afficher sous forme de liste, tu peux faire ceci :

```jsx
function NameList({ names }) {
  return (
    <ul>
      {names.map((name, index) => (
        <li key={`${name}-${index}`}>{name}</li>
      ))}
    </ul>
  );
}
```

- Pense toujours à fournir une clé unique pour chaque élément de liste afin d'aider React à gérer la mise à jour et l'affichage. Avec ces techniques, tu peux créer des listes flexibles, efficaces et dynamiques dans tes applications React.

## Styles en ligne en React

- Les styles en ligne en React te permettent d'appliquer des styles CSS directement aux éléments JSX via des objets JavaScript.
- Pour appliquer des styles en ligne en React, tu peux utiliser l'attribut style sur les éléments JSX. L'attribut style prend un objet dont les clés sont des propriétés CSS en camelCase et les valeurs sont les valeurs correspondantes. Voici un exemple :

```jsx
function Greeting() {
  return (
    <h1
      style={{ color: 'blue', fontSize: '24px', backgroundColor: 'lightgray' }}
    >
      Hello, world!
    </h1>
  );
}

export default Greeting;
```

Tu peux aussi extraire les styles dans un objet séparé et le référencer dans l'attribut `style` de cette façon :

```jsx
function Greeting() {
  const styles = {
    color: 'blue',
    fontSize: '24px',
    backgroundColor: 'lightgray'
  };

  return <h1 style={styles}>Hello, world!</h1>;
}

export default Greeting;
```

- Les styles en ligne permettent un style dynamique en appliquant des styles selon les props ou l'état. Voici un exemple d'application conditionnelle de styles selon une prop :

```jsx
function Greeting({ isImportant }) {
  const styles = {
    color: isImportant ? 'red' : 'black',
    fontSize: isImportant ? '24px' : '16px'
  };

  return <h1 style={styles}>Hello, world!</h1>;
}

export default Greeting;
```

- Dans le code ci-dessus, les styles `color` et `fontSize` sont définis conditionnellement selon la prop `isImportant`.
