# --description--

L'API Web Storage fournit un mécanisme permettant aux navigateurs de stocker des paires clé-valeur directement dans le navigateur, ce qui permet aux développeurs de stocker des informations utilisables d'un rechargement de page à l'autre et d'une session à l'autre.

Les deux principaux composants de l'API Web Storage sont `localStorage` et `sessionStorage`.

`localStorage` est la partie de l'API Web Storage qui permet aux données de persister même après la fermeture de la fenêtre du navigateur ou le rafraîchissement de la page. Ces données restent disponibles jusqu'à ce qu'elles soient explicitement supprimées par l'application ou l'utilisateur.

`sessionStorage` est une autre partie de l'API Web Storage qui stocke des données pendant la durée de la session de page, c'est-à-dire que les données sont disponibles tant que l'onglet ou la fenêtre du navigateur est ouvert. Cependant, contrairement à `localStorage`, les données de `sessionStorage` sont effacées lorsque l'onglet ou la fenêtre est fermé. Tu en apprendras davantage sur `sessionStorage` dans la prochaine leçon.

Les cas d'usage courants de `localStorage` incluent le stockage des paramètres utilisateur, comme les thèmes ou les préférences de langue, la mémorisation des données de formulaire d'une session de navigateur à l'autre, et la mise en cache de petites informations pour améliorer les performances des applications web.

La mise en cache consiste à stocker des données fréquemment consultées dans un emplacement de stockage temporaire, appelé cache, afin que les requêtes suivantes pour ces données puissent être servies plus rapidement sans avoir à les recalculer ou à les récupérer depuis une source plus lente, comme une base de données ou un serveur externe.

Parmi les méthodes courantes de `localStorage`, on trouve les méthodes `setItem`, `getItem`, `removeItem` et `clear`.

Voici un exemple d'utilisation de la méthode `setItem()` qui stocke une paire clé-valeur dans `localStorage`.

```js
localStorage.setItem('username', 'JaneDoe');
```

Ensuite, si on veut récupérer la valeur d'une clé donnée depuis `localStorage`, on peut utiliser la méthode `getItem()`.

```js
let username = localStorage.getItem('username');
console.log(username); // JaneDoe
```

Pour supprimer un élément de `localStorage` à l'aide de sa clé, tu peux utiliser la méthode `removeItem()`.

```js
localStorage.removeItem('username');
```

Pour effacer toutes les données de `localStorage`, tu peux utiliser la méthode `clear()`.

```js
localStorage.clear();
```

Maintenant, regardons un exemple où on utilise `localStorage` pour stocker le thème préféré d'un utilisateur.

```js
// Store the user's theme preference
localStorage.setItem('theme', 'dark');

// Retrieve the stored theme preference
const userTheme = localStorage.getItem('theme');
console.log(userTheme); // 'dark'

// Remove the theme preference
localStorage.removeItem('theme');

// Clear all localStorage data
localStorage.clear();
```

Dans cet exemple :

- On stocke d'abord un choix de thème (`dark`) pour l'utilisateur.

- Ensuite, on récupère ce thème et on l'affiche dans la console.

- Enfin, on montre comment supprimer un élément spécifique ou effacer toutes les données stockées.

`localStorage` est très utile pour stocker de petites données qui doivent persister entre les sessions, mais il est important de noter que `localStorage` ne doit pas être utilisé pour stocker des informations sensibles, comme des mots de passe, car cela peut présenter des risques de sécurité.
