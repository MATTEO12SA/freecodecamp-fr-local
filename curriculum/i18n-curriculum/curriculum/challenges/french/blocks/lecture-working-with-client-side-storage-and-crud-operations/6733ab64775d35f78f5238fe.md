# --description--

CRUD est un acronyme qui signifie Create, Read, Update et Delete (Créer, Lire, Mettre à jour et Supprimer). Ce sont les quatre opérations du stockage persistant.

Le stockage persistant consiste à enregistrer des données de façon à ce qu'elles restent disponibles même après une coupure d'alimentation ou un redémarrage de l'appareil.

Comprendre le fonctionnement de base du CRUD est crucial en développement web, car cela constitue le fondement du travail avec les bases de données et de la construction d'applications où les utilisateurs peuvent ajouter, consulter, modifier et supprimer des données.

Maintenant, regardons de plus près chaque partie du CRUD

- Create désigne le processus de création de nouvelles données. Par exemple, dans une application web, cela peut être lorsqu'un utilisateur ajoute un nouvel article à un blog.

- Read est l'opération où les données sont récupérées depuis une base de données. Par exemple, lorsque tu consultes un article de blog ou que tu affiches ton profil sur un site, tu effectues une opération de lecture pour récupérer et afficher des données stockées dans la base de données.

- Update consiste à modifier des données existantes dans la base de données. Un exemple serait l'édition d'un article de blog ou la mise à jour des informations de ton profil.

- Delete est l'opération qui supprime des données d'une base de données. Par exemple, lorsque tu supprimes un article de blog ou un compte, tu effectues une opération de suppression.

Le CRUD est utilisé lorsqu'on travaille avec des bases de données, l'interface utilisateur et les API RESTful. Les API RESTful sont un ensemble de conventions pour construire des services web qui permettent au client d'interagir avec une base de données ou un système back-end en effectuant des opérations CRUD via des méthodes HTTP standard.

HTTP signifie Hypertext Transfer Protocol et c'est le fondement de la communication de données sur le web. Il existe des méthodes HTTP qui définissent les actions pouvant être effectuées sur des ressources via le web. Les méthodes courantes sont `GET`, `POST`, `PUT`, `PATCH`, `DELETE`.

Tu en apprendras davantage sur les API RESTful et HTTP dans de futures leçons, mais voici un rapide aperçu de la façon dont le CRUD correspond aux différentes méthodes HTTP.

- `POST` est utilisé pour créer une nouvelle ressource.

- `GET` est utilisé pour récupérer ou lire des données.

- `PUT` est utilisé pour mettre à jour une ressource en la remplaçant entièrement.

- `PATCH` est utilisé pour mettre à jour partiellement une ressource.

- `DELETE` est utilisé pour supprimer une ressource.

Voici un exemple de la façon dont les opérations CRUD peuvent être représentées en code à l'aide d'un simple tableau en JavaScript :

```js
let items = [];

// Create
function createItem(item) {
  items.push(item);
}

// Read
function readItems() {
  return items;
}

// Update
function updateItem(index, newItem) {
  items[index] = newItem;
}

// Delete
function deleteItem(index) {
  items.splice(index, 1);
}

// Example Usage
createItem('Book');
console.log(readItems()); // ['Book']
updateItem(0, 'Magazine');
console.log(readItems()); // ['Magazine']
deleteItem(0);
console.log(readItems()); // []
```

Dans cet exemple :

- On crée un élément en l'ajoutant dans un tableau.

- On lit les éléments en renvoyant le tableau.

- On met à jour un élément en modifiant l'élément du tableau à un indice donné.

- On supprime un élément en le retirant du tableau avec `splice()`.
