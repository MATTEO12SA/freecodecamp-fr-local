# --description--

Comme tu l'as appris dans les leçons précédentes, les cookies sont de simples données que les sites web peuvent stocker sur l'appareil d'un utilisateur.

Cependant, tu peux en fait stocker des structures de données plus complexes dans les cookies. Une méthode courante est d'utiliser JSON pour stocker des objets ou des tableaux. Voici un exemple :

```js
const userData = {
  name: "John Doe",
  age: 30,
  role: "admin"
};

document.cookie = "userInfo=" + JSON.stringify(userData) + "; path=/";
```

Dans cet exemple, on crée un objet avec des données utilisateur, on le convertit en chaîne JSON, puis on le stocke dans un cookie. Lorsque l'on veut récupérer ces données, on peut analyser la chaîne JSON en objet avec `JSON.parse()`.

Maintenant, tu te demandes peut-être ce qu'il en est de l'aspect « en-têtes HTTP » de notre sujet. Typiquement, les cookies sont définis par le serveur à l'aide d'en-têtes HTTP.

Par exemple, un serveur pourrait envoyer un en-tête comme ceci :

```http
Set-Cookie: username=John Doe; expires=Thu, 31 Dec 2024 6:00:00 IST; path=/
```

Cet en-tête indique au navigateur de définir un cookie.

On peut aussi définir des cookies directement dans le navigateur avec JavaScript. C'est utile pour stocker des données qui n'ont pas besoin d'être envoyées immédiatement au serveur.

Note que les cookies ont une limite de taille d'environ 4 Ko, et stocker trop de données dedans peut ralentir ton application web.

Stocker de grandes quantités de données dans les cookies peut augmenter le trafic réseau car les cookies sont envoyés avec chaque requête HTTP.
