# --description--

Dans la leçon précédente, nous avons appris à travailler avec `localStorage` et avons été brièvement présentés à `sessionStorage`.

Rappelle-toi que `sessionStorage` efface les données dès que l'utilisateur ferme l'onglet ou la fenêtre dans laquelle l'application web s'exécute. C'est idéal pour les situations où les données n'ont besoin de persister que pendant une seule session, comme le maintien des données de formulaire pendant la navigation ou le stockage d'informations d'état temporaires pendant un processus de paiement.

Tout comme `localStorage`, `sessionStorage` utilise des paires clé-valeur pour stocker et récupérer des données. Les méthodes utilisées avec `sessionStorage` sont aussi les mêmes que pour `localStorage`, la seule réelle différence étant la durée de stockage des données.

Voici quelques exemples d'utilisation des différentes méthodes :

- `sessionStorage.setItem()` : Stocke une paire clé-valeur dans `sessionStorage`.

```js
sessionStorage.setItem('cart', '3 items');
```

- `sessionStorage.getItem()` : Récupère la valeur d'une clé donnée depuis `sessionStorage`.

```js
let cart = sessionStorage.getItem('cart');
console.log(cart); // Outputs: '3 items'
```

- `sessionStorage.removeItem()` : Supprime un élément spécifique de `sessionStorage` à l'aide de sa clé.

```js
sessionStorage.removeItem('cart');
```

- `sessionStorage.clear()` : Efface toutes les données stockées dans `sessionStorage`.

```js
sessionStorage.clear();
```

Regardons un exemple où on stocke des données dans `sessionStorage` qui ne durent que tant que l'onglet ou la fenêtre du navigateur est ouvert :

```js
// Store data in sessionStorage
sessionStorage.setItem('currentUser', 'JohnDoe');

// Retrieve the stored data
const user = sessionStorage.getItem('currentUser');
console.log(user); // 'JohnDoe'

// Remove a specific key from sessionStorage
sessionStorage.removeItem('currentUser');

// Clear all sessionStorage data
sessionStorage.clear();
```

Dans cet exemple, on :

1. Stocke le nom de l'utilisateur actuel (`JohnDoe`) dans `sessionStorage`.

2. Le récupère et l'affiche.

3. Supprime l'élément associé à la clé `currentUser`.

4. Efface toutes les données de `sessionStorage`.

La différence clé par rapport à `localStorage` est que dès que l'utilisateur ferme l'onglet, toutes les données de session stockées seront perdues.

`sessionStorage` est particulièrement utile dans des scénarios comme :

- Le stockage de données temporaires telles que les saisies de formulaire pendant un processus de formulaire multi-pages.

- Le stockage de sélections ou de préférences temporaires qui n'ont pas besoin de persister d'une session à l'autre.

- Le maintien de l'état dans une application monopage qui n'a pas besoin d'être mémorisé une fois l'onglet fermé.

`sessionStorage` garantit qu'une fois que l'utilisateur quitte la page, les données de session sont effacées, ce qui est idéal pour les scénarios où tu ne veux pas conserver d'informations au-delà de la session actuelle.
