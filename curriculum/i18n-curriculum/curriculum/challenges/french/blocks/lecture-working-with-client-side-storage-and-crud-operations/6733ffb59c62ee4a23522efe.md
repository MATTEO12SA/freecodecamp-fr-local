# --interactive--

`IndexedDB` est un outil pour stocker des données structurées dans le navigateur. Il est intégré aux navigateurs web modernes, permettant aux applications web de stocker et de récupérer des objets JavaScript efficacement.

Contrairement à d'autres mécanismes de stockage comme `localStorage`, qui est limité au stockage de chaînes, `IndexedDB` peut stocker des objets JavaScript, des fichiers, et à peu près n'importe quel autre type de données. Cela facilite la vie des applications web qui doivent travailler avec de grandes structures de données complexes.

Maintenant, voyons comment `IndexedDB` fonctionne.

La première étape est d'ouvrir une base de données. Voici un exemple :

:::interactive_editor

```js
let request = indexedDB.open("Sample DB", 1);

request.onerror = function(event) {
  console.log("Error opening database");
};

request.onsuccess = function(event) {
  let db = event.target.result;
  console.log("Database opened successfully");
};
```

:::

Dans ce code, on ouvre une base de données nommée `"Sample DB"` avec la version 1. On fournit deux fonctions de rappel : une pour gérer les erreurs, et une autre pour lorsque la base de données est ouverte avec succès. L'objet `db` que l'on obtient dans le rappel de succès est ce que l'on utilisera pour interagir avec la base de données.

Si tu vérifies l'interface Application des outils de développement du navigateur, tu verras que ta `Sample DB` a été ouverte dans la section `IndexedDb`. Une fois ta base de données ouverte, tu peux commencer à travailler avec les object stores.

Les object stores dans IndexedDB sont similaires aux tables dans les bases de données traditionnelles. Ils contiennent les données réelles que tu veux stocker. Voici comment créer un object store :

```js
let request = indexedDB.open("Sample DB", 1);

request.onupgradeneeded = function(event) {
  let db = event.target.result;
  let objectStore = db.createObjectStore("customers", { keyPath: "id" });
};
```

Ce code crée un object store nommé `"customers"` avec `"id"` comme chemin de clé. Le chemin de clé est comme une clé primaire dans une base de données traditionnelle — il est utilisé pour identifier de façon unique chaque enregistrement.

Pour ajouter des données à notre object store, on ferait quelque chose comme ceci. Le `db` dans cet exemple représente l'instance de la base de données `IndexedDB`.

```js
let transaction = db.transaction(["customers"], "readwrite");
let objectStore = transaction.objectStore("customers");
let request = objectStore.add({ id: 1, name: "John Doe", email: "john@example.com" });

request.onerror = function(event) {
  console.log("Error adding data");
};

request.onsuccess = function(event) {
  console.log("Data added successfully");
};
```

Ce code ajoute un nouveau client à notre object store `"customers"`. On démarre une transaction (c'est ainsi que l'on regroupe les opérations de base de données), on obtient une référence à notre object store, puis on ajoute nos données.

La récupération de données fonctionne de façon similaire. On démarre une transaction, on obtient notre object store, puis on utilise des méthodes comme `get` pour récupérer les données :

```js
let transaction = db.transaction(["customers"]);
let objectStore = transaction.objectStore("customers");
let request = objectStore.get(1);

request.onerror = function(event) {
  console.log("Error retrieving data");
};

request.onsuccess = function(event) {
  console.log("Customer:", request.result);
};
```

Ce code récupère le client avec l'`id` de `1` depuis notre object store `"customers"`.

L'une des caractéristiques clés d'`IndexedDB` est qu'il est asynchrone.

Cela signifie que lorsque tu interagis avec `IndexedDB`, les opérations ne bloquent pas le fil principal de l'application web. Cela garantit que ton application web reste réactive même lorsqu'elle traite de grandes quantités de données.

Bien qu'`IndexedDB` offre des capacités puissantes, il a une courbe d'apprentissage plus raide que les autres options d'API de stockage plus simples, ce qui peut être un défi pour les débutants. Cependant, pour les applications qui doivent gérer de grandes quantités de données structurées côté client, `IndexedDB` offre des capacités inégalées.
