# --interactive--

Les closures sont l'une des fonctionnalités les plus puissantes et souvent mal comprises en JavaScript. À la base, une closure est une fonction qui a accès aux variables de sa portée lexicale englobante extérieure, même après que la fonction extérieure a renvoyé. Cela peut sembler complexe, mais c'est un concept fondamental qui permet de nombreux modèles de programmation avancés en JavaScript.

Pour comprendre les closures, commençons par un exemple :

:::interactive_editor

```js
function outerFunction(x) {
    let y = 10;
    function innerFunction(){
        console.log(x + y);
    }
    return innerFunction;
}

let closure = outerFunction(5);
console.log(closure()); // 15
```

:::

Dans cet exemple, `outerFunction` prend un paramètre `x` et définit une variable locale `y`. Elle définit ensuite une `innerFunction` qui utilise à la fois `x` et `y`. Enfin, elle renvoie `innerFunction`. Lorsque nous appelons `outerFunction(5)`, elle renvoie `innerFunction` que nous assignons à la variable `closure`. Lorsque nous appelons ensuite `closure()`, elle a toujours accès à `x` et `y` de `outerFunction`, même si `outerFunction` a déjà fini de s'exécuter. C'est l'essence d'une closure.

La fonction interne maintient une référence à son environnement lexical extérieur, préservant l'accès aux variables de cet environnement même après que la fonction extérieure s'est terminée.

Les closures sont particulièrement utiles pour créer des variables et des fonctions privées. Considère cet exemple :

:::interactive_editor

```js
function createCounter() {
    let count = 0;
    return function () {
        count++;
        return count;
    };
}

let counter = createCounter();
console.log(counter()); // 1
console.log(counter()); // 2
```

:::

Dans ce cas, `createCounter` renvoie une fonction qui incrémente et renvoie une variable `count`. La variable `count` n'est pas directement accessible depuis l'extérieur de `createCounter`, mais la fonction renvoyée (notre closure) y a accès. Chaque fois que nous appelons `counter()`, elle incrémente et renvoie le `count`.

Les closures peuvent aussi capturer plusieurs variables de leur portée extérieure. Par exemple :

:::interactive_editor

```js
function multiply(x) {
    return function (y) {
        return x * y;
    };
}

let double = multiply(2);
console.log(double(5)); // 10
```

:::

Ici, la fonction interne capture le paramètre `x` de `multiply`. Lorsque nous créons `double` en appelant `multiply(2)`, elle renvoie une fonction qui multiplie toujours son argument par `2`.

Une chose importante à noter à propos des closures est qu'elles capturent les variables par référence et non par valeur. Cela signifie que si la valeur d'une variable capturée change, la closure verra la nouvelle valeur. Par exemple :

:::interactive_editor

```js
function createIncrementer() {
    let count = 0;
    return function () {
        count++;
        console.log(count);
    };
}

let increment = createIncrementer();
increment(); // 1
increment(); // 2
```

:::

Chaque fois que nous appelons `increment`, elle travaille avec la même variable `count`, et non une copie de sa valeur initiale. Les closures sont un outil puissant en JavaScript. À mesure que tu continues à travailler avec JavaScript, tu découvriras que comprendre et utiliser efficacement les closures peut grandement améliorer ta capacité à écrire du code propre, efficace et puissant.
