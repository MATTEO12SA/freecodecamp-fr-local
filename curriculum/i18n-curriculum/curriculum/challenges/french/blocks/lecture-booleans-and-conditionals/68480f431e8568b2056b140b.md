# --description--

Dans la leçon précédente, tu as appris à utiliser les opérateurs de comparaison et les instructions conditionnelles pour contrôler le déroulement de tes programmes.

Même si ces outils sont très puissants, tu rencontreras souvent des situations où tu dois comparer plusieurs valeurs à la fois. Cela peut mener à des instructions conditionnelles imbriquées, par exemple :

```python
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

L'exemple ci-dessus vérifie d'abord si `is_citizen` vaut `True`. Si c'est le cas, il passe ensuite à l'instruction `if` imbriquée et vérifie si `age` est supérieur ou égal à `18`. Comme `age` est supérieur ou égal à `18`, le message affiché dans le terminal sera `You are eligible to vote`. Si `is_citizen` valait `False`, le message affiché dans le terminal aurait été `You are not eligible to vote`.

Si tu travailles avec des instructions conditionnelles plus complexes, tu peux utiliser les opérateurs `and`, `or` et `not` de Python.

Mais avant de plonger dans ces opérateurs, voyons ce que sont les valeurs truthy et falsy.

En Python, chaque valeur a une valeur booléenne inhérente, c'est-à-dire une notion intégrée indiquant si elle doit être traitée comme `True` ou `False` dans un contexte logique. De nombreuses valeurs sont considérées comme **truthy**, c'est-à-dire qu'elles s'évaluent à `True` dans un contexte logique. D'autres sont **falsy**, ce qui signifie qu'elles s'évaluent à `False`.

Voici quelques valeurs falsy :

- `None`
- `False`
- L'entier `0`
- Le flottant `0.0`
- Les chaînes vides `""`

D'autres valeurs comme les nombres non nuls et les chaînes non vides sont truthy.

Si tu veux vérifier si une valeur est truthy ou falsy, tu peux utiliser la fonction intégrée `bool()`. Elle convertit explicitement une valeur en son équivalent booléen et renvoie `True` pour les valeurs truthy et `False` pour les valeurs falsy. Voici quelques exemples :

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

Maintenant que tu comprends les valeurs truthy et falsy, on peut s'intéresser aux opérateurs booléens, aussi appelés opérateurs logiques. Ce sont des opérateurs spéciaux qui te permettent de combiner plusieurs expressions pour créer une logique de décision plus complexe dans ton code.

Il y a trois opérateurs booléens en Python : `and`, `or` et `not`.

Commençons par l'opérateur `and`.

L'opérateur `and` prend deux opérandes et renvoie le premier opérande s'il est falsy, sinon il renvoie le second opérande. Les deux opérandes doivent être truthy pour qu'une expression donne une valeur truthy.

Voici un exemple :

```python
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

Dans l'exemple ci-dessus, le nombre 25 est affiché dans le terminal parce que l'opérateur `and` évaluera le second opérande si le premier opérande est `True`. L'opérateur `and` est connu comme un opérateur à court-circuit. Le court-circuit signifie que Python vérifie les valeurs de gauche à droite et s'arrête dès qu'il détermine le résultat final.

Tu utiliseras souvent `and` dans des instructions `if` pour vérifier si plusieurs conditions sont remplies. Voici comment tu peux réécrire l'exemple précédent pour utiliser l'opérateur `and` au lieu d'instructions `if` imbriquées :

```python
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

Dans l'exemple ci-dessus, `is_citizen` vaut `True`, et `age >= 18` s'évalue à `True`. Comme les deux opérandes de l'opérateur `and` sont truthy, la condition `is_citizen and age >= 18` s'évalue à `True`, et l'appel `print` dans le bloc `if` s'exécute.

Regardons maintenant l'opérateur `or`. Cet opérateur renvoie le premier opérande s'il est truthy, sinon il renvoie le second opérande. Une expression `or` donne une valeur truthy si au moins un opérande est truthy. L'opérateur `or` est aussi connu comme un opérateur à court-circuit. Voici un exemple :

```python
age = 19
is_employed = False

print(age or is_employed) # 19
```

Le code suivant affichera le nombre 19 parce que le premier opérande `age` est `True`.

Si tu as besoin de vérifier si une ou plusieurs expressions valent `True`, tu peux utiliser l'opérateur `or` dans une conditionnelle comme ceci :

```python
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

Dans ce cas, `age < 18` vaut `False`, mais `is_student` vaut `True`. Comme au moins une condition est vraie, toute l'expression `or` s'évalue à `True`, et le message de réduction dans le bloc `if` s'affiche.

Le dernier opérateur que nous allons voir est l'opérateur `not`, qui prend un seul opérande et inverse sa valeur booléenne. Il convertit les valeurs truthy en `False` et les valeurs falsy en `True`. Contrairement aux opérateurs précédents, `not` renvoie toujours `True` ou `False`.

Voici quelques exemples :

```python
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

Il est courant d'utiliser l'opérateur `not` dans les conditionnelles pour vérifier si quelque chose n'est pas `True` ou `False`, comme ceci :

```python
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

Comme `is_admin` vaut `False`, `not is_admin` revient à dire non `False`, ce qui vaut `True`. Donc le message `Access denied for non-administrators.` sera affiché.

Maintenant que tu comprends les valeurs truthy et falsy, les opérateurs `and`, `or` et `not`, et le fonctionnement du court-circuit, tu peux écrire une logique conditionnelle plus souple et plus lisible.
