# --interactive--

Il existe deux méthodes puissantes en JavaScript pour gérer les données JSON : `JSON.parse()` et `JSON.stringify()`. Ces méthodes sont couramment utilisées pour convertir entre des chaînes JSON et des objets JavaScript.

`JSON.stringify()` est utilisée pour convertir un objet JavaScript en une chaîne JSON. C'est utile lorsque tu veux stocker ou transmettre des données dans un format qui peut être facilement partagé ou transféré entre des systèmes.

Voici comment tu peux utiliser la méthode `JSON.stringify()` :

:::interactive_editor

```js
const user = {
  name: "John",
  age: 30,
  isAdmin: true
};

const jsonString = JSON.stringify(user);
console.log(jsonString);
```

:::

La méthode `JSON.stringify()` accepte aussi un paramètre optionnel appelé replacer, qui peut être une fonction ou un tableau. Voici un exemple d'utilisation d'un tableau pour le paramètre optionnel replacer :

:::interactive_editor

```js
const developerObj = {
  firstName: "Jessica",
  isAwesome: true,
  isMusician: true,
  country: "USA",
};

// result: {"firstName":"Jessica","country":"USA"}
console.log(JSON.stringify(developerObj, ["firstName", "country"]));
```

:::

Dans cet exemple, nous avons un `developerObj` avec quatre propriétés. Lorsque nous utilisons la méthode `JSON.stringify()`, nous pouvons passer un tableau comme second paramètre et spécifier quelles propriétés nous voulons convertir en chaîne. Le résultat sera un objet converti en chaîne contenant uniquement les propriétés `firstName` et `country`.

Un autre paramètre optionnel de la méthode `JSON.stringify()` serait le paramètre spacer. Il te permet de contrôler l'espacement du résultat converti en chaîne :

:::interactive_editor

```js
const developerObj = {
  firstName: "Jessica",
  isAwesome: true,
  isMusician: true,
  country: "USA",
};

console.log(JSON.stringify(developerObj, null, 2));

/* result
{
  "firstName": "Jessica",
  "isAwesome": true,
  "isMusician": true,
  "country": "USA"
}
*/
```

:::

La plupart du temps, tu n'utiliseras aucun de ces paramètres optionnels de la méthode `JSON.stringify()`, mais il est tout de même utile d'en être conscient.

Une autre méthode que tu utiliseras beaucoup dans ta programmation est la méthode `JSON.parse()`. `JSON.parse()` reconvertit une chaîne JSON en un objet JavaScript. C'est utile lorsque tu récupères des données JSON depuis un serveur web ou depuis le `localStorage` et que tu as besoin de manipuler les données dans ton application. Tu en apprendras davantage sur le `localStorage` dans une prochaine leçon.

Voici un exemple de comment travailler avec la méthode `JSON.parse()` :

:::interactive_editor

```js
const jsonString = '{"name":"John","age":30,"isAdmin":true}';
const userObject = JSON.parse(jsonString);
console.log(userObject);

// Result:
// { name: 'John', age: 30, isAdmin: true }
```

:::

Cela te permet de travailler avec les données de ton programme comme un objet JavaScript normal, ce qui les rend plus faciles à manipuler et à utiliser.

Dans de futurs modules, nous continuerons d'apprendre comment travailler avec le JSON et les méthodes `JSON.parse()` et `JSON.stringify()`.
