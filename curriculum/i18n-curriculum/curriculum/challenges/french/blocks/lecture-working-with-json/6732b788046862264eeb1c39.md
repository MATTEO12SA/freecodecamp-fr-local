# --description--

Qu'est-ce que le JSON et comment accéder aux valeurs avec la notation par crochets et par point ?

JSON signifie JavaScript Object Notation. C'est un format de données léger, basé sur du texte, couramment utilisé pour échanger des données entre un serveur et une application web.

L'une des raisons pour lesquelles le JSON est si populaire dans le développement web, c'est qu'il est à la fois analysable par une machine et lisible par un humain.

Comme le JSON est indépendant du langage, tu peux facilement envoyer des données JSON d'une application Java vers une application Python, ou d'une application JavaScript vers une application C#.

Le JSON prend en charge de nombreux types de données, y compris les objets, les tableaux, les chaînes, les booléens, null et les nombres.

Voici un exemple d'objet JSON :

```js
{
  "name": "Alice",
  "age": 30,
  "isStudent": false,
  "list of courses": ["Mathematics", "Physics", "Computer Science"]
}
```

Comme tu peux le voir, le JSON utilise des paires clé-valeur pour stocker des informations et chaque paire est séparée par une virgule. Chaque clé doit être entourée de guillemets doubles, sinon tu obtiendras une erreur.

Pour accéder aux données d'un objet JSON, tu peux utiliser soit la notation par point, soit la notation par crochets. Dans cet exemple, nous utilisons la notation par point pour accéder à l'`age` de l'objet JSON :

```js
import data from "./example.json" with { type: "json" };

console.log(data.age);
```

Cet exemple particulier utilise ce qu'on appelle une instruction `import`, qui importe l'objet JSON dans ce fichier afin que nous y ayons accès. Tu en apprendras davantage sur l'instruction `import` dans une prochaine leçon.

Tu peux aussi utiliser la notation par crochets pour accéder aux informations des objets JSON. Voici un exemple d'accès au tableau `list of courses` :

```js
import data from "./example.json" with { type: "json" };

console.log(data["list of courses"]);
```

Utiliser la notation par crochets est particulièrement utile ici parce que la clé contient plusieurs mots séparés par des espaces. Si nous essayions d'utiliser la notation par point, cela provoquerait une erreur.

En résumé, le JSON est un format polyvalent qui peut stocker de nombreux types de données, y compris des tableaux et des objets imbriqués. En utilisant la notation par point ou la notation par crochets, tu peux facilement accéder aux valeurs stockées dans un objet JSON.
