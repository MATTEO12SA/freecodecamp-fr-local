# --description--

- La récursion est un concept de programmation qui te permet d'appeler une fonction de façon répétée jusqu'à atteindre un cas de base.

Voici un exemple de fonction récursive qui calcule la factorielle d'un nombre :

```js
function findFactorial(n) {
  if (n === 0) {
    return 1;
  }
  return n * findFactorial(n - 1);
}
```

Dans l'exemple ci-dessus, la fonction `findFactorial` est appelée de façon récursive jusqu'à ce que `n` atteigne `0`. Quand `n` vaut `0`, le cas de base est atteint et la fonction renvoie `1`. La fonction renvoie ensuite le produit de `n` et du résultat de l'appel récursif à `findFactorial(n - 1)`.

- La récursion te permet de gérer quelque chose dont la profondeur est inconnue, comme des objets/tableaux profondément imbriqués, ou une arborescence de fichiers.
- Une pile d'appels est utilisée pour suivre les appels de fonction dans une fonction récursive. Chaque fois qu'une fonction est appelée, elle est ajoutée à la pile d'appels. Quand le cas de base est atteint, les appels de fonction sont retirés de la pile.
- Tu dois définir soigneusement le cas de base, car l'appeler indéfiniment peut faire planter ton code. C'est parce que la récursion empile de plus en plus d'appels de fonction jusqu'à ce que le système n'ait plus de mémoire.
- Les récursions trouvent leur utilité pour résoudre des problèmes mathématiques comme la factorielle et Fibonacci, parcourir des arbres et des graphes, générer des permutations et des combinaisons, et bien plus encore.
