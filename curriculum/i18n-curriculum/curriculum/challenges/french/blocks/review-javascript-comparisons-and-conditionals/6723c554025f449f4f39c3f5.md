## Les comparaisons et les types de données `null` et `undefined`

- **Les comparaisons et `undefined`** : une variable est `undefined` quand elle a été déclarée mais qu'aucune valeur ne lui a été affectée. C'est la valeur par défaut des variables non initialisées et des paramètres de fonction auxquels aucun argument n'a été fourni. `undefined` se convertit en `NaN` dans les contextes numériques, ce qui fait que toutes les comparaisons numériques avec `undefined` renvoient `false`.

:::interactive_editor

```js
console.log(undefined < 0); // false (NaN < 0 is false)
console.log(undefined >= 0); // false (NaN >= 0 is false)
```

:::

- **Les comparaisons et `null`** : le type `null` représente l'absence intentionnelle de valeur. `null` se convertit en `0` dans les contextes numériques, ce qui peut entraîner un comportement inattendu dans les comparaisons numériques :

:::interactive_editor

```js
console.log(null < 0); // false (0 < 0 is false)
console.log(null >= 0); // true (0 >= 0 is true)
```

:::

- Quand on utilise l'opérateur d'égalité (`==`), `null` et `undefined` ne sont égaux qu'entre eux et à eux-mêmes :

:::interactive_editor

```js
console.log(null == undefined); // true
console.log(null == 0); // false
console.log(undefined == NaN); // false
```

:::

- Cependant, quand on utilise l'opérateur d'égalité stricte (`===`), qui vérifie à la fois la valeur et le type sans effectuer de coercition de type, `null` et `undefined` ne sont pas égaux :

:::interactive_editor

```js
console.log(null === undefined); // false
```

:::

## Les instructions `switch`

- **Définition** : une instruction `switch` évalue une expression et compare sa valeur à une série de clauses `case`. Quand une correspondance est trouvée, le bloc de code associé à ce cas est exécuté. Une instruction `break` devrait être placée à la fin de chaque cas, pour terminer son exécution et continuer avec le suivant. Le cas `default` est un cas facultatif qui ne s'exécute que si aucun des autres cas ne correspond. Le cas `default` est placé à la fin d'une instruction `switch`.

:::interactive_editor

```js
const dayOfWeek = 3;

switch (dayOfWeek) {
  case 1:
    console.log("It's Monday! Time to start the week strong.");
    break;
  case 2:
    console.log("It's Tuesday! Keep the momentum going.");
    break;
  case 3:
    console.log("It's Wednesday! We're halfway there.");
    break;
  case 4:
    console.log("It's Thursday! Almost the weekend.");
    break;
  case 5:
    console.log("It's Friday! The weekend is near.");
    break;
  case 6:
    console.log("It's Saturday! Enjoy your weekend.");
    break;
  case 7:
    console.log("It's Sunday! Rest and recharge.");
    break;
  default:
    console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

:::
