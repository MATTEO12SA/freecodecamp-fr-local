# --interactive--

Tu as déjà appris comment le balisage sémantique et les attributs ARIA rendent le contenu accessible. Dans les applications réelles, le contenu est rarement statique, et les pages se mettent souvent à jour dynamiquement via JavaScript. Quand cela arrive, il est important que ces changements se reflètent aussi dans le HTML. Ainsi, les lecteurs d'écran peuvent transmettre correctement l'état mis à jour aux utilisateurs. Sans cela, les personnes qui s'appuient sur des outils d'assistance pourraient ne jamais savoir que quelque chose a changé, ou recevoir des informations obsolètes ou trompeuses.

Regardons un scénario courant où JavaScript change l'état d'un élément, et comment tu peux garder ton HTML accessible en mettant à jour les attributs ARIA.

Suppose que tu as un bouton qui ouvre et ferme un menu déroulant :

:::interactive_editor

```html
<button id="menuButton" aria-expanded="false" aria-controls="menuList">
  Menu
</button>

<ul id="menuList" hidden>
  <li>List item 1</li>
  <li>List item 2</li>
</ul>
<script src="index.js"></script>
```

```js
const button = document.getElementById("menuButton");
const menu = document.getElementById("menuList");

button.addEventListener("click", () => {
  const expanded = button.getAttribute("aria-expanded") === "true";
  button.setAttribute("aria-expanded", String(!expanded));
  menu.hidden = expanded;
});
```

:::

Le HTML met en place un bouton qui contrôle un menu déroulant. Le bouton utilise `aria-expanded` pour indiquer si le menu est ouvert, et `aria-controls` pour le lier au menu en référençant l'`id` du menu.

Le JavaScript écoute les clics sur le bouton du menu. Au clic, il bascule la valeur de `aria-expanded` et met à jour la propriété `hidden` du menu. Cela garde la visibilité du menu et les informations d'accessibilité synchronisées, pour que les utilisateurs voyants et ceux de lecteurs d'écran sachent si le menu est ouvert ou fermé.

Tu en apprendras plus sur ces attributs ARIA dans les leçons suivantes. Pour l'instant, retiens juste que quand ton JavaScript change l'état d'un élément, tu dois aussi mettre à jour les attributs ARIA concernés pour que les technologies d'assistance reflètent fidèlement ce qui est réellement à l'écran.
