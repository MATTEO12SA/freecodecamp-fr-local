# --interactive--

En JavaScript, une fonction de rappel est une fonction passée comme argument à une autre fonction, afin que la fonction externe puisse l'appeler à un moment précis.

Ce concept est fondamental pour comprendre de nombreux aspects de JavaScript, y compris le fonctionnement de la méthode `forEach`.

Commençons par comprendre ce qu'est une fonction de rappel dans un contexte simple.

Imagine que tu as une fonction, et qu'à l'intérieur de cette fonction tu veux faire quelque chose plusieurs fois. Au lieu d'écrire tout le code dans une seule grosse fonction, tu peux passer une seconde fonction (la fonction de rappel) à exécuter chaque fois que tu as besoin que cette action précise soit faite. Cela permet d'avoir un code plus flexible et plus modulaire.

Introduisons maintenant la méthode `forEach`. `forEach` est une méthode intégrée des tableaux en JavaScript. Elle te permet de parcourir chaque élément d'un tableau et d'effectuer une opération sur chaque élément. L'opération à effectuer est définie dans une fonction de rappel que tu fournis à `forEach`.

Voici un exemple du fonctionnement de `forEach` avec une fonction de rappel :

:::interactive_editor

```js
let numbers = [1, 2, 3, 4, 5];

numbers.forEach(function(number) {
  console.log(number * 2);
});
```

:::

Dans cet exemple, nous avons un tableau de nombres. Nous utilisons la méthode `forEach` sur ce tableau et nous fournissons une fonction de rappel comme argument à `forEach`.

Cette fonction de rappel prend un paramètre, qui représente chaque élément du tableau. La méthode `forEach` appellera cette fonction de rappel une fois pour chaque élément du tableau.

Dans ce cas, la fonction de rappel multiplie chaque nombre par `2` et affiche le résultat dans la console. Donc, quand ce code s'exécute, il affiche :

```md
2
4
6
8
10
```

Il est important de comprendre que la fonction de rappel est appelée une fois pour chaque élément du tableau, dans l'ordre. `forEach` s'occupe de la boucle pour toi, donc tu n'as pas besoin d'écrire toi-même une boucle `for`.

Tu peux aussi utiliser une fonction fléchée comme fonction de rappel, ce qui peut rendre ton code encore plus concis :

:::interactive_editor

```js
let numbers = [1, 2, 3, 4, 5];
numbers.forEach(number => console.log(number * 2));
```

:::

Cela fait exactement la même chose que l'exemple précédent, mais avec moins de code.

La fonction de rappel dans `forEach` peut en réalité prendre jusqu'à trois arguments : l'élément courant, l'indice de l'élément courant et le tableau sur lequel `forEach` a été appelée.

Voici un exemple utilisant les trois :

:::interactive_editor

```js
let numbers = [1, 2, 3, 4, 5];
numbers.forEach((number, index, array) => {
  console.log(`Element ${number} is at index ${index} in array ${array}`);
});
```

:::

Cela afficherait des informations sur chaque élément, son indice et le tableau d'origine.

Comprendre les fonctions de rappel et les méthodes comme `forEach` est important au fil de ta progression en JavaScript. Elles forment la base de nombreux concepts plus avancés du langage, notamment la programmation asynchrone que tu découvriras dans de prochaines leçons.
