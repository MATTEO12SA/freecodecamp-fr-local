# --interactive--

La méthode `reduce` est une fonction en JavaScript qui te permet de traiter un tableau et de le condenser en une seule valeur. Cette valeur unique peut être un nombre, une chaîne, un objet ou même un autre tableau.

Elle s'appelle `reduce` parce qu'elle réduit un tableau à une seule sortie. Même si elle peut sembler compliquée au début, comprendre `reduce` peut grandement simplifier ton code dans de nombreuses situations.

À la base, `reduce` fonctionne en appliquant une fonction à chaque élément du tableau, dans l'ordre, puis en transmettant le résultat de chaque calcul au suivant. Cette fonction est souvent appelée fonction réductrice.

La fonction réductrice prend deux paramètres principaux : un accumulateur et la valeur courante. L'accumulateur est l'endroit où tu stockes le résultat en cours de tes opérations, et la valeur courante est l'élément du tableau en cours de traitement.

Regardons un exemple pour illustrer le fonctionnement de `reduce` :

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce(
  (accumulator, currentValue) => accumulator + currentValue,
  0
);

console.log(sum); // 15
```

:::

Dans cet exemple, nous utilisons `reduce` pour obtenir la somme de tous les nombres du tableau.

La fonction réductrice prend l'accumulateur (qui commence à `0`, comme l'indique le second argument de `reduce`) et y ajoute chaque nombre.

Le résultat de chaque addition devient le nouvel accumulateur pour l'itération suivante.

La méthode `reduce` peut aussi prendre une valeur initiale comme second argument. C'est la valeur avec laquelle l'accumulateur commence. Dans l'exemple ci-dessus, nous l'avons définie à `0`.

Si tu ne fournis pas de valeur initiale, `reduce` utilisera le premier élément du tableau comme accumulateur initial et commencera le processus à partir du deuxième élément.

L'un des grands atouts de `reduce` est sa flexibilité. Comme tu définis la fonction réductrice, tu contrôles entièrement la façon dont le tableau est traité et le type de résultat que tu veux produire. Cela rend `reduce` extrêmement puissante, mais peut aussi la rendre un peu difficile à comprendre au début.

Avec de la pratique, tu prendras le coup de main avec la méthode `reduce`.
