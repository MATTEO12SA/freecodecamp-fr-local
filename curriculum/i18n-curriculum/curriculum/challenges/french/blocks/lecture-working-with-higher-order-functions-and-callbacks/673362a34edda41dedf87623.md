# --interactive--

La méthode `map` est une fonction puissante et très utilisée en JavaScript qui opère sur les tableaux. Elle est conçue pour créer un nouveau tableau en appliquant une fonction donnée à chaque élément du tableau d'origine.

Cette méthode ne modifie pas le tableau d'origine. Elle renvoie plutôt un nouveau tableau contenant les résultats de la fonction appliquée à chaque élément.

Voici un exemple d'utilisation de la méthode `map` sur un tableau de nombres :

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map((num) => num * 2);
console.log(numbers); // [1, 2, 3, 4, 5]
console.log(doubled); // [2, 4, 6, 8, 10]
```

:::

Pour créer un nouveau tableau où chaque nombre est doublé, nous utilisons la méthode `map`. La méthode `map` accepte une fonction de rappel qui est appelée sur chaque élément du tableau.

Dans ce cas, chaque nombre du tableau sera multiplié par `2`. Le résultat sera un nouveau tableau contenant les nombres `2,4,6,8,10`.

La fonction de rappel peut accepter jusqu'à trois arguments.

Le premier argument est l'élément courant en cours de traitement.

:::interactive_editor

```js
const numbers = [3, 4, 5, 6, 7].map((element) => {
  console.log("Element:", element);
  return element * 2;
});
```

:::

Le deuxième argument est l'indice de l'élément courant en cours de traitement.

:::interactive_editor

```js
const numbers = [3, 4, 5, 6, 7].map((element, index) => {
  console.log("Element:", element);
  console.log("Index:", index);
  return element * 2;
});
```

:::

Le troisième argument est le tableau sur lequel `map` est appelée.

:::interactive_editor

```js
const numbers = [3, 4, 5, 6, 7].map((element, index, array) => {
  console.log("Element:", element);
  console.log("Index:", index);
  console.log("Array:", array);
  return element * 2;
});
```

:::

Comprendre et utiliser efficacement la méthode `map` peut améliorer nettement ta capacité à travailler avec des tableaux en JavaScript. Dans de prochaines leçons, nous approfondirons des usages plus avancés de `map` et verrons comment elle peut être un outil puissant pour construire des programmes dynamiques et efficaces.
