# --interactive--

Le chaînage de méthodes est une technique où tu appelles plusieurs méthodes les unes après les autres. Tu peux utiliser le chaînage de méthodes sur de nombreux types de valeurs en JavaScript, y compris les chaînes, les tableaux et les objets. Même si les chaînes sont des valeurs primitives, JavaScript les enveloppe temporairement dans un objet `String` lorsque tu utilises une méthode de chaîne.

Regardons un exemple utilisant différentes méthodes de chaîne :

:::interactive_editor

```js
const result = "  Hello, World!  "
  .trim()
  .toLowerCase()
  .replace("world", "JavaScript");

console.log(result); // "hello, JavaScript!"
```

:::

Dans cet exemple, nous partons d'une chaîne et effectuons trois opérations en séquence : supprimer les espaces, convertir en minuscules et remplacer la chaîne `world` par `JavaScript`. Chaque méthode renvoie une nouvelle chaîne, qui devient la cible de l'appel de méthode suivant.

Le chaînage de méthodes peut améliorer nettement la lisibilité du code lorsque tu travailles avec des opérations complexes.

Par exemple, considère cet exemple utilisant les méthodes `filter`, `map` et `reduce` :

:::interactive_editor

```js
const transactions = [
  { amount: 100, type: "credit" },
  { amount: 20, type: "cash" },
  { amount: 150, type: "credit" },
  { amount: 50, type: "cash" },
  { amount: 75, type: "credit" }
];

const totalCreditWithBonus = transactions
  .filter((transaction) => transaction.type === "credit")
  .map((transaction) => transaction.amount * 1.1)
  .reduce((sum, amount) => sum + amount, 0);

console.log(totalCreditWithBonus); // 357.5
```

:::

Dans cet exemple, nous avons un tableau de transactions où chaque objet possède un montant et un type carte de crédit ou espèces.

Nous filtrons d'abord les transactions pour créer un nouveau tableau contenant uniquement les transactions par carte de crédit. Ensuite, nous chaînons la méthode `map` au résultat filtré et, pour chaque montant de transaction, nous le multiplions par `1.1`, ce qui représente un bonus de `10%`.

Ensuite, nous prenons ce résultat et chaînons la méthode `reduce` pour additionner chacun des montants, ce qui donne `357.5`.

Même si le chaînage de méthodes peut rendre le code plus concis et plus lisible, il est important de l'utiliser avec discernement.

Les très longues chaînes peuvent devenir difficiles à déboguer, car on ne voit pas immédiatement quelle étape de la chaîne peut causer un problème. Une bonne pratique consiste souvent à découper les très longues chaînes en plusieurs étapes pour plus de clarté et un débogage plus simple.

Tu peux aussi chaîner des méthodes sur un objet. Dans ce cas, chaque méthode renvoie `this`, qui fait référence à l'objet courant, ce qui permet à la méthode suivante de la chaîne de s'exécuter sur lui.

:::interactive_editor

```js
const calculator = {
  total: 0,
  add(n) {
    this.total += n;
    return this;
  },
  multiply(n) {
    this.total *= n;
    return this;
  },
  subtract(n) {
    this.total -= n;
    return this;
  },
  getResult() {
    return this.total;
  }
};

const result = calculator.add(5).multiply(2).subtract(3).getResult();
console.log(result); // 7
```

:::

Ainsi, chaque méthode renvoie le même objet, ce qui te permet de continuer à chaîner les appels les uns après les autres.
