# --interactive--

Il existe de nombreuses façons de trier tes données en programmation. Dans cette leçon, nous allons nous concentrer sur la méthode intégrée `sort` en JavaScript.

La méthode `sort` sert à organiser les éléments d'un tableau et renvoie une référence vers le tableau trié. Aucune copie n'est créée, car les éléments sont triés sur place.

Voici la syntaxe de base de la méthode `sort` :

```js
array.sort(compareFunction);
```

Le paramètre `compareFunction` est un paramètre optionnel qui indique une fonction définissant l'ordre de tri. Nous verrons plus tard comment utiliser une fonction de comparaison lors du tri de nombres.

Dans ce premier exemple, nous avons un tableau de chaînes dans un ordre aléatoire.

```js
const fruits = ["Banana", "Orange", "Apple", "Mango"];
```

Notre objectif est de trier le tableau par ordre alphabétique. Nous pouvons le faire en appelant la méthode `sort` sur le tableau `fruits`.

:::interactive_editor

```js
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.sort();

console.log(fruits); // ["Apple", "Banana", "Mango", "Orange"]
```

:::

Le résultat sera un tableau de fruits trié par ordre alphabétique, en commençant par le fruit `Apple`.

Dans l'exemple suivant, nous voulons trier le tableau de nombres suivant :

```js
const numbers = [414, 200, 5, 10, 3];
```

Si nous essayons d'utiliser la méthode `sort` sur ce tableau `numbers`, nous obtiendrons des résultats inattendus.

:::interactive_editor

```js
const numbers = [414, 200, 5, 10, 3];
numbers.sort();

console.log(numbers); // [10, 200, 3, 414, 5]
```

:::

Nous nous attendions à voir le résultat `[3, 5, 10, 200, 414]`, mais nous avons obtenu `[10, 200, 3, 414, 5]` à la place.

C'est parce que la méthode `sort` convertit les éléments en chaînes, puis compare leurs séquences de valeurs d'unités de code UTF-16.

Les unités de code UTF-16 sont les valeurs numériques qui représentent les caractères dans la chaîne. Par exemple, les unités de code UTF-16 `65`, `66` et `67` représentent respectivement les caractères `A`, `B` et `C`.

Le nombre `200` apparaît donc avant le nombre `3` dans le tableau, parce que la chaîne `200` vient avant la chaîne `3` lorsque leurs unités de code UTF-16 sont comparées.

La solution à ce problème consiste à fournir une fonction de comparaison à la méthode `sort`.

Voici un exemple montrant comment trier le tableau `numbers` avec une fonction de comparaison :

:::interactive_editor

```js
const numbers = [414, 200, 5, 10, 3];

numbers.sort((a, b) => a - b);

console.log(numbers); // [3, 5, 10, 200, 414]
```

:::

Les paramètres `a` et `b` sont les deux éléments comparés. La fonction de comparaison doit renvoyer une valeur négative si `a` doit venir avant `b`, une valeur positive si `a` doit venir après `b`, et zéro si `a` et `b` sont égaux.

La première comparaison se fait entre les nombres `414` et `200`. Le résultat de `414 - 200` est `214`, une valeur positive. Cela signifie que `414` doit venir après `200` dans le tableau trié.

La comparaison suivante se fait entre les nombres `200` et `5`. Le résultat de `200 - 5` est `195`, une valeur positive. Cela signifie que `200` doit venir après `5` dans le tableau trié.

Nous répétons ce processus pour tous les éléments du tableau, et le résultat est un tableau de nombres trié.

Même s'il existe beaucoup d'autres façons de trier des données en programmation, la méthode `sort` en JavaScript peut être utile et efficace dans de nombreux cas lorsque tu dois trier un tableau d'éléments.
