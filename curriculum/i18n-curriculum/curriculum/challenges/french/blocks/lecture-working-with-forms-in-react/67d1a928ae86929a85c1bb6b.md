# --description--

Les formulaires sont fondamentaux dans toute application web car ils te permettent de gérer les saisies, collecter des données et déclencher des actions.

En React, les formulaires sont gérés avec le state ou les refs, ce qui te donne un contrôle total sur leur comportement et leur validation. Ces deux façons de gérer les formulaires s'appellent entrées « contrôlées » et « non contrôlées ».

Regardons ce que sont les entrées contrôlées et non contrôlées.

L'entrée contrôlée est la façon la plus « React » de gérer les champs de formulaire. Avec les entrées contrôlées, tu stockes la valeur du champ dans le state et tu la mets à jour via les événements `onChange`. Cela te donne un contrôle total sur les données du formulaire et permet une validation instantanée et un rendu conditionnel.

Le processus fonctionne ainsi : React maintient le state du formulaire avec le hook `useState`, et tu le mets à jour à chaque changement. Quand un utilisateur tape dans un champ, l'événement `onChange` se déclenche, met à jour le state, et React re-rend le composant avec la nouvelle valeur.

```jsx
import { useState } from "react";

function App() {
  const [name, setName] = useState("");

  const handleChange = (e) => {
    setName(e.target.value);
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log(name);
  };

  return (
    <>
      <form onSubmit={handleSubmit}>
        <label htmlFor="name">Your name</label> <br />
        <input value={name} id="name" onChange={handleChange} type="text" />
        <button type="submit">Submit</button>
      </form>
    </>
  );
}

export default App;
```

Les avantages des entrées contrôlées incluent les suivants :

- Accès immédiat aux données du formulaire.

- Tu peux implémenter une validation instantanée.

- Tu peux désactiver conditionnellement le bouton d'envoi.

- Tu peux contrôler la valeur de l'entrée par programme.

Les entrées non contrôlées, elles, se rencontrent davantage dans les formulaires HTML traditionnels. Donc, au lieu de gérer les entrées via le hook `useState`, les entrées non contrôlées en HTML maintiennent leur propre état interne avec l'aide du DOM.

Comme le DOM contrôle les valeurs des entrées, ce dont tu as besoin c'est de récupérer les valeurs des champs avec une ref. Cette approche demande moins de code et est plus performante car les refs ne forcent pas React à re-rendre.

Voici un exemple d'entrées non contrôlées :

```jsx
import { useRef } from "react";

function App() {
  const nameRef = useRef();

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log(nameRef.current.value);
  };

  return (
    <form onSubmit={handleSubmit}>
      <label htmlFor="name">Your</label>{" "}
      <input type="text" ref={nameRef} id="name" />
      <button type="submit">Submit</button>
    </form>
  );
}

export default App;
```

Un avantage très notable des entrées non contrôlées est qu'elles demandent moins de code. Elles sont aussi plus performantes et paraissent plus naturelles aux débutants React familiarisés avec le HTML.

Alors, laquelle utiliser entre les entrées contrôlées et non contrôlées ?

Utilise les entrées contrôlées quand tu as besoin de mises à jour dynamiques, de validation en temps réel, ou quand tu veux synchroniser les valeurs avec le state. Elles offrent un meilleur contrôle mais demandent plus de re-renders.

Utilise les entrées non contrôlées pour des formulaires plus simples, quand tu veux accéder aux valeurs seulement à l'envoi, ou quand tu travailles avec du code non-React.

Quelle que soit celle que tu utilises entre contrôlées et non contrôlées, voici quelques bonnes pratiques à suivre en créant des formulaires en React :

- Empêche toujours la soumission par défaut du formulaire.

- Assure-toi de valider les entrées avant la soumission.

- Fournis toujours un retour clair aux utilisateurs avec chargement, erreurs de validation ou autres états associés.
