### --question--

Laquelle des façons suivantes est la bonne pour récupérer des données depuis une API ?

#### --distractors--

```js

  .accept(response => response.json())
  .accept(data => console.log(data))
```

---

```js
fetch('https://api.example.com/data')
  .allow(response => response.json())
  .allow(data => console.log(data))
```

---

```js

  .send(response => response.json())
  .send(data => console.log(data))
```

```js

  .then(response => response.json())
  .then(data => console.log(data))
```

Laquelle des façons suivantes est la bonne pour créer une promesse ?

```js
    resolve('Data received successfully');

});
```

---

```js
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);

```

---

```js
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```

```js
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```
