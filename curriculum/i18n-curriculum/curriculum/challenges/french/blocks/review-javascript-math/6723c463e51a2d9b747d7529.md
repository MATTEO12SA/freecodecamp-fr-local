## Travailler avec le type de données Number

- **Définition** : le type `Number` de JavaScript inclut les entiers, les nombres à virgule flottante, `Infinity` et `NaN`. Les nombres à virgule flottante sont des nombres avec une virgule décimale. `Infinity` positif est un nombre supérieur à tout autre nombre, tandis que `-Infinity` est un nombre inférieur à tout autre nombre. `NaN` (`Not a Number`) représente une valeur numérique invalide comme la chaîne `"Jessica"`.

## Les opérations arithmétiques courantes

- **Opérateur d'addition** : cet opérateur (`+`) est utilisé pour calculer la somme de deux nombres ou plus.
- **Opérateur de soustraction** : cet opérateur (`-`) est utilisé pour calculer la différence entre deux nombres.
- **Opérateur de multiplication** : cet opérateur (`*`) est utilisé pour calculer le produit de deux nombres ou plus.
- **Opérateur de division** : cet opérateur (`/`) est utilisé pour calculer le quotient entre deux nombres
- **Division par zéro** : si tu essaies de diviser par zéro, JavaScript renverra `Infinity`.
- **Opérateur de reste** : cet opérateur (`%`) renvoie le reste d'une division.
- **Opérateur d'exponentiation** : cet opérateur (`**`) élève un nombre à la puissance d'un autre.

## Les calculs avec des nombres et des chaînes

- **Explication** : quand tu utilises l'opérateur `+` avec un nombre et une chaîne, JavaScript convertit le nombre en chaîne et concatène les deux valeurs. Quand tu utilises les opérateurs `-`, `*` ou `/` avec une chaîne et un nombre, JavaScript convertit la chaîne en nombre et le résultat sera un nombre. Pour `null` et `undefined`, JavaScript traite `null` comme 0 et undefined comme `NaN` dans les opérations mathématiques.

:::interactive_editor

```js
const result = 5 + '10';

console.log(result); // "510"
console.log(typeof result); // string

const subtractionResult = '10' - 5;
console.log(subtractionResult); // 5
console.log(typeof subtractionResult); // number

const multiplicationResult = '10' * 2;
console.log(multiplicationResult); // 20
console.log(typeof multiplicationResult); // number

const divisionResult = '20' / 2;
console.log(divisionResult); // 10
console.log(typeof divisionResult); // number

const result1 = null + 5;
console.log(result1); // 5
console.log(typeof result1); // number

const result2 = undefined + 5;
console.log(result2); // NaN
console.log(typeof result2); // number
```

:::

## La précédence des opérateurs

- **Définition** : la précédence des opérateurs détermine l'ordre dans lequel les opérations sont évaluées dans une expression. Les opérateurs ayant une précédence plus élevée sont évalués avant ceux ayant une précédence plus faible. Les valeurs à l'intérieur des parenthèses seront évaluées en premier et la multiplication/division aura une précédence plus élevée que l'addition/soustraction. Si les opérateurs ont la même précédence, alors JavaScript utilisera l'associativité.

:::interactive_editor

```js
const result = (2 + 3) * 4;

console.log(result); // 20

const result2 = 10 - 2 + 3;

console.log(result2); // 11

const result3 = 2 ** 3 ** 2;

console.log(result3); // 512
```

:::

- **Définition** : l'associativité nous indique la direction dans laquelle une expression est évaluée quand plusieurs opérateurs du même type existent. Elle définit si l'expression doit être évaluée de gauche à droite (`left-associative`) ou de droite à gauche (`right-associative`). Par exemple, l'opérateur d'exposant est lui aussi associatif de droite à gauche :

:::interactive_editor

```js
const result4 = 5 ** 4 ** 1;

console.log(result4); // 625
```

:::

## Les opérateurs d'incrémentation et de décrémentation

- **Opérateur d'incrémentation** : cet opérateur est utilisé pour augmenter la valeur de un. La notation préfixe `++num` augmente d'abord la valeur de la variable, puis renvoie une nouvelle valeur. La notation postfixe `num++` renvoie d'abord la valeur actuelle de la variable, puis l'augmente.

:::interactive_editor

```js
let x = 5;

console.log(++x); // 6
console.log(x); // 6


let y = 5;

console.log(y++); // 5
console.log(y); // 6
```

:::

- **Opérateur de décrémentation** : cet opérateur est utilisé pour diminuer la valeur de un. La notation préfixe et la notation postfixe fonctionnent de la même manière que précédemment avec l'opérateur d'incrémentation.

:::interactive_editor

```js
let num = 5;

console.log(--num); // 4
console.log(num--); // 4
console.log(num); // 3
```

:::

## Les opérateurs d'affectation composée

- **Opérateur d'affectation par addition (`+=`)** : cet opérateur effectue une addition sur les valeurs et affecte le résultat à la variable.
- **Opérateur d'affectation par soustraction (`-=`)** : cet opérateur effectue une soustraction sur les valeurs et affecte le résultat à la variable.
- **Opérateur d'affectation par multiplication (`*=`)** : cet opérateur effectue une multiplication sur les valeurs et affecte le résultat à la variable.
- **Opérateur d'affectation par division (`/=`)** : cet opérateur effectue une division sur les valeurs et affecte le résultat à la variable.
- **Opérateur d'affectation par reste (`%=`)** : cet opérateur divise une variable par le nombre spécifié et affecte le reste à la variable.
- **Opérateur d'affectation par exponentiation (`**=`)** : cet opérateur élève une variable à la puissance du nombre spécifié et réaffecte le résultat à la variable.

## Les booléens et l'égalité

- **Définition d'un booléen** : un booléen est un type de données qui ne peut avoir que deux valeurs : `true` ou `false`.
- **Opérateur d'égalité (`==`)** : cet opérateur utilise la coercition de type avant de vérifier si les valeurs sont égales.

:::interactive_editor

```js
console.log(5 == '5'); // true
```

:::

- **Opérateur d'égalité stricte (`===`)** : cet opérateur n'effectue pas de coercition de type et vérifie si les types et les valeurs sont égaux.

:::interactive_editor

```js
console.log(5 === '5'); // false
```

:::

- **Opérateur d'inégalité (`!=`)** : cet opérateur utilise la coercition de type avant de vérifier si les valeurs ne sont pas égales.
- **Opérateur d'inégalité stricte (`!==`)** : cet opérateur n'effectue pas de coercition de type et vérifie si les types et les valeurs ne sont pas égaux.

## Les opérateurs de comparaison

- **Opérateur supérieur à (`>`)** : cet opérateur vérifie si la valeur de gauche est supérieure à celle de droite.
- **Opérateur supérieur ou égal (`>=`)** : cet opérateur vérifie si la valeur de gauche est supérieure ou égale à celle de droite.
- **Opérateur inférieur à (`<`)** : cet opérateur vérifie si la valeur de gauche est inférieure à celle de droite.
- **Opérateur inférieur ou égal (`<=`)** : cet opérateur vérifie si la valeur de gauche est inférieure ou égale à celle de droite.

## Les opérateurs unaires

- **Opérateur plus unaire** : cet opérateur convertit son opérande en nombre. Si l'opérande est déjà un nombre, il reste inchangé.

:::interactive_editor

```js
const str = '42';
const num = +str;

console.log(num); // 42
console.log(typeof num); // number
```

:::

- **Opérateur de négation unaire (`-`)** : cet opérateur inverse le signe de l'opérande.

:::interactive_editor

```js
const num = 4;
console.log(-num); // -4
```

:::

- **Opérateur NON logique (`!`)** : cet opérateur inverse la valeur booléenne de son opérande. Donc, si l'opérande est `true`, il devient `false`, et s'il est `false`, il devient `true`.

## Les opérateurs bit à bit

- **Opérateur ET bit à bit (`&`)** : cet opérateur renvoie un 1 à chaque position de bit pour laquelle les bits correspondants des deux opérandes sont à 1.
- **Opérateur d'affectation ET bit à bit (`&=`)** : cet opérateur effectue une opération `ET bit à bit` avec le nombre spécifié et réaffecte le résultat à la variable.
- **Opérateur OU bit à bit (`|`)** : cet opérateur renvoie un 1 à chaque position de bit pour laquelle les bits correspondants de l'un ou des deux opérandes sont à 1.
- **Opérateur d'affectation OU bit à bit (`|=`)** : cet opérateur effectue une opération `OU bit à bit` avec le nombre spécifié et réaffecte le résultat à la variable.
- **Opérateur OU exclusif bit à bit (`^`)** : cet opérateur renvoie un 1 à chaque position de bit pour laquelle les bits correspondants de l'un, mais pas des deux, opérandes sont à 1.
- **Opérateur NON bit à bit (`~`)** : cet opérateur inverse la représentation binaire d'un nombre.
- **Opérateur de décalage à gauche (`<<`)** : cet opérateur décale tous les bits vers la gauche d'un nombre de positions spécifié.
- **Opérateur de décalage à droite (`>>`)** : cet opérateur décale tous les bits vers la droite.

## Les instructions conditionnelles, les valeurs truthy, les valeurs falsy et l'opérateur ternaire

- **`if/else if/else`** : une instruction `if` prend une condition et exécute un bloc de code si cette condition est `truthy`. Si la condition est `false`, alors elle passe au bloc `else if`. Si aucune de ces conditions n'est `true`, alors elle exécutera la clause `else`. Les valeurs `truthy` sont toutes les valeurs qui donnent `true` lorsqu'elles sont évaluées dans un contexte booléen comme une instruction `if`. Les valeurs `falsy` sont des valeurs qui s'évaluent à `false` dans un contexte booléen.

:::interactive_editor

```js
const score = 87;

if (score >= 90) {
 console.log('You got an A');
} else if (score >= 80) {
 console.log('You got a B'); // You got a B
} else if (score >= 70) {
 console.log('You got a C');
} else {
 console.log('You failed! You need to study more!');
}
```

:::

- **Opérateur ternaire** : cet opérateur est souvent utilisé comme une façon plus courte d'écrire des instructions `if else`.

:::interactive_editor

```js
const temperature = 30;
const weather = temperature > 25 ? 'sunny' : 'cool';

console.log(`It's a ${weather} day!`); // It's a sunny day!
```

:::

## Les opérateurs logiques binaires

- **Opérateur ET logique (`&&`)** : cet opérateur vérifie si les deux opérandes sont `true`. Si les deux sont `true`, alors il renverra la deuxième valeur. Si l'un des opérandes est `falsy`, alors il renverra la valeur `falsy`. Si les deux opérandes sont `falsy`, il renverra la première valeur `falsy`.

:::interactive_editor

```js
const result = true && 'hello';

console.log(result); // hello
```

:::

- **Opérateur OU logique (`||`)** : cet opérateur vérifie si au moins l'un des opérandes est truthy.
- **Opérateur de coalescence des nuls (`??`)** : cet opérateur ne renverra une valeur que si la première est `null` ou `undefined`.

:::interactive_editor

```js
const userSettings = {
 theme: null,
 volume: 0,
 notifications: false,
};

let theme = userSettings.theme ?? 'light';
console.log(theme); // light
```

:::

## L'objet `Math`

- **La méthode `Math.random()`** : cette méthode génère un nombre à virgule flottante aléatoire entre 0 (inclus) et 1 (exclu). Cela signifie que la sortie possible peut être 0, mais elle n'atteindra jamais réellement 1.
- **La méthode `Math.max()`** : cette méthode prend un ensemble de nombres et renvoie la valeur maximale.
- **La méthode `Math.min()`** : cette méthode prend un ensemble de nombres et renvoie la valeur minimale.
- **La méthode `Math.ceil()`** : cette méthode arrondit une valeur vers le haut à l'entier le plus proche.
- **La méthode `Math.floor()`** : cette méthode arrondit une valeur vers le bas à l'entier le plus proche.
- **La méthode `Math.round()`** : cette méthode arrondit une valeur à l'entier le plus proche.

:::interactive_editor

```js
console.log(Math.round(2.3)); // 2
console.log(Math.round(4.5)); // 5
console.log(Math.round(4.8)); // 5
```

:::

- **La méthode `Math.trunc()`** : cette méthode supprime la partie décimale d'un nombre, ne renvoyant que la partie entière, sans arrondir.
- **La méthode `Math.sqrt()`** : cette méthode renverra la racine carrée d'un nombre.
- **La méthode `Math.cbrt()`** : cette méthode renverra la racine cubique d'un nombre.
- **La méthode `Math.abs()`** : cette méthode renverra la valeur absolue d'un nombre.
- **La méthode `Math.pow()`** : cette méthode prend deux nombres et élève le premier à la puissance du second.

## Les méthodes de nombre courantes

- **`isNaN()`** : `NaN` signifie "Not-a-Number" (pas un nombre). C'est une valeur spéciale qui représente un résultat numérique non représentable ou indéfini. La propriété fonction `isNaN()` est utilisée pour déterminer si une valeur est `NaN` ou non. `Number.isNaN()` offre une façon plus fiable de vérifier les valeurs `NaN`, surtout dans les cas où la coercition de type pourrait conduire à des résultats inattendus avec la fonction globale `isNaN()`.

:::interactive_editor

```js
console.log(isNaN(NaN));       // true
console.log(isNaN(undefined)); // true
console.log(isNaN({}));        // true

console.log(isNaN(true));      // false
console.log(isNaN(null));      // false
console.log(isNaN(37));        // false


console.log(Number.isNaN(NaN));        // true
console.log(Number.isNaN(Number.NaN)); // true
console.log(Number.isNaN(0 / 0));      // true

console.log(Number.isNaN("NaN"));      // false
console.log(Number.isNaN(undefined));  // false
```

:::

- **La méthode `parseFloat()`** : cette méthode analyse un argument de type chaîne et renvoie un nombre à virgule flottante. Elle est conçue pour extraire un nombre depuis le début d'une chaîne, même si la chaîne contient des caractères non numériques par la suite.
- **La méthode `parseInt()`** : cette méthode analyse un argument de type chaîne et renvoie un entier. `parseInt()` arrête l'analyse au premier caractère non numérique qu'elle rencontre. Pour les nombres à virgule flottante, elle ne renvoie que la partie entière. Si elle ne trouve pas d'entier valide au début de la chaîne, elle renvoie `NaN`.
- **La méthode `toFixed()`** : cette méthode est appelée sur un nombre et prend un argument facultatif, qui est le nombre de chiffres à faire apparaître après la virgule décimale. Elle renvoie une représentation sous forme de chaîne du nombre avec le nombre de décimales spécifié.
